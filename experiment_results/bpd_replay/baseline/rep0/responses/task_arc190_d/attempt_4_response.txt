### Step-by-step reasoning
- We model the sum over all B as summing over all fillings of the zero entries of A (let K be the number of zeros). Each filling corresponds to a matrix B with entries in 0..p-1, where nonzero entries from A stay fixed and zeros are filled with values in {1,...,p-1}.
- The quantity we need is S = sum_B B^p (entrywise, modulo p). Each entry (i,j) of B^p is a sum over all length-p walks from i to j, where each step uses an edge (u,v) with weight B[u,v], and the total is the sum of products of p edge-weights along the walk.
- If we sum over all fillings, for a fixed path (i → … → j) of length p, the contribution becomes a product over edges on that path:
  - If an edge (u,v) is fixed (A[u,v] != 0), its contribution is A[u,v].
  - If an edge (u,v) is a zero-edge (A[u,v] == 0), its contribution is a variable x_{u,v} in {1,...,p-1}.
- Summing over all x_{u,v} for each zero-edge gives a factor:
  sum_{x∈F_p*} x^e, where e is the number of times edge (u,v) is used in the path.
  This value is:
  - p-1 if e = 0,
  - p-1 if e = p-1 (since p-1 ≡ -1 modulo p),
  - 0 otherwise.
- Therefore, only those walks for which every zero-edge is used either 0 times or exactly p-1 times contribute nontrivially. For p ≥ 4, a path can have at most p-1 occurrences of a single edge, and to realize p-1 occurrences of a zero-edge while keeping other zero-edges usage to 0 is generally impossible due to path continuity, except in very special low-p cases (p=3). In particular:
  - For p ≥ 4: the only contributing walks are those that use no zero-edges at all. Thus the total sum equals (p-1)^K times the (i,j) entry of A′^p, where A′ is A with zeros kept as 0 (i.e., standard matrix power using the fixed nonzero entries only).
  - For p = 2: every zero-edge contributes a factor of p-1 = 1 regardless of usage, so all walks contribute as if zero-edges had weight 1. The sum reduces to B^2 with B having zeros replaced by 1; i.e., compute (A with zeros replaced by 1)^2 modulo 2.
  - For p = 3: there are additional contributions from walks that use exactly one zero-edge twice (exponent p-1 = 2) and no other zero-edges. Such walks exist only in two patterns:
    - If the zero-edge e = (a,b) with a ≠ b, there is a contributing path i=a, j=b using e at steps 1 and 3 and a single nonzero middle step (b → a). This contributes A[b][a] multiplied by −(p-1)^{K-1} to the (i,j) entry, provided A[b][a] ≠ 0.
    - If e = (a,a) is a loop, there is a contributing path from i=a to any j via e at steps 1 and 2 and a single nonzero final step (a → j). This contributes A[a][j] multiplied by −(p-1)^{K-1} to the (i,j) entries for i=a.
    - In addition, all walks that use no zero-edges contribute (p-1)^K times the (i,j) entry of A^3′, where A′ is A with zeros treated as 0.
- With these observations, we can derive an efficient plan:
  - If p ≥ 4: ans = (p-1)^K mod p times (A with zeros kept 0) raised to the p-th power modulo p.
  - If p = 2: ans = (A with zeros replaced by 1) squared modulo 2.
  - If p = 3:
    - Compute M = p-1 = 2. Let W0 = (A with zeros kept 0)^3 modulo p. Start ans = M^K * W0 (mod p).
    - For each zero-edge e = (a,b):
      - If a == b: for all j, ans[a][j] += − M^{K−1} * A[a][j] (mod p).
      - If a != b: if A[b][a] != 0, ans[a][b] += − M^{K−1} * A[b][a] (mod p).
    - All updates are modulo p, and only edges with the described conditions contribute.
- This approach yields correct results for the provided samples and runs in reasonable time given N ≤ 100.

import sys

def mat_mul(A, B, mod):
    n = len(A)
    m = len(B[0])
    p = len(B)
    res = [[0]*m for _ in range(n)]
    for i in range(n):
        Ai = A[i]
        Ri = res[i]
        for k in range(p):
            aik = Ai[k]
            if aik:
                Bk = B[k]
                for j in range(m):
                    Ri[j] = (Ri[j] + aik * Bk[j]) % mod
    return res

def mat_pow(A, e, mod):
    n = len(A)
    # Identity matrix
    R = [[0]*n for _ in range(n)]
    for i in range(n):
        R[i][i] = 1 % mod
    X = [row[:] for row in A]
    while e > 0:
        if e & 1:
            R = mat_mul(R, X, mod)
        X = mat_mul(X, X, mod)
        e >>= 1
    return R

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    N = int(next(it))
    p = int(next(it))

    A = []
    zeros = []
    for i in range(N):
        row = []
        for j in range(N):
            v = int(next(it))
            row.append(v)
            if v == 0:
                zeros.append((i, j))
        A.append(row)

    K = len(zeros)

    # Special case: p == 2
    if p == 2:
        # Fill zeros with 1 and compute B^2 modulo 2
        B = [[(A[i][j] if A[i][j] != 0 else 1) % 2 for j in range(N)] for i in range(N)]
        # Compute B^2
        C = mat_pow(B, 2, 2)
        for i in range(N):
            print(' '.join(str(C[i][j] % 2) for j in range(N)))
        return

    # Special case: p == 3
    if p == 3:
        M = 2  # p-1
        # W0: (A with zeros treated as 0)^3
        B0 = [[A[i][j] % 3 for j in range(N)] for i in range(N)]
        for i in range(N):
            for j in range(N):
                if B0[i][j] == 0:
                    B0[i][j] = 0
        W0 = mat_pow(B0, 3, 3)
        # ans starts with (p-1)^K * W0
        mul_all = pow(M, K, 3)
        ans = [[(W0[i][j] * mul_all) % 3 for j in range(N)] for i in range(N)]
        if K > 0:
            inv_exp = pow(M, K-1, 3)
            neg = (-inv_exp) % 3
            # For each zero-edge e
            for (a, b) in zeros:
                if a == b:
                    # i = a, last step is nonzero to j
                    for j in range(N):
                        add = (neg * A[a][j]) % 3
                        ans[a][j] = (ans[a][j] + add) % 3
                else:
                    # i = a, j = b, need A[b][a] != 0
                    if A[b][a] % 3 != 0:
                        add = (neg * A[b][a]) % 3
                        ans[a][b] = (ans[a][b] + add) % 3
        for i in range(N):
            print(' '.join(str(ans[i][j] % 3) for j in range(N)))
        return

    # General case: p >= 4
    # Only zero-free walks contribute
    # ans = (p-1)^K * (A with zeros kept 0)^p
    M = p - 1
    mul = pow(M, K, p)
    B = [[A[i][j] % p for j in range(N)] for i in range(N)]
    # Ensure zeros remain zero
    for (i, j) in zeros:
        B[i][j] = 0
    P = mat_pow(B, p, p)
    ans = [[(P[i][j] * mul) % p for j in range(N)] for i in range(N)]
    for i in range(N):
        print(' '.join(str(ans[i][j] % p) for j in range(N)))

if __name__ == "__main__":
    solve()
