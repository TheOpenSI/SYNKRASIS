### Step-by-step reasoning
- We need to compute S = sum over all fillings B (where A's zeros are filled with 1..p-1) of B^p, computed elementwise modulo p.
- For any path P of length p from i to j, the contribution of that path to (B^p)_{i,j} is the product of edge weights along P. If an edge (u,v) is fixed in A (A[u][v] != 0), its weight along P is A[u][v] raised to the number of times that edge is used in P. If (u,v) was a zero in A, in B it becomes x_{u,v} ∈ {1,...,p-1}.
- When summing over all fillings, for a given path P, the contribution factorizes over zero-edges:
  - For each zero-edge e, the exponent n_e is how many times e is used in P.
  - sum_{x ∈ F_p*} x^n_e equals p-1 if n_e ≡ 0 mod (p-1) and 0 otherwise.
  - In a path of length p, at most one zero-edge can be used with n_e = p-1; if a zero-edge is used, all other zero-edges must be used 0 times.
  - Therefore, only two kinds of paths contribute nonzero sums:
    - Type A: paths that use no zero-edges at all. Their total contribution equals (p-1)^K times the (i,j) entry of (A with zeros kept 0)^p.
    - Type B (and similar): paths that use exactly one zero-edge e with n_e = p-1; the rest of the path uses only fixed edges. Depending on whether e is a loop or not, these contribute differently:
      - If e = (a,a) (a loop zero-edge): the path must involve exactly one additional fixed edge adjacent to a (either into a or out of a). The total contribution for all such paths reduces to adding (p-1)^K times the corresponding fixed-edge weights into appropriate positions of the sum.
      - If e = (u,v) with u != v (non-loop zero-edge): for p=3 there is an additional pattern (u → v) with an intermediate fixed edge v → u; for p≥4 such patterns do not exist due to path length constraints (you cannot place the single nonzero fixed edge to satisfy connectivity while using e p-1 times).
- Concretely, we can implement for all p:
  - Base contribution: compute W0 = (A with zeros replaced by 0)^p modulo p, and scale by mul = (p-1)^K modulo p. This covers Type A contributions.
  - Additional Type B contributions for loop-zero-edges (a,a): for every i with A[i][a] != 0 add mul * A[i][a] to S[i][a], and for every j with A[a][j] != 0 add mul * A[a][j] to S[a][j].
  - For p=3 specifically, also include Non-loop-zero-edge contributions: for every zero-edge (u,v) with u != v, if A[v][u] != 0 then add mul * A[v][u] to S[u][v].
- Edge cases:
  - p = 2: fill zeros with 1 and compute B^2 modulo 2 directly.
  - p ≥ 4: follow the base Type A plus Type B (loops) contributions only.
- Complexity: We perform matrix exponentiation with exponent p (log p steps) on N×N matrices (N ≤ 100). Each multiplication is O(N^3), which is acceptable given constraints.

import sys

def mat_mul(A, B, mod):
    n = len(A)
    m = len(B[0])
    p = len(B)
    res = [[0] * m for _ in range(n)]
    for i in range(n):
        Ai = A[i]
        Ri = res[i]
        for k in range(p):
            aik = Ai[k]
            if aik:
                Bk = B[k]
                a = aik
                for j in range(m):
                    Ri[j] = (Ri[j] + a * Bk[j]) % mod
    return res

def mat_pow(A, e, mod):
    n = len(A)
    # Identity
    R = [[0] * n for _ in range(n)]
    for i in range(n):
        R[i][i] = 1 % mod
    X = [row[:] for row in A]
    while e > 0:
        if e & 1:
            R = mat_mul(R, X, mod)
        X = mat_mul(X, X, mod)
        e >>= 1
    return R

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    N = int(next(it))
    p = int(next(it))

    A = []
    zeros = []
    for i in range(N):
        row = []
        for j in range(N):
            v = int(next(it))
            row.append(v)
            if v == 0:
                zeros.append((i, j))
        A.append(row)

    K = len(zeros)

    # Special case p = 2
    if p == 2:
        B = [[(A[i][j] if A[i][j] != 0 else 1) % 2 for j in range(N)] for i in range(N)]
        C = mat_pow(B, 2, 2)
        for i in range(N):
            print(' '.join(str(C[i][j] % 2) for j in range(N)))
        return

    # General cases p >= 3
    # B0: A with zeros treated as 0 (already 0)
    B0 = [[A[i][j] % p for j in range(N)] for i in range(N)]
    W0 = mat_pow(B0, p, p)  # (A with zeros -> 0)^p

    M = p - 1
    mul = pow(M, K, p)  # (p-1)^K mod p

    # Base contribution: Type A
    ans = [[(W0[i][j] * mul) % p for j in range(N)] for i in range(N)]

    # Type B contributions for loop-zero-edges
    for a in range(N):
        # For i such that A[i][a] != 0: add mul * A[i][a] to ans[i][a]
        for i in range(N):
            if A[i][a] != 0:
                ans[i][a] = (ans[i][a] + mul * (A[i][a] % p)) % p
        # For j such that A[a][j] != 0: add mul * A[a][j] to ans[a][j]
        for j in range(N):
            if A[a][j] != 0:
                ans[a][j] = (ans[a][j] + mul * (A[a][j] % p)) % p

    # Additional Type C contributions for p = 3 from non-loop zero-edges
    if p == 3:
        for u in range(N):
            for v in range(N):
                if u != v and A[u][v] == 0:
                    # zero-edge (u,v)
                    if A[v][u] != 0:
                        ans[u][v] = (ans[u][v] + mul * (A[v][u] % p)) % p

    for i in range(N):
        print(' '.join(str(ans[i][j] % p) for j in range(N)))

if __name__ == "__main__":
    solve()
