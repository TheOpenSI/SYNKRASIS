### Step-by-step reasoning
- Each block stays in its own column (x is fixed). Blocks never move between columns.
- A removal happens at the start of a time step t if and only if every column currently has a block at y = 1 (the bottom row is full). In that case, in that step all bottom-row blocks (one per column) are removed simultaneously.
- After the potential removals at the start of a step, all remaining blocks are processed from bottom to top. A block moves down by one cell iff it is not in the bottom row and the cell below it is empty (no block in the cell immediately below). Blocks move at most one cell per step.
- Key observations:
  - If any column is initially empty, the bottom row can never become full in any step, so no removals ever happen.
  - Let for each column x the minimum Y among blocks in that column be minY_x (the bottom-most block in that column initially). At time 0, the bottom row is full only if every column has a block at y = 1; otherwise, after some gravity steps blocks fall and eventually the bottom-most block in each column can reach y = 1.
  - The bottom row first becomes full at time B = max_x(minY_x). Intuition: in the column with the largest initial bottom Y, we need minY_x - 1 gravity steps to bring its bottom-most block to y = 1; all other columns reach y = 1 earlier or at the same time, so at the start of step B the bottom row becomes full and removals begin.
  - Let m be the minimum number of blocks in any column: m = min_x k_x, where k_x is the number of blocks in column x. While the bottom row remains full, for s = 1..m we perform the s-th removal in step t = B + s - 1. In each such removal step, the bottom s blocks in every non-empty column are removed (i.e., blocks with rank r ≤ s within their column are removed). After s = m steps, every column has had its bottom m blocks removed; a column with k_x = m becomes empty, breaking the bottom-row-full condition thereafter.
  - After removals finish, blocks continue to fall due to gravity in subsequent steps, but no more removals occur (because bottom row is no longer full since some column is empty). Existence of a block is determined solely by whether its initial rank within its column was removed (r ≤ m) or not (r > m). If a block is not removed, it persists (possibly after further settling) for all future times.
- Therefore:
  - If any column is empty initially: answer is Yes for all queries.
  - Otherwise:
    - Compute B = max(minY_x) across columns.
    - Compute m = min(k_x) across columns.
    - For each block i, compute its rank within its column x: rank[i] = its 1-based position when blocks in that column are sorted by increasing Y.
    - For a query (T, A):
      - If T < B: no removals have occurred yet; block A exists.
      - If B ≤ T ≤ B + m - 1: s = T - B + 1 removals have occurred; block A exists iff rank[A] > s.
      - If T > B + m - 1: all removals finished; block A exists iff rank[A] > m.
- Complexity: O(N log N) to sort blocks within each column (total blocks N), plus O(Q) to answer queries. Memory is O(N + W).

None

### Code
```
import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)
    N = next(it)
    W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # convert to 0-based block index

    # Build per-column lists of (Y, block_index)
    cols = [[] for _ in range(W + 1)]
    for i in range(N):
        x = X[i]
        y = Y[i]
        cols[x].append((y, i))

    # If any column is empty, bottom row can never be full; no removals occur
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    rank = [0] * N  # rank of each block within its column (1-based)
    B = 0
    m = 0

    if not hasZero:
        # Compute B = max(minY_x) over columns
        minYs = []
        for x in range(1, W + 1):
            col = cols[x]
            minY = min(y for (y, idx) in col)
            minYs.append(minY)
        B = max(minYs)

        # m = min number of blocks in any column
        m = min(len(col) for col in cols[1:])

        # Assign ranks within each column
        for x in range(1, W + 1):
            col = cols[x]
            col.sort(key=lambda t: t[0])  # sort by Y
            for pos, (y, idx) in enumerate(col, start=1):
                rank[idx] = pos

    out_lines = []
    if hasZero:
        out_lines = ["Yes"] * Q
    else:
        for j in range(Q):
            t = T_arr[j]
            a = A_arr[j]
            r = rank[a]
            if t < B:
                out_lines.append("Yes")
            elif t <= B + m - 1:
                s = t - B + 1
                out_lines.append("Yes" if r > s else "No")
            else:
                out_lines.append("Yes" if r > m else "No")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```
