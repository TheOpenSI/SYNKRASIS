### Step-by-step reasoning
- Each block stays in its original column; blocks never move between columns.
- Removals happen only when the bottom row (y = 1) is filled in all W columns at the start of a time step.
- If that happens, every column loses exactly one block from its bottom (the block currently at the bottom in that column), and then the remaining blocks may move down within that same time step according to the rule (but removals only happen at the start of the step).
- After s removal steps have occurred (s = 0, 1, ..., m where m = min number of blocks across all columns), in every column exactly s blocks from the bottom are removed. A block in a column with initial rank r (1 = bottom-most in that column) survives after s removals iff r > s.
- Let:
  - k_x be the number of blocks in column x,
  - minY_x be the smallest Y among blocks in column x (i.e., the bottom-most block’s initial height in that column),
  - B = max_x minY_x (time step at which the bottom row first becomes full across all columns, counting steps from t = 1),
  - m = min_x k_x (total number of removal steps possible before some column becomes empty).
- For a query (T, A) asking whether block A exists at time T + 0.5:
  - If any column is empty initially (k_x = 0 for some x), then bottom row can never be full; there are no removals ever, so every block exists for all times. Answer is Yes for all queries.
  - Otherwise, removals start at time t = B and continue up to t = B + m - 1. After t steps, the number of removals performed is s = t - B + 1 (for B ≤ t ≤ B + m - 1). Blocks with rank r ≤ s are removed; blocks with rank r > s survive.
  - For t ≥ B + m, all removals are finished, and blocks with rank r ≤ m are removed; blocks with rank r > m survive.
- Preprocessing:
  - Build per-column lists of (Y, block_index).
  - If any column is empty, we can skip further processing and answer Yes for all queries.
  - Otherwise, compute B = max(minY_x) over columns, m = min(k_x) over columns.
  - For each column, sort its blocks by Y and assign rank[block_index] = position (1-based within its column).
- Then answer each query in O(1) time using the above rules.

Notes:
- This approach handles all edge cases, including tiny inputs, max constraints, and duplicates or ties (within a column Y-values are distinct due to distinct (X, Y) pairs).
- Time complexity: O(N log N) for sorting blocks within columns; O(Q) for answering queries.
- No external libraries required.

None

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)
    N = next(it)
    W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # convert to 0-based index for blocks

    # Build per-column lists of (Y, block_index)
    cols = [[] for _ in range(W + 1)]
    for i in range(N):
        x = X[i]
        y = Y[i]
        cols[x].append((y, i))

    # If any column is empty, no removal ever occurs; all blocks always exist
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    rank = [0] * N  # rank within its column, 1-based
    B = 0
    m = 0

    if not hasZero:
        # Compute B and m
        minYs = []
        for x in range(1, W + 1):
            col = cols[x]
            minY = min(y for (y, idx) in col)
            minYs.append(minY)
        B = max(minYs)
        m = min(len(col) for col in cols[1:])  # columns are 1..W

        # Assign ranks within each column
        for x in range(1, W + 1):
            col = cols[x]
            col.sort(key=lambda t: t[0])  # sort by Y
            for pos, (y, idx) in enumerate(col, start=1):
                rank[idx] = pos

    out_lines = []
    if hasZero:
        out_lines = ["Yes"] * Q
    else:
        for j in range(Q):
            t = T_arr[j]
            a = A_arr[j]
            r = rank[a]
            if t < B:
                out_lines.append("Yes")
            elif t <= B + m - 1:
                s = t - B + 1
                out_lines.append("Yes" if r > s else "No")
            else:
                out_lines.append("Yes" if r > m else "No")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
