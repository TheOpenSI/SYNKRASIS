### Step-by-step reasoning
- The blocks never move between columns; each block stays in its original X column.
- The only removal happens at the start of a time step, and only if the bottom row (y = 1) is fully occupied across all columns. If any column is empty, the bottom row can never be full again, so no removals will ever happen.
- Within a column, blocks maintain their vertical order (relative ranking from bottom to top does not change through the process). Therefore, in a given column, the blocks get removed in the same order as their initial bottom-to-top ranking.
- Let:
  - k_x be the number of blocks in column x.
  - minY_x be the smallest Y among blocks in column x (the bottom-most block in that column initially).
  - rank_i be the 1-based rank of block i within its column when sorting blocks in that column by increasing Y (bottom-most block has rank 1).
- If any column is empty, no removals ever happen; all blocks exist for all times.
- Otherwise:
  - The bottom row becomes full for the first time at step B = max_x minY_x (the earliest step when every column has a block at y = 1 at the start of that step).
  - The process can perform removals for at most m steps, where m = min_x k_x (the smallest column height). After m removals, at least one column becomes empty and further removals stop.
  - Blocks removed are exactly the blocks with rank r ≤ s after s removals have occurred. If T is the number of completed steps, then the number of removals so far is:
    - s = 0 if T < B
    - s = T - B + 1 if B ≤ T ≤ B + m - 1
    - s = m if T > B + m - 1
  - A block with rank r in its column exists after T steps iff r > s.

- Algorithm:
  1) Build per-column lists of (Y, block_index). If any column is empty, answer is "Yes" for all queries.
  2) Otherwise compute:
     - B = max over columns of the minimum Y in that column.
     - m = min over columns of the count of blocks in that column.
     - rank[block] for every block by sorting that column by Y and assigning ranks 1..k_x.
  3) For each query (T, A):
     - If any column was empty: Yes (covered by step 1).
     - If T < B: Yes.
     - Else if T ≤ B + m - 1: s = T - B + 1; answer Yes if rank[A] > s, else No.
     - Else: answer Yes if rank[A] > m, else No.

- Correctness hinges on the observation that blocks in each column retain their relative order and removals happen in a fixed prefix (the first m blocks in each column), starting at step B.

- Time complexity: Building per-column lists and sorting inside each column takes O(N log N) in total. Answering Q queries is O(Q). Memory is O(N + W).

- Edge cases:
  - Some column empty -> all Yes.
  - All columns non-empty but B and m computed as above handle all removals timeline correctly.
  - Large values of Y and T fit in Python integers.

None

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)
    N = next(it)
    W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # 0-based block index

    # Build per-column lists of (Y, block_index)
    cols = [[] for _ in range(W + 1)]
    for i in range(N):
        x = X[i]
        y = Y[i]
        cols[x].append((y, i))

    # If any column is empty, bottom row can never be full; no removals occur
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    rank = [0] * N  # 1-based rank of each block within its column
    B = 0
    m = 0

    if not hasZero:
        # Compute B = max(minY_x) over columns
        minYs = []
        for x in range(1, W + 1):
            col = cols[x]
            minY = min(y for (y, idx) in col)
            minYs.append(minY)
        B = max(minYs)

        # Compute m = min number of blocks in any column
        m = min(len(cols[x]) for x in range(1, W + 1))

        # Assign ranks within each column (by increasing Y)
        for x in range(1, W + 1):
            col = cols[x]
            col.sort(key=lambda t: t[0])  # sort by Y
            for pos, (_y, idx) in enumerate(col, start=1):
                rank[idx] = pos

    out_lines = []
    if hasZero:
        out_lines = ["Yes"] * Q
    else:
        for j in range(Q):
            t = T_arr[j]
            a = A_arr[j]
            r = rank[a]
            if t < B:
                out_lines.append("Yes")
            elif t <= B + m - 1:
                s = t - B + 1
                out_lines.append("Yes" if r > s else "No")
            else:
                out_lines.append("Yes" if r > m else "No")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
