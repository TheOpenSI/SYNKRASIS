### Step-by-step reasoning
- Blocks do not move between columns. Each block stays in its original X column for all time.
- A removal (at the start of some time step) happens only if the bottom row (y = 1) is full across all columns. If any column is empty at that moment, the bottom row can never become full again, so no removals will ever happen.
- If removals can happen, they happen simultaneously for all columns: at the start of a step, every column that currently has a block at y = 1 loses that bottom block.
- After each removal step, remaining blocks may move down by at most 1 within that same step, but crucially, the blocks removed from a column are the blocks with the smallest initial Y in that column, in order of increasing initial Y. Thus, after s removals, in every column, the s blocks with the smallest initial Y in that column are gone, and blocks with rank > s remain.
- Let:
  - k_x be the number of blocks in column x.
  - minY_x be the smallest initial Y in column x.
  - rank[i] be the 1-based rank of block i within its column when blocks in that column are sorted by increasing initial Y.
- The first removal can occur only after time B = max_x minY_x. After that, removals can continue for at most m = min_x k_x times (one per column per removal) until some column becomes empty.
- For time T (integer), define s:
  - s = 0 if T < B (no removals yet),
  - s = T - B + 1 if B ≤ T ≤ B + m - 1 (we have had s = T - B + 1 removals so far),
  - s = m if T > B + m - 1 (all possible removals done).
- A block exists at time T + 0.5 iff its rank in its column is greater than s (i.e., it has not been removed yet).

Algorithm outline:
1) Build per-column lists of (Y, block_index).
2) If any column is empty, no removals ever occur; answer is "Yes" for all queries.
3) Otherwise:
   - B = max_x minY_x, where minY_x is the smallest Y in column x.
   - m = min_x k_x, where k_x is the number of blocks in column x.
   - For each column, sort its blocks by Y and assign rank[i] = position in that sorted order (1-based).
4) For each query (T, A):
   - If any column was empty: print "Yes".
   - Else compute s as above and print "Yes" if rank[A] > s, else "No".

This approach runs in O(N log N) overall due to the per-column sorting, and O(Q) for answering queries. It handles edge cases such as an empty column, large times, and ties in Y correctly.

None

### Code
```
import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)
    N = next(it)
    W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # convert to 0-based block index

    # Build per-column lists of (Y, block_index)
    cols = [[] for _ in range(W + 1)]  # 1..W used

    for i in range(N):
        x = X[i]
        y = Y[i]
        cols[x].append((y, i))

    # If any column is empty, bottom row can never be full; no removals occur
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    rank = [0] * N  # 1-based rank within its column
    B = 0
    m = 0

    if not hasZero:
        # Compute B = max(minY_x) over columns
        minYs = []
        for x in range(1, W + 1):
            col = cols[x]
            minY = min(y for (y, idx) in col)
            minYs.append(minY)
        B = max(minYs)

        # Compute m = min number of blocks in any column
        m = min(len(cols[x]) for x in range(1, W + 1))

        # Assign ranks within each column (by increasing Y)
        for x in range(1, W + 1):
            col = cols[x]
            col.sort(key=lambda t: t[0])  # sort by Y
            for pos, (_y, idx) in enumerate(col, start=1):
                rank[idx] = pos

    out_lines = []
    if hasZero:
        out_lines = ["Yes"] * Q
    else:
        for j in range(Q):
            t = T_arr[j]
            a = A_arr[j]
            r = rank[a]
            if t < B:
                out_lines.append("Yes")
            elif t <= B + m - 1:
                s = t - B + 1
                out_lines.append("Yes" if r > s else "No")
            else:
                out_lines.append("Yes" if r > m else "No")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```
