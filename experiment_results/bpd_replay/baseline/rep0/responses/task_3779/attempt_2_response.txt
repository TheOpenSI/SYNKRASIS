### Step-by-step reasoning
- Problem restatement: We have n pizzas (n is a multiple of 4). We partition them into D = n/4 groups of 4, one group per day. For each group, sort its four weights W <= X <= Y <= Z. On odd-numbered days, we gain Z (the maximum of that group). On even-numbered days, we gain Y (the second largest of that group). We want to maximize the total gain.

- Why the previous solution failed: It attempted a greedy that counted the second largest (Y) incorrectly on even days by taking the next largest element as Y and then removing other elements in a way that doesn’t reflect the actual group composition. In the simple example [8,7,6,5,4,3,2,1], the previous approach would count 7 for day 2 instead of the correct 6, yielding an overestimate and incorrect results for many inputs.

- Correct approach intuition:
  - On Day 1 (odd), to maximize Z, pair the current largest pizza with three smallest pizzas. This guarantees we get the largest possible Z while not “wasting” large numbers that could serve as Y on later even days.
  - On Day 2 (even), among the remaining pizzas, the best we can do to maximize Y is to form a group from the four largest remaining numbers. In that group, the largest will be Z (not counted on this day), and the second largest will be Y (which we want as large as possible). So we should take the four largest remaining numbers and add their second largest to the answer.
  - Repeat: alternate between those two strategies for subsequent days.

- Implementation plan:
  - Sort the array in ascending order to easily access smallest and largest values.
  - Maintain two pointers: L at the start (smallest), R at the end (largest).
  - For each day i from 0 to D-1:
    - If i is even (Day 1, 3, ...): add a[R] to the answer (Z), then move R one step left (consume Z) and move L three steps right (consume the three smallest: W, X, Y for this day but only Z counts now).
    - If i is odd (Day 2, 4, ...): consider the four largest remaining numbers a[R], a[R-1], a[R-2], a[R-3]. The second largest among these is a[R-1], so add a[R-1] to the answer. Then remove these four numbers by moving R left by 4.
  - Complexity: Sorting O(n log n), the loop is O(n). Overall O(n log n) time, O(1) extra space beyond sorting (besides input).

- Edge cases:
  - n = 4: single day; answer is the maximum value.
  - Duplicates: handled naturally by sorting and index access.
  - Large n (up to 2e5): O(n log n) is fine.

from typing import List

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        D = n // 4  # number of days/groups

        # Work with ascending order to easily access smallest and largest values
        pizzas.sort()
        L = 0           # pointer to the smallest element
        R = n - 1       # pointer to the largest element

        ans = 0
        for i in range(D):
            if i % 2 == 0:
                # Odd day (1-indexed): take the current largest as Z
                ans += pizzas[R]
                R -= 1       # consume Z
                L += 3       # consume the three smallest (W, X, Y) for this day
            else:
                # Even day: form a group from the four largest remaining
                # Among [pizzas[R], pizzas[R-1], pizzas[R-2], pizzas[R-3]],
                # the second largest is pizzas[R-1]
                ans += pizzas[R - 1]
                R -= 4       # remove the four largest for this day

        return ans
