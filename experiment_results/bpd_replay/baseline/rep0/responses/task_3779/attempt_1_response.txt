### Step-by-step reasoning
- Problem recap: We have n pizzas (n is a multiple of 4). Each day we pick exactly 4 pizzas and gain either the maximum (Z) of that group on odd days or the second maximum (Y) on even days, where W <= X <= Y <= Z within the chosen group.
- Observations:
  - The number of odd days is ceil(D/2) where D = n/4 (the number of groups). Those days contribute the group maximum Z.
  - The number of even days is floor(D/2). Those days contribute the second largest Y of their group.
  - To maximize the total, we should avoid wasting very large numbers as potential Y on odd days (since only Zs on odd days are counted). Conversely, we should try to maximize Y on even days by using large numbers as the second largest in those groups.
- Greedy strategy justification:
  - Sort pizzas in descending order and process days left to right.
  - Day 1 (odd): take the current largest as Z and pair it with the three smallest remaining numbers. This maximizes Z for this day while preserving large numbers for future Y values.
  - Day 2 (even): after removing the previous group, take the next largest as the new Z for this day but, since Z is not counted on even days, we consider forming the group with the next three largest remaining numbers. The second largest among these is the largest of the three, which will be the Y gained on this day.
  - Repeating this pattern yields optimal use of the largest numbers: large numbers serve as Z on odd days, and the next largest numbers serve as Y on even days.
- Complexity:
  - Sorting dominates: O(n log n).
  - The per-day operations are O(1) with a deque (constant number of pops).
  - Overall O(n log n) time and O(n) space.

- Edge cases:
  - n = 4: only one day, answer is the maximum of the four values (works with the algorithm).
  - Duplicates: the approach relies on order rather than uniqueness; it handles duplicates correctly.
  - Large n up to 2e5: O(n log n) remains efficient in Python.

### Requirements
None

### Code
```
from typing import List
from collections import deque

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        D = n // 4  # number of days/groups

        # Work with pizzas sorted in descending order
        dq = deque(sorted(pizzas, reverse=True))

        ans = 0
        for i in range(D):
            # Z: the largest remaining value for this group
            max_val = dq.popleft()

            if i % 2 == 0:
                # Odd day: gain the group max
                ans += max_val
                # Fill with three smallest remaining values
                dq.pop()
                dq.pop()
                dq.pop()
            else:
                # Even day: the group's Z is not counted; gain the largest among the other three
                y = dq.popleft()
                ans += y
                # Remove the other two (largest remaining after y)
                dq.popleft()
                dq.popleft()

        return ans
```
