### Step-by-step reasoning
- Only positions where A_i != B_i must be flipped to reach B. Flipping any position with A_i == B_i would create extra flips and additional positive costs, so it is never beneficial.
- Let S0 be the initial sum S0 = sum_i A_i * C_i. When we flip a position i:
  - If A_i = 1 and we flip to 0, the delta in S is -C_i.
  - If A_i = 0 and we flip to 1, the delta in S is +C_i.
  So for each i with A_i != B_i, we have a delta delta_i = +/- C_i as above.
- After applying a sequence of deltas, the total cost is:
  total = sum_{t=1..d} S_t, where S_t is the sum after t-th flip and d is the number of indices with A_i != B_i.
  This equals total = d * S0 + sum_{t=1..d} (d - t + 1) * delta_t if we denote delta_t as the delta of the t-th flip in that order.
- To minimize total, we should pair the most negative deltas with the largest weights, i.e., order deltas in nondecreasing order (ascending). This is a standard rearrangement inequality application.
- Implementation plan:
  1. Compute S0.
  2. Collect deltas for indices where A_i != B_i: delta = -C_i if A_i = 1, else delta = +C_i.
  3. Sort deltas ascending.
  4. Simulate flips: S = S0; total = 0; for delta in deltas: S += delta; total += S.
  5. Output total.

This yields the correct minimum total cost for all test cases, including tricky ones like test case 3.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    try:
        N = int(next(it))
    except StopIteration:
        print(0)
        return

    A = [int(next(it)) for _ in range(N)]
    B = [int(next(it)) for _ in range(N)]
    C = [int(next(it)) for _ in range(N)]

    # Initial sum S0
    S0 = 0
    for i in range(N):
        if A[i] == 1:
            S0 += C[i]

    # Collect deltas for indices where A_i != B_i
    deltas = []
    for i in range(N):
        if A[i] ^ B[i]:
            # If A[i] == 1, flipping to 0 decreases S by C[i] -> delta = -C[i]
            # If A[i] == 0, flipping to 1 increases S by C[i] -> delta = +C[i]
            deltas.append(-C[i] if A[i] == 1 else C[i])

    if not deltas:
        print(0)
        return

    deltas.sort()  # ascending: most negative first

    S = S0
    total = 0
    for dlt in deltas:
        S += dlt
        total += S

    print(total)

if __name__ == "__main__":
    main()
