### Step-by-step reasoning
- We model the process as a sequence of flips. Each flip changes A_i and costs the current weighted sum S = sum A_k * C_k after the flip.
- Let:
  - M1 = indices with A_i = 1 and B_i = 0. These flips must happen exactly once (negative flips, decreasing S by C_i).
  - M2 = indices with A_i = 0 and B_i = 1. These flips must happen exactly once (positive flips, increasing S by C_i).
  - X  = indices with A_i = B_i = 1. If we use an index from X, we flip it twice: first (negative) then later (positive).
- The optimal order to minimize total cost is to perform all negative flips first (in descending order of C_i) and then all positive flips (in ascending order of C_i). This minimizes the sum of the intermediate S values.
- For a fixed subset X' ⊆ X, define:
  - NegC = M1 ∪ X' (sorted descending)
  - PosC = M2 ∪ X' (sorted ascending)
  - Let S0 = sum_i A_i * C_i (initial weighted sum)
  - sumNegTerm = sum_{i=1..K} n_i * (K - i + 1) where n_i are NegC sorted descending and K = |NegC|
  - sumNeg = sum(NegC)
  - sumNegCost = K * S0 - sumNegTerm
  - startS = S0 - sumNeg
  - sumPosTerm = sum_{i=1..L} p_i * (L - i + 1) where p_i are PosC sorted ascending and L = |PosC|
  - sumPosCost = L * startS + sumPosTerm
  - TotalCost(X') = sumNegCost + sumPosCost
- We need to choose X' to minimize TotalCost. A direct 2^|X| search is impossible. We can try a greedy incremental approach:
  - Process C-values of X in some order (two passes: ascending and descending) and decide to include a value c if including it reduces the total cost (delta < 0). When we add c to both NegC and PosC, the neg and pos cost components change in a way that can be computed incrementally.
  - If we process values in a fixed order, the incremental delta for inserting c into both lists can be expressed using counts and sums:
    - For NegC (inserting into a descending list):
      deltaNeg = sum of all elements currently greater than c + c * (number of elements ≤ c in NegC + 1)
      Specifically: deltaNeg = sumGT + c * (countLE + 1), where:
        - countLE = number of elements in NegC ≤ c
        - sumGT = sum of elements in NegC that are > c
    - For PosC (inserting into an ascending list):
      deltaPos = sum of all elements currently less than c + c * (number of elements ≥ c in PosC + 1)
      Specifically: deltaPos = sumLT + c * ((L - countLT) + 1), where:
        - countLT = number of elements in PosC < c
        - sumLT = sum of elements in PosC that are < c
    - DeltaTotal = deltaNeg + deltaPos
  - We can maintain two Fenwick trees (one for NegC, one for PosC) to support:
    - For NegC: query sum and count of elements ≤ c, and total sum; update by inserting c.
    - For PosC: query sum and count of elements < c, and total count; update by inserting c.
- A two-pass strategy (ascending order and descending order of X values) increases robustness: it’s not guaranteed that a single order gives the global optimum. We take the minimum total cost obtained from both passes.

The approach runs in O(N log N) time for each pass, which is suitable for N up to 2e5.

import sys

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, i, delta):
        while i <= self.n:
            self.bit[i] += delta
            i += i & -i

    def sum(self, i):
        res = 0
        while i > 0:
            res += self.bit[i]
            i -= i & -i
        return res

def read_input():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    try:
        N = int(next(it))
    except StopIteration:
        return None
    A = [int(next(it)) for _ in range(N)]
    B = [int(next(it)) for _ in range(N)]
    C = [int(next(it)) for _ in range(N)]
    return N, A, B, C

def solve():
    res = read_input()
    if res is None:
        print(0)
        return
    N, A, B, C = res

    # Precompute S0 and partition indices
    S0 = 0
    M1 = []  # A=1, B=0
    M2 = []  # A=0, B=1
    Xvals = []  # A=B=1
    for i in range(N):
        if A[i] == 1:
            S0 += C[i]
        if A[i] == 1 and B[i] == 0:
            M1.append(C[i])
        elif A[i] == 0 and B[i] == 1:
            M2.append(C[i])
        elif A[i] == 1 and B[i] == 1:
            Xvals.append(C[i])

    # Initial NegC and PosC from M1 and M2
    # initial K, L, sumNeg
    M1_sorted_desc = sorted(M1, reverse=True)
    K0 = len(M1_sorted_desc)
    sumNegTerm0 = 0
    for idx, v in enumerate(M1_sorted_desc):
        # weight = K0 - idx
        sumNegTerm0 += v * (K0 - idx)

    sumNeg0 = sum(M1)

    totalNegCost0 = K0 * S0 - sumNegTerm0
    M2_sorted_asc = sorted(M2)
    L0 = len(M2_sorted_asc)
    sumPosTerm0 = 0
    for idx, v in enumerate(M2_sorted_asc):
        sumPosTerm0 += v * (L0 - idx)

    startS0 = S0 - sumNeg0
    totalPosCost0 = L0 * startS0 + sumPosTerm0

    initialTotal = totalNegCost0 + totalPosCost0

    # Coordinate compression for all possible C values
    coords = set(M1)
    coords.update(M2)
    coords.update(Xvals)
    if coords:
        sorted_vals = sorted(coords)
        comp = {v: i+1 for i, v in enumerate(sorted_vals)}
        m = len(sorted_vals)
    else:
        comp = {}
        m = 0

    def compute_min_cost(order):
        # Rebuild Fenwicks from scratch for this pass
        negCount = Fenwick(m)
        negSum = Fenwick(m)
        posCount = Fenwick(m)
        posSum = Fenwick(m)

        sumNeg = 0
        K = 0
        for v in M1:
            idx = comp[v]
            negCount.add(idx, 1)
            negSum.add(idx, v)
            sumNeg += v
            K += 1

        sumPos = 0
        L = 0
        for v in M2:
            idx = comp[v]
            posCount.add(idx, 1)
            posSum.add(idx, v)
            sumPos += v
            L += 1

        # Compute initial total from formula
        sortM1_desc = sorted(M1, reverse=True)
        K0_local = len(sortM1_desc)
        sumNegTerm = 0
        for j, val in enumerate(sortM1_desc):
            sumNegTerm += val * (K0_local - j)
        totalNegCost = K0_local * S0 - sumNegTerm

        sortM2_asc = sorted(M2)
        L0_local = len(sortM2_asc)
        sumPosTerm = 0
        for j, val in enumerate(sortM2_asc):
            sumPosTerm += val * (L0_local - j)
        sumNeg_local = sum(M1)
        startS = S0 - sumNeg_local
        totalPosCost = L0_local * startS + sumPosTerm

        total = totalNegCost + totalPosCost

        # Process X values in the given order
        for c in order:
            idx = comp[c]
            # Neg delta
            countLE = negCount.sum(idx)       # number of elements <= c in NegC
            sumLE = negSum.sum(idx)           # sum of elements <= c in NegC
            sumGT = sumNeg - sumLE             # elements > c
            deltaNeg = sumGT + c * (countLE + 1)

            # Pos delta
            # count of elements < c in PosC
            if idx - 1 > 0:
                countLT = posCount.sum(idx - 1)
                sumLT = posSum.sum(idx - 1)
            else:
                countLT = 0
                sumLT = 0
            deltaPos = sumLT + c * ((L - countLT) + 1)

            delta = deltaNeg + deltaPos
            if delta < 0:
                # insert into Neg
                negCount.add(idx, 1)
                negSum.add(idx, c)
                sumNeg += c
                K += 1

                # insert into Pos
                posCount.add(idx, 1)
                posSum.add(idx, c)
                L += 1

                total += delta
        return total

    # Two passes: ascending and descending
    X_sorted_asc = sorted(Xvals)
    X_sorted_desc = sorted(Xvals, reverse=True)

    ans = initialTotal
    if X_sorted_asc:
        ans = min(ans, compute_min_cost(X_sorted_asc))
    else:
        ans = initialTotal

    if X_sorted_desc:
        ans = min(ans, compute_min_cost(X_sorted_desc))

    print(ans)

if __name__ == "__main__":
    solve()
