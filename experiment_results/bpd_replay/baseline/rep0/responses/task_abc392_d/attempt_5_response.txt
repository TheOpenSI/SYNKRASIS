### Step-by-step reasoning
- For two fixed dice i and j, let fi[v] be the count of value v on die i ( Fi has Ki faces ), and similarly fj[v] for die j with Kj faces.
- The probability that both dice show the same value v is (fi[v]/Ki) * (fj[v]/Kj). Summing over all possible values v yields:
  P(i, j) = sum_v (fi[v]/Ki) * (fj[v]/Kj) = (1 / (Ki * Kj)) * sum_v fi[v] * fj[v].
- If we store fi as a frequency map (value -> count) for each die, then sum_v fi[v] * fj[v] is the dot product of the two frequency vectors over the values they share.
- To compute this efficiently, for each pair (i, j) we iterate over the smaller frequency map and look up matching counts in the other map, accumulating dot = sum fi[v] * fj[v] for shared v. Then P(i, j) = dot / (Ki * Kj).
- We compute P(i, j) for all pairs i < j and take the maximum.
- Complexity: Building frequency maps is O(sum Ki). For each pair, we perform O(min(len(fi), len(fj))) lookups. This is efficient given sum Ki ≤ 1e5 and N ≤ 100.
- Edge cases: If there is no common value between two dice, the dot product is 0 and the probability is 0.
- Output: print the maximum probability with high precision (15 decimal places) to meet the required error tolerance.

None

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    it = iter(data)
    N = next(it)

    freq_maps = []
    Ks = []

    for _ in range(N):
        Ki = next(it)
        Ks.append(Ki)
        freq = {}
        for _ in range(Ki):
            v = next(it)
            freq[v] = freq.get(v, 0) + 1
        freq_maps.append(freq)

    max_prob = 0.0

    for i in range(N):
        fi = freq_maps[i]
        Ki = Ks[i]
        for j in range(i + 1, N):
            fj = freq_maps[j]
            Kj = Ks[j]

            # Compute dot product efficiently by iterating over the smaller map
            if len(fi) <= len(fj):
                dot = 0
                for val, cnt_i in fi.items():
                    cnt_j = fj.get(val, 0)
                    if cnt_j:
                        dot += cnt_i * cnt_j
            else:
                dot = 0
                for val, cnt_j in fj.items():
                    cnt_i = fi.get(val, 0)
                    if cnt_i:
                        dot += cnt_i * cnt_j

            prob = dot / (Ki * Kj)
            if prob > max_prob:
                max_prob = prob

    print("{:.15f}".format(max_prob))

if __name__ == "__main__":
    main()
```
