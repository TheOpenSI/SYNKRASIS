### Step-by-step reasoning
- For two dice i and j, let freq_i[v] be how many times value v appears on die i, and Ki be the number of faces on die i. The probability that both dice show the same value v is (freq_i[v]/Ki) * (freq_j[v]/Kj). Summing over all possible values v gives the probability that the two dice show the same number:
  P(i, j) = sum_v (freq_i[v] / Ki) * (freq_j[v] / Kj) = (1 / (Ki * Kj)) * sum_v freq_i[v] * freq_j[v].
- So, for each pair of dice, we need the dot product of their value-count vectors, divided by Ki * Kj. We should compute this efficiently by iterating over the smaller set of values between the two dice and looking up the counts in the other die.
- The answer is the maximum P(i, j) over all pairs i < j.
- Implementation notes:
  - Build, for each die, a dictionary mapping value -> frequency on that die.
  - Iterate all pairs; for each pair, compute the dot product by iterating over the smaller dictionary.
  - Complexity: sum of Ki across all dice is at most 1e5, and the number of pairs is ≤ 4950 for N ≤ 100. This approach is efficient enough.
  - Print the result with high precision (15 decimals) to satisfy the required accuracy.

None

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        print("0.0")
        return

    it = iter(data)
    N = next(it)

    dicts = []
    Ks = []

    for _ in range(N):
        Ki = next(it)
        Ks.append(Ki)
        counts = {}
        for _ in range(Ki):
            v = next(it)
            counts[v] = counts.get(v, 0) + 1
        dicts.append(counts)

    max_prob = 0.0

    for i in range(N):
        di = dicts[i]
        Ki = Ks[i]
        for j in range(i + 1, N):
            dj = dicts[j]
            Kj = Ks[j]

            # Compute dot product efficiently by iterating over the smaller dictionary
            if len(di) < len(dj):
                dot = 0
                for v, c in di.items():
                    dot += c * dj.get(v, 0)
            else:
                dot = 0
                for v, c in dj.items():
                    dot += c * di.get(v, 0)

            prob = dot / (Ki * Kj)
            if prob > max_prob:
                max_prob = prob

    print("{:.15f}".format(max_prob))

if __name__ == "__main__":
    main()
```
