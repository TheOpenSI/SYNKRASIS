### Step-by-step reasoning
- Let the graph consist of the fixed forward chain 1 -> 2 -> ... -> 2N and N extra edges from white vertices to black vertices, determined by a pairing between white and black vertices.
- The graph is strongly connected iff for every cut between k and k+1 (1 <= k <= 2N-1) there exists at least one backward edge (w -> b) with w > k >= b. Equivalently, the set of backward edges must cover all cuts.
- Use inclusion-exclusion (IE) over the possible cuts T to enforce that every cut is crossed by at least one backward edge. For a subset T of cuts, let M(T) be the number of pairings in which no backward edge crosses any cut in T.
- A backward edge (w, b) crosses a cut k iff b <= k < w. If you partition the line into the gaps induced by T, a backward edge can cross a gap only if w and b lie in different gaps. Therefore, to avoid crossing any cut in T, every backward edge must lie inside the same gap, i.e., w and b must be in the same gap.
- If a gap contains a whites and b blacks, to have a perfect pairing across the whole graph without crossing cuts in T, whites in a gap may only be paired with blacks in the same gap. Thus a valid T contributes M(T) = product over gaps of (count_white_in_gap)! if in every gap the number of whites equals the number of blacks; otherwise M(T) = 0.
- A key simplification: a partition of the line into gaps such that every gap has equal numbers of Whites and Blacks is exactly a partition of the string into balanced segments, i.e., each segment has the same number of Ws and Bs.
- Let S be the given color string of length 2N with N Ws and N Bs. Define D[i] as the difference (#W - #B) in the prefix S[1..i]. Then a segment [l+1..r] is balanced iff D[r] = D[l].
- In IE, cuts are chosen only at positions where D[i] = 0 (since D[0] = D[2N] = 0). Let the zero-positions in (0, 2N) be z1 < z2 < ... < zK. Any valid partition into balanced segments is obtained by choosing a subsequence of these zero-positions as cut boundaries, together with the endpoints 0 and 2N.
- If we denote the extended zero positions as Zext = [0, z1, z2, ..., zK, 2N], and let length L = K+2, then every segment in a partition corresponds to a pair of consecutive chosen endpoints (Zext[i], Zext[j]) with i < j, and its number of Ws is a = (Zext[j] - Zext[i]) / 2, so its internal pairings count is a!.
- The IE yields:
  Answer = sum over all partitions of [0 = i0 < i1 < ... < im = L-1] of (-1)^(m-1) * product over t=1..m of ((Zext[i_t] - Zext[i_{t-1}])/2)!
- This can be computed with a dynamic programming over the zero endpoints:
  Let y_i = Zext[i] / 2 (since Zext[i] are even, y_i is an integer). Then
  DP[0] = 1, and for k from 1 to L-1:
    DP[k] = - sum_{0 <= j < k} DP[j] * fact[ y_k - y_j ]
  where fact[x] = x! (mod 998244353) and we take modulo arithmetic.
  Finally, the answer is -DP[L-1] (mod 998244353) because the IE sign is (-1)^(m-1) and DP accumulates (-1)^m contributions.
- Complexity: The straightforward DP is O(L^2), where L <= N+2 in typical worst-case. The number L can be as large as N+2 (when the string alternates B/W, giving a zero prefix at every even position). This approach is correct but may be borderline for N = 2·10^5 in Python.

- Implementation details:
  - The necessary condition for a nonzero answer is S[0] = 'B' (black at position 1) and S[-1] = 'W' (white at position 2N). If not satisfied, answer is 0.
  - Compute D[i] efficiently by a simple pass.
  - Build Zext as [0] + all i in (1..2N-1) with D[i] == 0 in increasing order + [2N].
  - Compute y_i = Zext[i] // 2 for all i.
  - Precompute factorials fact[0..N].
  - Do the O(L^2) DP to obtain DP[L-1], then output (-DP[L-1]) mod MOD.

```
import sys

MOD = 998244353

def solve():
    input = sys.stdin.readline
    N_line = input().strip()
    while N_line == "":
        N_line = input().strip()
    N = int(N_line)
    S = input().strip()
    # Quick necessary condition: first vertex must be black, last white
    if not S or S[0] != 'B' or S[-1] != 'W':
        print(0)
        return
    M = 2 * N

    # Compute D[i] = (#W - #B) in prefix S[1..i], with D[0] = 0
    D = [0] * (M + 1)
    w = 0
    for i in range(1, M + 1):
        if S[i - 1] == 'W':
            w += 1
        else:
            w -= 1
        D[i] = w

    # Collect zero positions i in (0, 2N); also include endpoints 0 and 2N
    zeros = [0]
    for i in range(1, M):
        if D[i] == 0:
            zeros.append(i)
    zeros.append(M)  # include 2N

    # Extended zero positions Zext
    Zext = zeros  # already [0, ..., 2N]
    L = len(Zext)

    # y_i = Zext[i] / 2 (integers)
    y = [z // 2 for z in Zext]

    # Precompute factorials up to N
    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = (fact[i - 1] * i) % MOD

    # DP over zero-endpoints
    DP = [0] * L
    DP[0] = 1

    for k in range(1, L):
        total = 0
        yk = y[k]
        for j in range(0, k):
            dy = yk - y[j]
            if dy < 0:
                continue
            total = (total + DP[j] * fact[dy]) % MOD
        DP[k] = (-total) % MOD

    # Final answer is -DP[last] mod MOD
    ans = (-DP[L - 1]) % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```
