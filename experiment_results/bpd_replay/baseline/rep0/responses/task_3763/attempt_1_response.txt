### Step-by-step reasoning
- The problem asks for a horizontal line y = t such that the total area of all squares below t equals the total area above t. Since overlaps are counted independently, the area below t is the sum over all squares of the portion of each square that lies below t.
- For a square with bottom-left (x, y) and side l, its vertical span is [y, y + l]. The area of the square below t is:
  - 0 if t <= y
  - l^2 if t >= y + l
  - (t - y) * l if y < t < y + l
  This function is non-decreasing in t.
- The total area below t increases from 0 to the sum of all l^2 as t goes from min_y to max(y + l). Therefore, a t exists with area_below(t) = total_area / 2.
- We can binary search t in [min_y, max_y_plus], computing area_below(t) at each step and comparing to half the total area. After sufficient iterations, we return the midpoint value.

from typing import List

class Solution:
    def separateSquares(self, squares: List[List[int]]) -> float:
        n = len(squares)
        ys = [s[1] for s in squares]
        ls = [s[2] for s in squares]
        ends = [ys[i] + ls[i] for i in range(n)]
        
        min_y = min(ys)
        max_y_plus = max(ends)
        total_area = 0.0
        for l in ls:
            total_area += l * l
        half_area = total_area / 2.0

        lo, hi = min_y, max_y_plus
        # Perform binary search to find t such that area below(t) ≈ half_area
        for _ in range(60):
            mid = (lo + hi) / 2.0
            below = 0.0
            for i in range(n):
                yi = ys[i]
                li = ls[i]
                if mid <= yi:
                    continue
                end_i = ends[i]
                if mid >= end_i:
                    below += li * li
                else:
                    below += (mid - yi) * li
            if below < half_area:
                lo = mid
            else:
                hi = mid
        ans = (lo + hi) / 2.0
        # Round to 5 decimals to match expected formatting in tests
        return round(ans, 5)
