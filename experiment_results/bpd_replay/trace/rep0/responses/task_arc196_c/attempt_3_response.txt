### Step-by-step reasoning
- Let the 2N vertices be partitioned into m base blocks by the zeros of the prefix difference diff = (#W - #B) in the prefix. In block t, there are a_t white vertices, and sum a_t = N.
- If we require that for every cut between blocks there exists a cross-edge (white -> black) crossing the cut, inclusion-exclusion over cuts yields:
  - For any partition of the blocks into consecutive segments, the number of pairings that do not cross any of the chosen cuts equals the product of factorials of the whites count in each segment.
  - By inclusion-exclusion, the answer is the sum over all partitions of the blocks into consecutive segments of
    (-1)^(number_of_segments - 1) * product over segments (whites_in_segment)!
- Let pref[i] be the prefix sum of a_t up to block i, with pref[0] = 0.
- For a partition of the first i blocks into k segments, the whites in the last segment (j+1 .. i) is pref[i] - pref[j]. The total contribution for all partitions of 1..i can be computed via:
  dp[i] = fact[pref[i]] - sum_{j=1}^{i-1} dp[j] * fact[pref[i] - pref[j]]
  where:
  - dp[i] is the total contribution (with the correct sign) for partitions of blocks 1..i,
  - fact[x] = x! modulo MOD,
  - The base term fact[pref[i]] corresponds to the partition consisting of a single segment [1..i].
- The final answer is dp[m].
- A naive O(m^2) DP works for small m, but not for m up to O(N). We implement a CDQ divide-and-conquer approach with convolution (NTT) to achieve fast computation:
  - Initialize dp[i] = fact[pref[i]] for i = 1..m.
  - In CDQ(l, r), after solving the left half, accumulate contributions from dp[j] (j in [l, mid]) to dp[i] (i in [mid+1, r]) using a convolution:
    - Build G where G[pref[j]] += dp[j] for j in [l, mid].
    - conv = convolution(G, fact).
    - For each i in [mid+1, r], subtract conv[pref[i]] from dp[i].
  - Recurse on the right half.
- We also include a quick necessary condition: if the first character is not 'B' or the last is not 'W', the answer is 0.

Notes:
- We use a standard iterative NTT implementation for modular convolution under 998244353.
- For small N (or small m), we use the straightforward O(m^2) DP to ensure correctness and reduce overhead.
- No external libraries are required.

None

```
import sys
MOD = 998244353
ROOT = 3  # primitive root for MOD

def addmod(a, b):
    a += b
    if a >= MOD:
        a -= MOD
    return a

def submod(a, b):
    a -= b
    if a < 0:
        a += MOD
    return a

def mulmod(a, b):
    return (a * b) % MOD

def modinv(a):
    return pow(a, MOD - 2, MOD)

# Iterative in-place NTT
def ntt(a, invert):
    n = len(a)
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]
    len_ = 2
    while len_ <= n:
        wlen = pow(ROOT, (MOD - 1) // len_, MOD)
        if invert:
            wlen = modinv(wlen)
        for i in range(0, n, len_):
            w = 1
            half = len_ // 2
            for j in range(half):
                u = a[i + j]
                v = a[i + j + half] * w % MOD
                a[i + j] = (u + v) % MOD
                a[i + j + half] = (u - v) % MOD
                w = w * wlen % MOD
        len_ <<= 1
    if invert:
        inv_n = modinv(n)
        for i in range(n):
            a[i] = a[i] * inv_n % MOD

def convolution_ntt(a, b):
    if not a or not b:
        return []
    need = len(a) + len(b) - 1
    n = 1
    while n < need:
        n <<= 1
    fa = a + [0] * (n - len(a))
    fb = b + [0] * (n - len(b))
    ntt(fa, False)
    ntt(fb, False)
    for i in range(n):
        fa[i] = fa[i] * fb[i] % MOD
    ntt(fa, True)
    return fa[:need]

def convolution_naive(a, b):
    if not a or not b:
        return []
    res = [0] * (len(a) + len(b) - 1)
    for i in range(len(a)):
        ai = a[i]
        if ai == 0:
            continue
        for j in range(len(b)):
            bj = b[j]
            if bj:
                res[i + j] = (res[i + j] + ai * bj) % MOD
    return res

def convolution(a, b):
    # heuristic: small sizes -> naive, large sizes -> NTT
    TH = 2000  # tune threshold
    if len(a) * len(b) <= TH:
        return convolution_naive(a, b)
    return convolution_ntt(a, b)

def solve():
    input = sys.stdin.readline
    line = input().strip()
    while line == "":
        line = input().strip()
    N = int(line)
    S = input().strip()

    total_len = 2 * N
    if len(S) != total_len:
        print(0)
        return

    # Endpoint condition
    if S[0] != 'B' or S[-1] != 'W':
        print(0)
        return

    # Build base blocks: a_t = number of Ws in each block
    diff = 0
    curr_w = 0
    a = []
    for i in range(1, total_len + 1):
        ch = S[i - 1]
        if ch == 'W':
            diff += 1
            curr_w += 1
        else:
            diff -= 1
        if i != total_len and diff == 0:
            a.append(curr_w)
            curr_w = 0
    a.append(curr_w)  # final block up to 2N

    L = len(a)  # number of base blocks
    # pref[0] = 0, pref[i] = sum_{t=1..i} a_t
    pref = [0] * (L + 1)
    for i in range(1, L + 1):
        pref[i] = pref[i - 1] + a[i - 1]
    # pref values lie in [0, N]

    # Precompute factorials up to N
    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD

    NAIVE_LIMIT = 1000  # safe threshold for naive DP

    if L <= NAIVE_LIMIT:
        # Simple O(L^2) DP using the derived recurrence:
        # dp[i] = fact[pref[i]] - sum_{j=1}^{i-1} dp[j] * fact[pref[i]-pref[j]]
        dp = [0] * (L + 1)
        for i in range(1, L + 1):
            val = fact[pref[i]]
            for j in range(1, i):
                diff = pref[i] - pref[j]
                val = (val - dp[j] * fact[diff]) % MOD
            dp[i] = val
        print(dp[L] % MOD)
        return

    # Large case: CDQ divide-and-conquer with convolution
    # dp[i] = fact[pref[i]] - sum_{j=1}^{i-1} dp[j] * fact[pref[i]-pref[j]]
    dp = [0] * (L + 1)
    for i in range(1, L + 1):
        dp[i] = fact[pref[i]]

    def cdq(l, r):
        if l >= r:
            return
        mid = (l + r) >> 1
        cdq(l, mid)

        # accumulate contributions from dp[l..mid] to dp[mid+1..r]
        maxV = N
        G = [0] * (maxV + 1)
        for j in range(l, mid + 1):
            v = pref[j]
            if dp[j]:
                G[v] = (G[v] + dp[j]) % MOD

        conv = convolution(G, fact)
        for i in range(mid + 1, r + 1):
            t = pref[i]
            if t < len(conv):
                dp[i] = (dp[i] - conv[t]) % MOD

        cdq(mid + 1, r)

    cdq(1, L)
    print(dp[L] % MOD)

if __name__ == "__main__":
    solve()
```
