### Step-by-step reasoning
- The graph has a fixed chain edges 1 -> 2 -> ... -> 2N and N extra edges from white vertices to black vertices (a pairing between white and black vertices).
- The final graph is strongly connected iff for every cut between k and k+1 (k = 1..2N-1) there exists at least one backward cross edge that crosses this cut, i.e., an edge w -> b with w > k and b <= k.
- If we define the white/black positions and consider a partition of whites and blacks, the condition “for every cut k there is a backward edge crossing k” is equivalent to: there is no cut k such that all backward edges lie entirely on one side of k. Equivalently, if you force some cuts to have no crossing backward edge, the whites/blacks must split into independent blocks.
- Let the 2N positions be split at the k where D(k) = (#W in [1..k]) - (#B in [1..k]) equals 0. These k partition the sequence into base blocks where the number of whites equals the number of blacks in each block. If we choose a subset of these 0-difference cuts as actual block boundaries, the whole vertex set is partitioned into contiguous blocks. Within each block, whites and blacks appear in equal numbers, so the internal pairing is independent of other blocks.
- Using inclusion-exclusion over the set Z of cuts with D(k) = 0 (1 <= k <= 2N-1), the number of good matchings equals:
  Sum over all subsets T of Z of (-1)^{|T|} times the number of matchings that do not cross any cut in T.
  If T partitions the sequence into blocks, and the i-th block contains w_i whites (and blacks), then the number of matchings that do not cross any cut in T is the product over blocks of w_i!.
- Let a_t be the number of whites in the t-th base block (between consecutive zero-difference cuts; there are m+1 such blocks for m cuts in Z). Let pref[i] be the prefix sum of a_1..a_i (with pref[0] = 0). Then the inclusion-exclusion sum can be computed via a dynamic programming over partitions of the base blocks:
  Define F[i] as the total contribution for the first i base blocks, i.e., sum over partitions of a_1..a_i into consecutive blocks of
  (-1)^{(#blocks - 1)} * product of (sum of a_j in each block)!.
  Then F[0] = -1 (to make the base case work), and for i >= 1:
    F[i] = - sum_{s=1..i} F[s-1] * (sum_{t=s..i} a_t)!
  The answer is F[m+1], where m is the number of zero-difference cuts in 1..2N-1 and m+1 is the number of base blocks.
- Important endpoint check: For the graph to possibly be strongly connected, the first vertex must be black and the last vertex must be white (S[0] = 'B', S[2N-1] = 'W'). If not, the answer is 0.

- The straightforward O((m+1)^2) DP would be too slow for N up to 2e5. We derive a faster DP by transforming the recurrence with a convolution:
  Let pref[i] be as above, 0 <= pref[i] <= N. Then
    F[i] = - sum_{j=0..i-1} F[j] * fact[pref[i] - pref[j]]
  where fact[x] is x! modulo MOD and F[0] = -1.
  This can be computed efficiently using a divide-and-conquer optimization (CDQ DP) with convolution:
  - In a CDQ step, contributions from j in left half [L, M] to i in right half [M+1, R] are:
      sum_{j in [L, M]} F[j] * fact[pref[i] - pref[j]]
    which depends only on pref[j] values. Group by pref[j], accumulate sums G[v] = sum F[j] for all j with pref[j] = v, and then the contributions to all i in the right half can be computed as (G * fact)[pref[i]] (a convolution).
  - We recursively combine contributions from left to right, finally obtaining F[i] for all i. The final answer is F[L-1], with L = m+2 (since there are m+1 base blocks, indices 0..m+1).

- Since Python is slower for huge polynomial convolutions, we:
  - Implement a convolution helper that uses a fast NTT for large inputs and a naive fallback for small inputs (to keep overhead reasonable).
  - Use CDQ divide-and-conquer to accumulate contributions in O(N log^2 N) time in the worst case, but practical for this problem with optimizations.

- Summary of steps to implement:
  1) Read N and S. If S[0] != 'B' or S[2N-1] != 'W', print 0.
  2) Build the base blocks by walking S and collecting a_t = whites in each block between successive zero-difference prefixes. Let a be the list of these counts, with length L = m+1.
  3) Build pref[0..L] with pref[0] = 0 and pref[i] = pref[i-1] + a[i-1], so pref[i] in 0..N.
  4) Prepare factorials fact[0..N].
  5) Run CDQ DP on indices [0..L], with F[0] = MOD-1 and F[i] initially 0 for i > 0, and perform the described convolutions to accumulate contributions.
  6) The answer is F[L] modulo 998244353.

- This approach is fully self-contained (no external libraries).

None

```
import sys

MOD = 998244353
ROOT = 3  # primitive root for MOD

def addmod(a, b):
    a += b
    if a >= MOD:
        a -= MOD
    return a

def submod(a, b):
    a -= b
    if a < 0:
        a += MOD
    return a

def mulmod(a, b):
    return (a * b) % MOD

def modinv(a):
    return pow(a, MOD - 2, MOD)

# Iterative in-place NTT
def ntt(a, invert):
    n = len(a)
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]
    len_ = 2
    while len_ <= n:
        wlen = pow(ROOT, (MOD - 1) // len_, MOD)
        if invert:
            wlen = modinv(wlen)
        for i in range(0, n, len_):
            w = 1
            half = len_ // 2
            for j in range(half):
                u = a[i + j]
                v = a[i + j + half] * w % MOD
                a[i + j] = (u + v) % MOD
                a[i + j + half] = (u - v) % MOD
                w = w * wlen % MOD
        len_ <<= 1
    if invert:
        inv_n = modinv(n)
        for i in range(n):
            a[i] = a[i] * inv_n % MOD

def convolution_ntt(a, b):
    if not a or not b:
        return []
    need = len(a) + len(b) - 1
    n = 1
    while n < need:
        n <<= 1
    fa = a + [0] * (n - len(a))
    fb = b + [0] * (n - len(b))
    ntt(fa, False)
    ntt(fb, False)
    for i in range(n):
        fa[i] = fa[i] * fb[i] % MOD
    ntt(fa, True)
    return fa[:need]

def convolution_naive(a, b):
    if not a or not b:
        return []
    res = [0] * (len(a) + len(b) - 1)
    for i in range(len(a)):
        ai = a[i]
        if ai == 0:
            continue
        for j in range(len(b)):
            bj = b[j]
            if bj:
                res[i + j] = (res[i + j] + ai * bj) % MOD
    return res

def convolution(a, b):
    # heuristic: small sizes -> naive, large sizes -> NTT
    TH = 2000  # tune threshold
    if len(a) * len(b) <= TH:
        return convolution_naive(a, b)
    return convolution_ntt(a, b)

def solve():
    input = sys.stdin.readline
    line = input().strip()
    while line == "":
        line = input().strip()
    N = int(line)
    S = input().strip()

    total_len = 2 * N
    if len(S) != total_len:
        print(0)
        return

    # Endpoint necessary condition
    if S[0] != 'B' or S[-1] != 'W':
        print(0)
        return

    # Build base blocks: a_t = number of Ws in each block
    diff = 0
    curr_w = 0
    a = []
    for i in range(1, total_len + 1):
        ch = S[i - 1]
        if ch == 'W':
            diff += 1
            curr_w += 1
        else:
            diff -= 1
        if i != total_len and diff == 0:
            a.append(curr_w)
            curr_w = 0
    a.append(curr_w)  # final block up to 2N

    L = len(a)  # number of base blocks
    # pref[0] = 0, pref[i] = sum_{t=1..i} a_t
    pref = [0] * (L + 1)
    for i in range(1, L + 1):
        pref[i] = pref[i - 1] + a[i - 1]
    # pref values lie in [0, N]

    # Precompute factorials up to N
    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD

    # CDQ DP on indices [0..L]
    # F[0] = -1, F[k] = 0 for k>0 initially
    F = [0] * (L + 1)
    F[0] = (MOD - 1)  # -1 mod MOD

    # Helper to check if left part has any nonzero contributions
    # We'll implement CDQ as a recursive function
    def cdq(l, r):
        if l >= r:
            return
        mid = (l + r) >> 1
        cdq(l, mid)

        # Build G[v] = sum_{j in [l..mid], pref[j] = v} F[j]
        maxV = N
        G = [0] * (maxV + 1)
        any_nonzero = False
        for j in range(l, mid + 1):
            v = pref[j]
            if F[j]:
                G[v] = (G[v] + F[j]) % MOD
                any_nonzero = True

        if any_nonzero:
            # Convolution of G with fact
            conv = convolution(G, fact)
            # Apply contributions to i in [mid+1 .. r]
            for i in range(mid + 1, r + 1):
                t = pref[i]
                if t < len(conv):
                    F[i] = (F[i] - conv[t]) % MOD
        # Recurse on right half
        cdq(mid + 1, r)

    cdq(0, L)

    # Final answer is F[L]
    print(F[L] % MOD)

if __name__ == "__main__":
    solve()
```
