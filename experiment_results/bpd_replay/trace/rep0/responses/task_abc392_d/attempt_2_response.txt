### Step-by-step reasoning
- For two dice i and j, the probability that they show the same number is sum over all values v of p_i(v) * p_j(v), where p_i(v) is the probability that die i shows v (count of v on die i divided by Ki).
- A straightforward way is to build, for every die, its distribution p_i(v) as a map from value to probability, then for every pair (i, j) compute the dot product sum_v p_i(v) * p_j(v).
- To keep things robust and efficient, for each pair (i, j) we compute the dot product by iterating only over the smaller distribution among the two dice, checking membership in the other distribution. This yields O(min(|dist_i|, |dist_j|)) work per pair, and with N ≤ 100 and total faces sum Ki ≤ 1e5 this is easily fast enough.
- After evaluating all pairs, take the maximum probability found and print it with high precision (at least 1e-8 accuracy required).

### Requirements
None

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        print("0.000000000000000")
        return

    it = iter(data)
    N = next(it)

    # For each die, build a map value -> probability p_i(v)
    dists = []
    for _ in range(N):
        Ki = next(it)
        counts = {}
        for _ in range(Ki):
            v = next(it)
            counts[v] = counts.get(v, 0) + 1
        dist = {v: cnt / Ki for v, cnt in counts.items()}
        dists.append(dist)

    maxp = 0.0
    for i in range(N - 1):
        di = dists[i]
        for j in range(i + 1, N):
            dj = dists[j]
            if len(di) <= len(dj):
                s = 0.0
                for v, pi in di.items():
                    pj = dj.get(v)
                    if pj is not None:
                        s += pi * pj
            else:
                s = 0.0
                for v, pj in dj.items():
                    pi = di.get(v)
                    if pi is not None:
                        s += pi * pj
            if s > maxp:
                maxp = s

    print("{:.15f}".format(maxp))

if __name__ == "__main__":
    main()
```
