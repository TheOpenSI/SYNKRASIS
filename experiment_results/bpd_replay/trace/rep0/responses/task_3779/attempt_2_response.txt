### Step-by-step reasoning
- Problem restatement: We have n pizzas (n is a multiple of 4). Each day we pick 4 pizzas, sort their weights as W <= X <= Y <= Z. On odd days we gain Z, on even days we gain Y. We want to maximize the total gain over all days.

- Key insight:
  - On an odd day (day 1, 3, 5, ...), the gain is the maximum in the chosen group. To maximize the overall total, we should keep the largest values available for the days where they contribute.
  - On an even day (day 2, 4, 6, ...), the gain is the second largest in the group. To maximize this day, we should form the group so that its second largest is as large as possible, i.e., use the three largest remaining numbers (besides the day’s max) as fillers.

- Greedy strategy (constructive, proven by exchange argument intuition):
  - Always sort pizzas in non-increasing order.
  - Maintain two pointers:
    - l points to the next largest not yet used (left side).
    - r points to the next smallest not yet used (right side) to account for the three smallest fillers on odd days.
  - For each day i from 0 to D-1 (D = n/4):
    - Take max_val = arr[l], increment l by 1 (this is the largest in the current day’s group).
    - If i is even (i = 0, 2, 4, ... → odd-numbered days): add max_val to the answer and remove three smallest elements from the right (r -= 3).
    - If i is odd (i = 1, 3, 5, ... → even-numbered days): take second = arr[l] (the next largest after removing max), add it to the answer, and skip the next two fillers as well by advancing l by 3 more (effectively removing the next three largest after max). So l += 3 in this branch (since we already did l += 1 for the max).

- Correctness sketch:
  - Odd days: using the current maximum as the day’s gain and discarding three smallest minimizes the loss of future opportunities (we don’t waste large numbers as fillers).
  - Even days: using the current maximum as the group’s max would waste the opportunity to gain from a large second max; instead, by forming the group with the next three largest values as fillers, the day’s gain becomes the largest among those fillers, i.e., the second largest of the group, which is as large as possible given the remaining numbers.
  - Repeating this process across days yields a globally optimal partition under the parity constraint.

- Complexity:
  - Sorting: O(n log n)
  - Each day uses O(1) work, total O(n) across all days
  - Space: O(1) beyond input (besides the in-place sort)

- Output format: The method returns an int, matching the required signature.

- None: No external libraries are required.

### Code
```
from typing import List

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        pizzas.sort(reverse=True)  # Descending order
        l = 0        # left pointer (largest not yet used)
        r = n - 1    # right pointer (smallest not yet used)
        days = n // 4
        ans = 0

        for day in range(days):
            max_val = pizzas[l]
            l += 1

            if day % 2 == 0:
                # Odd day (1,3,5,...): gain the max; remove three smallest from the right
                ans += max_val
                r -= 3
            else:
                # Even day (2,4,6,...): gain the second largest in the group
                second = pizzas[l]
                ans += second
                # Remove the next three largest (the second and the two following)
                l += 3

        return ans
```
