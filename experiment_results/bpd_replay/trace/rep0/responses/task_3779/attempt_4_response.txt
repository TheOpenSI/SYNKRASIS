### Step-by-step reasoning
- Problem restatement: We have n pizzas (n multiple of 4). Each day we pick 4 pizzas, sort their weights W <= X <= Y <= Z. On odd days we gain Z, on even days we gain Y. We want to maximize the total weight gained after all pizzas are eaten.

- Key observations:
  1) There are D = n/4 days. Among these days, the odd days (ceil(D/2) of them) contribute the maximum Z from their 4-pizza group, and the even days (the remaining floor(D/2)) contribute the second maximum Y from their 4-pizza group.
  2) To maximize the total, it makes sense to use the largest possible numbers as the Z contributions on the odd days. Specifically, the k = ceil(D/2) largest numbers should be used as the Z values for the odd days. This is feasible because we can always form k groups around these k largest numbers and fill each with three smaller pizzas.
  3) The 3k other pizzas used as fillers for the odd-day groups should be as small as possible to not waste potential for the Y contributions on even days. Therefore, we assign the 3k smallest numbers as fillers for the odd-day groups.
  4) After removing the k largest numbers (for Z) and the 3k smallest numbers (fillers), we are left with 4(D - k) numbers for the even-day groups. For each even day, the contribution is the second-largest in its group. To maximize the sum of these second-largest values across all remaining blocks, we should group the remaining numbers in descending order into consecutive blocks of 4. Then the second element of each block (the second-largest in that block) is the contributed value. This yields taking the elements at indices 1, 5, 9, ... in the remaining list after removal.

- Therefore, the algorithm is:
  1) Sort pizzas in descending order.
  2) Let D = n/4 and k = ceil(D/2) = (D+1)//2.
  3) Z_sum = sum of the first k elements (these become the Z contributions on odd days).
  4) Remove those k largest elements and also remove the 3k smallest elements (fillers). Let B be the remaining list of length 4*(D - k).
  5) Y_sum is the sum of B[1], B[5], B[9], ... (i.e., sum of every 4th element starting from index 1).
  6) Answer = Z_sum + Y_sum.

- Correctness intuition:
  - Using the k largest values as Z is optimal because each odd day yields exactly one Z, and using a larger number there cannot hurt future even-day contributions beyond the necessary grouping constraint.
  - Filling with the 3k smallest numbers minimizes opportunity cost for the later even-day groups.
  - Among the remaining numbers, grouping in descending order into blocks of four maximizes each block’s second-largest value, hence maximizing the sum of all Y contributions.

- Complexity: Sorting dominates with O(n log n) time. The rest is linear in n. Extra space is O(1) beyond the input list (in-place sort) or O(n) if you copy.

### Requirements
None

### Code
```
from typing import List

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        # Sort in descending order to easily pick largest and smallest ranges
        pizzas.sort(reverse=True)

        D = n // 4
        k = (D + 1) // 2  # number of odd-day groups (ceil(D/2))

        # Z contributions: sum of the k largest values
        z_sum = sum(pizzas[:k])

        # Remaining after removing k largest and 3*k smallest fillers for odd-day groups
        if k > 0:
            B = pizzas[k : n - 3 * k]
        else:
            B = pizzas[:]

        # B should have length 4*(D - k)
        y_sum = 0
        # For each even-day group, the second largest is the second element in each 4-block of B
        for i in range(1, len(B), 4):
            y_sum += B[i]

        return z_sum + y_sum
```
