### Step-by-step reasoning
- Problem understanding: We have n pizzas (n is multiple of 4). Each day we pick 4 pizzas, sort them W <= X <= Y <= Z. On day 1, 3, 5, ... (odd days) we gain Z; on day 2, 4, 6, ... (even days) we gain Y. We want to maximize the total weight gained after all pizzas are eaten.

- Key observation: Let D = n / 4 (number of days). There are k = ceil(D/2) odd days and D - k even days. Exactly k groups will contribute their maximum Z, and D - k groups will contribute their second maximum Y.

- Strategy outline:
  1) Put the k largest numbers as the maxima Z for the k odd-day groups. This is feasible because we can form k groups, each with one of these large numbers as its maximum, and fill the rest with smaller numbers.
  2) For each odd-day group, use three of the smallest numbers as fillers to minimize impact on later groups.
  3) After removing those k maxima and 3k smallest fillers, we have 4(D - k) numbers left to form the even-day groups. For an even-day group, the contribution is the group’s second largest number. To maximize the sum of these second maxima across all (D - k) even groups, we should pair the largest remaining numbers together in groups so that the second largest in each group is as large as possible.
     - If we sort the remaining numbers in descending order and partition them into blocks of four as they appear, the second largest in each block is the second element of that block. Therefore, the total Y contribution is the sum of B[1], B[5], B[9], ... where B is the remaining list after removing k largest and 3k smallest.

- Resulting algorithm:
  - Sort pizzas in descending order.
  - Let D = n // 4 and k = (D + 1) // 2 (ceil division).
  - Z_sum = sum of the first k elements (these are the odd-day maxima).
  - Remove those k largest elements and the 3k smallest elements from consideration for the even-day groups.
  - Let B be the remaining list (length 4*(D - k)). The Y_sum is sum of B[1], B[5], B[9], ... (i.e., every 4th element starting from index 1).
  - The answer is Z_sum + Y_sum.

- Correctness intuition:
  - Using the k largest numbers as the Z values is optimal since only k such values are ever counted (one per odd day), and placing any larger number into an odd-day group cannot hurt future even-day contributions beyond the constraint that it cannot be used as a Y elsewhere.
  - Filling odd-day groups with the smallest numbers minimizes the potential loss for the remaining even-day groups.
  - Among the remaining numbers, grouping to maximize each even-day group’s second largest is achieved by pairing the largest remaining numbers together in the same 4-number block, which yields the largest possible second-largest values for those groups. Summing the second largest of each block corresponds to summing B[1], B[5], B[9], ...

- Complexity: Sorting O(n log n). The rest is linear in n. Overall O(n log n) time and O(1) additional space (in-place sort).

### Requirements
None

### Code
```
from typing import List

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        pizzas.sort(reverse=True)  # Descending order

        D = n // 4
        k = (D + 1) // 2  # number of odd-day groups

        # Z contributions: sum of the k largest values
        z_sum = sum(pizzas[:k])

        # Remaining after removing k largest and 3*k smallest fillers for odd-day groups
        if k > 0:
            # Remove k largest and 3k smallest
            B = pizzas[k : n - 3 * k]
        else:
            B = pizzas[:]

        # B should have length 4*(D - k)
        y_sum = 0
        # For each even-day group, the second largest is the second element in each 4-block of B
        for i in range(1, len(B), 4):
            y_sum += B[i]

        return z_sum + y_sum
```
