### Step-by-step reasoning
- We have binary sequences A and B of length N, and costs C. Each operation flips one A_i and costs the sum S of A_k * C_k after the flip. We want to reach B with minimum total cost.
- Let S0 be the initial sum: S0 = sum_i A_i * C_i.
- We must flip indices where A_i != B_i an odd number of times. Indices where A_i = B_i can be flipped 0 or 2 times (or more, but flipping more than 2 times is never beneficial for optimality due to monotonic cost structure).
  - If A_i = 1, B_i = 0: a mandatory first flip (negative delta) reduces S by C_i.
  - If A_i = 0, B_i = 1: a mandatory first flip (positive delta) increases S by C_i.
  - If A_i = 1, B_i = 1: optional to flip twice (two flips) to possibly improve total cost; this creates a pair: first flip gives negative delta -C_i, then later a second flip gives positive delta +C_i.
- The optimal strategy can be described by deciding a subset Z of indices where A_i = B_i = 1 to form extra flip pairs (two flips) or none. If we take a subset Z of size k, we flip all A_i = 1, B_i = 0 (negatives) and all chosen k elements from Z once in the first phase (these contribute negative deltas). Then we flip all A_i = 0, B_i = 1 (positives) plus the same k elements from Z once more in the second phase (these contribute positive deltas). To minimize total cost, it is optimal to:
  - perform negative flips in descending C_i (largest C first),
  - perform positive flips in ascending C_i (smallest C first).
  - among Z, pick the k largest C_i values to form the extra pairs (this is optimal for the same reason: larger C_i provide larger potential reduction in early negative phase and controlled increase in the later positive phase).
- We can compute the total cost for each k efficiently by maintaining dynamic multisets:
  - Negatives (the A_i = 1, B_i = 0 flips) plus the chosen k from Z, sorted in descending order.
  - Positives (the A_i = 0, B_i = 1 flips) plus the chosen k from Z, sorted in ascending order.
- Let d be the number of negative flips in the current scenario, and let neg be the list of their costs (descending). The contribution to total cost from the negative flips is:
  TotalNeg = d * S0 - sum_{t=1..d} t * neg[t]
  where neg[t] is the t-th element in the descending list.
- After applying all negatives, S becomes S0 - sum(neg). For positives, let m be the number of positive flips (including the k Z elements, in ascending order). Let pos be the list of their costs (ascending), and let sum_pos be their sum, and old_sum_pos = sum_{t=1..m} (t-1) * pos[t]. Then the contribution from the positives is:
  TotalPos = m * (S0 - sum(neg)) + sum_pos + old_sum_pos
- The total cost for a given k is TotalNeg + TotalPos. We try all k from 0 to |Z| and take the minimum.
- To do this efficiently for N up to 2e5, we process k from 0 to |Z| incrementally by inserting one Z element (the next largest C_i) at a time into both the negative and positive multisets, maintaining:
  - old_sum_neg = sum_{t=1..d} t * neg[t], updated when inserting a value into the descending neg list.
  - sum_neg = sum(neg)
  - old_sum_pos = sum_{t=1..m} (t-1) * pos[t], updated when inserting a value into the ascending pos list.
  We implement these updates in O(log M) per insertion using coordinate-compressed Fenwick trees (one for negative values and one for positive values) to find insertion ranks and sums efficiently.
- This approach fixes previous mistakes where a simple closed-form merge led to incorrect totals, and runs in O((N + |Z|) log M) time with M being the number of distinct C values.

Time and space:
- Time: O((N + |Z|) log M)
- Space: O(M)

None

import sys

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, i, delta):
        while i <= self.n:
            self.bit[i] += delta
            i += i & -i

    def sum(self, i):
        s = 0
        while i > 0:
            s += self.bit[i]
            i -= i & -i
        return s

    def range_sum(self, l, r):
        if r < l:
            return 0
        return self.sum(r) - self.sum(l - 1)

def main():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    try:
        N = int(next(it))
    except StopIteration:
        print(0)
        return

    A = [int(next(it)) for _ in range(N)]
    B = [int(next(it)) for _ in range(N)]
    C = [int(next(it)) for _ in range(N)]

    # Base sums and partitions
    S0 = 0
    neg_vals = []  # A_i=1, B_i=0
    pos_vals = []  # A_i=0, B_i=1
    Z_vals = []    # A_i=1, B_i=1 (optional pairs)

    for i in range(N):
        ai = A[i]
        bi = B[i]
        ci = C[i]
        S0 += ai * ci
        if ai == 1 and bi == 0:
            neg_vals.append(ci)
        elif ai == 0 and bi == 1:
            pos_vals.append(ci)
        elif ai == 1 and bi == 1:
            Z_vals.append(ci)
        else:
            # ai == 0 and bi == 0 : nothing mandatory
            pass

    # If nothing to do
    if not neg_vals and not pos_vals and not Z_vals:
        print(0)
        return

    # Coordinate compression on all possible C values
    all_vals = sorted(set(neg_vals + pos_vals + Z_vals))
    comp = {v: i+1 for i, v in enumerate(all_vals)}  # 1-based index for Fenwick

    # Initial sorted orders for negatives (descending) and positives (ascending)
    neg_sorted = sorted(neg_vals, reverse=True)  # for initial old_sum_neg
    pos_sorted = sorted(pos_vals)               # for initial old_sum_pos

    # Initial old sums
    old_sum_neg = 0
    for idx, val in enumerate(neg_sorted, start=1):
        old_sum_neg += idx * val  # sum t * neg[t]

    old_sum_pos = 0
    for idx, val in enumerate(pos_sorted, start=0):
        old_sum_pos += idx * val  # (t-1) * pos[t], t = idx+1, so idx*(val)

    # Initial sums and counts
    sum_neg = sum(neg_vals)
    sum_pos = sum(pos_vals)
    d = len(neg_vals)
    m = len(pos_vals)

    total_vals = len(all_vals)
    # Fenwicks for negatives (values stored as counts and sums by value)
    fenw_neg_cnt = Fenwick(total_vals)
    fenw_neg_sum = Fenwick(total_vals)
    for v in neg_vals:
        idx = comp[v]
        fenw_neg_cnt.add(idx, 1)
        fenw_neg_sum.add(idx, v)

    # Fenwicks for positives (ascending list)
    fenw_pos_cnt = Fenwick(total_vals)
    fenw_pos_sum = Fenwick(total_vals)
    for v in pos_vals:
        idx = comp[v]
        fenw_pos_cnt.add(idx, 1)
        fenw_pos_sum.add(idx, v)

    # Function to compute current Total given current states
    def current_total(S0, d, old_sum_neg, sum_neg, old_sum_pos, sum_pos, m):
        total_neg = d * S0 - old_sum_neg
        S_after_neg = S0 - sum_neg
        total_pos = m * S_after_neg + sum_pos + old_sum_pos
        return total_neg + total_pos

    # Initial total (k = 0)
    ans = current_total(S0, d, old_sum_neg, sum_neg, old_sum_pos, sum_pos, m)

    # Prepare Z values sorted descending (largest first)
    Z_desc = sorted(Z_vals, reverse=True)

    # Incrementally add k elements from Z_desc into both neg and pos
    for z in Z_desc:
        idx_z = comp[z]

        # Insert into negatives (descending order)
        # pos_neg (1-based index of new z in the descending list)
        # count_greater = number of elements > z in current neg list
        cnt_leq = fenw_neg_cnt.sum(idx_z)        # number of elements <= z
        total_cnt_neg = d
        count_greater = total_cnt_neg - cnt_leq    # since list is descending, elements > z come first
        pos_neg = count_greater + 1                 # insertion position (1-based)

        sum_tail_neg = fenw_neg_sum.sum(idx_z)     # sum of elements <= z in current neg list

        # Update old_sum_neg with insertion formula: old_sum_neg = old_sum_neg + pos*z + sum_tail
        old_sum_neg += pos_neg * z + sum_tail_neg

        # Update Fenwick structures and sums for neg
        fenw_neg_cnt.add(idx_z, 1)
        fenw_neg_sum.add(idx_z, z)
        sum_neg += z
        d += 1

        # Insert into positives (ascending order)
        # pos_pos (1-based index of new z in the ascending list)
        cnt_leq_pos = fenw_pos_cnt.sum(idx_z)  # number of elements <= z in current pos list
        total_cnt_pos = m
        pos_pos = cnt_leq_pos + 1              # insertion position (1-based)

        sum_leq_pos = fenw_pos_sum.sum(idx_z)
        sum_gt_pos = sum_pos - sum_leq_pos

        # Update old_sum_pos with insertion formula: old_sum_pos = old_sum_pos + z*(pos-1) + sum_gt
        old_sum_pos += z * (pos_pos - 1) + sum_gt_pos

        # Update Fenwick structures and sums for pos
        fenw_pos_cnt.add(idx_z, 1)
        fenw_pos_sum.add(idx_z, z)
        sum_pos += z
        m += 1

        # Recompute total for this k
        total = current_total(S0, d, old_sum_neg, sum_neg, old_sum_pos, sum_pos, m)
        if total < ans:
            ans = total

    print(ans)

if __name__ == "__main__":
    main()
