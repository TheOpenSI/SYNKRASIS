### Step-by-step reasoning
- Blocks stay within their columns; only vertical movement happens, and only when there is no block directly below a block (and the block is not already on the bottom row).
- A global removal happens at a time step t if and only if at the start of that step every column has a block at y = 1 (the bottom row is full). In that case, exactly one block from the bottom of every non-empty column is removed, and then remaining blocks may cascade downward within that same time step.
- If any column is empty from the start, the bottom row can never be full at any time, hence no removals ever occur, and all blocks always exist.
- If no column is empty, removals begin at the first time step t = B, where B is when the bottom row first becomes full. For a column, the bottom-most block (the one with the smallest initial Y in that column) reaches y = 1 after mxt steps equal to its initial height in that column. The bottom row becomes full only when the last column’s bottom-most block reaches y = 1, which happens at B = max over columns of (minimum initial Y in that column).
- After that, removals continue in every step t = B, B+1, ..., B+m-1, where m is the minimum initial height among all columns (the number of removals that can be performed before some column becomes empty). After m removals, at least one column becomes empty, so no further removals can occur.
- For a block i in column x, let r_i be its rank within that column when blocks are sorted by initial Y ascending (1-based, bottom-most in that column has rank 1).
  - After s removals, blocks with rank ≤ s in that column are removed; blocks with rank > s survive that many removals.
  - Let T be the time (integer steps). Then:
    - If T < B, s = 0, all blocks exist.
    - If B ≤ T ≤ B + m − 1, s = T − B + 1, block i exists iff r_i > s.
    - If T ≥ B + m, s = m, block i exists iff r_i > m.

Algorithm:
- Group blocks by their column; for each column collect pairs (Y_i, block_index).
- If any column is empty, answer "Yes" for all queries.
- Otherwise:
  - Compute B = max over columns of the minimum Y in that column.
  - Compute m = min over columns of their heights.
  - For each column, sort its blocks by Y and assign rank to each block.
  - For each query (T, A):
    - If T < B: Yes
    - Else if T ≤ B + m − 1: s = T − B + 1; Yes if rank[A] > s
    - Else: Yes if rank[A] > m

This runs in O(N log N) preprocessing (due to sorting within columns) and O(1) per query. Memory is O(N).

### Requirements
None

### Code
```
import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    N = next(it); W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # 0-based block index

    # Build per-column blocks
    cols = [[] for _ in range(W)]
    heights = [0] * W
    for i in range(N):
        x = X[i] - 1
        cols[x].append((Y[i], i))
        heights[x] += 1

    # If any column is empty, no removals ever happen
    any_empty = any(h == 0 for h in heights)

    rank = [0] * N  # 1-based rank within its column
    B = 0
    m = 0

    if not any_empty:
        # Compute B = max over columns of minY, and m = min height
        minY_per_col = []
        for col in cols:
            # col is non-empty
            minY = min(y for (y, idx) in col)
            minY_per_col.append(minY)
        B = max(minY_per_col)
        m = min(heights)

        # Assign ranks within each column
        for col in cols:
            col.sort(key=lambda t: t[0])  # sort by Y
            for pos, (y, idx) in enumerate(col, start=1):
                rank[idx] = pos

    out_lines = []
    if any_empty:
        out_lines = ["Yes"] * Q
    else:
        Bp = B
        mp = m
        for j in range(Q):
            t = T_arr[j]
            a = A_arr[j]
            r = rank[a]
            if t < Bp:
                out_lines.append("Yes")
            elif t <= Bp + mp - 1:
                s = t - Bp + 1
                out_lines.append("Yes" if r > s else "No")
            else:
                out_lines.append("Yes" if r > mp else "No")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```
