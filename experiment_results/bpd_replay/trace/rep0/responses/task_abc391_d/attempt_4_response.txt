### Step-by-step reasoning
- Let h[c] be the number of blocks in column c (1-based columns, c ∈ [1..W]). If any h[c] = 0, then the bottom row can never be full, so there will be no removals at all. In this case, every block remains forever, so every query is Yes.
- Otherwise all columns are non-empty initially. In that case:
  - During each time step, if the bottom row is full at the start, one block is removed from the bottom of every non-empty column, and then all remaining blocks cascade downward within their columns.
  - The total number of removal steps equals M = min_c h[c].
  - The bottom row is full at the start of the first removal step either at step 1 (if initially every column has a block at y=1) or at step 2 (otherwise). If initially at y=1 every column has a block, then we remove the current bottom block from every column in step 1, otherwise the first removal happens in step 2 after one gravity step.
  - In every column, blocks never cross each other. If you sort the blocks in a column by their initial Y (ascending), that order is preserved throughout, and the blocks removed during the removal steps are exactly the blocks with the smallest ranks within their column, up to M blocks per column, with a possible offset of 0 or 1 depending on whether the initial bottom row was full.
- Concretely, let:
  - For each column, rank[i] be the 1-based rank of block i within its column when blocks are sorted by initial Y ascending (rank 1 is the bottom-most initial block in that column).
  - B0 be True if initially every column has a block at Y = 1 (i.e., for every column there exists a block with Y = 1 in that column). Otherwise B0 is False.
  - M = min_c h[c].
- Then the time (in steps) when a block i is removed is:
  - If M = 0: no removals at all (covered by the first case).
  - If B0 is True: t_remove(i) = rank[i], but only if rank[i] ≤ M; otherwise t_remove(i) = +∞ (block never removed).
  - If B0 is False: t_remove(i) = rank[i] + 1, but only if rank[i] ≤ M; otherwise t_remove(i) = +∞.
- A block i exists at time T (i.e., after step T) iff T < t_remove(i). If t_remove(i) = +∞, it always exists. This matches the process in which removals happen at the beginnings of certain steps, removing entire bottom rows across columns, and blocks not removed stay (they either sit on top of others or have already fallen into the bottom of their column).

Plan:
- Build per-column lists of (Y, block_index).
- Compute h[c] and M = min h[c].
- If M = 0: answer Yes for all queries.
- Else:
  - Compute B0 by checking if every column has a block with Y = 1.
  - For each column, sort its blocks by Y and assign rank[block_index] = position in the sorted list (1-based).
  - For each block i, compute t_remove(i) as above using M and B0.
  - For each query (T, A): output Yes if T < t_remove(A), else No.

Complexities:
- Sorting blocks within all columns total is O(∑ h[c] log h[c]) ≤ O(N log N).
- All other steps are linear in N or Q.
- Works within given constraints (N, Q ≤ 2e5).

None

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    N = next(it)
    W = next(it)

    X = [0] * N
    Y = [0] * N
    per_col = [[] for _ in range(W)]
    heights = [0] * W

    for i in range(N):
        x = next(it)
        y = next(it)
        X[i] = x
        Y[i] = y
        c = x - 1
        per_col[c].append((y, i))
        heights[c] += 1

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # zero-based index for block

    # Compute M = min height across all columns
    M = min(heights)

    # If any column is empty, there are no removals; all blocks survive
    if M == 0:
        out = ["Yes"] * Q
        sys.stdout.write("\n".join(out))
        return

    # Compute B0: initially bottom row full (every column has a block at Y=1)
    has_y1 = [False] * W
    for c in range(W):
        for (y, idx) in per_col[c]:
            if y == 1:
                has_y1[c] = True
                break
    B0 = all(has_y1)

    # Compute ranks for each block: rank within its column when sorted by Y asc
    rank = [0] * N
    for c in range(W):
        col_blocks = per_col[c]
        col_blocks.sort(key=lambda t: t[0])  # sort by Y
        for pos, (y, idx) in enumerate(col_blocks, start=1):
            rank[idx] = pos

    INF = 10**18
    t_remove = [INF] * N

    for i in range(N):
        r = rank[i]
        if r <= M:
            if B0:
                t_remove[i] = r
            else:
                t_remove[i] = r + 1
        else:
            t_remove[i] = INF

    out = []
    for j in range(Q):
        T = T_arr[j]
        a = A_arr[j]
        if T < t_remove[a]:
            out.append("Yes")
        else:
            out.append("No")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
