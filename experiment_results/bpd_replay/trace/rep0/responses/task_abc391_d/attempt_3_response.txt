### Step-by-step reasoning
- Blocks move only vertically within their column; there is no horizontal movement.
- A global removal occurs at the start of a step if and only if every column has a block at y = 1 (the bottom row). In that case, exactly one block from the bottom of every non-empty column is removed, then remaining blocks may cascade downward in that same step.
- If any column is empty from the start, the bottom row can never be full (since blocks only move downward, no new blocks appear in an empty column). Therefore no removals ever occur, and all blocks always exist.
- If all columns are non-empty, define:
  - B = max over all columns of the smallest initial Y in that column (minY). This is the step index when the bottom row becomes full for the first time (at the start of step B).
  - m = min over all columns of their heights (number of blocks in that column). After m removals (occurring in steps B, B+1, ..., B+m-1), the shortest column becomes empty, and no further removals can occur because the bottom row will no longer be full.
- For a block i in some column, define r_i as its rank within its column when blocks are sorted by initial Y ascending (the bottom-most has rank 1).
  - After s removals, blocks with rank ≤ s are removed in that column.
- At time T (after T steps), let s be the number of removals that happened up to that time:
  - If T < B: s = 0, all blocks exist.
  - If B ≤ T ≤ B + m − 1: s = T − B + 1, block exists iff r_i > s.
  - If T ≥ B + m: s = m, block exists iff r_i > m.

Algorithm:
- Group blocks by their column; for each column store (Y_i, block_index).
- If any column is empty, answer "Yes" for all queries.
- Otherwise:
  - Compute B = max(minY_per_col) and m = min(height_per_col).
  - For each column, sort blocks by Y and assign rank to each block.
  - For each query (T, A):
    - If T < B: "Yes"
    - Else if T ≤ B + m − 1: s = T − B + 1; print "Yes" if rank[A] > s else "No"
    - Else: print "Yes" if rank[A] > m else "No"

This runs in O(N log N) preprocessing (due to sorting within columns) and O(1) per query, with O(N) memory.

### Requirements
None

### Code
```
import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    N = next(it); W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # 0-based block index

    # Build per-column blocks
    cols = [[] for _ in range(W)]
    heights = [0] * W
    for i in range(N):
        x = X[i] - 1
        cols[x].append((Y[i], i))
        heights[x] += 1

    # If any column is empty, no removals ever happen
    any_empty = any(h == 0 for h in heights)

    rank = [0] * N  # 1-based rank within its column
    B = 0
    m = 0

    if not any_empty:
        # Compute B = max over columns of minY, and m = min height
        minY_per_col = []
        for col in cols:
            # col is non-empty
            minY = min(y for (y, idx) in col)
            minY_per_col.append(minY)
        B = max(minY_per_col)
        m = min(heights)

        # Assign ranks within each column
        for col in cols:
            col.sort(key=lambda t: t[0])  # sort by Y
            for pos, (y, idx) in enumerate(col, start=1):
                rank[idx] = pos

    out_lines = []
    if any_empty:
        out_lines = ["Yes"] * Q
    else:
        Bp = B
        mp = m
        for j in range(Q):
            t = T_arr[j]
            a = A_arr[j]
            r = rank[a]
            if t < Bp:
                out_lines.append("Yes")
            elif t <= Bp + mp - 1:
                s = t - Bp + 1
                out_lines.append("Yes" if r > s else "No")
            else:
                out_lines.append("Yes" if r > mp else "No")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```
