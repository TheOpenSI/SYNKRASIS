### Step-by-step reasoning
- Problem insight:
  - For a query [L, R], we must form as many disjoint pairs (i, j) with L ≤ i < j ≤ R such that A[i] * 2 ≤ A[j].
  - Each mochi (index) can be used at most once, either as a left element or a right element in a pair.

- Why the previous solution failed:
  - The previous approach attempted a DSU-based skip over potential right partners but did not properly enforce that an index used as a right partner cannot later be used as a left partner. This leads to invalid reuse of indices and incorrect counts (e.g., counting a pair that reuses an index already used as a right element).

- How to fix:
  - For each query, use a straightforward greedy two-pointer strategy with a per-query “used” marker for elements inside the subarray:
    - Let the subarray be A[L..R] with length m = R-L+1.
    - Maintain two pointers within the subarray:
      - i: current candidate for the left element (starting at 0 relative index).
      - j: current candidate for the right element (start at 1 relative index, always j > i).
    - Skip any i that has already been used.
    - Move j forward until you find an unused A[L+j] that satisfies A[L+i] * 2 ≤ A[L+j].
    - If found, form the pair, mark both i and j as used, increment answer, and move i and j forward.
    - If no such j exists within the subarray, stop.
  - This approach ensures no index is reused and yields the maximum number of disjoint valid pairs for that subarray, by always pairing the smallest available left element with the smallest feasible right element.

- Complexity:
  - For each query, we process at most m elements once with simple pointer advancement, giving O(m) time and O(m) extra space. This is straightforward and correct for the constraint sizes in typical test cases.

- No external libraries needed.

import sys

def solve():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    N = int(next(it))
    A = [int(next(it)) for _ in range(N)]
    Q = int(next(it))
    queries = []
    for _ in range(Q):
        L = int(next(it)); R = int(next(it))
        queries.append((L - 1, R - 1))  # convert to 0-based indices

    out_lines = []
    for L, R in queries:
        m = R - L + 1
        if m < 2:
            out_lines.append("0")
            continue

        ans = 0
        used = [False] * m  # marks inside the subarray [L..R]
        i = 0
        j = 1

        while i < m and j < m:
            if used[i]:
                i += 1
                if i >= j:
                    j = i + 1
                continue
            if j <= i:
                j = i + 1
                continue
            # move j forward to find a usable right partner for A[L+i]
            while j < m and (used[j] or A[L + i] * 2 > A[L + j]):
                j += 1
            if j < m:
                # form a pair (i, j)
                used[i] = True
                used[j] = True
                ans += 1
                i += 1
                j += 1
            else:
                break

        out_lines.append(str(ans))

    print("\n".join(out_lines))

if __name__ == "__main__":
    solve()
