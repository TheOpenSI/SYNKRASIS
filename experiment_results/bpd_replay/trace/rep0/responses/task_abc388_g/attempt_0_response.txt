### Step-by-step reasoning

- Problem restatement:
  - We have a nondecreasing array A of size N.
  - For each query [L, R], consider the subarray A[L..R].
  - We want the maximum number of disjoint pairs (a, b) from this subarray such that a <= b/2.
  - Each mochi (array element) can be used at most once, either as a or as a part of a pair.

- Observations:
  - In a subarray, a valid pair must have the smaller element on the left and the larger on the right since A is sorted and i < j in a pair (A[i] and A[j]).
  - A natural greedy idea is to process the elements from left to right (as potential "smaller" elements) and for each unused left element pick the smallest unused right element that can pair with it (i.e., the smallest j > i with A[j] >= 2*A[i]).
  - This greedy strategy is standard for matching in chain-like bipartite graphs where left elements precede right elements and the edge condition is monotone. It yields a maximum matching for this specific constraint.

- Plan:
  - For each query [L, R], run the following greedy:
    - Maintain a boolean array used indicating whether an index in [L..R] has already been used in some pair.
    - Precompute for every i the earliest index j >= i+1 such that A[j] >= 2*A[i]. Let p_eff[i] = max(i+1, lower_bound(A, 2*A[i])) so that we always start from a valid j > i. If p_eff[i] > N-1, there is no possible partner for i in the whole array.
    - Iterate i from L to R-1:
      - If i is already used, continue.
      - Let jstart = max(p_eff[i], L). Use a disjoint-set (DSU) data structure to quickly find the next unused j >= jstart.
      - If found j <= R, form a pair (i, j): mark used[i] = True and used[j] = True, and mark j as used in the DSU (so it won’t be used again as a right partner). Increase answer.
      - Otherwise, no partner for this i within [L..R], continue to next i.
  - Complexity per query is roughly O((R-L+1) log N) due to the lower_bound operations and DSU operations; this is straightforward to implement and correct.

- Edge cases:
  - If R-L+1 < 2, answer is 0.
  - If for a given i there is no j > i with A[j] >= 2*A[i], then p_eff[i] will be large and the algorithm will skip i quickly.
  - Large inputs: The above approach is not the most optimal for the worst-case constraints, but it is correct and runs in practice for many datasets. If necessary, it can be optimized with careful block processing or more advanced data structures.

- Implementation notes:
  - We’ll implement a per-query approach with a DSU (disjoint-set union) to efficiently skip used right elements.
  - We precompute p_eff[i] once for all i.
  - Use Python’s bisect_left to compute lower bounds.

### Code
```
import sys
from bisect import bisect_left

def solve():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    N = int(next(it))
    A = [int(next(it)) for _ in range(N)]
    Q = int(next(it))
    queries = []
    for _ in range(Q):
        L = int(next(it)); R = int(next(it))
        queries.append((L-1, R-1))  # convert to 0-based indices

    # Precompute p_eff[i] = max(i+1, lower_bound(A, 2*A[i]))
    p_eff = [0]*N
    for i in range(N):
        two_ai = 2 * A[i]
        j0 = bisect_left(A, two_ai)  # first index with A[j0] >= 2*A[i]
        if j0 <= i:
            j0 = i + 1
        p_eff[i] = j0

    out_lines = []
    for L, R in queries:
        m = R - L + 1
        if m < 2:
            out_lines.append("0")
            continue

        # Disjoint-set union (DSU) to track next available right positions
        # We only need DSU for indices in [L, R] (rights). We'll map k in [L..R] to k-L in DSU.
        size = m + 1  # includes sentinel at R+1
        parent = list(range(size))

        def find(x):
            # path compression
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def use(pos):
            # mark position pos (mapped index pos-L) as used and union with next
            x = pos - L  # DSU index
            # union with next
            parent[x] = find(x + 1)

        # used array for both sides (we'll need to know if an index has already been used as left)
        used = [False] * (N)

        ans = 0
        for i in range(L, R):
            if used[i]:
                continue
            # earliest possible right partner for i
            jstart = p_eff[i]
            if jstart < L:
                jstart = L
            if jstart > R:
                continue
            # find the first unused right >= jstart
            jdsu = find(jstart - L)
            j = jstart if jdsu == (jstart - L) else (jstart)  # ensure we have a valid j; we'll recompute properly below
            # The above approach needs exact mapping; simpler compute via:
            x = jstart
            fj = find(x - L)
            j = x
            # If the DSU find(y) returns y, it means y is free; but our representation uses 0..m
            # We'll implement a direct check: find(jstart - L) gives the DSU index of next free, but we must convert back to array index
            idx = find(jstart - L)
            if idx > R - L:
                # no free right in [jstart..R]
                continue
            j = L + idx
            if j <= R:
                # We have a pair (i, j)
                used[i] = True
                used[j] = True
                use(j)  # mark right j as used
                ans += 1
        out_lines.append(str(ans))

    print("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```
