### Step-by-step reasoning
- The problem describes inserting i into A so that it becomes the Pi-th element from the start. This is equivalent to performing an insertion at position Pi in a dynamically growing array.
- A direct forward simulation would be O(N^2). To handle N up to 5e5 efficiently, process the construction in reverse.
- Observation: After all operations, there are exactly i empty slots when placing i in reverse (since the final array has N positions and we place N, N-1, ..., 1 successively). The Pi-th element from the beginning in the current (partial) array corresponds to placing i into the Pi-th empty slot of the final array.
- Use a data structure to support:
  - tracking which slots are still empty,
  - finding the k-th empty slot quickly,
  - marking a slot as filled.
  A Fenwick (Binary Indexed) Tree (BIT) over an array of size N is perfect for this:
  - We store 1 for an empty slot and 0 for a filled slot.
  - We can query the k-th empty slot by performing a “kth order statistic” operation via binary lifting on the Fenwick tree.
  - After placing i into a position pos, we update that position by -1 to mark it as filled.
- Algorithm:
  - Initialize a Fenwick tree with N positions, all 1 (empty).
  - For i from N down to 1:
    - k = P_i
    - pos = kth(k) in the Fenwick tree (the index of the k-th empty slot)
    - A_final[pos] = i
    - update Fenwick at pos by -1 (slot becomes filled)
  - Output A_final from index 1 to N.
- Corner cases:
  - N = 1, P_1 = 1: returns [1].
  - All P_i = 1: final A is [N, N-1, ..., 1].
  - Time complexity is O(N log N) and memory O(N), suitable for N up to 5e5.
- Output format: print A_1 A_2 ... A_N separated by spaces and ending with a newline.

import sys

class Fenwick:
    def __init__(self, n: int):
        self.n = n
        self.bit = [0] * (n + 1)
        # Initialize with all slots empty: bit[i] = i & -i
        for i in range(1, n + 1):
            self.bit[i] = i & -i

    def add(self, i: int, delta: int):
        while i <= self.n:
            self.bit[i] += delta
            i += i & -i

    def kth(self, k: int) -> int:
        # Find the smallest index pos such that prefix sum >= k
        idx = 0
        bit_mask = 1 << (self.n.bit_length())  # start with a power of two >= n
        while bit_mask:
            t = idx + bit_mask
            if t <= self.n and self.bit[t] < k:
                idx = t
                k -= self.bit[t]
            bit_mask >>= 1
        return idx + 1

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n = data[0]
    p = data[1:1 + n]

    ft = Fenwick(n)
    ans = [0] * (n + 1)  # 1-indexed

    for i in range(n, 0, -1):
        k = p[i - 1]
        pos = ft.kth(k)
        ans[pos] = i
        ft.add(pos, -1)  # mark as filled

    sys.stdout.write(' '.join(str(ans[i]) for i in range(1, n + 1)))
    sys.stdout.write('\n')

if __name__ == "__main__":
    main()
