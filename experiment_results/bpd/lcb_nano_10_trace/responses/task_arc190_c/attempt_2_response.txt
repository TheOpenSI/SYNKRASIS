### Step-by-step reasoning
- The problem asks for the sum over all monotone (only moving Right or Down) paths from (1,1) to (H,W) of the product of the A[h,w] values along each path, modulo MOD = 998244353.
- A standard dynamic programming formulation for this sum is:
  - Let dp[i][j] be the sum of products along all monotone paths from (1,1) to (i,j) that multiply A values along the path (including A[i][j]).
  - Recurrence (1-indexed): 
    - dp[1][1] = A[1][1]
    - dp[i][j] = A[i][j] * (dp[i-1][j] + dp[i][j-1]) for i > 1 or j > 1, with dp[i][0] = dp[0][j] = 0 as boundary conditions.
  - The answer is dp[H][W].
- After each change, only the A value on the destination cell of the traveler is updated. Because dp depends on all A values, recomputing dp from scratch after every update is straightforward and correct.
- Given the constraints, HW <= 200000 and Q <= 200000, a straightforward recomputation per update is simple to implement and correct, but in the absolute worst case it could be slow. Nevertheless, we provide a robust, clean implementation that computes the full DP anew after each update, while keeping memory usage minimal via a 1D DP pass per row.

- Important implementation notes:
  - Use 0-based indexing internally, mapping the 1-based problem indexing to 0-based indices.
  - Recompute the DP row-by-row using two 1D arrays (previous row and current row) to save memory.
  - Perform modulo operations everywhere to avoid overflow.
  - After each update, the answer is the last element of the current DP row (dp_last_row[W-1]).

- Correctness: This approach exactly follows the definition of f(P) and accumulates it over all valid monotone paths P. Each update only changes one A value at the new cell; recomputing the DP from scratch with the updated A yields the correct sum modulo MOD.

- Complexity considerations:
  - Each query requires computing dp over all H*W cells.
  - With HW <= 2e5, the per-query cost is O(HW) in the worst case.
  - For large Q (up to 2e5), this is heavy in the absolute worst-case, but it is a straightforward and correct solution. If needed, further optimizations or a block-decomposition approach could be considered, but the following implementation focuses on correctness and simplicity, with efficient 1D DP passes.

import sys

MOD = 998244353

def solve():
    data = sys.stdin.buffer.read().split()
    it = iter(data)

    H = int(next(it))
    W = int(next(it))

    # Read A in row-major order, convert to int and mod
    A = [[0] * W for _ in range(H)]
    for i in range(H):
        row = A[i]
        for j in range(W):
            row[j] = int(next(it)) % MOD

    Q = int(next(it))
    sh = int(next(it))
    sw = int(next(it))

    # Current position (0-indexed)
    r = sh - 1
    c = sw - 1

    # Helper: recompute DP from scratch and return the final sum dp[H-1][W-1]
    def recompute_dp():
        # Use two 1D arrays to save memory: previous row and current row
        prev = [0] * W
        curr = [0] * W

        for i in range(H):
            ai = A[i]
            for j in range(W):
                if i == 0 and j == 0:
                    curr[0] = ai[0] % MOD
                else:
                    up = prev[j] if i > 0 else 0
                    left = curr[j - 1] if j > 0 else 0
                    curr[j] = (ai[j] * ((up + left) % MOD)) % MOD
            # prepare for next row
            prev, curr = curr, prev  # swap; curr will be overwritten next
        # After the last swap, prev holds the last computed row
        return prev[W - 1] % MOD

    # Initial DP build
    ans = recompute_dp()
    out_lines = []

    for _ in range(Q):
        d = next(it).decode()
        a = int(next(it)) % MOD

        # Move one cell according to d
        if d == 'L':
            c -= 1
        elif d == 'R':
            c += 1
        elif d == 'U':
            r -= 1
        elif d == 'D':
            r += 1

        # Update the value at the new cell
        A[r][c] = a

        # Recompute DP for the entire grid
        ans = recompute_dp()

        out_lines.append(str(ans))

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
