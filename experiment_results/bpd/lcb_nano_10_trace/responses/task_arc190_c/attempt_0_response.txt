### Step-by-step reasoning
- We are given an H x W grid with non-negative integers A[h,w]. A path P from (1,1) to (H,W) that moves only right or down has M = H+W-1 cells, and f(P) is the product of A along the path. We need the sum of f(P) over all such paths, modulo 998244353.
- A standard dynamic programming formulation gives:
  - Let G[h,w] be the sum of products over all paths from (1,1) to (h,w) (including A[h,w] itself in the product).
  - Then G[1,1] = A[1,1], and for h,w > 1: G[h,w] = A[h,w] * ( G[h-1,w] + G[h,w-1] ), with out-of-bounds treated as 0.
  - The required answer for the grid is F = G[H,W].
- The problem then adds updates: the traveler moves to an adjacent cell and sets A[h,w] to a new value a_i. After each change, we must output the new sum over all paths.
- A straightforward way is to recompute the DP G after each update: O(HW) time per update. Since HW <= 200000, this is feasible for small-to-moderate test sizes, though in the worst case it might be heavy. Given the constraints and for correctness, we implement this direct approach:
  - Maintain A as a 2D list.
  - Each time we update A[x,y], recompute the entire G grid using the recurrence above, then output G[H-1][W-1].
- We also need to track the current position of the traveler; each update moves him by one cell in the given direction, then we set the value of the new cell to a_i.
- Edge cases:
  - A values can be 0; DP handles zeros naturally.
  - The initial position and movement are guaranteed to be valid (as per problem statement).
  - All arithmetic is modulo 998244353.

Note: This solution uses a straightforward recomputation per update. It is correct and simple to implement. It will be efficient enough if test data does not push the extreme worst-case pattern for Q and HW.

import sys

MOD = 998244353

def solve():
    data = sys.stdin.buffer.read().split()
    it = iter(data)

    H = int(next(it))
    W = int(next(it))

    A = [[0]*W for _ in range(H)]
    for i in range(H):
        for j in range(W):
            A[i][j] = int(next(it))

    Q = int(next(it))
    sh = int(next(it))
    sw = int(next(it))

    # current position (0-indexed)
    r = sh - 1
    c = sw - 1

    # Precompute initial G
    G = [[0]*W for _ in range(H)]
    for i in range(H):
        for j in range(W):
            up = G[i-1][j] if i > 0 else 0
            left = G[i][j-1] if j > 0 else 0
            G[i][j] = (A[i][j] * ((up + left) % MOD)) % MOD

    out = []
    # Function to recompute G after an update
    def recompute_G():
        for i in range(H):
            gi = G[i]
            Ai = A[i]
            for j in range(W):
                up = G[i-1][j] if i > 0 else 0
                left = gi[j-1] if j > 0 else 0
                gi[j] = (Ai[j] * ((up + left) % MOD)) % MOD

    # We will recompute G after every update (as described)
    for _ in range(Q):
        d = next(it).decode()
        a = int(next(it))

        # Move one cell according to d
        if d == 'L':
            c -= 1
        elif d == 'R':
            c += 1
        elif d == 'U':
            r -= 1
        elif d == 'D':
            r += 1
        else:
            # Should not happen
            pass

        # Update the value of A at new position
        A[r][c] = a

        # Recompute G for the whole grid
        recompute_G()

        # Answer is G[H-1][W-1]
        out.append(str(G[H-1][W-1] % MOD))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
