### Step-by-step reasoning
- Parse S as a rooted tree T by matching parentheses. Create a virtual root 0. Each pair of matching parentheses becomes a node; the children of a node are the top-level VPS blocks directly inside that pair. The top-level blocks of S become the children of root 0.
- For a node v, define:
  - E(v): the encoding of the subtree rooted at v in the natural orientation: "(" + E(child1) + E(child2) + ... + E(childk) + ")".
  - Rev(v): the encoding after mirroring the subtree: "(" + Rev(childk) + Rev(childk-1) + ... + Rev(child1) + ")".
- An operation consists of choosing a contiguous substring that is a VPS and reversing it with the provided rule. Such a substring corresponds exactly to E(v) for some node v in the current tree, and the result is Rev(v) for that v.
- Key observation (independence): If E(v) != Rev(v), then mirroring the subtree rooted at v changes the final string in a way that cannot be undone by mirroring other subtrees. Therefore, each node with E(v) != Rev(v) contributes a binary choice (mirror or not) that yields a distinct final string, independently of choices on other nodes.
- If E(v) == Rev(v), mirroring v has no effect on the final string, so such nodes do not contribute to the count.
- Consequently, the number of distinct final strings equals 2^K modulo 998244353, where K is the number of nodes v (including the virtual root) such that E(v) != Rev(v).
- Implementation plan:
  - Build the tree T from S.
  - Compute, bottom-up, for every node v both E(v) and Rev(v) encodings using robust polynomial hashing (two independent moduli) to avoid storing long strings. Track their lengths as well to ensure correct concatenation.
  - Count K as the number of nodes where E(v) and Rev(v) differ (by comparing both hashes and lengths).
  - Output 2^K mod 998244353.

Notes:
- We include the virtual root 0, since reversing the entire string is allowed (the root’s operation corresponds to taking Rev(0)).
- We use double hashing to reduce collision risk. No external libraries are required.

import sys

def main():
    MOD_TARGET = 998244353

    data = sys.stdin.read().strip().split()
    N = int(data[0])
    S = data[1].strip()

    # Build tree: node 0 is virtual root
    # Each '(' creates a new node; its parent is current stack top (if any) else root
    children = [[]]  # index 0 is root
    stack = []

    for ch in S:
        if ch == '(':
            nid = len(children)
            children.append([])
            if stack:
                parent = stack[-1]
                children[parent].append(nid)
            else:
                children[0].append(nid)
            stack.append(nid)
        else:  # ')'
            stack.pop()

    M = len(children) - 1  # number of actual nodes (excluding root)

    # Precompute postorder (iterative)
    order = []
    st = [0]
    while st:
        v = st.pop()
        order.append(v)
        for c in children[v]:
            st.append(c)

    # Hashing setup
    MOD1 = 1000000007
    MOD2 = 1000000009
    BASE1 = 911382323
    BASE2 = 972663749
    OPEN_C = 1
    CLOSE_C = 2

    maxLen = N + 5
    pow1 = [1] * (maxLen + 1)
    pow2 = [1] * (maxLen + 1)
    for i in range(1, maxLen + 1):
        pow1[i] = (pow1[i-1] * BASE1) % MOD1
        pow2[i] = (pow2[i-1] * BASE2) % MOD2

    # Buffers per node
    norm_h1 = [0] * (M + 1)
    norm_h2 = [0] * (M + 1)
    rev_h1  = [0] * (M + 1)
    rev_h2  = [0] * (M + 1)
    lenE = [0] * (M + 1)
    lenR = [0] * (M + 1)

    # Helpers for encoding
    def code_open():
        return OPEN_C
    def code_close():
        return CLOSE_C

    # Process in postorder
    for v in reversed(order):
        if v == 0:
            # E(0): concatenation of E(child) in order (no extra outer parentheses)
            h1 = 0
            h2 = 0
            L = 0
            for c in children[v]:
                h1 = (h1 * pow1[lenE[c]] + norm_h1[c]) % MOD1
                h2 = (h2 * pow2[lenE[c]] + norm_h2[c]) % MOD2
                L += lenE[c]
            norm_h1[v] = h1
            norm_h2[v] = h2
            lenE[v] = L

            # RevEnc(0): RevEnc(child_k) + ... + RevEnc(child_1)
            h1 = 0
            h2 = 0
            L = 0
            for c in reversed(children[v]):
                h1 = (h1 * pow1[lenR[c]] + rev_h1[c]) % MOD1
                h2 = (h2 * pow2[lenR[c]] + rev_h2[c]) % MOD2
                L += lenR[c]
            rev_h1[v] = h1
            rev_h2[v] = h2
            lenR[v] = L
        else:
            k = len(children[v])
            if k == 0:
                # leaf: E(v) = "()", Rev(v) = "()"
                h1 = code_open()
                h1 = (h1 * BASE1 + code_close()) % MOD1
                L = 2
                norm_h1[v] = h1

                h2 = code_open()
                h2 = (h2 * BASE2 + code_close()) % MOD2
                norm_h2[v] = h2
                lenE[v] = L

                rev_h1[v] = norm_h1[v]
                rev_h2[v] = norm_h2[v]
                lenR[v] = L
            else:
                # E(v) = "(" + E(c1) + E(c2) + ... + E(ck) + ")"
                h1 = code_open()
                h2 = code_open()
                L1 = 1
                L2 = 1
                for c in children[v]:
                    h1 = (h1 * pow1[lenE[c]] + norm_h1[c]) % MOD1
                    h2 = (h2 * pow2[lenE[c]] + norm_h2[c]) % MOD2
                    L1 += lenE[c]
                    L2 += lenR[c]
                h1 = (h1 * BASE1 + code_close()) % MOD1
                h2 = (h2 * BASE2 + code_close()) % MOD2
                L1 += 1
                L2 += 1
                norm_h1[v] = h1
                norm_h2[v] = h2
                lenE[v] = L1  # L1 == L2

                # RevEnc(v) = "(" + RevEnc(ck) + RevEnc(ck-1) + ... + RevEnc(c1) + ")"
                h1 = code_open()
                h2 = code_open()
                L1 = 1
                L2 = 1
                for c in reversed(children[v]):
                    h1 = (h1 * pow1[lenR[c]] + rev_h1[c]) % MOD1
                    h2 = (h2 * pow2[lenR[c]] + rev_h2[c]) % MOD2
                    L1 += lenR[c]
                    L2 += lenR[c]
                h1 = (h1 * BASE1 + code_close()) % MOD1
                h2 = (h2 * BASE2 + code_close()) % MOD2
                L1 += 1
                L2 += 1
                rev_h1[v] = h1
                rev_h2[v] = h2
                lenR[v] = L1

    # Count non-symmetric nodes (including root 0)
    count = 0
    for v in range(0, M + 1):
        if not (norm_h1[v] == rev_h1[v] and norm_h2[v] == rev_h2[v] and lenE[v] == lenR[v]):
            count += 1

    # Answer
    ans = pow(2, count, MOD_TARGET)
    print(ans)

if __name__ == "__main__":
    main()
