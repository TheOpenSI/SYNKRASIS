### Step-by-step reasoning
- Interpret the string S as a rooted ordered tree of matching parentheses.
  - Each pair of matching parentheses corresponds to a node.
  - The children of a node are the pairs directly contained inside it, in left-to-right order.
  - There is a virtual root (node 0) whose children are the top-level pairs in S.
- The allowed operation: reverse a contiguous VPS substring and swap parentheses inside that substring.
  - If you take a subtree rooted at some node, reversing the entire substring corresponding to that subtree yields the “reverse-encoded” version of that subtree.
  - For any node v, define:
    - E(v): the encoding of the subtree rooted at v in the original orientation.
    - Rev(v): the encoding of the same subtree after applying the reverse-swap operation to the whole subtree (i.e., reverse_swap(E(v))).
  - Recurrences:
    - For a node v > 0 with k children c1, c2, ..., ck:
      - E(v) = "(" + E(c1) + E(c2) + ... + E(ck) + ")"
      - Rev(v) = "(" + Rev(ck) + Rev(ck-1) + ... + Rev(c1) + ")"
    - For a leaf (k = 0): E(v) = "()" and Rev(v) = "()".
    - For the virtual root 0 (which has no surrounding parentheses):
      - E(0) = E(c1) + E(c2) + ... + E(ck)
      - Rev(0) = Rev(ck) + Rev(ck-1) + ... + Rev(c1)
- The key observation: a non-symmetric subtree is one where E(v) != Rev(v). Each such subtree contributes a binary choice (whether we apply the reversal on that subtree or not), and the total number of distinct strings reachable is 2 raised to the number of non-symmetric subtrees (including the root 0).
- We don’t want to build actual strings (could be O(N^2)); instead, we compute hashes for E(v) and Rev(v) to compare equality efficiently.
  - Use double hashing to reduce collision chances.
  - While concatenating, use base powers to efficiently combine hashes.
  - For the root 0, the encodings exclude outer parentheses, while for v > 0 they include a pair of parentheses around their children encodings.
- Algorithm outline:
  1. Build the tree from S using a stack:
     - Create node IDs for each '('; attach as a child to the current top of the stack, or to the virtual root 0 if the stack is empty.
     - Pop when encountering ')'.
     - After processing, node 0’s children are the top-level VPS blocks.
  2. Do an iterative post-order traversal to compute for every node:
     - len_E[v], norm hash of E(v)
     - len_rev[v], Rev hash of Rev(v)
     - For root 0, treat len_E[0], hash as concatenation of its children in order; Rev(0) is concatenation of children’ Rev in reverse order.
  3. Count how many nodes v (including root 0) have E(v) != Rev(v) by comparing both hashes (and lengths as safety).
  4. Answer is 2^count modulo 998244353.
- Edge cases:
  - A chain of nesting (each node has one child) yields all subtrees symmetric; answer is 1.
  - A root with many top-level blocks yields non-symmetric root often, giving multiple possibilities.
  - N is up to 5000; the approach is O(N) in time and memory with small constants.

None

import sys

def main():
    MOD_TARGET = 998244353

    data = sys.stdin.read().strip().split()
    N = int(data[0])
    S = data[1].strip()

    # Build tree: node 0 is virtual root
    # Each '(' creates a new node; its parent is current stack top (if any) else root
    children = [[]]  # index 0 is root
    stack = []

    for ch in S:
        if ch == '(':
            nid = len(children)
            children.append([])
            if stack:
                parent = stack[-1]
                children[parent].append(nid)
            else:
                children[0].append(nid)
            stack.append(nid)
        else:  # ')'
            stack.pop()

    M = len(children) - 1  # number of actual nodes (excluding root)

    # Precompute postorder (iterative)
    order = []
    st = [0]
    while st:
        v = st.pop()
        order.append(v)
        for c in children[v]:
            st.append(c)

    # Hashing setup
    MOD1 = 1000000007
    MOD2 = 1000000009
    BASE1 = 911382323
    BASE2 = 972663749
    OPEN_C = 1
    CLOSE_C = 2

    maxLen = N + 5
    pow1 = [1] * (maxLen + 1)
    pow2 = [1] * (maxLen + 1)
    for i in range(1, maxLen + 1):
        pow1[i] = (pow1[i-1] * BASE1) % MOD1
        pow2[i] = (pow2[i-1] * BASE2) % MOD2

    # Buffers per node
    norm_h1 = [0] * (M + 1)
    norm_h2 = [0] * (M + 1)
    rev_h1  = [0] * (M + 1)
    rev_h2  = [0] * (M + 1)
    lenE = [0] * (M + 1)
    lenR = [0] * (M + 1)

    # Helper to get code
    def code_open():
        return OPEN_C
    def code_close():
        return CLOSE_C

    # Process in postorder
    for v in reversed(order):
        if v == 0:
            # E(0): concatenation of E(child) in order
            h1 = 0
            h2 = 0
            L = 0
            for c in children[v]:
                h1 = (h1 * pow1[lenE[c]] + norm_h1[c]) % MOD1
                h2 = (h2 * pow2[lenE[c]] + norm_h2[c]) % MOD2
                L += lenE[c]
            norm_h1[v] = h1
            norm_h2[v] = h2
            lenE[v] = L

            # RevEnc(0): RevEnc(child_k) + ... + RevEnc(child_1)
            h1 = 0
            h2 = 0
            L = 0
            for c in reversed(children[v]):
                h1 = (h1 * pow1[lenR[c]] + rev_h1[c]) % MOD1
                h2 = (h2 * pow2[lenR[c]] + rev_h2[c]) % MOD2
                L += lenR[c]
            rev_h1[v] = h1
            rev_h2[v] = h2
            lenR[v] = L
        else:
            k = len(children[v])
            if k == 0:
                # leaf: E(v) = "()", Rev(v) = "()"
                h1 = code_open()
                h1 = (h1 * BASE1 + code_close()) % MOD1
                L = 2
                norm_h1[v] = h1

                h2 = code_open()
                h2 = (h2 * BASE2 + code_close()) % MOD2
                norm_h2[v] = h2
                lenE[v] = L

                rev_h1[v] = norm_h1[v]
                rev_h2[v] = norm_h2[v]
                lenR[v] = L
            else:
                # E(v) = "(" + E(c1) + E(c2) + ... + E(ck) + ")"
                h1 = code_open()
                h2 = code_open()
                L1 = 1
                L2 = 1
                for c in children[v]:
                    h1 = (h1 * pow1[lenE[c]] + norm_h1[c]) % MOD1
                    h2 = (h2 * pow2[lenE[c]] + norm_h2[c]) % MOD2
                    L1 += lenE[c]
                    L2 += lenE[c]
                h1 = (h1 * BASE1 + code_close()) % MOD1
                h2 = (h2 * BASE2 + code_close()) % MOD2
                L1 += 1
                L2 += 1
                norm_h1[v] = h1
                norm_h2[v] = h2
                lenE[v] = L1  # L1 == L2

                # RevEnc(v) = "(" + RevEnc(ck) + RevEnc(ck-1) + ... + RevEnc(c1) + ")"
                h1 = code_open()
                h2 = code_open()
                L1 = 1
                L2 = 1
                for c in reversed(children[v]):
                    h1 = (h1 * pow1[lenR[c]] + rev_h1[c]) % MOD1
                    h2 = (h2 * pow2[lenR[c]] + rev_h2[c]) % MOD2
                    L1 += lenR[c]
                    L2 += lenR[c]
                h1 = (h1 * BASE1 + code_close()) % MOD1
                h2 = (h2 * BASE2 + code_close()) % MOD2
                L1 += 1
                L2 += 1
                rev_h1[v] = h1
                rev_h2[v] = h2
                lenR[v] = L1  # L1 == L2

    # Count non-symmetric nodes (including root 0)
    count = 0
    for v in range(0, M + 1):
        if not (norm_h1[v] == rev_h1[v] and norm_h2[v] == rev_h2[v] and lenE[v] == lenR[v]):
            count += 1

    # Answer
    ans = pow(2, count, MOD_TARGET)
    print(ans)

if __name__ == "__main__":
    main()
