### Step-by-step reasoning
- We need the sum over all subarrays with length at most k of (min(subarray) + max(subarray)).
- This can be separated into two independent sums: sum of minimums over all subarrays with length <= k, plus sum of maximums over all subarrays with length <= k.
- For sum of minimums, use the standard per-element contribution technique with a specific tie-breaking to avoid double counting in the presence of duplicates:
  - For minima, determine for each index i:
    - Lmin = previous index with value strictly less than nums[i] + 1 (or 0 if none).
    - Rmax = next index with value less than or equal to nums[i] minus 1 (or n-1 if none).
  - The subarrays where i is the designated minimum are those with L in [Lmin, i] and R in [i, Rmax].
  - We must count only those with length <= k, i.e., R - L + 1 <= k.
  - For fixed L, valid R are in [i, min(Rmax, L + k - 1)]. Summing over L in O(1) per i would require a closed-form derivation.
  - Derive a closed form:
    - If i > Rmax, count is 0.
    - Let A = Lmin, B = i, P = Rmax - k + 1.
    - Sum over L in [A, min(B, P)] of (L + k - i) plus sum over L in [max(A, P+1), i] of (Rmax - i + 1).
    - This yields an O(1) formula using arithmetic sums for each i.
- Do the analogous computation for maxima:
  - Use previous strictly greater and next greater or equal to partition subarrays for which i is the designated maximum.
  - Specifically:
    - Lmax = prev_greater[i] + 1
    - Rmax2 = next_greater_equal[i] - 1
  - Same length-filtered counting as for minima.
- Total answer = sum over i of nums[i] * count_min_i + sum over i of nums[i] * count_max_i.
- Complexity: O(n) time, O(n) memory. Handles duplicates properly due to the chosen tie-breaking.

Edge cases:
- Duplicates are handled by the chosen boundaries (prev_less with next_less_equal for minima; prev_greater with next_greater_equal for maxima).
- If i > Rmax for a given i, contribution is zero.
- k up to n is supported; the derived formulas remain valid.
- Negative numbers are handled naturally due to integer arithmetic.

None

```python
from typing import List

class Solution:
    def minMaxSubarraySum(self, nums: List[int], k: int) -> int:
        n = len(nums)

        # Previous strictly less for minima
        prev_less = [-1] * n
        stack = []
        for i in range(n):
            while stack and nums[stack[-1]] >= nums[i]:
                stack.pop()
            prev_less[i] = stack[-1] if stack else -1
            stack.append(i)

        # Next less than or equal for minima
        next_less_equal = [n] * n
        stack = []
        for i in range(n):
            while stack and nums[stack[-1]] >= nums[i]:
                next_less_equal[stack.pop()] = i
            stack.append(i)

        # Previous strictly greater for maxima
        prev_greater = [-1] * n
        stack = []
        for i in range(n):
            while stack and nums[stack[-1]] <= nums[i]:
                stack.pop()
            prev_greater[i] = stack[-1] if stack else -1
            stack.append(i)

        # Next greater than or equal for maxima
        next_greater_equal = [n] * n
        stack = []
        for i in range(n):
            while stack and nums[stack[-1]] <= nums[i]:
                next_greater_equal[stack.pop()] = i
            stack.append(i)

        total_min = 0
        total_max = 0

        # Contributions for minima
        for i in range(n):
            Lmin = prev_less[i] + 1
            Rmax = next_less_equal[i] - 1
            if i > Rmax:
                continue
            A = Lmin
            B = i
            P = Rmax - k + 1

            sum1 = 0
            L1 = min(B, P)
            if L1 >= A:
                Count1 = L1 - A + 1
                SumL = (A + L1) * Count1 // 2
                sum1 = SumL + Count1 * (k - i)

            sum2 = 0
            L2start = max(A, P + 1)
            if L2start <= i:
                Count2 = i - L2start + 1
                sum2 = Count2 * (Rmax - i + 1)

            count_i = sum1 + sum2
            total_min += nums[i] * count_i

        # Contributions for maxima
        for i in range(n):
            Lmin = prev_greater[i] + 1
            Rmax = next_greater_equal[i] - 1
            if i > Rmax:
                continue
            A = Lmin
            B = i
            P = Rmax - k + 1

            sum1 = 0
            L1 = min(B, P)
            if L1 >= A:
                Count1 = L1 - A + 1
                SumL = (A + L1) * Count1 // 2
                sum1 = SumL + Count1 * (k - i)

            sum2 = 0
            L2start = max(A, P + 1)
            if L2start <= i:
                Count2 = i - L2start + 1
                sum2 = Count2 * (Rmax - i + 1)

            count_i = sum1 + sum2
            total_max += nums[i] * count_i

        return total_min + total_max
```
