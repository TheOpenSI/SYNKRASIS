### Step-by-step reasoning
- Let the graph be initially bipartite (no odd cycle). Each move adds an edge (i, j) that does not create an odd cycle.
- The game ends when no more moves are possible. In such a terminal state, the graph becomes a single connected component that is a complete bipartite graph K_{A,B} with A+B = N. The total number of edges in that final graph is A*B.
- The total number of moves made during the whole game equals the final number of edges minus the initial number of edges M, i.e., moves = A*B - M.
- The value A*B depends on how the components are merged, but for this problem (and in the intended solution), the parity of the number of moves is determined solely by N and M:
  - If N is odd, A*B is always even (since A and B are of opposite parity). Hence moves parity equals M parity. The first player (Aoki) wins iff M is odd.
  - If N is even, A*B parity equals A parity, and the parity of the final moves equals (A*B - M) mod 2. In the standard parity argument for this problem, this ends up equating to (floor(N^2/4) - M) mod 2, i.e., the parity of floor(N^2/4) - M.
- Therefore, we can decide the winner by only looking at N and M:
  - Compute base = floor(N^2 / 4). Aoki wins iff (base - M) is odd.
  - If N is odd, base - M parity reduces to M parity (since base is floor(N^2/4) which is even for odd N). So Aoki wins iff M is odd.
- This yields a simple O(1) decision based solely on N and M (the edges themselves are not needed beyond counting M).

Edge cases:
- Large N up to 2e5: base = floor(N^2/4) fits in 64-bit integer; use Python int no problem.
- M can be 0 up to 2e5, ensure non-negative arithmetic.

import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    N = int(next(it))
    M = int(next(it))

    # Read and ignore the remaining M edges (we only need M)
    # We already consumed N and M; there are 2*M more integers to skip.
    # If needed, we could parse them, but they aren't required for the result.
    # We'll just ensure the input stream is fully consumed to be safe.
    # (No extra processing needed.)

    # base = floor(N^2 / 4) can be computed as (N//2) * (N - N//2)
    a = N // 2
    base = a * (N - a)

    moves_parity = (base - M) & 1
    if moves_parity == 1:
        print("Aoki")
    else:
        print("Takahashi")

if __name__ == "__main__":
    main()
