### Step-by-step reasoning
- Read N and the sequence A of length N from standard input.
- Check whether the sequence is strictly increasing by verifying A[i] < A[i+1] for every i from 0 to N-2.
- If any pair violates the strict increase (A[i] >= A[i+1]), the answer is "No".
- If all adjacent pairs satisfy the inequality, the answer is "Yes".
- Edge cases:
  - N is at least 2, so there is at least one comparison.
  - The first violation can occur early (e.g., A1 >= A2) or later.
  - The input may contain trailing whitespace or extra numbers; only the first N numbers after N are considered.
- Complexity: O(N) time, O(1) extra space (besides input storage).

### Requirements
None

### Code
```
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    N = int(data[0])
    A = list(map(int, data[1:1+N]))
    is_strictly_increasing = all(A[i] < A[i+1] for i in range(N - 1))
    print("Yes" if is_strictly_increasing else "No")

if __name__ == "__main__":
    main()
```
