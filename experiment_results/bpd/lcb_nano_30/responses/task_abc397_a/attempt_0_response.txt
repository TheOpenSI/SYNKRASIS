### Step-by-step reasoning
- We receive a single numeric input X representing body temperature in Celsius with one decimal place.
- Classification rules:
  - If X >= 38.0 → 1 (High fever)
  - Else if X >= 37.5 → 2 (Fever)
  - Else → 3 (Normal)
- To avoid floating-point precision issues around the exact boundaries (37.5 and 38.0), compare using exact decimal arithmetic.
- Approach:
  - Read the input as a string.
  - Convert to Decimal for precise comparisons.
  - Apply the thresholds in order and output the corresponding integer.
- Edge cases:
  - Exactly 38.0 → 1
  - Exactly 37.5 → 2
  - Exactly 37.4 → 3
  - Values within [30, 50] as per constraints
- This approach handles all boundary values correctly and avoids floating-point pitfalls.

### Requirements
None

### Code
```
import sys
from decimal import Decimal

def main():
    s = sys.stdin.readline().strip()
    if not s:
        return
    x = Decimal(s)

    if x >= Decimal('38.0'):
        print(1)
    elif x >= Decimal('37.5'):
        print(2)
    else:
        print(3)

if __name__ == "__main__":
    main()
```
