### Step-by-step reasoning
- We are summing f(P) over all permutations P of 1..N, where f(P) is the concatenation of A_i in the order of the permutation. If A_i has d(A_i) digits, then in the final number A_i is multiplied by 10^{sum of digits of all following A_j}.
- Let w(j) = 10^{d(j)}. For a fixed permutation, the contribution of A_i at position i is A_i multiplied by the product of w(j) for all j after i.

- By linearity and symmetry, for a fixed i and a fixed element x in position i, the set of elements after i is a random subset T of size N-i from the remaining N-1 numbers. Therefore the total contribution for a fixed i and x is x times (i-1)!*(N-i)! times the sum over all T of size N-i of prod_{j in T} w(j).

- Summing over x, we get a formula that depends only on the elementary symmetric sums of the weights w(j) and the sums of indices:
  - Let e_k be the k-th elementary symmetric sum of the multiset {w(j)} for j=1..N:
    e_k = sum over all T subset of [N], |T|=k, prod_{j in T} w(j).
  - Let F_k = sum_{T, |T|=k} (prod_{j in T} w(j)) * (sum_{j in T} j).
  - Then S_i, the inner sum for fixed i, equals S1 * e_k - F_k, where k = N - i and S1 = sum_{j=1}^N j = N(N+1)/2.
  - F_k can be expressed in terms of e_m and S_r = sum_{j=1}^N j * (w(j))^r via a convolution:
    F_k = sum_{r=1}^k (-1)^{r-1} e_{k-r} * S_r.
  - Therefore, the total answer is:
    ans = sum_{k=0}^{N-1} (N-k-1)! * k! * ( S1 * e_k - F_k ) mod M, where M = 998244353.

- Observations to implement efficiently:
  - w(j) only depends on the number of digits of j. Group numbers by digit length d. For numbers with d digits, w(j) = 10^d.
  - e_k is the coefficient of t^k in E(t) = ∏_{groups g} (1 + W_g t)^{cnt_g}, where W_g = 10^d and cnt_g is how many numbers have d digits.
  - Since there are only a few groups (d up to 6 for N ≤ 2e5), we can compute E(t) by multiplying the polynomials P_g(t) = ∑_{k=0}^{cnt_g} C(cnt_g, k) * (W_g)^k * t^k using NTT-based polynomial multiplication.
  - S_r can be computed group-by-group: S_r = sum_d (W_d^r * sumIdx_d), where sumIdx_d is the sum of all indices j with d(j) = d (e.g., 1..9, 10..99, etc.). We can compute S_r for all r = 1..N in O(6*N) by iteratively multiplying by W_d.

- After obtaining e_k for k=0..N and S_r for r=1..N, we compute:
  - A_r = (-1)^{r-1} * S_r
  - F_k is the convolution of A with e: F = A * e, so F_k = sum_{r=1..k} A_r * e_{k-r}. We implement this as a convolution using NTT.
  - Finally compute the answer using the formula above with factorials (N-k-1)! and k!.

- Complexity:
  - Building e_k via NTT-based multiplication of up to 6 small polynomials: near O(N log N).
  - Computing F_k via one large convolution: O(N log N).
  - All other steps are linear or quadratic in the small number of digit groups.

Edge cases:
- N = 1: should return 1.
- Large N up to 2e5: algorithm uses NTT with arrays of size up to around 2^19 = 524,288, which is feasible in optimized Python (PyPy) with careful implementation.
- All computations modulo 998244353; use modular arithmetic everywhere.

None

import sys

MOD = 998244353
G = 3  # primitive root for MOD

# Fast modular arithmetic helpers
def modinv(a):
    return pow(a, MOD - 2, MOD)

# In-place iterative NTT
def ntt(a, invert):
    n = len(a)
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]

    length = 2
    while length <= n:
        wlen = pow(G, (MOD - 1) // length, MOD)
        if invert:
            wlen = modinv(wlen)
        for i in range(0, n, length):
            w = 1
            half = length >> 1
            for j in range(i, i + half):
                u = a[j]
                v = a[j + half] * w % MOD
                a[j] = (u + v) % MOD
                a[j + half] = (u - v) % MOD
                w = (w * wlen) % MOD
        length <<= 1

    if invert:
        inv_n = modinv(n)
        for i in range(n):
            a[i] = (a[i] * inv_n) % MOD

def multiply(a, b):
    if not a or not b:
        return []
    need = len(a) + len(b) - 1
    n = 1
    while n < need:
        n <<= 1
    fa = a[:] + [0] * (n - len(a))
    fb = b[:] + [0] * (n - len(b))
    ntt(fa, False)
    ntt(fb, False)
    for i in range(n):
        fa[i] = (fa[i] * fb[i]) % MOD
    ntt(fa, True)
    return fa[:need]


def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    N = int(data[0])

    # Precompute powers of 10 up to needed digits and sums per digit group
    pow10 = [1]
    for _ in range(1, 10):
        pow10.append((pow10[-1] * 10) % MOD)

    # Build digit groups: (d, count)
    groups = []
    d = 1
    while pow10[d - 1] <= N:
        lo = pow10[d - 1]
        hi = min(N, pow10[d] - 1)
        cnt = hi - lo + 1
        if cnt > 0:
            groups.append((d, cnt))
        d += 1
        if d >= len(pow10):  # safety
            break

    # Inverses for binomial coefficients
    maxN = N
    inv = [0] * (maxN + 1)
    inv[1] = 1
    for i in range(2, maxN + 1):
        inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

    # Build e(t) = prod_g (1 + W_g t)^{cnt_g}
    total_poly = [1]
    for d, cnt in groups:
        W = pow10[d] % MOD  # W_g
        # Build poly_g: coef[k] = C(cnt, k) * W^k
        C = 1  # C(cnt, 0)
        poly_g = [1]
        W_pow = 1
        for k in range(1, cnt + 1):
            # C(cnt, k) = C(cnt, k-1) * (cnt - k + 1) / k
            C = (C * (cnt - k + 1)) % MOD
            C = (C * inv[k]) % MOD
            W_pow = (W_pow * W) % MOD
            coef = (C * W_pow) % MOD
            poly_g.append(coef)
        total_poly = multiply(total_poly, poly_g)

    e = total_poly
    # Pad e to length N+1 if needed
    if len(e) < N + 1:
        e += [0] * (N + 1 - len(e))
    else:
        e = e[:N + 1]

    # Compute S_r for r=1..N: S_r = sum_j j * (w(j))^r
    # We group by digit length again
    S = [0] * (N + 1)  # S[0] unused
    for d, cnt in groups:
        lo = pow10[d - 1]
        hi = min(N, pow10[d] - 1)
        # sum of indices in [lo, hi]
        cnt_num = hi - lo + 1
        sumIdx = (lo + hi) * cnt_num // 2
        sumIdx %= MOD
        base = pow10[d] % MOD
        p = base
        for r in range(1, N + 1):
            S[r] = (S[r] + p * sumIdx) % MOD
            p = (p * base) % MOD

    # A_r = (-1)^{r-1} * S_r
    A = [0] * (N + 1)
    for r in range(1, N + 1):
        if r % 2 == 1:
            A[r] = S[r] % MOD
        else:
            A[r] = (MOD - (S[r] % MOD)) % MOD

    # F_k = (A * e)_k
    F_conv = multiply(A, e)
    # F_k defined for k in [0, N], F_k = F_conv[k]

    # S1 = sum 1..N = N*(N+1)/2
    S1 = (N * (N + 1) // 2) % MOD

    # factorials up to N
    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = (fact[i - 1] * i) % MOD

    # Final answer
    ans = 0
    for k in range(0, N):
        term = (fact[N - k - 1] * fact[k]) % MOD
        ek = e[k] if k < len(e) else 0
        Fk = F_conv[k] if k < len(F_conv) else 0
        val = (S1 * ek - Fk) % MOD
        ans = (ans + term * val) % MOD

    print(ans)

if __name__ == "__main__":
    main()
