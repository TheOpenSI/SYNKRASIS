### Step-by-step reasoning
- Each block stays in its column; blocks never move between columns.
- Within a column, blocks move downward when there is empty space below them, but removals happen only when the bottom row is fully occupied across all columns at the start of a time step.
- Let for each column x (1..W) k_x be the number of blocks in that column initially, and b_x be the minimum initial Y among blocks in that column (the lowest block’s initial height in that column).
- If any column has zero blocks initially (k_x = 0 for some x), then the bottom row can never be full, so no removals ever happen. All blocks always exist.
- If all k_x > 0, the bottom row will become full for the first time at time t = B, where B = max_x b_x. After that, removals occur at steps t = B, B+1, ..., B+m-1, where m = min_x k_x, decreasing every column’s height by 1 on each such step.
- During steps before B, no removals happen; all blocks exist.
- Let r_i be the rank of block i within its column when blocks are ordered by increasing Y in that column (1 = bottom-most, up to k_x).
- After s removal steps (s = 0, 1, ..., m), in every column, exactly s blocks are removed, namely those with rank r_i <= s. Therefore block i in its column i survives after s steps iff r_i > s.
- For a time T:
  - If any k_x = 0: answer is Always "Yes".
  - Else:
    - If T < B: s = 0, so block exists since r_i > 0 always.
    - If B <= T <= B + m - 1: s = T - B + 1; block exists iff r_i > s.
    - If T >= B + m: all removals finished; block exists iff r_i > m.

Algorithm plan
- Build per-column lists of blocks: for each x, store pairs (Y_i, block_index).
- If any column is empty, mark hasZero = True.
- If not hasZero:
  - Compute b_x_min for every column and B = max of those; compute m = min of k_x across columns.
  - For each column, sort by Y, assign ranks r_i to blocks in that column.
- For each query (T, A):
  - If hasZero: print Yes.
  - Else apply the above conditional using B, m, and r_A.

Edge cases
- All blocks exist forever if any column is empty initially.
- If all columns have blocks but some column has exactly 1 block, only one removal step occurs (m could be 1).
- Large T, large N handled in O(N log N) preprocessing and O(1) per query.

None

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)
    N = next(it); W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # 0-based index for blocks

    # Collect per-column blocks
    cols = [[] for _ in range(W + 1)]
    for i in range(N):
        x = X[i]
        y = Y[i]
        cols[x].append((y, i))

    rank = [0] * N
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    if not hasZero:
        # Compute B and m
        mins = []
        m = None
        B = 0
        for x in range(1, W + 1):
            col = cols[x]
            minY = min(y for (y, idx) in col)
            mins.append(minY)
        B = max(mins)
        m = min(len(col) for col in cols[1:])

        # Assign ranks within each column
        for x in range(1, W + 1):
            col = cols[x]
            col.sort(key=lambda t: t[0])  # sort by Y
            for pos, (y, idx) in enumerate(col, start=1):
                rank[idx] = pos
    # If hasZero is True, we don't need ranks or B/m since answer is always Yes

    out_lines = []
    if hasZero:
        out_lines = ["Yes"] * Q
    else:
        for j in range(Q):
            t = T_arr[j]
            a = A_arr[j]
            r = rank[a]
            if t < B:
                out_lines.append("Yes")
            elif t <= B + m - 1:
                s = t - B + 1
                out_lines.append("Yes" if r > s else "No")
            else:
                out_lines.append("Yes" if r > m else "No")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
