### Step-by-step reasoning
- We have n pizzas, with n a multiple of 4. Each day we pick 4 pizzas with weights W <= X <= Y <= Z. We gain Z on odd-numbered days and Y on even-numbered days.
- Intuition:
  - On odd days (where we gain Z), the gain depends only on the largest pizza of that day. To maximize total gain, use the current largest remaining pizza as Z and avoid wasting other large pizzas in that day. Thus, pair the current largest with three of the smallest remaining pizzas (W, X, Y) and remove them from consideration.
  - On even days (where we gain Y), we want Y to be as large as possible. This is achieved by forming the day with the four largest remaining pizzas, so the second largest among those four (the Y for that day) is as large as possible.
- Algorithm:
  - Sort pizzas in ascending order.
  - Maintain two pointers: left for the smallest remaining, right for the largest remaining.
  - For each day:
    - If the day is odd (0-based index even), add pizzas[right] to the total, then move right left by 1 and move left right by 3 (effectively removing one largest and three smallest from consideration).
    - If the day is even (0-based index odd), add pizzas[right - 1] to the total, then move right left by 4 (removing the four largest remaining).
- This ensures we maximize the contributions on both odd and even days while consuming all pizzas in groups of four.
- Time complexity: O(n log n) due to sorting, and O(1) extra space beyond the input.

### Requirements
None

### Code
```
from typing import List

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        pizzas.sort()  # ascending
        left = 0       # pointer to smallest remaining
        right = n - 1  # pointer to largest remaining
        days = n // 4
        total = 0

        for day in range(days):
            if day % 2 == 0:  # odd-numbered day (1-indexed)
                total += pizzas[right]
                right -= 1
                left += 3  # remove three smallest implicitly
            else:             # even-numbered day
                total += pizzas[right - 1]
                right -= 4      # remove the four largest remaining

        return total
```
