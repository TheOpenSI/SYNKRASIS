### Step-by-step reasoning
- Understand the problem: We have n pizzas (n is a multiple of 4). Each day we pick 4 pizzas with weights W <= X <= Y <= Z. We gain Z on odd-numbered days and Y on even-numbered days. Every pizza can be eaten exactly once. We want to maximize the total gain after all pizzas are eaten.
- Key idea: We should allocate the largest values to the days where they contribute to the gain (Z on odd days, Y on even days) while wasting as few large values as possible on non-contributing positions (W and X).
- Greedy strategy:
  - Sort pizzas ascending.
  - Maintain two pointers: left (l) at the smallest remaining, right (r) at the largest remaining.
  - For each day (total days = n/4):
    - If the day is odd (1st, 3rd, ...): take the current largest as Z, and pair it with the three smallest remaining as W, X, Y. This yields maximal Z for that day and minimizes waste of large numbers, since three smallest are removed from the pool.
      - Implementation: add pizzas[r] to total; then r -= 1; l += 3.
    - If the day is even (2nd, 4th, ...): take the four largest remaining as W, X, Y, Z, so that Y (the second largest) is as large as possible for this day.
      - Implementation: add pizzas[r - 1] to total; then r -= 4.
- Why this works: By always giving odd days the current global maximum as Z and consuming the three smallest elements alongside it, we preserve larger values for future even days as potential Y. By giving even days the four largest remaining, we maximize the Y gained on that day. This greedy approach preserves large numbers for future use and minimizes waste.
- Complexity: Sorting is O(n log n). The pass over days is O(n). Space complexity is O(1) beyond the input array.

None

### Code
```
from typing import List

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        pizzas.sort()  # ascending
        left = 0       # smallest remaining index
        right = n - 1  # largest remaining index
        days = n // 4
        total = 0

        for day in range(days):
            if day % 2 == 0:  # odd-numbered day (1-indexed)
                total += pizzas[right]
                right -= 1
                left += 3  # remove three smallest
            else:             # even-numbered day
                total += pizzas[right - 1]
                right -= 4  # remove the four largest remaining

        return total
```
