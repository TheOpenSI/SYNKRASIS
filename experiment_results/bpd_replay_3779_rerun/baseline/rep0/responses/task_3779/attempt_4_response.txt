### Step-by-step reasoning
- Problem recap: We have n pizzas (n multiple of 4). Each day we pick 4 pizzas with weights W <= X <= Y <= Z. On odd-numbered days we gain Z, on even-numbered days we gain Y. We want to maximize total gain over all days.
- Key observations:
  - On odd days we gain the largest in that day (Z). To maximize total, we should assign the current global largest remaining pizza to be Z on an odd day.
  - On even days we gain the second-largest in that day (Y). After placing the largest for a previous odd day, the best we can do on an even day is to form a day from the four largest remaining pizzas, so that the second largest among those (which is the Y for that day) is as large as possible.
  - To avoid wasting large values on even days, we should pair odd days with the largest remaining pizza and the three smallest remaining pizzas, so we don’t “consume” other large values that could contribute as Y later.
- Greedy approach:
  1. Sort pizzas in ascending order.
  2. Maintain two pointers: left (l) to the smallest remaining weight, right (r) to the largest remaining weight.
  3. For each day (total days = n/4):
     - If the day is odd (1st, 3rd, ...): gain pizzas[r] (the current largest), then remove that largest and three smallest remaining: r-- and l += 3.
     - If the day is even (2nd, 4th, ...): gain pizzas[r-1] (the second largest among the remaining four largest), then remove the four largest remaining: r -= 4.
- This runs in O(n log n) time due to sorting, with O(1) extra space beyond the input.
- Robustness: handles duplicates and edge cases since it relies on sorted order and explicit removal of the appropriate elements.

### Requirements
None

### Code
```
from typing import List

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        pizzas.sort()  # ascending
        left = 0       # smallest remaining index
        right = n - 1  # largest remaining index
        days = n // 4
        total = 0

        for day in range(days):
            if day % 2 == 0:  # odd-numbered day (1-indexed)
                total += pizzas[right]
                right -= 1
                left += 3  # remove three smallest
            else:             # even-numbered day
                total += pizzas[right - 1]
                right -= 4  # remove the four largest remaining

        return total
```
