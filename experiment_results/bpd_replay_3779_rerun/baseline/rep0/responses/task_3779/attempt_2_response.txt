### Step-by-step reasoning
- Understand the process: We have n pizzas (n is a multiple of 4). Each day we pick 4 pizzas with weights W <= X <= Y <= Z. On odd days (1, 3, 5, ...) we gain Z, and on even days (2, 4, 6, ...) we gain Y. We want to maximize the total gain.
- Key insight for odd days: Since Z (the largest in the day) is the only one that contributes on odd days, we should pair the largest remaining pizza as Z and avoid "wasting" other large pizzas in that same day. Therefore, after taking the largest as Z, we should use the three smallest pizzas for W, X, Y. This leaves the largest numbers available for future days.
- Key insight for even days: On even days, Y is the second largest in that day’s quadruple. To maximize Y, we should form the day with the four largest remaining pizzas, so that the second-largest among them (i.e., Y) is as large as possible.
- Repeat the process: 
  - Day 1 (odd): take the current largest as Z, remove three smallest others.
  - Day 2 (even): take the four largest remaining pizzas as the day’s group; add the second-largest of that group to the result.
  - Continue for all days.
- This exchange argument shows removing three smallest on odd days and consuming the four largest on even days maximizes the contributions across days.
- Implementation detail: Sort the array ascending, use two indices, left (smallest) and right (largest). For each day:
  - If day is odd (0-based index even in code): add pizzas[right], then right-- and effectively skip 3 smallest (left += 3).
  - If day is even (0-based index odd in code): add pizzas[right-1], then right -= 4 (consume the four largest remaining).
- Time complexity: O(n log n) due to sorting, and O(1) extra space beyond input.

None

### Code
```
from typing import List

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        pizzas.sort()  # ascending
        left = 0       # pointer to smallest
        right = n - 1  # pointer to largest
        days = n // 4
        ans = 0

        for day in range(days):
            if day % 2 == 0:  # odd-numbered day (1-indexed)
                ans += pizzas[right]
                right -= 1
                left += 3       # remove three smallest implicitly
            else:               # even-numbered day
                ans += pizzas[right - 1]
                right -= 4        # consume the four largest remaining

        return ans
```
