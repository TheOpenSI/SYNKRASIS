### Step-by-step reasoning
- Problem restatement: We have n pizzas (n multiple of 4). Each day we pick 4 pizzas with weights W <= X <= Y <= Z. On odd days we gain Z, on even days we gain Y. We want to maximize the total gain after all pizzas are eaten.

- Observations:
  - For each day, the gain depends only on the largest and second-largest values in the chosen group (Z and Y). The two smallest (W and X) don’t affect the gain directly.
  - A greedy strategy can be designed by controlling how we form the groups day by day:
    - On odd days (where we gain Z), it is beneficial to pair the largest available weight Z with as small as possible other weights (to avoid wasting large weights that could serve as Y on even days). Thus, after taking the largest as Z, we should group it with the three smallest remaining weights.
    - On even days (where we gain Y), we want the second-largest in the group (Y) to be as large as possible. After removing the odd-day group, the best we can do for this day is to form the group using the current largest remaining values so that Y is the second-largest among the four. Concretely, this means taking the two largest available values as Z and Y (with Z being the largest), and the other two as the smallest available weights (which don’t contribute to the sum).

- Greedy algorithm:
  - Sort pizzas in descending order.
  - Maintain two pointers:
    - l points to the current largest unused element.
    - r points to the current smallest unused element.
  - For each day (total days = n/4):
    - If the day is odd (0-indexed day even): take Z = a[l], add Z to the answer, advance l by 1, and shrink the pool by removing the three smallest elements (r -= 3).
    - If the day is even (0-indexed day odd): take Y = a[l+1] (second largest among current remaining after removing Z), add Y to the answer, advance l by 2, and shrink the pool by removing the two largest remaining after Z (which are a[l+0] and a[l+1]) and two smallest (r -= 2).
  - This approach uses the largest values as Z on odd days and maximizes the Y values on even days while minimizing waste from W and X.

- Correctness intuition:
  - By always assigning the current largest as Z on odd days and pairing it with the three smallest elements, we maximize Z while minimizing the opportunity loss of Y in that group.
  - By on even days taking Y as the second-largest among the remaining (i.e., forming the group from the top two remaining values and the two smallest remaining ones), we maximize the Y value contributed on that day.
  - This alternating optimal packing yields the maximum possible total gain under the constraint that groups are of size 4 and days alternate in parity.

- Complexity:
  - Sorting: O(n log n)
  - The loop processes n/4 days with O(1) work per day, so O(n) additional time.
  - Space: O(1) beyond input (besides the sorting in place or the copy for sorted).

- Edge cases:
  - n = 4: only one day, odd day, total equals the maximum weight.
  - Duplicates and ties are handled naturally by the sorting and pointer arithmetic.

None

### Code
```
from typing import List

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        a = sorted(pizzas, reverse=True)

        l = 0           # index for the current largest unused element
        r = n - 1       # index for the current smallest unused element
        days = n // 4
        ans = 0

        for day in range(days):
            if day % 2 == 0:
                # Odd-numbered day (1,3,...) -> gain Z; pair with three smallest
                ans += a[l]
                l += 1
                r -= 3
            else:
                # Even-numbered day (2,4,...) -> gain Y; form group with top two remaining
                ans += a[l + 1]
                l += 2
                r -= 2

        return ans
```
