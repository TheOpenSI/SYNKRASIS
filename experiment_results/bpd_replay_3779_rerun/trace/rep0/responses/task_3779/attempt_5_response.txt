### Step-by-step reasoning
- Understand the task: We have n pizzas (n is multiple of 4). Each day we pick 4 pizzas with weights W <= X <= Y <= Z. On day 1 (odd), we gain Z; on day 2 (even), we gain Y; and so on. We want to maximize the total gain after all pizzas are eaten.

- Key observations:
  - Only the largest (Z) and the second largest (Y) in each 4-pizza group contribute to the total. The two smallest in each group (W and X) don’t affect the gain.
  - To maximize the total, decisions should be greedy per day:
    - On odd days (where we gain Z), we should maximize Z. That means pairing the current largest available pizza as Z and filling the rest with the smallest available pizzas to “consume” the smallest weights that could otherwise reduce future gains.
    - On even days (where we gain Y), we should maximize Y. The best possible Y on that day is the second-largest among the currently remaining pizzas. To realize this, we should form a group that includes the two largest remaining pizzas (so Y becomes the second largest in that group) and pair them with the two smallest remaining pizzas.

- Greedy strategy:
  - Sort pizzas in descending order: a[0] >= a[1] >= ... >= a[n-1].
  - Maintain two pointers:
    - l points to the current largest unused element.
    - r points to the current smallest unused element.
  - For each day (total days = n/4):
    - If the day is odd (0-based even index, i.e., 1st, 3rd, ...): add a[l] to the answer (Z), then move l forward by 1 and move r backward by 3 (consume three smallest as W, X, Y in that group).
    - If the day is even (0-based odd index, i.e., 2nd, 4th, ...): add a[l+1] to the answer (Y, the second largest in the current pool), then move l forward by 2 and move r backward by 2 (consume two largest and two smallest).
  - This approach ensures we maximize the daily contribution while preserving as much value as possible for future days.

- Correctness sketch:
  - For odd days, maximizing Z by taking the current largest as Z and removing the three smallest minimizes harm to future days because W, X, Y in that day are the three smallest; none of them are among large values that could be used as Z or Y later.
  - For even days, maximizing Y by forming a group with the two largest remaining numbers ensures the best possible contribution for that day. Any deviation would either reduce the day’s Y or waste large numbers that could contribute later as Z on future odd days. Repeating this greedily across days yields an optimal total under the problem constraints.

- Complexity:
  - Sorting: O(n log n)
  - Each day performs O(1) work; there are n/4 days, so overall O(n).
  - Space: O(n) for the sorted copy (or in-place if allowed).

### Code
```
from typing import List

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        a = sorted(pizzas, reverse=True)

        l = 0           # index of current largest unused element
        r = n - 1       # index of current smallest unused element
        days = n // 4
        ans = 0

        for day in range(days):
            if day % 2 == 0:
                # Odd-numbered day (1,3,...) -> gain Z; pair with three smallest
                ans += a[l]
                l += 1
                r -= 3
            else:
                # Even-numbered day (2,4,...) -> gain Y; form group with top two remaining
                ans += a[l + 1]
                l += 2
                r -= 2

        return ans
```
