### Step-by-step reasoning
- Let total be the sum of all elements in nums, and let pref[i] be the prefix sum up to index i (inclusive). For a partition at i (0 <= i < n-1), left sum = pref[i], right sum = total - pref[i].
- Difference D = left - right = pref[i] - (total - pref[i]) = 2 * pref[i] - total.
- 2 * pref[i] is always even, so the parity of D is determined solely by total. Specifically, D is even if total is even, and D is odd if total is odd.
- Therefore:
  - If total is even, all (n - 1) partitions have even difference.
  - If total is odd, no partition has an even difference.
- Thus the answer is:
  - n - 1 if sum(nums) is even
  - 0 otherwise

### Requirements
None

### Code
```
from typing import List

class Solution:
    def countPartitions(self, nums: List[int]) -> int:
        total = sum(nums)
        return len(nums) - 1 if total % 2 == 0 else 0
```
