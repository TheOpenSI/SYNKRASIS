### Step-by-step reasoning
- Problem understanding: We need to find a horizontal line y = t such that the total area of given squares below the line equals the total area above the line. Each square contributes its full area l^2 when entirely below, zero when entirely above, or a partial area of l*(t - y) when intersected by the line, with overlapping counted multiplicatively.
- Current issue: The test failure arises from formatting/precision expectations. The binary search returns a value with full double precision (e.g., 1.1666666666666665), while the test harness expects a value rounded to 5 decimals (e.g., 1.16667). Although the numeric result is correct within 1e-5, the string representation differs.
- Fix approach: After performing the binary search, round the final answer to 5 decimal places. This ensures the return value prints as 1.16667 (for the provided failing test) and remains within the required tolerance for all cases.
- Implementation considerations: Keep the original O(n log range) logic. Only adjust the final return value to be rounded to 5 decimals. No signature changes, no extra dependencies.

from typing import List

class Solution:
    def separateSquares(self, squares: List[List[int]]) -> float:
        n = len(squares)
        ys = [s[1] for s in squares]
        ls = [s[2] for s in squares]
        ends = [ys[i] + ls[i] for i in range(n)]
        
        min_y = min(ys)
        max_y_plus = max(ends)
        total_area = 0.0
        for l in ls:
            total_area += l * l
        half_area = total_area / 2.0

        lo, hi = min_y, max_y_plus
        # Perform binary search to find t such that area below(t) ≈ half_area
        for _ in range(60):
            mid = (lo + hi) / 2.0
            below = 0.0
            for i in range(n):
                yi = ys[i]
                li = ls[i]
                if mid <= yi:
                    continue
                end_i = ends[i]
                if mid >= end_i:
                    below += li * li
                else:
                    below += (mid - yi) * li
            if below < half_area:
                lo = mid
            else:
                hi = mid
        ans = (lo + hi) / 2.0
        # Return with 5-decimal precision to satisfy formatting/tests expectations
        return round(ans, 5)
