### Step-by-step reasoning
- Let D be the set of indices i where A_i != B_i. Each such index must be flipped exactly once; flipping any other index is unnecessary.
- If we denote delta_i as the change in the total sum S = sum_j A_j * C_j caused by flipping i, then:
  - If A_i = 1 (and thus B_i = 0), delta_i = -C_i (since A_i becomes 0).
  - If A_i = 0 (and thus B_i = 1), delta_i = +C_i (since A_i becomes 1).
- Let k = |D| and S0 = sum_i A_i * C_i (the initial sum before any flips).
- Suppose we perform the flips in some order, giving deltas in the sequence delta_1, delta_2, ..., delta_k. The cost of the t-th flip is S0 plus the sum of deltas of all flips up to t:
  - S_after_t = S0 + sum_{j=1..t} delta_j
- The total cost becomes:
  - Total = sum_{t=1..k} S_after_t = k*S0 + sum_{t=1..k} sum_{j=1..t} delta_j
  - This simplifies to Total = k*S0 + sum_{j=1..k} delta_j * (k - j + 1)
- We need to minimize sum_{j=1..k} delta_j * (k - j + 1) by choosing the order of the deltas.
- The weights (k - j + 1) are decreasing with j. By the rearrangement inequality, to minimize the dot product with a decreasing sequence, we should pair the smallest deltas with the largest weights. Therefore, sort all delta_i in ascending order and apply the formula.
- The final algorithm:
  - Compute S0 and all deltas for i in D.
  - If k = 0, answer is 0.
  - Sort deltas ascending.
  - Total = k*S0 + sum_{j=1..k} deltas[j-1] * (k - j + 1)
- This runs in O(N log N) time and uses 64-bit integer range safely.

None

### Code
```
import sys

def main():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    N = int(next(it))

    A = [int(next(it)) for _ in range(N)]
    B = [int(next(it)) for _ in range(N)]
    C = [int(next(it)) for _ in range(N)]

    S0 = 0
    deltas = []  # delta for each i in D (A_i != B_i)

    for i in range(N):
        Ai = A[i]
        Bi = B[i]
        Ci = C[i]

        if Ai == 1:
            S0 += Ci  # contribute to initial sum
        # collect deltas only for positions where A_i != B_i
        if Ai != Bi:
            if Ai == 1:
                deltas.append(-Ci)  # flipping 1 -> 0 decreases sum by Ci
            else:
                deltas.append(+Ci)  # flipping 0 -> 1 increases sum by Ci

    k = len(deltas)
    if k == 0:
        print(0)
        return

    deltas.sort()  # ascending order

    total = k * S0
    # add delta_j * (k - j + 1) for j from 1..k (0-based index j-1 -> j)
    for idx, d in enumerate(deltas, start=1):
        weight = k - idx + 1
        total += d * weight

    print(total)

if __name__ == "__main__":
    main()
```
