### Step-by-step reasoning
- The task is to find N such that N! = X, with a guarantee that such N exists and is unique.
- A straightforward approach is to multiply consecutive integers starting from 1 until the product equals X.
- Bug in the previous solution: i started at 2 and f started at 1, then in the loop I incremented i before multiplying, causing an extra multiplication and overshooting the correct N (e.g., for X=6, it returned 4 instead of 3).
- Correct approach: initialize i = 1 and f = 1, then while f < X, increment i and multiply f by i. When f reaches X, i is the correct N.
- This runs in O(N) time with N ≤ 20 for the given constraints, which is fast enough.

### Requirements
None

### Code
```python
import sys

def main():
    data = sys.stdin.read().strip()
    if not data:
        return
    X = int(data)
    i = 1
    f = 1
    while f < X:
        i += 1
        f *= i
    print(i)

if __name__ == "__main__":
    main()
```
