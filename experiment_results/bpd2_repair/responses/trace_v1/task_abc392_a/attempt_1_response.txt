### Step-by-step reasoning
- We need to determine if there exists a permutation B of the given three numbers A1, A2, A3 such that B1 * B2 = B3.
- This is equivalent to checking whether any number is the product of the other two.
- Therefore, the condition to test is: A1*A2 == A3 or A1*A3 == A2 or A2*A3 == A1.
- The previous solution used an incorrect conditional, which caused it to output Yes for cases where none of the pairwise products equaled the remaining number (e.g., 5, 3, 2). It should only print Yes when one of the three exact equalities holds.

import sys

def main():
    data = sys.stdin.read().strip().split()
    if len(data) < 3:
        print("No")
        return
    a, b, c = map(int, data[:3])
    if a * b == c or a * c == b or b * c == a:
        print("Yes")
    else:
        print("No")

if __name__ == "__main__":
    main()
