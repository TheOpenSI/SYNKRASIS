### Step-by-step reasoning
- The previous solution attempted to simulate a state machine with a complex block-skipping logic. It introduced an incorrect interpretation of the bitmask used to determine if the next position is reachable, which caused wrong results on the sample test.
- A correct approach is to model reachability with a compact sliding window of the last B positions. Since A..B is small (≤ 20), we can store a B-bit mask S where:
  - Bit t (0-based) indicates whether position cur - (t+1) is reachable.
  - To land on position cur, we need that cur is not bad and there exists i ∈ [A, B] such that cur - i is reachable. In terms of S, that means checking bits indices A-1 to B-1.
- We process positions sequentially from 1 to N:
  - Position 1 is the starting point and always reachable (and not bad due to constraints).
  - For each cur > 1:
    - safe = not is_bad(cur)
    - can_cur_from_previous = OR of bits S[(A-1) .. (B-1)]
    - can_cur = safe and can_cur_from_previous
    - If cur == N and can_cur is True, print Yes.
    - Update S to reflect that cur is now reachable for future steps:
      S = ((S << 1) & ((1 << B) - 1)) | (1 if can_cur else 0)
- After finishing, if we never landed on N, print No.
- This approach is correct given the problem constraints (A, B ≤ 20) and handles the sample case where the previous solution failed.

import sys
from bisect import bisect_right

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    N = int(next(it))
    M = int(next(it))
    A = int(next(it))
    B = int(next(it))

    intervals = []
    for _ in range(M):
        L = int(next(it)); R = int(next(it))
        intervals.append((L, R))

    # Prepare for fast is_bad check using binary search over L_i
    Ls = [ln for ln, rn in intervals]
    Rs = [rn for ln, rn in intervals]
    def is_bad(x: int) -> bool:
        # Find the interval with largest L <= x
        idx = bisect_right(Ls, x) - 1
        if idx >= 0 and x <= Rs[idx]:
            return True
        return False

    if N == 1:
        # Starting position is the destination
        print("Yes")
        return

    # Bitmask state: B bits, bit t represents reachability of (cur - (t+1))
    S = 0
    # cur = 1 is reachable (start)
    # Update for next position (cur becomes 2)
    # can_cur for cur=1 is True, so we set the LSB for cur=1 being reachable
    S = ((S << 1) & ((1 << B) - 1)) | 1  # can_cur at cur=1 is True

    # We now iterate cur from 2 to N
    maskA = A - 1
    mask_len = B - A + 1
    range_mask = (1 << mask_len) - 1 if mask_len > 0 else 0

    for cur in range(2, N + 1):
        safe = not (is_bad(cur))
        # can_cur_from_previous: exists i in [A,B] with cur - i reachable
        can_cur_from_previous = ((S >> maskA) & range_mask) != 0 if mask_len > 0 else False
        can_cur = safe and can_cur_from_previous

        if cur == N and can_cur:
            print("Yes")
            return

        # Update state for next position
        S = ((S << 1) & ((1 << B) - 1)) | (1 if can_cur else 0)

    print("No")

if __name__ == "__main__":
    solve()
