### Step-by-step reasoning
- The goal is to find N such that N! = X. The factorial sequence is: 1!, 2!, 3!, ...
- The previous implementation started with i = 2 and updated f as f *= i after incrementing i. This caused it to skip multiplying by 2 (it computed 1*3 = 3 as the first product), leading to overshoot for X = 6 and returning 4 instead of 3.
- Correct approach: start from i = 1 with f = 1, and in the loop first increment i and then multiply f by i. This ensures f follows 1, 2, 6, 24, ... and stops exactly when f reaches X.
- The loop should run while f < X; since the problem guarantees X is a factorial, it will end with f == X and i == N.

### Requirements
None

### Code
```
import sys

def main():
    data = sys.stdin.read().strip()
    if not data:
        return
    X = int(data)
    i = 1
    f = 1
    while f < X:
        i += 1
        f *= i
    print(i)

if __name__ == '__main__':
    main()
```
