### Step-by-step reasoning
- We want the minimum number of edges to delete so that the graph becomes a forest (acyclic).
- In a forest with N vertices and C connected components, the maximum number of edges it can contain is N - C (a spanning forest).
- In the original graph, let the number of connected components be comp. Within each original component, we can keep at most (size_of_component - 1) edges to avoid cycles, which sums up to N - comp total edges that can remain without cycles.
- Therefore, the minimum number of deletions is:
  deletions = M - (N - comp)
- So we only need to compute the number of connected components comp in the original graph, then compute the formula above.
- We can compute comp using a Disjoint Set Union (Union-Find) data structure by uniting each edge's endpoints and counting unique roots at the end.

### Requirements
None

### Code
```
import sys

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))
        self.size = [1] * (n + 1)

    def find(self, x):
        # Path compression
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra = self.find(a)
        rb = self.find(b)
        if ra == rb:
            return False
        # Union by size
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        return True

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        print(0)
        return

    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    dsu = DSU(n)
    for _ in range(m):
        try:
            u = int(next(it))
            v = int(next(it))
        except StopIteration:
            break
        dsu.union(u, v)

    roots = set()
    for i in range(1, n + 1):
        roots.add(dsu.find(i))
    comp = len(roots)

    answer = m - (n - comp)
    print(answer)

if __name__ == "__main__":
    main()
```
