### Step-by-step reasoning
- Understand the problem: We need the shortest contiguous subarray that contains a value appearing at least twice in the entire array A. Equivalently, for any value that occurs multiple times in A, consider the distance between two consecutive occurrences; the minimal such distance (plus one for inclusive length) is the answer. If no value occurs twice, answer is -1.
- Identify the bug in the previous solution: The code read the input incorrectly. It set n = data[1] (the second integer) instead of data[0] (the first integer), which caused the subarray to be taken from a truncated portion of A.
- Plan to fix:
  - Parse N as data[0].
  - Parse A as data[1:1+N].
  - Traverse A while keeping a map of the last seen index for each value.
  - When a repeated value is found, compute the candidate subarray length as i - last_pos[v] + 1 and update the minimum.
  - If no duplicates exist, output -1.
- Complexity: O(N) time and O(U) space, where U is the number of distinct values encountered.

### Requirements
None

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        print(-1)
        return

    n = data[0]
    a = data[1:1 + n]

    last_pos = {}
    ans = None

    for i, v in enumerate(a):
        if v in last_pos:
            length = i - last_pos[v] + 1
            if ans is None or length < ans:
                ans = length
        last_pos[v] = i

    print(-1 if ans is None else ans)

if __name__ == "__main__":
    main()
```
