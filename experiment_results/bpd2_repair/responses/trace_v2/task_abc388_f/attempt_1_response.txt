### Step-by-step reasoning
- The previous solution attempted to simulate block-by-block but had incorrect state handling for jumping across bad segments, and it produced wrong results for the first sample.
- A robust approach is to treat the problem as a finite-state automaton over a sliding window of the last B positions. Let R be a bitmask of length B where bit k (0 <= k < B) indicates whether the position (current_x - B + 1) + k is reachable. The current end position is current_x.
- To move to the next position y = current_x + 1:
  - If y is safe, y is reachable if any of the previous positions in [y - B, y - A] were reachable. In terms of R, this means there is any bit set in R among indices 0..(B - A). The new window shifts: bits [0..B-2] become previous [1..B-1], and bit B-1 (for y) is set if there exists a reachable source.
  - If y is bad, y cannot be reached, so the top bit is 0; the rest of the window shifts as well.
- The transition for a single safe step is:
  Next = (R >> 1) | (1 << (B-1)) if (R & prefix_mask) != 0, else Next = (R >> 1), where prefix_mask = (1 << (B - A + 1)) - 1 (bits 0..B-A).
- N is up to 1e12, and B <= 20, so the number of possible R states is at most 2^20 (~1e6). The pattern of safe vs bad squares is determined by M disjoint intervals, hence after the last bad interval the pattern is always safe.
- We can process the path across the entire range [2, N] segment by segment:
  - Build safe segments between bad intervals: S0 = [2, L1-1], S1 = [R1+1, L2-1], ..., S_M = [R_M+1, N].
  - After finishing a safe segment, skip the following bad block by simply shifting R right by the bad block length, since each bad square forces a step with top bit 0.
  - While processing a safe segment, jump multiple steps at once by using cycle-detection within the safe-step transition (since F(R) for a safe step is deterministic). When a cycle is detected, we can skip many full cycles at once, since after a full cycle the state repeats.
  - If N lies inside a safe segment, we compute the state after exactly N - current_x safe steps and check whether bit B-1 is set (i.e., N is reachable). If so, answer Yes; otherwise No.

This method guarantees correctness and efficiently handles large N by skipping long safe blocks and entire bad blocks, with careful cycle-skipping to avoid O(N) time.

None

import sys

def main():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    N = int(next(it))
    M = int(next(it))
    A = int(next(it))
    B = int(next(it))

    intervals = []
    for _ in range(M):
        L = int(next(it))
        R = int(next(it))
        intervals.append((L, R))

    # Build safe segments: intervals of y not in any bad interval, within [2, N]
    # Safe segments: S0: [2, L1-1], S1: [R1+1, L2-1], ..., S_M: [R_M+1, N]
    segments = []
    cur = 2
    for (L, R) in intervals:
        if cur <= L - 1:
            segments.append((cur, L - 1))
        cur = R + 1
    if cur <= N:
        segments.append((cur, N))

    # State representation
    # R is a bitmask of length B, bit (B-1) corresponds to current position current_x.
    R = 1 << (B - 1)  # start at position 1
    current_x = 1

    # Transition for a single safe step
    # Next = (R >> 1) | (1 << (B-1)) if (R & prefix_mask) != 0 else (R >> 1)
    prefix_mask = (1 << (B - A + 1)) - 1  # bits 0..(B-A)

    def step_safe(R_cur: int) -> int:
        nxt = R_cur >> 1
        if (R_cur & prefix_mask) != 0:
            nxt |= 1 << (B - 1)
        return nxt

    def advance_safe(R_cur: int, t: int) -> int:
        # Advance R_cur by t safe steps, with cycle-detection to skip efficiently
        if t <= 0:
            return R_cur
        seen = {R_cur: 0}
        step = 0
        cur = R_cur
        while step < t:
            cur = step_safe(cur)
            step += 1
            if step == t:
                return cur
            if cur in seen:
                start = seen[cur]
                cycle_len = step - start
                remaining = t - step
                if cycle_len > 0 and remaining > 0:
                    cycles_to_skip = remaining // cycle_len
                    if cycles_to_skip > 0:
                        step += cycles_to_skip * cycle_len
                        # cur remains the same after full cycles
                        if step == t:
                            return cur
                # If not skipping, continue to traverse the next steps.
            else:
                seen[cur] = step
        return cur

    # Process each safe segment in order, skipping across bad blocks when possible
    for i, (s, e) in enumerate(segments):
        if current_x >= N:
            print("Yes" if (R >> (B - 1)) & 1 else "No")
            return

        # Number of safe steps available in this segment starting from current_x
        L_safe = max(0, e - current_x)
        if L_safe > 0:
            # If N lies inside this safe segment, compute exactly to N and check
            if N <= current_x + L_safe:
                t = N - current_x
                R_final = advance_safe(R, t)
                if (R_final >> (B - 1)) & 1:
                    print("Yes")
                else:
                    print("No")
                return
            else:
                R = advance_safe(R, L_safe)
                current_x += L_safe

        # After finishing a safe segment, skip the following bad block (if any)
        if i < len(segments) - 1:
            # The bad block after this safe segment corresponds to intervals[i]
            bad_L, bad_R = intervals[i]
            bad_len = bad_R - bad_L + 1
            if bad_len > 0:
                if bad_len >= B:
                    R = 0
                else:
                    R >>= bad_len
                current_x += bad_len

    # If we exit the loop without returning, N must not have been reachable
    print("No")

if __name__ == "__main__":
    main()
