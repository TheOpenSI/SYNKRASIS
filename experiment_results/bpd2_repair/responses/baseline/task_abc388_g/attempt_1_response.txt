### Step-by-step reasoning
- The problem asks, for each query interval [L, R], how many kagamimochi (pairs) can be formed such that in each pair (i, j) with i < j, A[i] <= A[j] / 2, and every mochi is used at most once.
- A[i] is sorted non-decreasingly. For a fixed i, the possible partners j must satisfy j > i and A[j] >= 2*A[i]. Let t[i] be the first index j such that A[j] >= 2*A[i] (0-based). If t[i] is outside the interval, i cannot be the top in any pair within that interval.
- A robust way to compute the maximum number of disjoint pairs in a subarray is to use a reverse greedy:
  - Process potential tops i from right to left (i from R-1 down to L).
  - For each i not yet used, choose the largest available bottom j in [max(t[i], i+1, L), R].
  - If such a j exists, pair (i, j) and remove both i and j from consideration (neither can be used again).
- To implement "largest available bottom" efficiently, we use a DSU (disjoint-set union) structure that keeps track of the largest still-available bottom index ≤ a given value. We also need to ensure that an index used as a top is not reused as a bottom later. We do this by removing both i and j from the bottom pool whenever we form a pair.
- We precompute t[i] for all i once, using binary search on A (O(N log N)).
- For each query, we run the reverse greedy with a small DSU over the interval, giving an O(m α(m)) time per query, where m = R-L+1 and α is the inverse Ackermann function (near-constant). While worst-case could be heavy, this approach correctly handles the tricky case where naive left-to-right greedy fails (e.g., [1,1,2,3,4] → two pairs (1,3) and (2,4)).

import sys
from bisect import bisect_left

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)
    N = next(it)
    A = [next(it) for _ in range(N)]
    Q = next(it)
    queries = []
    for _ in range(Q):
        L = next(it); R = next(it)
        queries.append((L - 1, R - 1))  # 0-based indices

    # Precompute t[i] = first index j such that A[j] >= 2*A[i], or N if none
    t = [0] * N
    for i in range(N):
        two_ai = 2 * A[i]
        j0 = bisect_left(A, two_ai)
        if j0 <= i:
            j0 = i + 1
        t[i] = j0

    out_lines = []
    for L, R in queries:
        m = R - L + 1
        if m < 2:
            out_lines.append("0")
            continue

        # DSU over indices [L-1 .. R] to manage available bottoms.
        # We map real index p to DSU index idx = p - (L-1), so:
        # idx in [0, m], where idx = m corresponds to p = R.
        size = m + 1  # number of DSU elements
        parent = list(range(size))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def remove(pos):
            # Remove a position 'pos' from the bottom pool
            idx = pos - (L - 1)
            if 0 <= idx < size:
                parent[idx] = find(idx - 1)

        used = [False] * N  # track if an index has been used (as top or bottom)

        ans = 0
        # Iterate potential tops from right to left
        for i in range(R - 1, L - 1, -1):
            if used[i]:
                continue
            # j must be in [max(t[i], i+1, L), R]
            jstart = t[i]
            if jstart < i + 1:
                jstart = i + 1
            if jstart < L:
                jstart = L
            if jstart > R:
                continue

            # Largest available bottom <= R
            idxR = find(R - (L - 1))
            need = jstart - (L - 1)
            if idxR >= need:
                j = (L - 1) + idxR
                # form pair (i, j)
                used[i] = True
                used[j] = True
                remove(i)
                remove(j)
                ans += 1

        out_lines.append(str(ans))

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
