### Step-by-step reasoning
- Let total be the sum of all elements in nums.
- For a partition index i (0 <= i < n-1), left is sum(nums[:i+1]) and right is total - left.
- The difference is diff = left - right = left - (total - left) = 2*left - total.
- Since 2*left is always even, the parity of diff is entirely determined by total:
  - If total is even, diff is even for every i (since even minus even is even).
  - If total is odd, diff is odd for every i (since even minus odd is odd).
- Therefore:
  - If total is even, all (n - 1) partitions satisfy the condition.
  - If total is odd, none satisfy the condition.
- The solution is simply: return n - 1 if sum(nums) is even, else return 0.

### Requirements
None

### Code
```python
from typing import List

class Solution:
    def countPartitions(self, nums: List[int]) -> int:
        total = sum(nums)
        return len(nums) - 1 if total % 2 == 0 else 0
```
