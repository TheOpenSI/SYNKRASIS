### Step-by-step reasoning
- Let A and B be the current and target binary arrays, and C the weights. Define S as the current total cost sum_k A_k * C_k.
- When we flip A_i:
  - If A_i was 0, it becomes 1, so S increases by C_i (delta = +C_i).
  - If A_i was 1, it becomes 0, so S decreases by C_i (delta = -C_i).
  - The operation cost for that flip is the new S after applying the flip, i.e., S' = S + delta.
- To end with A = B, each index i with A_i != B_i must be flipped an odd number of times; indices with A_i == B_i can be flipped any even number of times (including zero), but extra flips only add nonnegative costs, so they won’t help minimize the total cost. Therefore, in an optimal strategy, we flip exactly the d = number of positions where A_i != B_i once each.
- Each such flip has a fixed delta: if A_i = 0 and B_i = 1, delta = +C_i; if A_i = 1 and B_i = 0, delta = -C_i.
- Suppose we perform the flips in some order. Let deltas be D_j (j = 1..d) in the order we perform flips. The total cost equals:
  T = sum_{t=1..d} S_t, where S_t is the S after t-th flip.
  If S_0 is the initial S, then S_t = S_0 + sum_{j=1..t} D_j, so
  T = d * S_0 + sum_{t=1..d} sum_{j=1..t} D_j = d*S_0 + sum_{j=1..d} D_j * (d - j + 1).
- To minimize T, we should assign larger weights to more negative D_j (since D_j can be negative) and smaller weights to larger positive D_j. This is achieved by sorting the deltas D_j in nondecreasing order and pairing them with weights w_j = d - j + 1 (which are in nonincreasing order). In other words, sort D_j ascending and compute T with weights  d, d-1, ..., 1.
- The algorithm is:
  1) Compute S_0 = sum_i A_i * C_i.
  2) Collect deltas for all i with A_i != B_i: +C_i if A_i == 0, -C_i if A_i == 1.
  3) If d = 0, answer is 0.
  4) Sort deltas ascending. Compute T = d*S_0 + sum_{j=1..d} delta_j * (d - j + 1).
- This runs in O(N log N) due to sorting, which fits N up to 2e5.

None

### Code
```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    N = int(next(it))

    A = [int(next(it)) for _ in range(N)]
    B = [int(next(it)) for _ in range(N)]
    C = [int(next(it)) for _ in range(N)]

    # Initial S0: sum of A_i * C_i
    S0 = 0
    for i in range(N):
        S0 += A[i] * C[i]

    # Collect deltas for indices where A_i != B_i
    deltas = []
    for i in range(N):
        if A[i] != B[i]:
            if A[i] == 0:
                deltas.append(C[i])   # flipping 0 -> 1 increases S by C[i]
            else:
                deltas.append(-C[i])  # flipping 1 -> 0 decreases S by C[i]

    d = len(deltas)
    if d == 0:
        print(0)
        return

    deltas.sort()  # ascending: most negative first
    total = d * S0
    for idx, delta in enumerate(deltas, start=1):
        weight = d - idx + 1  # weights: d, d-1, ..., 1
        total += delta * weight

    print(total)

if __name__ == "__main__":
    main()
```
