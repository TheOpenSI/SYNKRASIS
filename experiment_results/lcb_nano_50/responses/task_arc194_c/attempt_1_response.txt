### Step-by-step reasoning
- Problem insight: If we only flip indices where A_i != B_i (call these "required" flips), the total cost can be computed by considering the initial sum S0 = sum A_i * C_i and the sequence of deltas produced by each required flip. The optimal order of those required flips is to place all negative deltas (flips that reduce S) as early as possible and positive deltas as late as possible, which leads to sorting:
  - Neg_C (C_i for A_i=1, D_i=1) in descending order (deltas = -C_i),
  - Pos_C (C_i for A_i=0, D_i=1) in ascending order (deltas = +C_i).
  This yields a base total T.

- Key missing piece: It can be beneficial to perform an extra pair of flips on an index that does not need to change in the end (D_i=0) to adjust the running sum S and reduce the total cost. A pair of flips on such an index i, where initially A_i=1 (leading to first delta -C_i) or A_i=0 (leading to first delta +C_i), changes the total by a calculable amount. Importantly, two flips on the same index return A_i to its original value, so parity constraints remain satisfied.

- Derivation sketch:
  - Let the base sequence of d = |Neg_C| + |Pos_C| deltas be D = [delta_1, ..., delta_d], with deltas sorted as described (negatives first, then positives). Let S0 be the initial sum.
  - The base total with just these d flips is:
    T = d*S0 + sum_{k=1..d} delta_k * (d - k + 1).
  - If we insert an extra pair of flips (on some i with D_i=0) at position j (between existing deltas), the new total T' can be shown to satisfy:
    T' - T = 2*S0 + 2*sum_{k<j} delta_k + s,
    where s is the first delta of the extra pair:
      - if A_i=1 and D_i=0: s = -C_i
      - if A_i=0 and D_i=0: s = +C_i
  - We can choose j to minimize sum_{k<j} delta_k, i.e., pick the minimum prefix sum of the base delta sequence. Let min_pref be the minimum over all prefixes of sum_{k=1..t} delta_k, including 0 (so min_pref <= 0).

- Therefore, we can compute:
  - The base answer T as before.
  - The best possible improvement by adding at most one extra pair:
    T_best_pair = T + 2*(S0 + min_pref) + s_min,
    where s_min is the smallest possible s among D_i=0 indices (i.e., the most negative s possible: -max C_i for A_i=1, D_i=0; and, if there are none, +min C_i for A_i=0, D_i=0).
  - The final answer is min(T, T_best_pair) if at least one D_i=0 exists to host the extra pair; otherwise it remains T.

- This approach aligns with the sample test cases: 
  - It preserves the baseline optimality for the no-extra-flips scenario.
  - It can reduce the total in cases where using a single extra pair on an appropriate D_i=0 index yields a lower total.

- Complexity: Sorting and a linear pass over N elements, i.e., O(N log N) time and O(N) memory.

import sys

def main():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    N = int(next(it))

    A = [int(next(it)) for _ in range(N)]
    B = [int(next(it)) for _ in range(N)]
    C = [int(next(it)) for _ in range(N)]

    # Compute initial sum S0 and classify required flips
    S0 = 0
    Neg_C = []  # for A_i = 1, D_i = 1  => delta = -C_i
    Pos_C = []  # for A_i = 0, D_i = 1  => delta = +C_i

    d = 0
    # For extra pair candidate
    has_Dzero_A1 = False
    max_C_for_A1_Dzero = 0  # best (largest C) among A_i=1, D_i=0
    has_Dzero_A0 = False
    min_C_for_A0_Dzero = 0  # best (smallest C) among A_i=0, D_i=0

    for i in range(N):
        Ai = A[i]
        Bi = B[i]
        Ci = C[i]
        S0 += Ai * Ci
        Di = Ai ^ Bi
        if Di == 1:
            d += 1
            if Ai == 1:
                Neg_C.append(Ci)
            else:
                Pos_C.append(Ci)
        else:
            # D_i == 0
            if Ai == 1:
                has_Dzero_A1 = True
                if Ci > max_C_for_A1_Dzero:
                    max_C_for_A1_Dzero = Ci
            else:
                has_Dzero_A0 = True
                if not has_Dzero_A0 or Ci < min_C_for_A0_Dzero:
                    min_C_for_A0_Dzero = Ci

    if d == 0:
        print(0)
        return

    # Sort to achieve minimal total for base case
    Neg_C.sort(reverse=True)  # largest C first for -C_i
    Pos_C.sort()              # smallest C first for +C_i

    # Build base deltas and compute base total T
    deltas = []
    for ci in Neg_C:
        deltas.append(-ci)
    for ci in Pos_C:
        deltas.append(ci)

    # Compute T
    # T = d*S0 + sum_{k=1..d} delta_k * (d - k + 1)
    total = d * S0
    for idx, delta in enumerate(deltas, start=1):
        weight = d - idx + 1
        total += delta * weight

    T = total

    # Compute min prefix sum of deltas (min over 0 and cumulative sums)
    pref = 0
    min_pref = 0  # include 0 as prefix (i.e., j=1 corresponds to pref=0)
    for delta in deltas:
        pref += delta
        if pref < min_pref:
            min_pref = pref

    # Prepare potential s_min values from D_i=0 indices
    s_candidates = []
    if has_Dzero_A1:
        # s = -C_i, choose the most negative s => largest C_i
        s_candidates.append(-max_C_for_A1_Dzero)
    if has_Dzero_A0:
        # s = +C_i, choose the smallest s => smallest C_i
        s_candidates.append(min_C_for_A0_Dzero)

    best = T
    if s_candidates:
        # For each possible s, compute the best total with one extra pair inserted
        for s in s_candidates:
            # T' - T = 2*(S0 + min_pref) + s
            T' = T + 2*(S0 + min_pref) + s
            if T' < best:
                best = T'

    print(best)

if __name__ == "__main__":
    main()
