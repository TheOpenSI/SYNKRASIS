### Step-by-step reasoning
- We have N squares, with some bad intervals [L_i, R_i] disjoint and sorted. All other squares are good. We start at position 1 (which is guaranteed to be good) and may jump from x to x+i where A ≤ i ≤ B, landing only on good squares and staying within 1..N.
- Since N can be as large as 1e12, we cannot simulate every single square. However A,B ≤ 20, so the jump window is small. We can model the process as a small finite automaton that tracks the reachability of the last B squares.
- State encoding:
  - Let M be a B-bit integer representing the reachability of the last B positions ending at current position p: positions [p-B+1, ..., p], where bit k (0-based) corresponds to position p-B+1+k (bit 0 is the oldest, bit B-1 is the newest, i.e., position p).
  - At a good (non-bad) next position x = p+1, reachability Next(x) is True if and only if there exists i ∈ [A,B] such that x-i is within the last B positions and reachable; equivalently Next = OR of bits M[0..B-A].
  - The transition when moving to x = p+1 is:
    - M' = (M >> 1) | (Next << (B-1))
    - Where Next is 1 if (M & prefix_mask) != 0, with prefix_mask = (1<<(B-A+1)) - 1, i.e., OR of bits 0..B-A.
  - If x is bad, Next = 0, so M' = (M >> 1).
- Initialization:
  - We start with position 1 already reached. So after processing position 1, the state is M = 1 << (B-1) (only position 1 in the window is reachable).
- We process the timeline block by block:
  - Safe blocks: consecutive safe positions. We need to advance many steps; we accelerate by spotting cycles in M. Since M has at most 2^B states (≤ 1,048,576), the sequence of M across a safe block is a deterministic finite automaton. When a cycle is detected, we can skip many full cycles at once, keeping M unchanged, until we reach near the end of the block or reach N, then continue step by step for the remainder.
  - Bad blocks: consecutive bad positions. Each bad step just shifts M right by 1 with Next=0. After at most B such steps, M becomes 0 and further bad steps do not change it. We can fast-forward across large bad blocks accordingly.
- Edge cases:
  - M can be 0 (no reachability in the last B squares); we still correctly propagate since Next depends on M.
  - A = 1 (shortest jump) and B ≤ 20; prefix masks adapt accordingly.
  - If N lies inside a bad block, the input guarantees this cannot happen (R_i < N and 1 < L_i).

- The overall approach processes blocks in O(number_of_blocks * min(block_cycle_limit, 2^B)) time, with a robust cycle-skipping strategy to handle large safe blocks efficiently.

None

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    N = int(next(it))
    M = int(next(it))
    A = int(next(it))
    B = int(next(it))

    intervals = []
    for _ in range(M):
        L = int(next(it)); R = int(next(it))
        intervals.append((L, R))

    # Precompute masks
    # prefix_mask covers bits 0..(B-A)
    prefix_mask = (1 << (B - A + 1)) - 1
    maskB = (1 << B) - 1

    # State initialization
    current = 1
    Mstate = 1 << (B - 1)  # after processing position 1, only position 1 is reachable

    # Helper: process a safe block of length "length" starting at current (we already processed up to current)
    # Returns True if we reach N during this block (landing on N with Next=1)
    def process_safe_block(length):
        nonlocal current, Mstate
        if length <= 0:
            return False
        end = current + length
        seen = dict()
        while current < end:
            # Cycle detection on Mstate
            if Mstate in seen:
                cycle_start_pos = seen[Mstate]
                cycle_len = current - cycle_start_pos
                rem = end - current
                if cycle_len > 0 and rem > 0:
                    # Compute how many full cycles we can skip without skipping the potential landing on N
                    if N > end:
                        max_cycles = rem // cycle_len
                    else:
                        # N is inside this block; ensure we don't skip past N
                        max_cycles = (N - current) // cycle_len
                        if max_cycles < 0:
                            max_cycles = 0
                    if max_cycles > 0:
                        # If N lies exactly at the end of a cycle, avoid skipping that final step
                        if N >= current and N <= end and ((N - current) % cycle_len) == 0:
                            max_cycles = max(0, max_cycles - 1)
                        if max_cycles > 0:
                            current += max_cycles * cycle_len
                            # Mstate remains the same
                            if current == N:
                                return False  # haven't landed yet; landing would have been checked during real steps
                            continue
                # If we can't skip or can't skip safely, proceed to step-by-step
            else:
                seen[Mstate] = current

            Next = 1 if (Mstate & prefix_mask) != 0 else 0
            Mstate = (Mstate >> 1) | (Next << (B - 1))
            current += 1
            if current == N and Next == 1:
                return True
        return False

    # Helper: process a bad block of length "length"
    def process_bad_block(length):
        nonlocal current, Mstate
        if length <= 0:
            return
        # For the first B bad steps, Mstate gets shifted right; after B steps, Mstate becomes 0.
        k = min(length, B)
        for _ in range(k):
            current += 1
            Mstate >>= 1
            # If N were bad, we'd check landing on N, but problem guarantees N is not bad.
        if length > B:
            # After B shifts, Mstate is 0; skip remaining bad steps
            current += (length - B)
            Mstate = 0

    # Process blocks
    # Iterate over M bad intervals, plus a final safe block to N
    for idx in range(M + 1):
        # Safe block before the next bad interval (or up to N if no more bad intervals)
        if idx < M:
            end_safe = intervals[idx][0] - 1
        else:
            end_safe = N

        length_safe = end_safe - current
        if length_safe > 0:
            if process_safe_block(length_safe):
                print("Yes")
                return

        current = end_safe
        if current >= N:
            break

        if idx < M:
            # Bad block
            L, R = intervals[idx]
            length_bad = R - L + 1
            process_bad_block(length_bad)
            current = R
            if current >= N:
                break

            # After bad block, next safe block starts at R+1 (handled in next iteration)

    # After processing all blocks, if we haven't landed on N, it's not reachable
    print("No")


if __name__ == "__main__":
    main()
```
