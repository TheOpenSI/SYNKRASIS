### Step-by-step reasoning
- The blocks never move between columns; each column evolves independently.
- If any column is empty initially (no blocks in that column), the bottom row can never be fully occupied across all columns, so no block will ever be removed. In this case, all blocks always exist.
- If every column has at least one block:
  - Let b_x be the minimum Y in column x (the lowest block in that column initially).
  - The bottom row becomes full for the first time at time t = max_x(b_x). After this moment, removals can happen on subsequent steps.
  - Let k_x be the number of blocks in column x. Across time, removals happen in synchronized steps: at times t = B, B+1, ..., B+(m-1), where B = max_x(b_x) and m = min_x(k_x). In every such removal step, exactly one block from the bottom of each column is removed, i.e., in a column, blocks with initial rank r_i (sorted by initial Y ascending, 1 is the lowest) are removed for r_i <= s, where s is the number of removal steps already performed.
  - Therefore, for a block i with rank r_i in its column:
    - It survives all removals if r_i > m.
    - It survives after s removals (0 <= s <= m) if r_i > s.
- For a given query with time T and block A:
  - If any column is empty initially: answer is Yes for all queries.
  - Otherwise:
    - If T < B: no removals have occurred; block exists.
    - If B <= T <= B + m - 1: s = T - B + 1 removals have occurred; block exists if r_A > s.
    - If T > B + m - 1: all removals have occurred; block exists if r_A > m.
- This yields O(N log N) preprocessing (sorting within each non-empty column) and O(1) per query.

Potential edge cases:
- Some column empty => all blocks always exist.
- All columns have blocks but with varying counts; m governs how many full removal rounds occur.
- Large values of T and large N handled by Python integers and linear preprocessing with per-column sorts.

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)
    N = next(it); W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # 0-based block index

    # Collect blocks per column
    cols = [[] for _ in range(W + 1)]
    for i in range(N):
        cols[X[i]].append((Y[i], i))

    rank = [0] * N
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    if not hasZero:
        # Compute B = max_x minY_x and m = min_x k_x
        mins = []
        for x in range(1, W + 1):
            col = cols[x]
            minY = min(y for (y, idx) in col)
            mins.append(minY)
        B = max(mins)
        m = min(len(col) for col in cols[1:])

        # Assign rank within each column by initial Y (ascending)
        for x in range(1, W + 1):
            col = cols[x]
            col.sort(key=lambda t: t[0])  # sort by Y
            for pos, (y, idx) in enumerate(col, start=1):
                rank[idx] = pos

    out_lines = []
    if hasZero:
        out_lines = ["Yes"] * Q
    else:
        for j in range(Q):
            t = T_arr[j]
            a = A_arr[j]
            r = rank[a]
            if t < B:
                out_lines.append("Yes")
            elif t <= B + m - 1:
                s = t - B + 1
                out_lines.append("Yes" if r > s else "No")
            else:
                out_lines.append("Yes" if r > m else "No")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
