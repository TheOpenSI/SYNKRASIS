### Step-by-step reasoning
- The problem asks, for each query [L, R], to form as many kagamimochi as possible by pairing mochi in that subarray such that in each pair the larger mochi is at least twice the smaller one (i.e., for a pair (i, j) with i < j, A[j] >= 2*A[i]).
- A valid solution must ensure that every mochi is used at most once across all pairs (no reuse of a mochi).
- A known approach precomputes for each i the earliest index t[i] > i with A[t[i]] >= 2*A[i], and then uses a greedy matching with a DSU (disjoint-set union) structure to allocate the smallest available right endpoint j for each left index i in [L, R-1], scanning i left-to-right.
- However, a subtle issue arises: a mochi can be used as the right element in an earlier pair (i.e., as a “top” in a kagamimochi) and later could be considered as a left element in another pair if we don’t track whether it has already been used as a right end. This could lead to reusing the same mochi in two different pairs, which is invalid.
- Fix: track mochi that have already been used as the right endpoint (i.e., used as a top in some pair) within each query. When considering i as the left element in the current iteration, skip i if it has already been used as a right endpoint. When we form a pair (i, j), mark j as used on the right. This guarantees every mochi is used at most once.
- The overall approach remains:
  - Precompute t[i] and lval[i] where lval[i] = max(i+1, t[i]).
  - For each query, use a DSU over right-slot indices corresponding to mochi positions [L+1, R], and a set to track which mochi have already been used as a right endpoint.
  - Iterate i from L to R-1, skip if i was already used as a right endpoint, and attempt to assign the smallest available right endpoint j >= lval[i]. If assigned, mark j as used and remove that slot using DSU.
- This guarantees correctness (no mochi is reused) and preserves the efficient structure of the previous solution.

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    N = next(it)
    A = [next(it) for _ in range(N)]
    Q = next(it)
    queries = []
    for _ in range(Q):
        L = next(it) - 1  # 0-based
        R = next(it) - 1
        queries.append((L, R))

    # Precompute t[i]: first index j > i with A[j] >= 2*A[i], or N if none
    t = [N] * N
    j = 0
    for i in range(N):
        if j <= i:
            j = i + 1
        while j < N and A[j] < 2 * A[i]:
            j += 1
        t[i] = j

    # Precompute l[i] = max(i+1, t[i])
    lval = [0] * N
    for i in range(N):
        li = t[i]
        if li < i + 1:
            li = i + 1
        lval[i] = li

    out_lines = []
    for L, R in queries:
        m = R - L  # number of possible right slots (indices base..R)
        if m <= 0:
            out_lines.append("0")
            continue

        base = L + 1  # first possible right index
        # DSU over right slots indices 0..m-1, with sentinel at m
        parent = list(range(m + 1))

        def find(x):
            # Iterative path-compressed find
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        ans = 0
        used_right = set()  # mochi indices used as the right endpoint in this query

        for i in range(L, R):  # i in [L, R-1]
            if i in used_right:
                # mochi i already used as a right endpoint in a previous pair
                continue

            li = lval[i]
            if li > R:
                continue
            s_min = li - base  # 0-based index into right-slot space
            if s_min < 0:
                s_min = 0
            if s_min >= m:
                continue

            idx = find(s_min)
            if idx >= m:
                continue

            jpos = base + idx  # actual mochi index for the right endpoint
            ans += 1
            used_right.add(jpos)
            # remove slot idx
            parent[idx] = find(idx + 1)

            if ans == m:
                break

        out_lines.append(str(ans))

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
