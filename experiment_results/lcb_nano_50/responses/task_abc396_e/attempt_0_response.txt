### Step-by-step reasoning
- Each constraint A_{X_i} xor A_{Y_i} = Z_i can be treated bit by bit. For a fixed bit k, define b_i as the k-th bit of A_i. Then for every constraint we must have b_{X_i} xor b_{Y_i} = z_i_k, where z_i_k is the k-th bit of Z_i.
- This yields a system of linear equations over GF(2) on variables b_i. The underlying graph has N vertices and M edges (X_i, Y_i). For a connected component:
  - If the constraints are consistent (i.e., all cycles satisfy xor of z along the cycle equals 0), there are exactly two solutions: one with the root bit 0, and one with the root bit 1 (global flip in that component).
  - If a cycle yields inconsistency, no solution exists for that bit (and thus overall no good sequence exists).
- To minimize the sum of A_i, we can choose the better orientation (root bit 0 or 1) independently for each component and each bit. For a component with size s and cnt1 ones when root is 0, the two possibilities give cnt1 ones or s - cnt1 ones. Choose the smaller.
- We can process each bit independently:
  - Do a BFS/DFS to assign provisional bits val[i] for all vertices, assuming root of each component is 0. Detect inconsistencies while traversing edges.
  - For each component, decide orientation (0 if cnt1 <= s - cnt1, else 1).
  - Finally set A_i’s k-th bit to val[i] ^ orientation_of_component(i).
- Complexity: We process up to 30 bits (since Z_i <= 1e9), each in O(N + M). With N up to 2e5 and M up to 1e5, this is efficient.

Edge cases:
- M = 0: no constraints, minimal A is all zeros.
- Inconsistent constraints for any bit: output -1.
- Isolated vertices (no incident edges) are their own components; orientation will be 0 leading to bit 0, contributing nothing to the sum.

import sys
from collections import deque

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    M = next(it)

    X = [0]*M
    Y = [0]*M
    Z = [0]*M

    for i in range(M):
        X[i] = next(it) - 1
        Y[i] = next(it) - 1
        Z[i] = next(it)

    # Build adjacency by incident edges (store edge indices)
    adj = [[] for _ in range(N)]
    for e in range(M):
        u = X[e]
        v = Y[e]
        adj[u].append(e)
        adj[v].append(e)

    maxZ = max(Z) if M > 0 else 0
    maxbit = maxZ.bit_length()

    A = [0] * N

    for k in range(maxbit):
        comp_id = [-1] * N  # component index per vertex
        val = [0] * N       # provisional bit values when root of each component is 0
        orient = []         # orientation per component: 0 (keep), 1 (flip)
        comp_cnt = 0

        for s in range(N):
            if comp_id[s] != -1:
                continue
            # start new component from s
            dq = deque([s])
            comp_id[s] = comp_cnt
            val[s] = 0
            comp_size = 0
            cnt1 = 0

            while dq:
                u = dq.popleft()
                comp_size += 1
                if val[u] == 1:
                    cnt1 += 1
                for e in adj[u]:
                    zbit = (Z[e] >> k) & 1
                    v = X[e] ^ Y[e] ^ u  # the other endpoint of edge e
                    if comp_id[v] == -1:
                        comp_id[v] = comp_cnt
                        val[v] = val[u] ^ zbit
                        dq.append(v)
                    else:
                        if val[v] != (val[u] ^ zbit):
                            print(-1)
                            return
            # orientation that minimizes ones in this component for this bit
            orient.append(0 if cnt1 <= comp_size - cnt1 else 1)
            comp_cnt += 1

        # incorporate bit k into A using the computed orientations
        for i in range(N):
            c = comp_id[i]
            bit = val[i] ^ orient[c]
            if bit:
                A[i] |= (1 << k)

    print(' '.join(map(str, A)))

if __name__ == "__main__":
    main()
