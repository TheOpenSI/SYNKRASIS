### Step-by-step reasoning
1. Consider all valid arrangements: choose k cells out of N = m * n on the grid. For every unordered pair of distinct cells (a, b), their Manhattan distance contributes to the total sum if and only if both cells are occupied in the arrangement.
2. By linearity of expectation (or summation), the total sum over all arrangements equals:
   - C(N-2, k-2) times the sum of Manhattan distances over all unordered pairs of cells, since once we fix two cells a and b to be occupied, the remaining k-2 pieces can be placed in any of the C(N-2, k-2) ways among the other N-2 cells.
3. Compute sum of Manhattan distances over all unordered pairs of cells in an m x n grid. Break distance into x- and y-components:
   - Sum of |dx| over all pairs: fix two distinct rows r1 < r2 with difference d = r2 - r1. There are (n^2) ways to choose columns (y1, y2) independently. The total contribution is n^2 * sum_{d=1}^{m-1} d*(m-d).
   - Sum of |dy| over all pairs: similarly, m^2 * sum_{d=1}^{n-1} d*(n-d).
4. Use the closed forms:
   - sum_{d=1}^{m-1} d*(m-d) = m(m-1)(m+1)/6
   - sum_{d=1}^{n-1} d*(n-d) = n(n-1)(n+1)/6
   Thus:
   SumPairs = n^2 * [m(m-1)(m+1)/6] + m^2 * [n(n-1)(n+1)/6]
5. Final answer: Ans = C(N-2, k-2) * SumPairs (mod 1e9+7).
6. Implement with modular arithmetic. Precompute factorials and inverse factorials up to N for binomial coefficients. All edge cases (including m=1 or n=1) are covered by the formulas (the sum terms become zero appropriately).
7. Complexity: O(N) time for precomputation, with N = m*n ≤ 1e5, and O(N) space.

### Requirements
None

### Code
```
class Solution:
    def distanceSum(self, m: int, n: int, k: int) -> int:
        MOD = 10**9 + 7
        N = m * n  # total cells

        # Precompute factorials and inverse factorials up to N for binomial C(a, b)
        fact = [1] * (N + 1)
        for i in range(1, N + 1):
            fact[i] = fact[i - 1] * i % MOD

        invfact = [1] * (N + 1)
        invfact[N] = pow(fact[N], MOD - 2, MOD)
        for i in range(N, 0, -1):
            invfact[i - 1] = invfact[i] * i % MOD

        def comb(a, b):
            if b < 0 or b > a:
                return 0
            return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

        inv6 = pow(6, MOD - 2, MOD)

        # S_m = sum_{d=1}^{m-1} d*(m-d) = m*(m-1)*(m+1)/6
        Sm = (m % MOD) * ((m - 1) % MOD) % MOD
        Sm = Sm * ((m + 1) % MOD) % MOD
        Sm = Sm * inv6 % MOD

        # S_n = sum_{d=1}^{n-1} d*(n-d) = n*(n-1)*(n+1)/6
        Sn = (n % MOD) * ((n - 1) % MOD) % MOD
        Sn = Sn * ((n + 1) % MOD) % MOD
        Sn = Sn * inv6 % MOD

        n2 = (n % MOD) * (n % MOD) % MOD  # n^2
        m2 = (m % MOD) * (m % MOD) % MOD  # m^2

        SumPairs = (n2 * Sm + m2 * Sn) % MOD

        c = comb(N - 2, k - 2)
        ans = SumPairs * c % MOD
        return ans
```
