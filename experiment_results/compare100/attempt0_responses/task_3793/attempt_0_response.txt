### Step-by-step reasoning
- We are allowed to pick any substring from s (including empty) and any substring from t (including empty), then concatenate them as A + B, and we want the longest possible palindrome.
- A straightforward approach is to enumerate all possible substrings from s and all substrings from t, form their concatenation, and check if it is a palindrome.
- The number of substrings for a string of length n is 1 + n(n+1)/2 when including the empty substring, which for n ≤ 30 gives at most 466 substrings. The total combinations are at most 466 * 466 ≈ 217k, which is feasible.
- For each pair (A, B), we form P = A + B and check if P is a palindrome. If yes, update the maximum length.
- Edge cases:
  - Both substrings could be empty, yielding length 0 (we initialize max length to 0).
  - Palindromes consisting solely of a substring from s or solely from t are captured when the other substring is empty.
  - All characters distinct across s and t still yield at least length 1 by selecting a single character from either string.
- Complexity: O((|s|(|s|+1)/2 + 1) * (|t|(|t|+1)/2 + 1)) substrings checked, each palindrome check costs O(|s|+|t|) in worst case. With |s|,|t| ≤ 30 this is easily fast enough.

### Requirements
None

### Code
```python
class Solution:
    def longestPalindrome(self, s: str, t: str) -> int:
        # Generate all substrings of s (including empty) and all substrings of t (including empty)
        n, m = len(s), len(t)
        A_subs = ['']  # empty substring from s
        for i in range(n):
            for j in range(i + 1, n + 1):
                A_subs.append(s[i:j])
        
        B_subs = ['']  # empty substring from t
        for i in range(m):
            for j in range(i + 1, m + 1):
                B_subs.append(t[i:j])
        
        max_len = 0
        for A in A_subs:
            for B in B_subs:
                P = A + B
                if P == P[::-1]:
                    if len(P) > max_len:
                        max_len = len(P)
        
        return max_len
```
