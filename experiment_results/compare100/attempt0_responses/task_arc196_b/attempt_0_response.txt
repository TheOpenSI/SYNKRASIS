### Step-by-step reasoning
- Represent every shared boundary (between two adjacent tiles) by a boolean variable indicating whether the line segment touches the boundary's midpoint on that side of the tile.
- For a cell (i, j), let Up, Down be the vertical boundary booleans above and below the cell, and Left, Right be the horizontal boundary booleans to the left and right of the cell.
- The tile in (i, j) has type p = 1 if S[i][j] = 'A' and p = 0 if S[i][j] = 'B'.
- Observing the possible two-edge patterns:
  - Type A (adjacent edges): Up XOR Down = 1 and Left XOR Right = 1.
  - Type B (opposite edges): Up XOR Down = 0 and Left XOR Right = 0.
- Therefore, for every cell (i, j) we must satisfy:
  - Up XOR Down = p(i, j)
  - Left XOR Right = p(i, j)
- These two equations decouple: 
  - The vertical edges (the Down values along a fixed column) form a cycle of length H with equations Down(i-1, j) XOR Down(i, j) = p(i, j) for all i. A solution exists for column j iff XOR over i of p(i, j) is 0. If it holds for all columns, there are exactly 2 possible assignments for the vertical edges of that column (choice of Down(0, j)).
  - The horizontal edges (the Right values along a fixed row) form a cycle of length W with equations Right(i, j-1) XOR Right(i, j) = p(i, j) for all j. A solution exists for row i iff XOR over j of p(i, j) is 0. If it holds for all rows, there are exactly 2 possible assignments for the horizontal edges of that row (choice of Right(i, 0)).
- The vertical and horizontal edge choices are independent, so:
  - If any column has odd parity of A’s (i.e., XOR of p(i, j) over i is 1), there are 0 valid placements.
  - If any row has odd parity of A’s (i.e., XOR of p(i, j) over j is 1), there are 0 valid placements.
  - If every column parity is 0 and every row parity is 0, the total number of valid edge assignments is 2^(W) * 2^(H) = 2^(H+W).
- We only need to compute the parities:
  - Column parity: for each column j, XOR across i of (S[i][j] == 'A').
  - Row parity: for each row i, XOR across j of (S[i][j] == 'A').

Algorithm per test case:
- Compute col_parity[j] = 0 for all j; as you read the grid, flip col_parity[j] whenever you see an 'A' at (i, j).
- For each row, compute the number of 'A' in that row; if any row has an odd count of 'A', answer is 0.
- After processing all rows, if any col_parity[j] is 1, answer is 0.
- Otherwise, answer is pow(2, H+W, MOD) with MOD = 998244353.

Edge cases:
- Large T with total HW up to 1e6: O(HW) across all test cases is fine.
- Ensure proper modular exponentiation.

### Code

import sys

MOD = 998244353

def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    idx = 1
    out_lines = []
    for _ in range(t):
        H = int(data[idx]); W = int(data[idx+1]); idx += 2

        col_parity = [0] * W
        ok = True
        # process H lines
        for i in range(H):
            s = data[idx].decode()
            idx += 1
            if ok:
                # row parity: number of 'A' in this row must be even
                cntA = s.count('A')
                if (cntA & 1) != 0:
                    ok = False
                # update column parities
                for j, ch in enumerate(s):
                    if ch == 'A':
                        col_parity[j] ^= 1
            else:
                # skip heavy work if already invalid
                # just continue to consume input
                pass

        if not ok:
            out_lines.append("0")
            continue

        if any(col_parity[j] != 0 for j in range(W)):
            out_lines.append("0")
            continue

        ans = pow(2, H + W, MOD)
        out_lines.append(str(ans))

    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
