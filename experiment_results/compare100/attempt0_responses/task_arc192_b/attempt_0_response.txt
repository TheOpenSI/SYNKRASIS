### Step-by-step reasoning
- There are N indices. To end the game, every index must be touched (selected) at least once, i.e., there must be N “first-time” openings of indices.
- On a move, a player picks any index with A_i > 0. If that index hasn’t been touched before, it enters the set S. The game ends immediately when S contains all indices.
- Extra moves are possible: after an index is opened, players can continue to pick that index (as long as A_i > 0) to delay the moment when the last index is opened. These extra moves do not affect which indices have been opened, but they change the total number of moves.
- However, regardless of how many extra moves are played, the last new index must be opened on some move, and the opening moves occur exactly N times (one per index). Since the first move is by Fennec, the player who performs the last opening move depends only on the parity of N:  
  - If N is odd, the last opening move is on Fennec’s turn, so Fennec wins.
  - If N is even, the last opening move is on Snuke’s turn, so Snuke wins.
- The actual A_i values do not affect the outcome under optimal play; only the parity of N matters.

Edge cases:
- N = 1 (odd) -> Fennec wins, which matches the rule.
- N up to 2e5, A_i up to 1e9: we only need N’s parity, so we ignore A_i values.

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    if not data:
        return
    N = data[0]
    # A_1 ... A_N are provided but not needed for the result
    print("Fennec" if N % 2 == 1 else "Snuke")

if __name__ == "__main__":
    main()
```
