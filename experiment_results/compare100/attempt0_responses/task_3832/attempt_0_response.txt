### Step-by-step reasoning
- Model the problem as a shortest-path problem on a directed graph.
- Nodes: positions 0, 1, ..., n (where n is the length of cost). We start at node n and want the minimum cost to reach each node i in [0, n-1].
- Edges:
  - If you are at position p and want to move to a position to the right (i > p), that swap is with someone behind you and is free. So add edges p -> i with weight 0 for all i > p.
  - If you want to move to a position in front (i < p), you must pay cost[i] to swap with person i. So add edges p -> i with weight cost[i] for all i < p.
- All costs are non-negative, so Dijkstra’s algorithm is appropriate.
- Run Dijkstra from start node n. The distance to node i yields the minimum cost to reach i from n.
- The required answer is the array of distances for nodes 0..n-1.

Edge cases:
- Smallest case: n = 1. Ensure we return a list of length 1.
- All costs positive as per constraints; no zero-cost except the allowed free moves to the right.
- Ensure we do not modify the given function signature; only implement the body.
- Complexity is acceptable: O(n^2 log n) in practice for n <= 100.

from typing import List
import heapq

class Solution:
    def minCosts(self, cost: List[int]) -> List[int]:
        n = len(cost)
        # Nodes are 0..n
        N = n + 1
        INF = 10**9
        dist = [INF] * (N)
        dist[n] = 0
        pq = [(0, n)]  # (distance, node)

        while pq:
            d, u = heapq.heappop(pq)
            if d != dist[u]:
                continue

            # Move to the right (i > u) with 0 cost
            for v in range(u + 1, N):
                if dist[v] > d:
                    dist[v] = d
                    heapq.heappush(pq, (d, v))

            # Move to the left (i < u) with cost[i]
            for v in range(0, u):
                nd = d + cost[v]
                if dist[v] > nd:
                    dist[v] = nd
                    heapq.heappush(pq, (nd, v))

        # Return costs for positions 0..n-1
        return dist[:n]
