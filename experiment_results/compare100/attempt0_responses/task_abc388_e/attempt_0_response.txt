### Step-by-step reasoning
- We need to form the maximum number K of disjoint pairs (top, bottom) such that top_size * 2 <= bottom_size.
- Since the sizes are sorted ascending, at most N/2 pairs can be formed (each pair uses 2 mochi). A natural greedy approach is to select the smallest N//2 elements as potential tops and the largest N - N//2 elements as potential bottoms.
- Use a two-pointer technique:
  - i points to the current smallest unused top (start at 0).
  - j points to the current candidate bottom in the upper half (start at N//2).
  - If A[i] * 2 <= A[j], we can form a pair: increment i, j, and count one pair.
  - Otherwise, A[j] is too small to pair with A[i], so move j forward to find a bigger bottom.
- Continue until we exhaust either the tops (i reaches N//2) or the bottoms (j reaches N).
- This linear-time greedy yields the maximum possible number of pairs due to always attempting to pair the smallest available top with the smallest feasible bottom.
- Edge cases:
  - No pairs possible: result 0.
  - Duplicates and equal sizes are handled by the condition a <= b/2.
  - N may be odd; we still use N//2 for tops, which is correct.

Time complexity: O(N)
Space complexity: O(1) beyond input storage

### Requirements
None

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        print(0)
        return
    N = data[0]
    A = data[1:1+N]  # The input provides N numbers in ascending order
    # According to problem statement, A is already sorted ascending.
    i = 0
    j = N // 2
    ans = 0
    tops = N // 2
    while i < tops and j < N:
        if A[i] * 2 <= A[j]:
            ans += 1
            i += 1
            j += 1
        else:
            j += 1
    print(ans)

if __name__ == "__main__":
    main()
```
