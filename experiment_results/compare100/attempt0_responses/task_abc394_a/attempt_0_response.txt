### Step-by-step reasoning
- Read the input string S from standard input.
- Create a new string that includes only the characters equal to '2', preserving their original order.
- Join the kept characters and print the result.
- Complexity: O(n) time where n is the length of S, and O(k) space where k is the number of '2's in S.
- Edge cases:
  - S contains digits with multiple '2's, keep all of them in order.
  - S contains digits with other digits interspersed; they are ignored.
  - The constraints guarantee at least one '2', but if none were present, the output would be an empty string.

### Requirements
None

### Code
```
import sys

def main():
    S = sys.stdin.readline().strip()
    result = [c for c in S if c == '2']
    print(''.join(result))

if __name__ == "__main__":
    main()
```
