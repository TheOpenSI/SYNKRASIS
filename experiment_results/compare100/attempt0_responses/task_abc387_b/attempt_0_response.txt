### Step-by-step reasoning
- The 9x9 multiplication grid has rows and columns 1 through 9. The value in cell (i, j) is i * j.
- The sum of all 81 cells is (sum of 1..9) * (sum of 1..9) = 45 * 45 = 2025.
- We need the sum of all entries that are not X. This equals total_sum - sum_of_entries_equal_to_X.
- The sum of entries equal to X is X times the number of cells (i, j) with i, j in [1, 9] and i * j = X. Since multiple cells can have the same value, we must account for all occurrences.
- Count such occurrences by iterating i from 1 to 9: if X % i == 0 and j = X // i is in [1, 9], then the cell (i, j) contains X; increment the count.
- Finally, answer = 2025 - X * count. If X does not appear in the grid, count is 0 and the answer is 2025.

Edge cases:
- X not present in the grid (e.g., X = 11): answer should be 2025.
- X present multiple times (e.g., X = 36): count correctly accounts for all ordered (i, j) pairs within 1..9, including symmetric ones.

### Code
```
#!/usr/bin/env python3
import sys

def main():
    data = sys.stdin.read().strip()
    if not data:
        return
    X = int(data)

    total = 45 * 45  # sum_{i=1..9} i * sum_{j=1..9} j = 2025
    count = 0
    for i in range(1, 10):
        if X % i == 0:
            j = X // i
            if 1 <= j <= 9:
                count += 1

    ans = total - X * count
    print(ans)

if __name__ == "__main__":
    main()
```
