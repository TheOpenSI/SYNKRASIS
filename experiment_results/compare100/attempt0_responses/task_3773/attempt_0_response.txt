### Step-by-step reasoning
- We must repeatedly perform operations on the array until it becomes non-decreasing. An operation replaces the adjacent pair with the minimum sum (leftmost if there are ties) by their total sum, effectively shrinking the array by one element.
- Algorithm outline:
  1. Check if the array is non-decreasing. If yes, return 0.
  2. Otherwise, find the leftmost index i such that nums[i] + nums[i+1] is the minimal sum among all adjacent pairs. This guarantees leftmost behavior in case of ties.
  3. Replace the pair at i with their sum: nums[i] = nums[i] + nums[i+1], and remove nums[i+1].
  4. Increment operation count and repeat from step 1.
- Edge cases:
  - If nums has length 1, it is already non-decreasing -> 0.
  - If already non-decreasing initially -> 0.
  - Negative numbers are allowed; the algorithm naturally handles them since we use actual sums.
  - The process terminates because the array length strictly decreases with every operation, and a single-element array is non-decreasing.
- Complexity considerations: At most n-1 operations for an array of length n (n <= 50). Each operation scans O(n) adjacent pairs to find the minimum, so overall O(n^2) in the worst case, which is fine here.

### Requirements
None

### Code
```python
from typing import List

class Solution:
    def minimumPairRemoval(self, nums: List[int]) -> int:
        def is_sorted(arr: List[int]) -> bool:
            for i in range(1, len(arr)):
                if arr[i] < arr[i - 1]:
                    return False
            return True

        ops = 0
        # If already sorted or trivial length
        while not is_sorted(nums):
            # Find the leftmost index of the minimum adjacent sum
            min_sum = None
            min_idx = 0
            for i in range(len(nums) - 1):
                s = nums[i] + nums[i + 1]
                if (min_sum is None) or (s < min_sum):
                    min_sum = s
                    min_idx = i
            # Replace the pair at min_idx with their sum
            nums[min_idx] = nums[min_idx] + nums[min_idx + 1]
            del nums[min_idx + 1]
            ops += 1

        return ops
```
