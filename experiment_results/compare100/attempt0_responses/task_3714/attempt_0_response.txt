### Step-by-step reasoning
- We are asked to sum, over all subsequences of nums with length at most k, the sum of each subsequence's minimum and maximum, modulo 1e9+7.
- A subsequence of length m chooses m elements from the multiset of values in nums. We can group elements by distinct values. Let distinct sorted values be v1 < v2 < ... < vd with counts c1, c2, ..., cd, and N = sum ci = len(nums).
- Consider the contribution to the total for a fixed subsequence length m:
  - The maximum of the subsequence is some value vj. If we fix j, the number of subsequences of length m whose maximum is exactly vj equals the number of ways to choose t elements from the j-th value group (t >= 1, t <= min(cj, m)) and the remaining m - t elements from values strictly less than vj. By Vandermonde's identity, this count is:
    count_max_m[j] = C(prefix_before_j + cj, m) - C(prefix_before_j, m)
    where prefix_before_j = sum of counts for indices < j.
  - Similarly, the minimum is some value vi. For i, the number of subsequences of length m whose minimum is exactly vi equals the number of ways to choose t elements from i-th group (t >= 1, t <= min(ci, m)) and the remaining m - t elements from values strictly greater than vi. This gives:
    count_min_m[i] = C(N - prefix_before_i, m) - C(N - prefix_before_i - ci, m)
    where prefix_before_i = sum of counts for indices < i.
  - Therefore, the total sum of min+max over all subsequences of length m is:
    Total_m = sum_{i=1..d} vi * ( count_min_m[i] ) + sum_{j=1..d} vj * ( count_max_m[j] )
           = sum_{t=1..d} vt * ( (C(prefix_before_t + ct, m) - C(prefix_before_t, m)) + (C(N - prefix_before_t, m) - C(N - prefix_before_t - ct, m)) )
- This formula uses only binomial coefficients and is O(d) per m. Since k <= 70, the overall complexity is O(N + d*k) which is feasible for N up to 1e5.
- We must sum Total_m for m = 1 to min(k, N).
- Implementation notes:
  - Precompute factorials and inverse factorials up to N to compute C(n, r) quickly.
  - Use modulo arithmetic carefully, ensuring non-negative results after subtractions.

```python
class Solution:
    def minMaxSums(self, nums: List[int], k: int) -> int:
        MOD = 10**9 + 7
        from collections import Counter

        n = len(nums)
        if n == 0:
            return 0

        # Build distinct values with counts, in ascending order
        cnt = Counter(nums)
        items = sorted(cnt.items())  # list of (value, count)
        d = len(items)
        values = [v for v, c in items]
        counts = [c for v, c in items]

        N = n
        # prefix_before[i] = total count of elements with index < i (i.e., with smaller value)
        prefix_before = [0] * d
        s = 0
        for i in range(d):
            prefix_before[i] = s
            s += counts[i]

        # Precompute factorials
        maxN = N
        fact = [1] * (maxN + 1)
        for i in range(1, maxN + 1):
            fact[i] = fact[i-1] * i % MOD
        invfact = [1] * (maxN + 1)
        # Fermat's little theorem for modular inverse since MOD is prime
        invfact[maxN] = pow(fact[maxN], MOD - 2, MOD)
        for i in range(maxN, 0, -1):
            invfact[i-1] = invfact[i] * i % MOD

        def C(n, r):
            if r < 0 or r > n or n < 0:
                return 0
            return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

        max_m = min(k, N)
        ans = 0

        for m in range(1, max_m + 1):
            total_m = 0
            for idx in range(d):
                c = counts[idx]
                pb = prefix_before[idx]

                # count_max_m = C(pb + c, m) - C(pb, m)
                cmx = C(pb + c, m) - C(pb, m)
                if cmx < 0:
                    cmx += MOD

                # count_min_m = C(N - pb, m) - C(N - pb - c, m)
                cmn = C(N - pb, m) - C(N - pb - c, m)
                if cmn < 0:
                    cmn += MOD

                contrib = (cmx + cmn) % MOD
                total_m = (total_m + (values[idx] % MOD) * contrib) % MOD

            ans = (ans + total_m) % MOD

        return ans
```
