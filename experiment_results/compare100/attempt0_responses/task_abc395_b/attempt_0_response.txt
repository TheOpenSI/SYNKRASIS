### Step-by-step reasoning
- The process loops i from 1 to floor((N+1)/2). For each i, it paints a square with corners (i,i) and (N+1-i, N+1-i) with color '#' if i is odd, or '.' if i is even. Later (larger) i overwrites earlier colors in overlapping cells.
- A cell (r, c) belongs to square i if i ≤ r, i ≤ c, r ≤ N+1−i, and c ≤ N+1−i. This is equivalent to i ≤ min(r, c, N+1−r, N+1−c).
- Therefore the last square that touches (r, c) has i = min( min(r, c, N+1−r, N+1−c), m ), where m = floor((N+1)/2).
- The final color is '#' if this i is odd, otherwise '.'.
- This yields an O(N^2) solution without explicit simulation, which is efficient for N ≤ 50.
- Edge cases:
  - N = 1: only cell is '#'.
  - N even: outermost square (i=1) covers all cells with '#'; inner overlays ensure the full pattern as required.
  - N odd: center cell will be '#', others determined by parity of the largest i covering them.

### Requirements
None

### Code
```
import sys

def main():
    data = sys.stdin.read().strip()
    if not data:
        return
    N = int(data)
    m = (N + 1) // 2  # number of painting steps

    lines = []
    for r in range(1, N + 1):
        row = []
        for c in range(1, N + 1):
            t = min(r, c, N + 1 - r, N + 1 - c)
            i0 = t if t <= m else m
            ch = '#' if (i0 % 2) == 1 else '.'
            row.append(ch)
        lines.append(''.join(row))

    print('\n'.join(lines))

if __name__ == "__main__":
    main()
```
