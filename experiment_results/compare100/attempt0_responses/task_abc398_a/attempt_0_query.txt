Find a length-N string that satisfies all of the following conditions:

- Each character is - or =.
- It is a palindrome.
- It contains exactly one or exactly two =s. If it contains two =s, they are adjacent.

Such a string is unique.

Input

The input is given from Standard Input in the following format:
N

Output

Print the answer.

Constraints


- 1 \leq N \leq 100
- N is an integer.

Sample Input 1

4

Sample Output 1

-==-

Sample Input 2

7

Sample Output 2

---=---

Read the input from standard input and write the answer to standard output. The code must be a complete standalone program, do not hard code the sample inputs.
