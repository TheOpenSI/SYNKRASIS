### Step-by-step reasoning
- The problem asks for the maximum absolute difference between any two adjacent elements in a circular array. In a circular array, the last element is also adjacent to the first element.
- Therefore, we need to examine each pair (nums[i], nums[(i+1) % n]) for i from 0 to n-1, compute the absolute difference, and track the maximum.
- Edge cases:
  - If the input length is 2, there are exactly two adjacent pairs: (0,1) and (1,0); both yield the same difference, so the result is simply abs(nums[0] - nums[1]).
  - If the input length is less than 2 (though not given by constraints), the maximum distance would be 0 since there are no adjacent pairs to compare.
- Time complexity: O(n), where n is the length of nums.
- Space complexity: O(1), aside from the loop variables.

### Requirements
None

### Code
```python
from typing import List

class Solution:
    def maxAdjacentDistance(self, nums: List[int]) -> int:
        if nums is None or len(nums) < 2:
            return 0

        n = len(nums)
        max_diff = 0

        for i in range(n):
            diff = abs(nums[i] - nums[(i + 1) % n])
            if diff > max_diff:
                max_diff = diff

        return max_diff
```
