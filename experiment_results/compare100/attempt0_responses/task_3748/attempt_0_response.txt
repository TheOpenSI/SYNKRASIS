### Step-by-step reasoning
- Let grid be an n x n matrix. Diagonals can be identified by delta d = i - j, where i is row index and j is column index.
- The bottom-left triangle (including the main diagonal) corresponds to d >= 0. For each such diagonal, collect all elements along the diagonal in order of increasing i (which is the natural order along that diagonal from the top-left towards bottom-right). Sort these values in non-increasing order and place them back along the same diagonal in that same order of i.
- The top-right triangle corresponds to d < 0. For each such diagonal, collect all elements along the diagonal in order of increasing i, sort these values in non-decreasing order, and put them back along the diagonal in the same order of i.
- Implementation details:
  - For each d >= 0, the diagonal consists of coordinates (i, j) with i from d to n-1 and j = i - d.
  - For each d < 0, the diagonal consists of coordinates (i, j) with i from 0 to n + d - 1 (since d is negative) and j = i - d.
- Edge cases:
  - n = 1: single element, nothing to change.
  - Diagonals with length 1 remain unchanged after sorting.
  - Negative numbers are allowed; sorting handles any integers.
- Time complexity: We process all n^2 elements across diagonals, with sorting per diagonal. Overall O(n^2 log n) in the worst case, which is fine for n <= 10.

### Requirements
None

### Code
```python
from typing import List

class Solution:
    def sortMatrix(self, grid: List[List[int]]) -> List[List[int]]:
        n = len(grid)
        # Bottom-left diagonals (d >= 0): sort in non-increasing order
        for d in range(n):
            vals = []
            coords = []
            for i in range(d, n):
                j = i - d
                vals.append(grid[i][j])
                coords.append((i, j))
            vals.sort(reverse=True)  # non-increasing
            for idx, (i, j) in enumerate(coords):
                grid[i][j] = vals[idx]

        # Top-right diagonals (d < 0): sort in non-decreasing order
        for d in range(-n + 1, 0):
            coords = []
            vals = []
            for i in range(0, n + d):  # d is negative
                j = i - d
                vals.append(grid[i][j])
                coords.append((i, j))
            vals.sort()  # non-decreasing
            for idx, (i, j) in enumerate(coords):
                grid[i][j] = vals[idx]

        return grid
```
