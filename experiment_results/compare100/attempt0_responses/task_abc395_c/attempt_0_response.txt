### Step-by-step reasoning
- The problem asks for the shortest non-empty contiguous subarray that contains a value which occurs more than once in the entire array A. Equivalently, we need the smallest subarray that contains two equal elements of A.
- If a value appears multiple times in A, the shortest subarray that contains two occurrences of that value is the distance between two consecutive occurrences of that value plus one.
- Therefore, as we scan A from left to right, we keep a dictionary last_pos mapping each value to its most recent index. When we encounter a value that’s already seen at index j, the candidate subarray length is current_index - j + 1. We take the minimum over all such candidates.
- If no value repeats in A, the answer is -1.
- Edge cases:
  - N = 1 -> -1.
  - All distinct -> -1.
  - Adjacent duplicates -> length 2.
  - Large N up to 2e5 -> O(N) time and O(number_of_distinct_values) memory.

### Requirements
None

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        print(-1)
        return
    n = data[0]
    a = data[1:1+n]

    last_pos = {}
    ans = None

    for i, v in enumerate(a):
        if v in last_pos:
            length = i - last_pos[v] + 1
            if ans is None or length < ans:
                ans = length
        last_pos[v] = i

    print(-1 if ans is None else ans)

if __name__ == "__main__":
    main()
```
