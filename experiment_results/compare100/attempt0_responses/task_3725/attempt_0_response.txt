### Step-by-step reasoning
- We need the sum of the maximum and minimum values over all subarrays with length at most k.
- A direct O(nk) approach is too slow for n up to 80k. We can compute the contribution of each element as a potential minimum and as a potential maximum, then sum these contributions with a length constraint.
- Known technique: for each index i, determine the range of subarrays where nums[i] is the (unique) minimum (or maximum) using monotonic stacks:
  - For minimums:
    - PLE_min[i] = index of previous element strictly less than nums[i] (left boundary)
    - NLE_min[i] = index of next element less than or equal to nums[i] (right boundary)
    - This guarantees unique counting in presence of duplicates.
  - For maximums:
    - PGE_max[i] = index of previous element strictly greater than nums[i] (left boundary)
    - NGE_max[i] = index of next element greater than or equal to nums[i] (right boundary)
- With these boundaries:
  - The left boundary l can range from l_min = PLE[i] + 1 to l_max = i.
  - The right boundary r can range from r_min = i to r_max = NLE[i] - 1 (for minimum case) or NGE[i] - 1 (for maximum case).
  - The total number of subarrays where i is the min (without length constraint) is (i - PLE[i]) * (NLE[i] - i). We need only those with length <= k.
- To count subarrays containing i with length <= k efficiently, split by r:
  - Region 1: r in [r_min, min(r_max, l_min + k - 1)]. Here length constraint is automatically satisfied, and there are A = i - PLE[i] choices for l, so contribution count = (r1_end - r_min + 1) * A.
  - Region 2: r in [max(r_min, l_min + k), min(r_max, i + k)]. Here l must be at least r - k + 1, leading to count per r of (i - r + k). Sum this arithmetic progression efficiently via formula.
  - Total count for i is count_region1 + count_region2.
- Do the same for maximums with their respective boundaries.
- The final answer is sum over i of nums[i] * count_min_i plus sum over i of nums[i] * count_max_i.
- Time complexity: O(n) to compute the four boundary arrays plus O(n) to accumulate counts. Space: O(n).

Edge cases:
- Duplicates: handled by the chosen boundary definitions (strict on left, non-strict on right for minima; strict on left, non-strict on right for maxima).
- k = 1: only subarrays of length 1 counted (sum of all elements twice: min and max equal to the element). Our count logic handles this.
- All negative, positive, or mixed values: arithmetic uses Python int (unbounded).

None

class Solution:
    def minMaxSubarraySum(self, nums, k: int) -> int:
        n = len(nums)
        if n == 0:
            return 0

        # Helper to compute count of subarrays where i is min with length <= k
        def count_min_with_boundaries(PLE, NLE, i, k):
            # PLE[i] = previous index with value < nums[i]
            # NLE[i] = next index with value <= nums[i]
            l_min = PLE[i] + 1
            l_max = i
            r_min = i
            r_max = NLE[i] - 1
            A = i - PLE[i]  # number of choices for left boundary

            # Region 1: r in [r_min, min(r_max, l_min + k - 1)]
            r1_end = min(r_max, l_min + k - 1)
            count1 = 0
            if r1_end >= r_min:
                count1 = (r1_end - r_min + 1) * A

            # Region 2: r in [max(r_min, l_min + k), min(r_max, i + k)]
            s2 = max(r_min, l_min + k)
            t2 = min(r_max, i + k)
            count2 = 0
            if t2 >= s2:
                m = t2 - s2 + 1
                sum_r = (s2 + t2) * m // 2
                count2 = m * (i + k) - sum_r

            return count1 + count2

        # Compute PLE_min and NLE_min
        PLE_min = [-1] * n
        stack = []
        for i in range(n):
            while stack and nums[stack[-1]] >= nums[i]:
                stack.pop()
            PLE_min[i] = stack[-1] if stack else -1
            stack.append(i)

        NLE_min = [n] * n
        stack.clear()
        for i in range(n - 1, -1, -1):
            while stack and nums[stack[-1]] > nums[i]:
                stack.pop()
            NLE_min[i] = stack[-1] if stack else n
            stack.append(i)

        # Compute PGE_max and NGE_max
        PGE_max = [-1] * n
        stack.clear()
        for i in range(n):
            while stack and nums[stack[-1]] <= nums[i]:
                stack.pop()
            PGE_max[i] = stack[-1] if stack else -1
            stack.append(i)

        NGE_max = [n] * n
        stack.clear()
        for i in range(n - 1, -1, -1):
            while stack and nums[stack[-1]] < nums[i]:
                stack.pop()
            NGE_max[i] = stack[-1] if stack else n
            stack.append(i)

        total_min = 0
        total_max = 0

        # Accumulate contributions for minimums
        for i in range(n):
            cnt_min = count_min_with_boundaries(PLE_min, NLE_min, i, k)
            total_min += nums[i] * cnt_min

        # Accumulate contributions for maximums
        # For maximum, boundaries are PGE_max and NGE_max
        def count_max_with_boundaries(PGE, NGE, i, k):
            l_min = PGE[i] + 1
            l_max = i
            r_min = i
            r_max = NGE[i] - 1
            A = i - PGE[i]  # number of choices for left boundary

            # Region 1
            r1_end = min(r_max, l_min + k - 1)
            count1 = 0
            if r1_end >= r_min:
                count1 = (r1_end - r_min + 1) * A

            # Region 2
            s2 = max(r_min, l_min + k)
            t2 = min(r_max, i + k)
            count2 = 0
            if t2 >= s2:
                m = t2 - s2 + 1
                sum_r = (s2 + t2) * m // 2
                count2 = m * (i + k) - sum_r

            return count1 + count2

        for i in range(n):
            cnt_max = count_max_with_boundaries(PGE_max, NGE_max, i, k)
            total_max += nums[i] * cnt_max

        return total_min + total_max
