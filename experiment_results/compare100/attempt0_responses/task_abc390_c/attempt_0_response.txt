### Step-by-step reasoning
- Let the set of already-painted black cells be the positions with '#'.
- Any final configuration must have all black cells forming one axis-aligned rectangle, and all other cells white.
- Therefore, the rectangle must cover all existing '#' cells, and it must not include any existing '.' cells (since those inside the final rectangle must be black).
- The smallest rectangle that contains all '#' cells is the bounding box:
  - rmin = minimum row index of '#'
  - rmax = maximum row index of '#'
  - cmin = minimum column index of '#'
  - cmax = maximum column index of '#'
- If any cell inside this bounding box is '.', it is impossible (since that cell would need to be black but is already white).
- If all cells inside the bounding box are either '#' or '?', we can fill all '?' inside to black and all cells outside to white, achieving a single black rectangle.
- Edge cases:
  - There is guaranteed to be at least one '#', per problem statement. If there were none, the problem constraints would be inconsistent with the statement, but the code can safely handle it (in that case, we could still paint a rectangle, but it’s outside the given guarantees).
  - The outside region cannot contain any '#', but by using the bounding box of all '#', that is automatically satisfied.

import sys

def solve():
    data = sys.stdin.read().splitlines()
    if not data:
        print("No")
        return
    H_W = data[0].split()
    H = int(H_W[0])
    W = int(H_W[1])

    grid = [list(data[i + 1].rstrip()) for i in range(H)]

    rmin, rmax = H, -1
    cmin, cmax = W, -1

    for i in range(H):
        for j in range(W):
            if grid[i][j] == '#':
                if i < rmin:
                    rmin = i
                if i > rmax:
                    rmax = i
                if j < cmin:
                    cmin = j
                if j > cmax:
                    cmax = j

    # If there are no '#', technically the problem guarantees at least one '#',
    # but handle gracefully.
    if rmax == -1:
        print("Yes")
        return

    for i in range(rmin, rmax + 1):
        for j in range(cmin, cmax + 1):
            if grid[i][j] == '.':
                print("No")
                return

    print("Yes")

if __name__ == "__main__":
    solve()
