### Step-by-step reasoning
- Let nums be [1, 2, ..., n] and each conflicting pair be [a, b] with a != b. After removing exactly one pair, we want to count subarrays that do not contain both endpoints of any remaining pair.
- A subarray [l, r] contains both endpoints of a pair (a, b) iff l <= min(a, b) and r >= max(a, b). For a fixed set of remaining pairs, the total number of valid subarrays can be computed with a helper function using a suffix-min approach.
- Define A[x] as the smallest y such that there exists a pair with min(a, b) = x and max(a, b) = y. If there is no pair with min == x, A[x] = INF (n+1).
- For any l, the smallest max endpoint among all remaining pairs with min >= l is B[l] = suffix_min(A, l) (i.e., the minimum of A[k] for k >= l). The number of valid subarrays starting at l is B[l] - l, and the total number of valid subarrays T is:
  T = sum_{l=1..n} (B[l] - l) = sum_{l=1..n} B[l] - n(n+1)/2
  Note: If there are no pairs with min >= l, B[l] = INF and B[l] - l = (n+1) - l, which contributes all subarrays starting at l as valid.
- Therefore, with all pairs present, we can compute:
  - A[x] for all x, using the min y per bucket x and also the second-min for quick updates.
  - Tail minimum array tail_min[i] = min_{k >= i} A[k].
  - Baseline total valid subarrays baseline_T = sum(tail_min) - n(n+1)/2.
- We need to remove exactly one pair. A removal only changes A[m] if the removed pair is the unique pair achieving the current minimum y in bucket m (i.e., A[m] is the minimum for min==m and it is unique). If there are multiple pairs achieving the same minimum y in that bucket, removing one of them does not change A[m].
- For a bucket m with a unique minimum a = A[m], and a second minimum a2 (INF if none), removing the pair moves A[m] to a2 (or INF). Let t = tail_min[m+1] (min of A[k] for k >= m+1).
  - If t <= a, removing this pair does not affect any B[l] (l <= m), so delta = 0.
  - Otherwise, B[l] for l <= m can change. A careful derivation shows we can compute the exact delta in O(length of the affected left block) by considering the block of indices i in (L, m], where L is the previous index to the left with A[L] < a (L can be found with a monotonic stack). For these i, define M_i as the minimum of A[i], A[i+1], ..., A[m-1] (i.e., the minimum among the left part of the range up to m-1). The updated value for B[i] becomes min(M_i, a2, t) after removal, while the old B[i] was min(M_i, a, t). Since a ≤ t in the non-trivial case, M_i ≥ a, and a ≤ t, we can compute delta_i = min(M_i, min(a2, t)) - a, and sum over i in [L+1, m].
  - Define u = min(a2, t). Then the delta over i in [L+1, m] is:
      delta = sum_{i=L+1..m} min(M_i, u) - a*(m - L)
- We can compute M_i by scanning left from m-1 down to L+1, maintaining cur_min = min(cur_min, A[i]) (initially INF). Also include i = m with M_m = INF in the sum as min(INF, u) = u.
- To get L efficiently for all m, we precompute previous smaller element indices using a monotonic stack:
  L[m] = index of the previous element to the left of m with A[L[m]] < A[m] (or 0 if none).
- We then:
  - Build A, count of minima per bucket, and the second-min for each bucket.
  - Build tail_min, baseline_T.
  - Build L using a monotonic stack.
  - For every m with A[m] finite and count_min_y[m] == 1:
    - If t <= a, skip (delta = 0).
    - Else compute delta by the left-block scan described above, and update the answer as max(baseline_T + delta).
  - The final answer is the maximum over baseline_T and all baseline_T + delta candidates.
- Time complexity:
  - Building buckets and A: O(k) where k <= 2n
  - tail_min and baseline_T: O(n)
  - L computation: O(n)
  - The heavy part is summing deltas for candidate m. In the worst-case it can be O(n^2), but in typical constraints it runs efficiently. The implementation handles edge cases and remains correct for all inputs within given constraints.

Edge cases:
- If no bucket has a unique minimum, the best is baseline_T (removing any pair leaves the same count).
- If a bucket has exactly one pair and removing it moves A[m] to INF, we handle INF as n+1.
- When there are multiple pairs with the same minimum y in a bucket, removing any one of them does not change A[m].

class Solution:
    def maxSubarrays(self, n: int, conflictingPairs: List[List[int]]) -> int:
        from math import inf
        INF = n + 1  # use n+1 as INF sentinel for A values

        # 1. Build buckets of max endpoints by min endpoint
        buckets = [[] for _ in range(n + 2)]  # 1..n
        for a, b in conflictingPairs:
            x, y = (a, b) if a < b else (b, a)
            buckets[x].append(y)

        # 2. For each x, compute:
        #    A[x] = min_y, count_min_y[x], second_min_y[x]
        A = [INF] * (n + 2)
        count_min = [0] * (n + 2)
        second_min = [INF] * (n + 2)

        for x in range(1, n + 1):
            if not buckets[x]:
                continue
            min_y = INF
            cnt = 0
            sec = INF
            for y in buckets[x]:
                if y < min_y:
                    sec = min_y
                    min_y = y
                    cnt = 1
                elif y == min_y:
                    cnt += 1
                elif y < sec:
                    sec = y
            A[x] = min_y
            count_min[x] = cnt
            second_min[x] = sec

        # 3. tail_min[i] = min_{k>=i} A[k]
        tail_min = [INF] * (n + 3)
        tail_min[n + 1] = INF
        for i in range(n, 0, -1):
            tail_min[i] = A[i] if A[i] < tail_min[i + 1] else tail_min[i + 1]

        # Baseline total number of valid subarrays with all pairs present
        total_tail = sum(tail_min[1:n + 1])
        baseline_T = total_tail - n * (n + 1) // 2

        # 4. Precompute L[m] = previous index to the left with A[L[m]] < A[m]
        L = [0] * (n + 2)
        stack = []  # indices with strictly increasing A values
        for i in range(1, n + 1):
            while stack and A[stack[-1]] >= A[i]:
                stack.pop()
            L[i] = stack[-1] if stack else 0
            stack.append(i)

        # 5. Evaluate candidate removals (where count_min[m] == 1)
        ans = baseline_T  # at least this (removing a non-influential pair)
        for m in range(1, n + 1):
            if A[m] >= INF:
                continue
            if count_min[m] != 1:
                continue

            a = A[m]
            t = tail_min[m + 1]  # min over k >= m+1 A[k]

            if t <= a:
                continue  # delta would be 0

            a2 = second_min[m]  # could be INF
            u = a2 if a2 < t else t  # min(a2, t)

            left_bound = L[m]\

            # We need to sum over i in (left_bound, m], i from m-1 down to left_bound+1
            sum_min = 0
            cur_min = INF
            # process i from m-1 down to left_bound+1
            for i in range(m - 1, left_bound, -1):
                if A[i] < cur_min:
                    cur_min = A[i]
                # min(M_i, u): M_i is cur_min
                if cur_min > u:
                    sum_min += u
                else:
                    sum_min += cur_min
            # include i = m term: M_m = INF, so min(M_m, u) = u
            sum_min += u

            delta = sum_min - a * (m - left_bound)
            candidate = baseline_T + delta
            if candidate > ans:
                ans = candidate

        return ans
