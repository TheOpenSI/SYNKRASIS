### Step-by-step reasoning
- The initial graph is acyclic with odd cycles forbidden, i.e., it is bipartite. Each move adds an edge that must not create an odd cycle. This implies:
  - If the endpoints are in different connected components, you can always add the edge (it just connects components and keeps bipartiteness, since you can orient the colorings appropriately).
  - If the endpoints are in the same connected component, you can only add the edge if the two vertices lie in opposite color classes of that component (adding such an edge creates an even cycle, which is allowed).

- If we continue adding edges, the end state is a complete bipartite graph on the final two-coloring of the whole graph: a K_{A,B} with A+B=N. The number of moves equals:
  total_moves = A*B - M
  where M is the initial number of edges.

- The value of A (the size of one color class in the final graph) is determined by choosing, for each initial connected component, how its two color classes map into the global A-side:
  - For a component with even size s_k, its two color class sizes have the same parity, and the parity contribution to A is fixed to p_k = (size of one color class) mod 2 in that component.
  - For a component with odd size s_k, its two color class sizes have opposite parity, so you can choose which color class contributes to A, effectively allowing a toggle of 1 in the parity contributed by that component.

- Let t be the number of odd-sized components. Then:
  - If t > 0, the final A parity can be chosen to be either of the two parities (the contributions from odd-sized components can be toggled to adjust A mod 2). This heavily constrains the game, but the ultimate outcome depends on N and M.
  - If t = 0, all components have even size, and the parity of A is fixed to S_fixed = sum of p_k over all components, modulo 2.

- The parity of total moves matters for who wins (normal play; last move wins). Let M be the initial number of edges and N the number of vertices.
  - If N is odd: A*B is always even for any A, so total_moves parity equals M mod 2. Aoki (first player) wins iff M is odd.
  - If N is even: A*B mod 2 equals A mod 2. So total_moves parity equals A mod 2 XOR M mod 2.
    - If t > 0, A mod 2 can be either 0 or 1, so the first player always has a winning strategy; Aoki wins.
    - If t = 0, A mod 2 is fixed to S_fixed, so total_moves parity is S_fixed XOR (M mod 2). Aoki wins iff this parity is 1.

- Therefore:
  - If N is odd: Aoki if M is odd, else Takahashi.
  - If N is even:
    - If there is at least one odd-sized component (t > 0): Aoki.
    - Otherwise (t = 0): compute S_fixed = sum over components of (size of one color class mod 2) using a BFS 2-coloring; Aoki if (S_fixed XOR (M mod 2)) == 1, else Takahashi.

Edge cases:
- No edges initially (all components are size 1, i.e., t = N which is > 0 unless N=0). The above rules handle this.
- Large N and M require linear-time BFS/DFS to compute component sizes and color parities.

### Code
```
import sys
from collections import deque

def main():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    N = int(next(it))
    M = int(next(it))

    adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (N + 1)
    t_odd = 0  # number of components with odd size
    S_fixed = 0  # sum of A_k % 2 for even-size components (parity contributions)

    for start in range(1, N + 1):
        if color[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        color[start] = 0
        cnt = [0, 0]
        cnt[0] += 1

        while q:
            u = q.popleft()
            cu = color[u]
            for w in adj[u]:
                if color[w] == -1:
                    color[w] = cu ^ 1
                    cnt[color[w]] += 1
                    q.append(w)
                # graph is guaranteed bipartite by problem statement; no need to handle conflicts

        size = cnt[0] + cnt[1]
        if size % 2 == 1:
            t_odd += 1
        else:
            S_fixed ^= (cnt[0] & 1)  # parity of one color class (cnt[0] % 2)

    if N % 2 == 1:
        print("Aoki" if M % 2 == 1 else "Takahashi")
        return

    # N is even
    if t_odd > 0:
        print("Aoki")
        return

    # All components even-sized
    # A parity is fixed to S_fixed; total moves parity = S_fixed XOR (M % 2)
    total_parity = S_fixed ^ (M & 1)
    print("Aoki" if total_parity == 1 else "Takahashi")

if __name__ == "__main__":
    main()
```
