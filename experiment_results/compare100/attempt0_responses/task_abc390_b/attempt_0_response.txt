### Step-by-step reasoning
- A geometric progression (GP) with positive terms a1, a2, ..., aN has a common ratio r such that ai = a1 * r^(i-1). Since all Ai are positive, the ratio is well-defined (no division by zero or negative values).
- A standard property of a GP is that for all i from 2 to N-1 (1-based indexing): Ai^2 = Ai-1 * Ai+1. This follows from Ai = Ai-1 * r and Ai+1 = Ai * r, so Ai^2 = Ai-1 * Ai+1.
- Therefore, to determine if the given sequence is a GP, we can check Ai^2 == Ai-1 * Ai+1 for every interior index i. If all hold, the sequence is a GP; otherwise, it is not.
- Edge cases:
  - If N = 2, any two positive numbers form a GP (trivially true). The check has no interior elements, so we should return Yes.
  - Because Ai are up to 1e9, Ai^2 can be up to 1e18, which Python handles with arbitrary-precision integers.
- Implementation approach: read N and the N sequence values, apply the check for i in [1, N-2] (0-based indexing), and print "Yes" or "No".

None

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    if not data:
        return
    N = data[0]
    A = data[1:1+N]

    # For N == 2, it's always a GP
    ans = "Yes"
    for i in range(1, N - 1):
        if A[i] * A[i] != A[i - 1] * A[i + 1]:
            ans = "No"
            break

    print(ans)

if __name__ == "__main__":
    main()
```
