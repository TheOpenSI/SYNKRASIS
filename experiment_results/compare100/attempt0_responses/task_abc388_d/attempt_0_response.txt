### Step-by-step reasoning
- Let C_i(t) be the stones of alien i just after year t (0-based year counting where year 0 is initial state). Initially C_i(0) = A_i.
- In year t (t from 1 to N), all currently adult aliens with positive stones donate 1 stone to the new adult t. This decreases each positive C_j by 1 for j < t, and increases C_t by the number of donors D_t (the number of positives among aliens 1..t-1 at the start of year t).
- A direct simulation would be O(N^2). We need an efficient approach.
- Observation: In each year, every currently positive alien loses 1 stone; the set of positives shrinks when some aliens reach 0. We can represent the current stones of all active aliens using a global offset that counts how many times we’ve subtracted 1 from all positives.
- Maintain for each active alien i a value v_i (their “base” stones plus the accumulated offset). The actual stones are C_i = v_i - off, where off is the current total decrements applied to all positives.
- Each year:
  - D = number of active aliens before this year.
  - off += 1 (decrement all positives by 1).
  - Remove all aliens with v_i == off (they hit zero now); their final stones are 0.
  - The new alien t enters with stones C_t = A_t + D. If C_t > 0, compute its base value v_t = C_t + off and insert it as active.
- To efficiently remove aliens whose v_i == off, group active aliens by their v_i value. Keep a map (bucket) from v value to a list of indices with that v. At each year, pop the bucket for off and mark those aliens as finished with B_i = 0.
- After processing all N years, remaining active aliens have final stones B_i = v_i - off_final, where off_final = N.
- This yields an O(N) solution with O(N) memory.

Edge cases:
- Aliens can start with A_i = 0, so they may not join the active set if D is also 0 and A_i + D = 0.
- Large values of A_i and N are supported because we only store per-alien base values and an offset; the bucket map grows with the number of aliens, not with stone counts.

None

### Code
```
import sys
from collections import defaultdict

def main():
    data = list(map(int, sys.stdin.read().strip().split()))
    if not data:
        return
    N = data[0]
    A = data[1:1+N]

    B = [0] * N  # final stones for each alien (default 0)

    # Buckets: map from base value v to list of indices currently active with that v
    buckets = defaultdict(list)

    off = 0        # total decrements applied to all active aliens
    active = 0     # number of active aliens (with C_i > 0) before current year

    for t in range(N):  # t is 0-based index for alien t+1
        D = active          # number of donors in this year
        off += 1            # decrement all current positives by 1

        # Remove aliens whose v == off (they reach 0 now)
        remove_list = buckets.pop(off, [])
        for idx in remove_list:
            B[idx] = 0        # final stones for removed aliens are 0
            active -= 1

        # Current alien t+1 enters with C = A[t] + D
        C_t = A[t] + D
        if C_t > 0:
            v_t = C_t + off
            buckets[v_t].append(t)
            active += 1
        else:
            # B[t] remains 0 (not added to active)
            pass

    off_final = off  # should be N

    # Remaining active aliens have final stones B_i = v_i - off_final
    for v, idxs in buckets.items():
        val = v - off_final
        for idx in idxs:
            B[idx] = val

    print(' '.join(map(str, B)))

if __name__ == "__main__":
    main()
```
