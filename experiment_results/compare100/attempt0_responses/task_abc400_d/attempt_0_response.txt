### Step-by-step reasoning
- We model Takahashi's actions as moves on a grid with two kinds of operations:
  1) Move to an adjacent cell that is a road ('.' in the initial grid). This costs 0 kicks.
  2) Perform a front kick in one of the four directions. This costs 1 kick and opens (turns to road) the cells that are exactly 1 and 2 steps away in that direction, if they exist within the grid. After the kick, those opened cells can be used for free (0-cost) moves along roads.

- A key observation is that any optimal sequence of kicks can be represented as a path in a graph where:
  - Edges with cost 0 connect adjacent cells that are roads in the initial grid.
  - Edges with cost 1 connect a cell to the cell that is 1 or 2 steps away in any direction (front kick opens these cells). After taking such an edge, those opened cells become accessible and can be reached via 0-cost moves subsequently.

- With this interpretation, we can compute the minimum number of kicks using a 0-1 BFS (deque-based shortest path) on the grid:
  - From a cell (i, j), add 0-cost edges to its 4-neighbors if that neighbor is a road in the initial grid.
  - From (i, j), add 1-cost edges to the cells at distance 1 and distance 2 in each of the 4 directions (i.e., the first and the second cells ahead, if inside bounds).
  - Maintain dist[i][j] as the minimum number of kicks to reach (i, j).

- Properties and edge cases:
  - Start and target cells are guaranteed to be roads.
  - The algorithm handles boundaries properly by checking bounds for all candidate moves.
  - The grid can be up to 1000x1000, so we should use an efficient O(H*W) approach with 0-1 BFS, avoiding heavy state tracking of the evolving map.

- This approach matches the samples:
  - Sample 2 and 3 rely on a single kick to unlock the needed cell(s).
  - Sample 1 demonstrates that one kick can unlock a path to the target.
  - Sample 4 is handled similarly with multiple kicks.

- Implementation notes:
  - Use 0-1 BFS with a deque.
  - dist initialized to a large value (INF); start with dist[start] = 0.
  - For 0-cost moves, push to the left of the deque; for 1-cost moves, push to the right.
  - Stop early if we pop the target cell from the deque.

import sys
from collections import deque

def main():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    H = int(next(it))
    W = int(next(it))
    grid = []
    for _ in range(H):
        grid.append(next(it).strip())
    A = int(next(it)) - 1
    B = int(next(it)) - 1
    C = int(next(it)) - 1
    D = int(next(it)) - 1

    INF = 10**9
    dist = [[INF] * W for _ in range(H)]
    dq = deque()

    dist[A][B] = 0
    dq.append((A, B))

    # Directions for 0-cost moves (up, down, left, right)
    dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]

    while dq:
        i, j = dq.popleft()
        d = dist[i][j]
        if i == C and j == D:
            print(d)
            return

        # 0-cost moves: adjacent roads in the initial grid
        for di, dj in dirs:
            ni, nj = i + di, j + dj
            if 0 <= ni < H and 0 <= nj < W:
                if grid[ni][nj] == '.' and dist[ni][nj] > d:
                    dist[ni][nj] = d
                    dq.appendleft((ni, nj))

        # 1-cost moves: front kicks to the two cells ahead in each direction
        for di, dj in dirs:
            # first ahead
            f1i, f1j = i + di, j + dj
            if 0 <= f1i < H and 0 <= f1j < W:
                if dist[f1i][f1j] > d + 1:
                    dist[f1i][f1j] = d + 1
                    dq.append((f1i, f1j))

            # second ahead
            f2i, f2j = i + 2*di, j + 2*dj
            if 0 <= f2i < H and 0 <= f2j < W:
                if dist[f2i][f2j] > d + 1:
                    dist[f2i][f2j] = d + 1
                    dq.append((f2i, f2j))

    # In theory, the target should always be reachable, but as a safety:
    print(dist[C][D] if dist[C][D] != INF else -1)

if __name__ == "__main__":
    main()
