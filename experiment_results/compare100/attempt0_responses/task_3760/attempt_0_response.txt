### Step-by-step reasoning
- For each group value g, we need the smallest index j such that groups[i] % elements[j] == 0, i.e., elements[j] divides g.
- A straightforward per-group scan of all elements would be too slow (O(len(groups) * len(elements))).
- Observation: If a value v appears in elements, and v divides g, then g is a multiple of v. Therefore, for every distinct value v in elements, all multiples of v up to max(groups) are eligible groups.
- Strategy: 
  - Build a map from each distinct element value to the smallest index where that value occurs in elements (to handle duplicates with the smallest index).
  - Let max_g be the maximum value in groups. Create an answer array best_index_for_value of length max_g + 1 initialized with a sentinel INF.
  - For each distinct value v (with its smallest index idx), iterate through all multiples m of v from v to max_g, and update best_index_for_value[m] = min(best_index_for_value[m], idx). This propagates the best candidate index to all groups that v can satisfy.
  - Finally, for each group g, if best_index_for_value[g] is still INF, there is no suitable element; otherwise, assign that index.
- Complexity: If max_g = max(groups), and distinct element values are V, the total work is roughly sum_{v in distinct elements, v <= max_g} (max_g / v). This is typically around O(max_g log max_g) in practice, which is efficient for max_g up to 1e5. Memory usage is O(max_g).
- Edge cases:
  - Duplicates in elements: use the smallest index for that value.
  - Elements with value > max_g: ignored since they cannot divide any group value.
  - If no suitable element for a group, assign -1.

from typing import List

class Solution:
    def assignElements(self, groups: List[int], elements: List[int]) -> List[int]:
        if not groups:
            return []
        
        # Map each distinct element value to its smallest index
        min_index_by_value = {}
        for idx, val in enumerate(elements):
            if val in min_index_by_value:
                if idx < min_index_by_value[val]:
                    min_index_by_value[val] = idx
            else:
                min_index_by_value[val] = idx

        max_g = max(groups)
        INF = len(elements) + 5
        # best_index_for_value[g] will hold the smallest index of an element that divides g
        best_index_for_value = [INF] * (max_g + 1)

        # Propagate the smallest index to all multiples of each value
        for val, idx in min_index_by_value.items():
            if val <= max_g:
                for m in range(val, max_g + 1, val):
                    if idx < best_index_for_value[m]:
                        best_index_for_value[m] = idx

        # Build the result for each group
        assigned = []
        for g in groups:
            if g <= max_g and best_index_for_value[g] != INF:
                assigned.append(best_index_for_value[g])
            else:
                assigned.append(-1)

        return assigned
