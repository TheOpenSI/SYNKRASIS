### Step-by-step reasoning
- Model: The constraint x_i ≤ x_{A_i} for all i defines a directed graph where every node has out-degree 1 (functional graph). Nodes on directed cycles must have equal values, since going around a cycle yields x_i ≤ x_{A_i} ≤ ... ≤ x_i.
- Components: Each connected component of this graph consists of one directed cycle and trees feeding into cycle nodes. Non-cycle nodes form in-trees rooted at cycle nodes; cycle nodes share a common value across the cycle.
- DP on trees (for non-cycle nodes):
  - For a non-cycle node v, let G_v(t) be the number of assignments in the subtree rooted at v if v's own value is t.
  - If v has non-cycle children c, then G_v(t) = ∏_c S_c(t), where S_c(t) = sum_{s=1..t} G_c(s).
  - For leaves (no non-cycle children), G_v(t) = 1.
  - Also define S_v(t) = sum_{s=1..t} G_v(s). We need S for parents to compute their G.
- For a cycle node i:
  - Let F_i(t) be the contribution from the in-tree attached to i when i’s value is t. F_i(t) = ∏_{c in non-cycle children of i} S_c(t).
  - The component value for a cycle is sum_{t=1..M} ∏_{i on cycle} F_i(t).
- Overall answer: Multiply the component values over all cycles (components), modulo 998244353.
- Implementation plan:
  1. Build A, and the children lists for every node.
  2. Find cycle nodes using Kahn’s algorithm on indegrees (nodes left with indegree > 0 are on cycles).
  3. For every non-cycle node v, prepare its list of non-cycle children (those u with A[u] = v and not on a cycle).
  4. DP on the forest of non-cycle nodes in a bottom-up manner:
     - Maintain deg_nc[v] = number of non-cycle children of v yet to be processed.
     - Start with leaves (deg_nc[v] == 0), compute S_v from G_v (initially G_v = 1 for leaves), propagate to parent, and repeat until all non-cycle nodes are processed.
     - Store S_v(t) for each non-cycle node v.
  5. Compute F_i(t) for each cycle node i as the product of S_v(t) over its non-cycle children v.
  6. Enumerate each cycle (component) and compute sum_{t=1..M} product_{i in cycle} F_i(t); multiply these into the final answer.
- Edge cases:
  - Self-loop cycles (A_i = i): handled, cycle length 1.
  - Large N, M up to 2025: complexity roughly O(N*M), which is fine.
  - Nodes with no non-cycle children contribute factor 1 for their F_i(t).

import sys
from collections import deque

MOD = 998244353

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        print(0)
        return
    it = iter(data)
    N = int(next(it))
    M = int(next(it))
    A = [0] * (N + 1)
    for i in range(1, N + 1):
        A[i] = int(next(it))

    # Build indegree to find cycles via Kahn's algorithm
    indeg = [0] * (N + 1)
    for i in range(1, N + 1):
        indeg[A[i]] += 1

    q = deque([i for i in range(1, N + 1) if indeg[i] == 0])
    removed = [False] * (N + 1)
    while q:
        v = q.popleft()
        removed[v] = True
        p = A[v]
        indeg[p] -= 1
        if indeg[p] == 0:
            q.append(p)

    cyc = [False] * (N + 1)
    for i in range(1, N + 1):
        if not removed[i]:
            cyc[i] = True  # node is in a directed cycle

    # Build non-cycle children: for every node, list non-cycle nodes that point to it
    noncycle_children = [[] for _ in range(N + 1)]
    for v in range(1, N + 1):
        if not cyc[v]:
            p = A[v]
            noncycle_children[p].append(v)

    # DP on non-cycle forest
    deg_nc = [0] * (N + 1)
    for v in range(1, N + 1):
        if not cyc[v]:
            deg_nc[v] = len(noncycle_children[v])

    # S[v] will store S_v(t) for t=1..M for non-cycle nodes
    S = [None] * (N + 1)

    dq = deque([v for v in range(1, N + 1) if not cyc[v] and deg_nc[v] == 0])
    while dq:
        v = dq.popleft()

        # Compute G_v(t) = product over children c of S_c(t)
        if not noncycle_children[v]:
            # leaf: G_v(t) = 1
            Gv = [0] * (M + 1)
            for t in range(1, M + 1):
                Gv[t] = 1
        else:
            Gv = [1] * (M + 1)
            for ch in noncycle_children[v]:
                Sc = S[ch]
                # Sc should be defined for all t
                for t in range(1, M + 1):
                    Gv[t] = (Gv[t] * Sc[t]) % MOD

        # Build S_v as prefix sums of G_v
        Sv = [0] * (M + 1)
        acc = 0
        for t in range(1, M + 1):
            acc += Gv[t]
            if acc >= MOD:
                acc -= MOD
            Sv[t] = acc
        S[v] = Sv

        # Propagate to parent
        p = A[v]
        if not cyc[p]:
            deg_nc[p] -= 1
            if deg_nc[p] == 0:
                dq.append(p)

    # Compute F_i(t) for cycle nodes
    F = [None] * (N + 1)
    for i in range(1, N + 1):
        if cyc[i]:
            Fi = [1] * (M + 1)
            for ch in noncycle_children[i]:
                Sc = S[ch]
                for t in range(1, M + 1):
                    Fi[t] = (Fi[t] * Sc[t]) % MOD
            F[i] = Fi

    # Enumerate cycles and compute component contributions
    visited = [False] * (N + 1)
    ans = 1
    for i in range(1, N + 1):
        if cyc[i] and not visited[i]:
            # collect this cycle
            cur = i
            cycle_nodes = []
            while not visited[cur]:
                visited[cur] = True
                cycle_nodes.append(cur)
                cur = A[cur]

            # For this cycle, compute sum_{t=1..M} prod_{u in cycle} F[u][t]
            comp = 0
            for t in range(1, M + 1):
                prod = 1
                for u in cycle_nodes:
                    prod = (prod * F[u][t]) % MOD
                comp += prod
                if comp >= MOD:
                    comp -= MOD
            ans = (ans * (comp % MOD)) % MOD

    print(ans)

if __name__ == "__main__":
    main()
