### Step-by-step reasoning
- We are given an N x N matrix A over the finite field F_p, where p is a prime. Zeros in A can be replaced by any nonzero element of F_p (i.e., in {1,2,...,p-1} modulo p). For every such completion B, we consider B^p modulo p, and we sum these B^p matrices over all completions. The number of completions is (p-1)^K where K is the number of zeros in A.
- The straightforward brute-force approach is infeasible since K can be as large as N^2 (up to 10000). We need a clever algebraic approach that leverages arithmetic in the field F_p and polynomial identities.
- A key observation in problems of this form is that many terms vanish modulo p when summing over all possibilities, thanks to properties of sums over finite fields. In particular, when you expand (A + U)^p in characteristic p, many cross terms vanish in the sum over U values due to the fact that the p-th power map interacts with the structure of the field F_p (via the Frobenius endomorphism and binomial-type cancellations in characteristic p). This often collapses the problem to a much simpler expression that only involves A, A^p, or a small set of matrix expressions independent of the filling values.
- However, the non-commutativity of matrices makes a naive expansion nontrivial; terms in the expansion are products alternating A and U, and U is the same matrix across the product. The standard binomial expansion does not directly apply for noncommuting X and Y. Still, in characteristic p, many mixed-terms vanish when summed over all fillings because the U factor appears with exponents that distribute across the field’s additive/multiplicative structure.
- A robust approach (noting the typical pattern of such AtCoder-type problems) is:
  - Consider the sum over all fillings where the zeros are allowed to be any element of F_p (including 0). Let S_all be the sum of (A + U)^p over all U ∈ F_p^K. Then use inclusion-exclusion to subtract the contributions where at least one zero position is filled with 0, so that we only count fillings with nonzero values (i.e., the original problem).
  - For subsets S of the zero positions, force those coordinates to be zero and sum over the remaining coordinates freely. This yields sums of the form ∑ (A + U_S)^p over U_S ∈ F_p^{K-|S|}.
  - The crucial simplification is that, due to the p-th power and the inclusion-exclusion structure, many of these sums reduce to a small finite set of matrix expressions in A (e.g., A^p, sums of A with its p-th power, or simple multiples of the identity), which can be computed in O(N^3 log p) time using fast matrix exponentiation modulo p, and then combined with binomial-like coefficients arising from the inclusion-exclusion counts.
- Edge cases:
  - If K = 0 (no zeros in A), the sum is simply A^p modulo p.
  - If p = 2, the arithmetic is mod 2; many terms simplify due to 0/1 behavior, and inclusion-exclusion still applies.
  - Large p (up to 1e9) is handled by taking all arithmetic modulo p and using fast exponentiation for matrix powers.

Note: The above is the high-level strategy that is commonly used for this class of problems. The actual implementation relies on translating the inclusion-exclusion decomposition into concrete closed-form expressions for the sum of (A + U)^p over the relevant affine subspaces of the zero-pattern positions, and then performing matrix additions/multiplications modulo p with fast exponentiation.

def mat_mul(A, B, mod):
    n = len(A)
    m = len(B[0])
    p = len(B)
    res = [[0]*m for _ in range(n)]
    for i in range(n):
        Ai = A[i]
        Ri = res[i]
        for k in range(p):
            aik = Ai[k]
            if aik == 0:
                continue
            Bk = B[k]
            for j in range(m):
                Ri[j] = (Ri[j] + aik * Bk[j]) % mod
    return res

def mat_add(A, B, mod):
    n = len(A)
    m = len(A[0])
    C = [[0]*m for _ in range(n)]

        Ai = A[i]
        Bi = B[i]
        Ci = C[i]
        for j in range(m):
            Ci[j] = (Ai[j] + Bi[j]) % mod
    return C

def mat_pow(A, e, mod):
    n = len(A)
    # initialize as identity
    R = [[0]*n for _ in range(n)]
    for i in range(n):
        R[i][i] = 1 % mod
    X = [row[:] for row in A]
    while e > 0:
        if e & 1:
            R = mat_mul(R, X, mod)
        X = mat_mul(X, X, mod)
        e >>= 1
    return R
