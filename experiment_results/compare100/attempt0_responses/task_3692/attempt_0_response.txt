### Step-by-step reasoning
- Let p be split into three fixed parts by the two asterisk wildcards: A + '*' + B + '*' + C, where A, B, C are strings (possibly empty).
- A match of p inside a substring of s means the substring can be written as A + x + B + y + C, where x and y are any (possibly empty) strings.
- Thus we need to find indices i, j, k such that:
  - s[i:i+len(A)] == A
  - s[j:j+len(B)] == B with j >= i + len(A)
  - s[k:k+len(C)] == C with k >= j + len(B)
  - The substring is s[i : k+len(C)] and its length is (k+len(C)) - i.
- To minimize the length efficiently:
  - Enumerate all start positions i where A occurs. If A is empty, any i in [0..n] is allowed.
  - For each such i, find the earliest B occurrence starting at or after i+len(A). If B is empty, that means B can start at i+len(A).
  - After choosing B at position j, find the earliest C occurrence starting at or after j+len(B). If C is empty, it can start at that position.
  - Compute the total length as end - i, where end = k + len(C) (k is the start of C).
  - Track the minimum length across all valid triples. If none found, return -1.
- Edge cases:
  - Empty A, B, or C: handle by allowing starts at all positions (0..n). When a segment is empty, its occurrences are allowed at every position.
  - All empty (p == "**" or "a**" with appropriate empties): shortest length can be 0 or the length of a fixed prefix, as required by the problem.
  - If no valid triple exists, return -1.
- Implementation should be O(n) on average by:
  - Using Python’s efficient substring search (str.find) to collect all occurrences of A, B, C.
  - Building next-occurrence arrays for B and C to quickly jump to the next valid start.

### Requirements
None

### Code
```python
class Solution:
    def shortestMatchingSubstring(self, s: str, p: str) -> int:
        # Split pattern p into A, B, C around the two '*'
        idx1 = p.find('*')
        idx2 = p.find('*', idx1 + 1)
        A = p[:idx1]
        B = p[idx1 + 1:idx2]
        C = p[idx2 + 1:]

        n = len(s)
        lenA, lenB, lenC = len(A), len(B), len(C)

        # Collect positions where A occurs
        positions_A = []
        if lenA == 0:
            # A can start at any index 0..n
            positions_A = list(range(n + 1))
        else:
            pos = s.find(A, 0)
            while pos != -1:
                positions_A.append(pos)
                pos = s.find(A, pos + 1)

        # Prepare B start positions
        if lenB == 0:
            is_B_start = [True] * (n + 1)
        else:
            is_B_start = [False] * (n + 1)
            pos = s.find(B, 0)
            while pos != -1:
                is_B_start[pos] = True
                pos = s.find(B, pos + 1)

        # Build next_B array: next_B[i] = earliest start index j >= i where B starts, or -1
        next_B = [-1] * (n + 2)
        for i in range(n, -1, -1):
            if is_B_start[i]:
                next_B[i] = i
            else:
                next_B[i] = next_B[i + 1]
        # Ensure boundary
        next_B[n + 1] = -1

        # Prepare C start positions
        if lenC == 0:
            is_C_start = [True] * (n + 1)
        else:
            is_C_start = [False] * (n + 1)
            pos = s.find(C, 0)
            while pos != -1:
                is_C_start[pos] = True
                pos = s.find(C, pos + 1)

        # Build next_C array: next_C[i] = earliest start index k >= i where C starts, or -1
        next_C = [-1] * (n + 2)
        for i in range(n, -1, -1):
            if is_C_start[i]:
                next_C[i] = i
            else:
                next_C[i] = next_C[i + 1]
        next_C[n + 1] = -1

        INF = 10**18
        best = INF

        for i in positions_A:
            posBmin = i + lenA
            if posBmin > n:
                continue
            j_start = next_B[posBmin]
            if j_start == -1:
                continue

            posCmin = j_start + lenB
            if posCmin > n:
                continue
            k_start = next_C[posCmin]
            if k_start == -1:
                continue

            end = k_start + lenC
            length = end - i
            if length < best:
                best = length

        return -1 if best == INF else best
```
