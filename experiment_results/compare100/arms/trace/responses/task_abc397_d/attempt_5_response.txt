### Step-by-step reasoning
- We need positive integers x > y > 0 such that x^3 - y^3 = N.
- Use the standard factorization: N = (x - y)(x^2 + x y + y^2). Let a = x - y > 0 and b = x^2 + x y + y^2 > 0, so N = a * b.
- Express x in terms of y and a: x = y + a. Then
  b = (y + a)^2 + y(y + a) + y^2 = 3y^2 + 3a y + a^2.
  Therefore N = a * b = a * (a^2 + 3a y + 3y^2).
- For a fixed a, b = N / a must be an integer, and we must have b = a^2 + 3a y + 3y^2 for some positive y.
- This yields a quadratic in y: 3y^2 + 3a y + (a^2 - b) = 0.
  Its discriminant is Δ = (3a)^2 - 12(a^2 - b) = 12b - 3a^2.
  We need Δ to be a non-negative perfect square, say Δ = s^2, and then
  y = (-3a + s) / 6. This requires s ≡ 3a (mod 6) and y > 0.
- Observations:
  - Since b = x^2 + x y + y^2 > a^2 (for y > 0), N = a*b > a^3, hence a^3 < N and thus a < cbrt(N).
  - Therefore it suffices to try a from 1 up to floor(cuberoot(N-1)).
  - For each a that divides N (since b = N / a), compute b, skip if b <= a^2 (no positive y), compute Δ = 12b - 3a^2; if Δ is not a perfect square, skip; if (sqrt(Δ) - 3a) is not divisible by 6, skip; otherwise y = (sqrt(Δ) - 3a) / 6; if y > 0, x = y + a is a valid solution.
- If no such a yields a solution, print -1.
- This yields O(cuberoot(N)) iterations, which is fast enough for N ≤ 1e18.

Edge cases:
- If N = 1, there is no pair; output -1.
- If N is a perfect cube, the naive bound still works because b > a^2 is required, so that a is never too large.

Time complexity: O(cuberoot(N)) with simple arithmetic per iteration. Memory usage is O(1).

None

### Code
```
import sys
import math

def integer_cuberoot(n: int) -> int:
    # Robust floor cube root via binary search
    if n < 0:
        return 0  # not expected for this problem, but safe guard
    lo, hi = 0, 10**6 + 3  # (10^6+3)^3 > 1e18, safe upper bound
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if mid * mid * mid <= n:
            lo = mid
        else:
            hi = mid - 1
    return lo

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    N = int(data[0])

    # a must satisfy a^3 < N, so limit a to floor(cuberoot(N-1))
    max_a = integer_cuberoot(N - 1) if N > 0 else 0

    for a in range(1, max_a + 1):
        if N % a != 0:
            continue
        b = N // a

        # For y > 0, require b > a^2
        if b <= a * a:
            continue

        Δ = 12 * b - 3 * a * a
        if Δ < 0:
            continue

        s = math.isqrt(Δ)
        if s * s != Δ:
            continue

        if (s - 3 * a) % 6 != 0:
            continue

        y = (s - 3 * a) // 6
        if y <= 0:
            continue

        x = y + a
        print(x, y)
        return

    print(-1)

if __name__ == "__main__":
    main()
```
