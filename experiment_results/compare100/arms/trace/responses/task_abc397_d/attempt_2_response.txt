### Step-by-step reasoning
- We need positive integers x > y > 0 such that x^3 - y^3 = N.
- Factorization: N = (x - y)(x^2 + xy + y^2) = a * b, where a = x - y > 0 and b = x^2 + xy + y^2.
- For a fixed a, write x = y + a. Then
  b = (y + a)^2 + y(y + a) + y^2 = 3y^2 + 3ay + a^2.
  So N = a * b implies b = N / a and we must solve 3y^2 + 3ay + (a^2 - b) = 0 for y > 0.
- This is a quadratic in y with discriminant Δ = (3a)^2 - 12(a^2 - b) = -3a^2 + 12b.
  To have an integer y, Δ must be a non-negative perfect square: Δ = s^2.
  Then y = (-3a + s) / 6, which requires s ≡ 3a (mod 6) and y > 0.
- Important observations:
  - For any valid pair, a < cbrt(N). Because b = a^2 + 3ay + 3y^2 > a^2, we have N = a*b > a^3, so a^3 < N.
  - Therefore it suffices to loop a from 1 up to floor(cuberoot(N)).
  - If N % a != 0, skip. Let b = N / a. Compute Δ, check if it's a perfect square, then compute y and verify y > 0.
- This approach is complete: for any valid pair (x, y), the corresponding a will be tried and yields a valid y; hence we will output a valid pair if one exists, otherwise -1.

- Complexity: O(cuberoot(N)) iterations. For N ≤ 1e18, this is at most about 1e6 iterations, with fast integer arithmetic.

- Output format: print x and y if a solution exists; otherwise print -1.

None

### Code
```
import sys
import math

def integer_cuberoot(n: int) -> int:
    # Robust integer cube root via binary search
    lo, hi = 0, 10**6 + 1  # (10^6+1)^3 > 1e18, safe upper bound
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if mid * mid * mid <= n:
            lo = mid
        else:
            hi = mid - 1
    return lo

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    N = int(data[0])

    max_a = integer_cuberoot(N)
    for a in range(1, max_a + 1):
        if N % a != 0:
            continue
        b = N // a

        Δ = -3 * a * a + 12 * b
        if Δ < 0:
            continue

        s = math.isqrt(Δ)
        if s * s != Δ:
            continue

        if (s - 3 * a) % 6 != 0:
            continue

        y = (s - 3 * a) // 6
        if y <= 0:
            continue

        x = y + a
        print(x, y)
        return

    print(-1)

if __name__ == "__main__":
    main()
```
