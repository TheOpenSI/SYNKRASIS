### Step-by-step reasoning
- We want positive integers x > y > 0 such that x^3 - y^3 = N.
- Factorization: N = (x - y)(x^2 + x y + y^2) = a * b, where a = x - y > 0 and b = x^2 + x y + y^2.
- Let x = y + a. Then
  b = (y + a)^2 + y(y + a) + y^2 = 3y^2 + 3a y + a^2.
  Therefore N = a * b with b = N / a and
  3y^2 + 3a y + a^2 = b.
- This is a quadratic in y: 3y^2 + 3a y + (a^2 - b) = 0.
  The discriminant is Δ = (3a)^2 - 12(a^2 - b) = -3a^2 + 12b.
  For integer y, Δ must be a non-negative perfect square: Δ = s^2.
  Then y = (-3a + s) / 6. This requires s ≡ 3a (mod 6) and y > 0.
- Observing y ≥ 1 gives b = a^2 + 3ay + 3y^2 > a^2, hence N = a*b > a^3, so a^3 < N and a < cbrt(N).
  Thus we only need to try a from 1 up to floor(cbrt(N)).
- Practical approach:
  - a must divide N (since b = N / a must be integer).
  - If b <= a^2, skip (no positive y can satisfy the equation).
  - Compute Δ = 12b - 3a^2; skip if negative or not a perfect square.
  - Let s = sqrt(Δ). If (s - 3a) is not divisible by 6, skip.
  - Compute y = (s - 3a) / 6; if y > 0, then x = y + a is a valid solution.
  - If any such pair found, print x and y. Else print -1.
- This yields O(cbrt(N)) iterations, which is safe for N ≤ 1e18.

Edge considerations:
- All arithmetic is done with Python integers (unbounded), so no overflow issues.
- The cube-root bound is strict due to a^3 < N; using a robust integer cube root avoids rounding errors.

### Code
```
import sys
import math

def integer_cuberoot(n: int) -> int:
    # Robust floor cube root via binary search
    lo, hi = 0, 10**6 + 2  # (10^6+2)^3 > 1e18, safe upper bound
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if mid * mid * mid <= n:
            lo = mid
        else:
            hi = mid - 1
    return lo

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    N = int(data[0])

    max_a = integer_cuberoot(N)
    for a in range(1, max_a + 1):
        if N % a != 0:
            continue
        b = N // a

        # If b is not strictly greater than a^2, no valid y exists
        if b <= a * a:
            continue

        Δ = 12 * b - 3 * a * a
        if Δ < 0:
            continue

        s = math.isqrt(Δ)
        if s * s != Δ:
            continue

        if (s - 3 * a) % 6 != 0:
            continue

        y = (s - 3 * a) // 6
        if y <= 0:
            continue

        x = y + a
        print(x, y)
        return

    print(-1)

if __name__ == "__main__":
    main()
```
