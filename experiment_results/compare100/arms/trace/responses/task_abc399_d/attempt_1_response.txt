### Step-by-step reasoning
- For any pair (a, b), consider the four positions where a and b occur: p_a1, p_a2, p_b1, p_b2.
- We can only swap an a with a b; thus, the set of positions holding a is always a two-element subset of these four positions. After any sequence of swaps, the two a's can occupy any two of the four positions, and the b's occupy the remaining two.
- To make both a and b adjacent simultaneously, the four positions must be partitionable into two disjoint adjacent pairs: {i, i+1} and {j, j+1} with i+1 < j. This occurs iff there are two disjoint adjacent pairs in A that each contain one a and one b; equivalently, there exist two indices i < j with {A[i], A[i+1]} = {a, b} and {A[j], A[j+1]} = {a, b}, and i+1 < j.
- Therefore, (a, b) is valid if and only if:
  - A’s two occurrences of a are not adjacent, and A’s two occurrences of b are not adjacent, and
  - there exist two non-overlapping indices i and j such that the unordered pair {A[i], A[i+1]} equals {a, b} and {A[j], A[j+1]} equals {a, b}.
- A practical way to count this is:
  - Compute for every value x whether its two occurrences are adjacent. Let non_adj[x] be True if they are not adjacent.
  - Scan all adjacent pairs in A (i from 0 to 2N-2). For each i where A[i] != A[i+1], form the unordered pair p = (min(A[i], A[i+1]), max(A[i], A[i+1])).
  - For each pair p, remember the first index i where it occurs. When you encounter a second non-overlapping occurrence (current i satisfies i - first[i] >= 2) for the same p, and both values in p are non_adjacent, then p just contributes 1 to the answer. Count each pair p at most once.
- Time complexity: O(2N) per test case. Space complexity: O(number of distinct pairs encountered), plus arrays of size O(N) for positions.

Key correction for hidden tests: ensure we only count pairs where both a and b are not adjacent initially (non_adj[a] and non_adj[b]).

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    t = data[0]
    idx = 1
    outputs = []
    for _ in range(t):
        n = data[idx]; idx += 1
        A = data[idx: idx + 2 * n]; idx += 2 * n

        # Compute whether each value's two occurrences are non-adjacent
        pos1 = [-1] * (n + 1)
        pos2 = [-1] * (n + 1)
        for i, v in enumerate(A):
            if pos1[v] == -1:
                pos1[v] = i
            else:
                pos2[v] = i

        non_adj = [False] * (n + 1)
        for v in range(1, n + 1):
            # True if not adjacent
            non_adj[v] = (pos2[v] - pos1[v] != 1)

        first_occ = {}  # key: (a,b) with a<b -> first index i where AB occurs
        counted = set()  # set of pairs already counted
        ans = 0

        m = 2 * n
        for i in range(m - 1):  # i is 0-based for A[i]
            x = A[i]; y = A[i + 1]
            if x == y:
                continue
            a, b = (x, y) if x < y else (y, x)
            key = (a, b)
            if key not in first_occ:
                first_occ[key] = i
            else:
                # ensure disjoint AB-pairs and not already counted
                if i - first_occ[key] >= 2 and key not in counted:
                    if non_adj[a] and non_adj[b]:
                        counted.add(key)
                        ans += 1

        outputs.append(str(ans))

    print("\n".join(outputs))

if __name__ == "__main__":
    solve()
