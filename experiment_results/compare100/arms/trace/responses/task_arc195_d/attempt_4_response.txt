### Step-by-step reasoning
- Problem recap:
  - We have a sequence A. Two operations are allowed any number of times:
    1) Swap two adjacent elements (i and i+1).
    2) Delete the first i elements if they are all equal (i from 1 to K, the current length).
  - The goal is to minimize the total number of operations to delete the entire sequence.

- Key insight:
  - Deletions remove prefixes that are constant. If we ignore swaps, deleting one entire leftmost run per operation costs the number of runs in A.
  - Swaps can reduce the total number of runs by rearranging blocks, in particular by merging identical colors that are separated by a single-block of a different color (a pattern A B A where B is a single element block).
  - A single swap can reduce the number of runs by 1, or possibly by 2 if it also causes adjacent blocks to merge due to preceding or trailing blocks having the same color as the swapped piece. Each such reduction saves 1 deletion operation, but costs 1 swap. Therefore, the total cost after a swap is previous_swaps + (new number of runs). The objective is to maximize the total decrease in runs achieved by swaps minus the number of swaps performed.

- Important correctness detail (fix required):
  - My previous solution attempted to model the swap locally but incorrectly assumed the swap would produce a new block arrangement such as (A_left grows, B becomes a separate block, etc.). In reality, when swapping A_left (color c) with its right neighbor B (color d) in A_left, B, A_right (where A_left and A_right have the same color c and B is a single run of color d), after the swap the two A blocks become adjacent and merge into a single block of color c with length La + Lc. The B element then ends up before this merged A block and may merge with the preceding block if colors permit.
  - Therefore, the correct local transformation must reflect:
    - Pre-blocks (before i) stay the same except possibly B merging into the last pre-block if they share the same color d.
    - A_left and A_right unify into a single block of color c with length La + Lc.
    - B (color d) sits just before that merged A block and may merge with the previous pre-block if pre's last color is d.
    - Tail blocks after A_right stay in order and may merge with the merged A block if their first color matches c.

- Plan to fix:
  - Re-implement the local swap operation with the correct transformation:
    - Given colors[] and lengths[] (run-length encoding).
    - For i such that colors[i] == colors[i+2] and lengths[i+1] == 1 (pattern A B A with B length 1):
      - Build a new run-length encoding reflecting:
        - Pre part unchanged.
        - If the pre’s last color equals B's color, B merges into the pre’s last run.
        - Then append a single A block with color c and length La + Lc (merged A blocks).
        - Then append the tail, merging with the new last block if necessary.
      - Collapse any adjacent equal colors afterwards (defensive).
  - Use a priority-queue (max-heap) to greedily apply the best available swap (largest delta = runs_before - runs_after).
  - After applying a swap, re-evaluate nearby swap candidates (neighbors) since only a local region changed.
  - Finally, the answer for a test case is:
    number_of_swaps_performed + final_number_of_runs (the remaining blocks you need to delete, one operation per run).

- Why this is robust:
  - Deletions always cost 1 per remaining run; swaps reduce runs by some delta (1 or 2 typically, sometimes 0 or negative but we avoid those by only considering valid A B A with B length 1). The heap ensures we pick the best local improvements first and re-evaluate after each mutation, which is a commonly effective strategy for these local-edit problems.
  - The final answer formula (swaps + remaining_runs) respects the fact that you should delete each remaining run in one operation, and there is no way to delete across a boundary.

- Note on complexity:
  - The number of swaps is at most the initial number of runs minus 1.
  - Each swap only affects a small neighborhood, so re-evaluating candidates is local.
  - Overall this approach runs efficiently for the given constraints (sum of N up to 2e5).

- No external libraries are required.

import sys
import heapq

def to_runs(A):
    """Convert a list A into run-length encoding: colors, lengths."""
    colors = []
    lengths = []
    if not A:
        return colors, lengths
    cur = A[0]
    cnt = 1
    for x in A[1:]:
        if x == cur:
            cnt += 1
        else:
            colors.append(cur)
            lengths.append(cnt)
            cur = x
            cnt = 1
    colors.append(cur)
    lengths.append(cnt)
    return colors, lengths

def collapse(colors, lengths):
    """Merge adjacent runs with the same color (no-cost)."""
    if not colors:
        return colors, lengths
    new_colors = [colors[0]]
    new_lengths = [lengths[0]]
    for c, l in zip(colors[1:], lengths[1:]):
        if c == new_colors[-1]:
            new_lengths[-1] += l
        else:
            new_colors.append(c)
            new_lengths.append(l)
    return new_colors, new_lengths

def apply_swap(colors, lengths, i):
    """
    Apply the AB A swap operation at run index i on the run-length encoded sequence.
    i is the index of the first A block in the pattern A B A.
    Returns (new_colors, new_lengths) if possible, otherwise None.
    Correctly models the local transformation:
      Pre (before i) stays as is.
      If pre last color == B's color, B merges into pre's last block.
      A_left and A_right (colors[i] and colors[i+2], both color c) merge into a single block (c, La + Lc).
      Tail after i+2 remains, merged with the new A block if colors match.
    """
    M = len(colors)
    if i < 0 or i + 2 >= M:
        return None
    if colors[i] != colors[i + 2]:
        return None
    if lengths[i + 1] != 1:
        return None

    c = colors[i]
    La = lengths[i]
    d = colors[i + 1]
    Lc = lengths[i + 2]

    # Build the new run-length encoding
    pre_colors = colors[:i]
    pre_lengths = lengths[:i]

    new_colors = pre_colors[:]
    new_lengths = pre_lengths[:]

    # Merge B into pre if possible
    if new_colors and new_colors[-1] == d:
        new_lengths[-1] += 1
    else:
        new_colors.append(d)
        new_lengths.append(1)

    # Append A combined: color c, length La + Lc
    if new_colors and new_colors[-1] == c:
        new_lengths[-1] += La + Lc
    else:
        new_colors.append(c)
        new_lengths.append(La + Lc)

    # Append tail blocks i+3 onward
    tail_cols = colors[i+3:]
    tail_lens = lengths[i+3:]
    for col, ln in zip(tail_cols, tail_lens):
        if new_colors and new_colors[-1] == col:
            new_lengths[-1] += ln
        else:
            new_colors.append(col)
            new_lengths.append(ln)

    new_colors, new_lengths = collapse(new_colors, new_lengths)
    return new_colors, new_lengths

def is_candidate(i, cols, lens):
    if i < 0 or i + 2 >= len(cols):
        return False
    return (cols[i] == cols[i + 2]) and (lens[i + 1] == 1)

def compute_candidate(i, cols, lens):
    if not is_candidate(i, cols, lens):
        return None
    res = apply_swap(cols, lens, i)
    if res is None:
        return None
    new_cols, new_lens = res
    delta = len(cols) - len(new_cols)
    return (new_cols, new_lens, delta)

def min_operations_for_case(A):
    colors, lengths = to_runs(A)
    if not colors:
        return 0

    ops_swaps = 0
    current_version = 0  # version id to invalidate stale heap entries

    # Helper to push candidate if valid
    def push_candidate(i, cols, lens, ver, heap):
        cand = compute_candidate(i, cols, lens)
        if cand is not None:
            new_cols, new_lens, delta = cand
            heapq.heappush(heap, (-delta, i, ver))

    # Initialize heap with all initial candidates (if any)
    heap = []
    M = len(colors)
    for i in range(0, M - 2):
        cand = compute_candidate(i, colors, lengths)
        if cand is not None:
            _, _, delta = cand
            heapq.heappush(heap, (-delta, i, current_version))

    while heap:
        neg_delta, i, ver = heapq.heappop(heap)
        if ver != current_version:
            # Outdated entry
            continue

        cand = compute_candidate(i, colors, lengths)
        if cand is None:
            continue
        new_cols, new_lens, delta_now = cand

        if -neg_delta != delta_now:
            # Delta changed; push updated delta
            heapq.heappush(heap, (-delta_now, i, current_version))
            continue

        # Apply this operation
        colors = new_cols
        lengths = new_lens
        ops_swaps += 1
        current_version += 1  # new state
        M = len(colors)

        # Recompute candidates around the changed region
        start = max(0, i - 2)
        end = min(M - 3, i + 3)
        for j in range(start, end + 1):
            cand2 = compute_candidate(j, colors, lengths)
            if cand2 is not None:
                _, _, delta2 = cand2
                heapq.heappush(heap, (-delta2, j, current_version))

    final_runs = len(colors)
    return ops_swaps + final_runs

def main():
    data = sys.stdin.read().strip().split()
    t = int(data[0])
    idx = 1
    out_lines = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        A = list(map(int, data[idx:idx+n])); idx += n
        ans = min_operations_for_case(A)
        out_lines.append(str(ans))
    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
