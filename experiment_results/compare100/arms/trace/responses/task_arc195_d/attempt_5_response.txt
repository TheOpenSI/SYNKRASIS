### Step-by-step reasoning
- Problem recap:
  - You have a sequence A. Two operations exist:
    1) swap any adjacent pair (cost 1)
    2) delete the prefix if it is constant (cost 1)
  - The goal is to delete the entire sequence with minimum total operations.

- Root cause of the failure:
  - My earlier solution assumed swaps that reduce runs by merging the two A-blocks around a B-block by swapping between A_left and B. However, the example that reduces the number of runs (1,1,2,1,2) -> (1,1,1,2,2) shows the beneficial swap occurs at the boundary between B and the next A-block (i.e., swap between the last element of B and the first element of the A_right block). This AB_A swap boundary can merge A-left and A-right blocks when B has length 1, and can also merge the B blocks with neighboring blocks, leading to a different run-length transformation than previously modeled.

- Correct approach for the swap:
  - Work on run-length encoding (colors, lengths) of A.
  - Consider a swap at the boundary between a B-block (index i) and the following A-block (index i+1), where A_left is at i-1 and A_right at i+1. The swap is valid (potentially beneficial) when colors[i-1] == colors[i+1] (A_left color equals A_right color). The B block has length lengths[i].
  - After swapping the last element of B with the first element of A_right, the local region transforms as:
    - A_left (color c, length La) remains, plus:
    - B' (color d, length lengths[i]-1) if lengths[i] > 1
    - A_right_first (color c, length 1)
    - B_last (color d, length 1)
    - A_right_rem (color c, length lengths[i+1]-1)
    - Then the tail remains unchanged.
  - This local transformation can be collapsed (merge adjacent runs of the same color). The number of total runs can change by delta = old_run_count - new_run_count.
  - We use a greedy approach with a max-heap: at any step, pick a valid swap candidate with maximum delta. After applying a swap, we re-evaluate nearby swap candidates because the local region changed.

- Why this works:
  - Each swap reduces or maintains the number of runs in the local region by delta. Deleting runs costs 1 per remaining run. So the total cost is initial_runs - sum(delta_applied) + number_of_swaps_applied. To minimize, we want good deltas, but swaps can enable further deltas; hence we re-evaluate after each application.
  - The candidate set is narrowed to i where there exists A_left and A_right around B and their colors match (i.e., 1 <= i <= M-2 and colors[i-1] == colors[i+1]). This aligns with the observed beneficial pattern.

- Complexity considerations:
  - The number of runs is at most N, and each swap reduces the total runs by at least 1 (or we skip if delta would be 0). We re-evaluate only a small neighborhood around the changed area, so the approach remains efficient for the given constraints (sum N across tests ≤ 2e5).

- Summary:
  - Fix: implement swap at boundary between B and A_right, not A_left and B, and compute the exact resulting run-length encoding after the swap.
  - Use a max-heap to apply the most beneficial swaps first, and re-check neighboring candidates after each swap.
  - Final answer per test case: number_of_swaps_performed + final_number_of_runs (after performing all beneficial swaps we choose to apply).

import sys
import heapq

def to_runs(A):
    """Convert a list A into run-length encoding: colors, lengths."""
    colors = []
    lengths = []
    if not A:
        return colors, lengths
    cur = A[0]
    cnt = 1
    for x in A[1:]:
        if x == cur:
            cnt += 1
        else:
            colors.append(cur)
            lengths.append(cnt)
            cur = x
            cnt = 1
    colors.append(cur)
    lengths.append(cnt)
    return colors, lengths

def collapse(colors, lengths):
    """Merge adjacent runs with the same color (no-cost)."""
    if not colors:
        return colors, lengths
    new_colors = [colors[0]]
    new_lengths = [lengths[0]]
    for c, l in zip(colors[1:], lengths[1:]):
        if c == new_colors[-1]:
            new_lengths[-1] += l
        else:
            new_colors.append(c)
            new_lengths.append(l)
    return new_colors, new_lengths

def apply_swap_boundary(colors, lengths, i):
    """
    Apply the AB A swap operation at the boundary between B (index i) and A_right (index i+1).
    i is the index of B in the run-length encoded sequence.
    Valid when 1 <= i <= len(colors)-2 and colors[i-1] == colors[i+1].
    Returns (new_colors, new_lengths) if possible, otherwise None.
    Transformation models swapping the last element of B with the first element of A_right.
    """
    M = len(colors)
    if i <= 0 or i >= M - 1:
        return None
    if colors[i-1] != colors[i+1]:
        return None

    c = colors[i-1]  # A_left color and A_right color (same)
    d = colors[i]      # B color
    La = lengths[i-1]    # A_left length
    Lb = lengths[i]      # B length
    Lc = lengths[i+1]    # A_right length

    pre_colors = colors[:i-1]
    pre_lengths = lengths[:i-1]

    new_colors = pre_colors[:]
    new_lengths = pre_lengths[:]

    # A_left remains
    new_colors.append(c)
    new_lengths.append(La)

    # B' = B minus its last element
    if Lb - 1 > 0:
        new_colors.append(d)
        new_lengths.append(Lb - 1)

    # A_right_first element (color c, length 1)
    new_colors.append(c)
    new_lengths.append(1)

    # B_last element (color d, length 1)
    new_colors.append(d)
    new_lengths.append(1)

    # A_right_rem remainder
    if Lc - 1 > 0:
        new_colors.append(c)
        new_lengths.append(Lc - 1)

    # Tail after i+1
    tail_colors = colors[i+2:]
    tail_lens = lengths[i+2:]
    for col, ln in zip(tail_colors, tail_lens):
        if new_colors and new_colors[-1] == col:
            new_lengths[-1] += ln
        else:
            new_colors.append(col)
            new_lengths.append(ln)

    new_colors, new_lengths = collapse(new_colors, new_lengths)
    return new_colors, new_lengths

def is_candidate(i, cols, lens):
    """Check if swapping at boundary B(i) with A_right(i+1) is a potentially beneficial candidate."""
    M = len(cols)
    return (1 <= i <= M - 2) and (cols[i-1] == cols[i+1])

def compute_candidate(i, cols, lens):
    if not is_candidate(i, cols, lens):
        return None
    res = apply_swap_boundary(cols, lens, i)
    if res is None:
        return None
    new_cols, new_lens = res
    delta = len(cols) - len(new_cols)
    return (new_cols, new_lens, delta)

def min_operations_for_case(A):
    colors, lengths = to_runs(A)
    if not colors:
        return 0

    ops_swaps = 0
    current_version = 0  # version id to invalidate stale heap entries

    # Initialize heap with all initial candidates (if any)
    heap = []
    M = len(colors)
    for i in range(1, M - 1):
        cand = compute_candidate(i, colors, lengths)
        if cand is not None:
            _, _, delta = cand
            heapq.heappush(heap, (-delta, i, current_version))

    while heap:
        neg_delta, i, ver = heapq.heappop(heap)
        if ver != current_version:
            # Outdated entry
            continue

        cand = compute_candidate(i, colors, lengths)
        if cand is None:
            continue
        new_cols, new_lens, delta_now = cand

        if -neg_delta != delta_now:
            # Delta changed; push updated delta
            heapq.heappush(heap, (-delta_now, i, current_version))
            continue

        # Apply this operation
        colors = new_cols
        lengths = new_lens
        ops_swaps += 1
        current_version += 1  # new state
        M = len(colors)

        # Recompute candidates around the changed region
        start = max(1, i - 2)
        end = min(M - 2, i + 3)
        for j in range(start, end + 1):
            cand2 = compute_candidate(j, colors, lengths)
            if cand2 is not None:
                _, _, delta2 = cand2
                heapq.heappush(heap, (-delta2, j, current_version))

    final_runs = len(colors)
    return ops_swaps + final_runs

def main():
    data = sys.stdin.read().strip().split()
    t = int(data[0])
    idx = 1
    out_lines = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        A = list(map(int, data[idx:idx+n])); idx += n
        ans = min_operations_for_case(A)
        out_lines.append(str(ans))
    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
