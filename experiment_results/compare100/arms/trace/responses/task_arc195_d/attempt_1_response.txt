### Step-by-step reasoning
- The previous approach treated a swap that merges two same-color runs separated by a single run of length 1 as always reducing the number of runs by 2 (and thus reducing the total operations by 1). However, this is not always true when you consider the full effect of a swap on the entire run-length encoding. A single swap can sometimes reduce the number of runs by 2, but in other cases it only reduces by 1 (especially when the pattern is at the very end or there are no further same-color runs to the right that can merge with the swapped element). Moreover, a swap may create new opportunities (or destroy) for further merges, so a purely local, single-pass count of “valid triples” isn’t always safe.
- A robust approach is to simulate the process on the run-length encoded sequence, applying actual swap-based opportunities greedily from left to right, and updating the run-length encoding accordingly after every swap. We only swap across the boundary between the last element of a run of length 1 (the middle run) and the first element of the next run (the right neighbor), i.e., the natural boundary choice that matches the example behavior where a single swap can merge two identical-color runs separated by a single singleton run.
- We maintain the sequence in run-length form: colors[] stores the color of each run, lengths[] stores the length of that run. We repeatedly scan for the leftmost pattern where colors[i] == colors[i+2] and lengths[i+1] == 1. If there exists i+3 and colors[i+3] == colors[i+1], a single swap can reduce the run count by 2 (and we then merge adjacent runs where possible). If not, the swap reduces the run count by 1 (and we merge the two outer runs if they have the same color afterward). After every swap, we collapse any adjacent equal-color runs to keep the encoding minimal.
- We continue applying such swaps as long as there is any i with the above properties. In the end, the remainder of the sequence consists of runs that must be deleted one by one (each run costs 1 operation). The total number of operations is the number of swaps performed plus the final number of runs.
- This approach is O(K) swaps in the worst case, and each swap updates only a small portion of the runs (with careful in-place updates). We also perform a final linear pass to delete the remaining runs.

Key points:
- We operate on the run-length encoding to keep the state compact.
- After every swap, we collapse any adjacent runs of the same color (this is a no-cost merging step, since those are just the result of how the array sits after the swap).
- We always pick the leftmost applicable i (greedy) to ensure we don’t miss opportunities that would otherwise delocalize.

Potential edge cases:
- Very small inputs (N ≤ 2) where no swap can help; the answer is simply the number of runs.
- Sequences where the best strategy is to apply multiple non-overlapping swaps; the greedy left-to-right sweep handles that because we re-scan after every merge and resume from the left.

Time complexity:
- Each swap reduces the number of runs by at least 1; since the number of initial runs M ≤ N and each operation involves only local updates to the run-length encoding, the total number of operations is O(M). The per-operation cost is amortized small due to localized updates and occasional merges. The final deletions cost O(M). Overall, it is efficient for the given constraints (sum N ≤ 2e5).

Output format and constraints:
- The function signature must not be changed.
- No external libraries are required.
- The code reads T test cases and prints the minimal number of operations for each case.

import sys

def min_operations_for_case(A):
    # Build run-length encoding: colors and their run lengths
    colors = []
    lengths = []
    if not A:
        return 0
    cur = A[0]
    cnt = 1
    for x in A[1:]:
        if x == cur:
            cnt += 1
        else:
            colors.append(cur)
            lengths.append(cnt)
            cur = x
            cnt = 1
    colors.append(cur)
    lengths.append(cnt)

    # Helper: collapse adjacent runs of the same color (no cost)
    def collapse(colors, lengths, idx=None):
        # Collapse any adjacent equal-color blocks in-place
        if not colors:
            return colors, lengths
        new_colors = [colors[0]]
        new_lengths = [lengths[0]]
        for c, l in zip(colors[1:], lengths[1:]):
            if c == new_colors[-1]:
                new_lengths[-1] += l
            else:
                new_colors.append(c)
                new_lengths.append(l)
        return new_colors, new_lengths

    # Start with a greedy process on the run-length encoding
    ops_swaps = 0

    # Work on copies to mutate
    colors = colors[:]
    lengths = lengths[:]

    # Main loop: apply swaps while there exists a usable pattern
    # We'll do a left-to-right scan, perform a swap when possible, collapse,
    # and restart scan from max(0, i-2) to catch new opportunities.
    while True:
        M = len(colors)
        if M < 3:
            break
        changed = False
        i = 0
        while i <= M - 3:
            # Pattern: colors[i] == colors[i+2] and lengths[i+1] == 1
            if colors[i] == colors[i+2] and lengths[i+1] == 1:
                # There is a potential swap at the boundary between run i+1 and i+2
                # Consider if there is a following run with same color as colors[i+1].
                # If so, this swap can merge two pairs and reduce M by 2.
                if i + 3 < M and colors[i+3] == colors[i+1]:
                    # Apply -2 style merge: merge i, i+2 into a single block, removing i+1 and i+2,
                    # then possibly merge with i+3 if colors match.
                    new_len = lengths[i] + lengths[i+2]
                    colors[i] = colors[i]  # unchanged
                    lengths[i] = new_len
                    # Remove i+1 and i+2
                    del colors[i+1:i+3]
                    del lengths[i+1:i+3]
                    # After deletion, there is a new next block at index i+1 (formerly i+3)
                    # If it exists and has the same color as the merged block, merge it
                    if i + 1 < len(colors) and colors[i+1] == colors[i]:
                        lengths[i] += lengths[i+1]
                        del colors[i+1]
                        del lengths[i+1]
                    # Collapse any accidental adjacent duplicates around the updated region
                    colors, lengths = collapse(colors, lengths)
                    ops_swaps += 1
                    changed = True
                    break
                else:
                    # Apply -1 style merge: merge i and i+2 into a single block at i,
                    # effectively removing the middle run i+1
                    new_len = lengths[i] + lengths[i+2]
                    colors[i] = colors[i]  # unchanged
                    lengths[i] = new_len
                    # Remove i+1 and i+2
                    del colors[i+1:i+3]
                    del lengths[i+1:i+3]
                    # After removal, check for possible merges with neighbors
                    # Merge with left neighbor if same color
                    if i - 1 >= 0 and colors[i-1] == colors[i]:
                        lengths[i-1] += lengths[i]
                        del colors[i]
                        del lengths[i]
                        i = max(0, i-1)
                    # After potential left-merge, also try merge with right neighbor if adjacent colors equal
                    if i + 1 < len(colors) and colors[i] == colors[i+1]:
                        lengths[i] += lengths[i+1]
                        del colors[i+1]
                        del lengths[i+1]
                    # Collapse around the region
                    colors, lengths = collapse(colors, lengths)
                    ops_swaps += 1
                    changed = True
                    break
            i += 1

        if not changed:
            break

    # After exhausting all swap opportunities, remaining runs must be deleted one by one
    final_runs = len(colors)
    return ops_swaps + final_runs


def main():
    data = sys.stdin.read().strip().split()
    t = int(data[0])
    idx = 1
    out_lines = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        A = list(map(int, data[idx:idx+n])); idx += n
        ans = min_operations_for_case(A)
        out_lines.append(str(ans))
    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
