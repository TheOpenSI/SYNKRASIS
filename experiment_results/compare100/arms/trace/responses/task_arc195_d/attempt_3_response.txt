### Step-by-step reasoning
- Understanding the operations on A:
  - Operation 1: swap A[i] and A[i+1] for some 1 <= i < K.
  - Operation 2: delete the first i elements if the first i elements are all equal. This means we can delete a prefix consisting of a single color; deleting any part of the current leftmost run is allowed, but optimality generally prefers deleting entire leftmost run at a time.

- Key observation (from the problem structure):
  - If the run-length encoding of A is a sequence of blocks (color, length): (c1, l1), (c2, l2), ..., (cm, lm), then a single swap can dramatically reduce the number of runs only in a specific local pattern:
    - If we have ... (ci, li) , (ci+1, li+1), (ci+2, li+2) ... with ci == ci+2 and li+1 == 1, then a swap across the boundary between the second and third blocks (i+1 and i+2) transforms the local region in a way that merges the two identical colors on the outer sides (ci) into a longer block and may merge with adjacent blocks of the same color. This can reduce the total number of runs by more than 1 in that local area, which is beneficial because deletions cost 1 per run.
  - In other words, meaningful progress comes from applying swaps only on AB A patterns where B has length 1 and the colors on both sides of B are equal.

- The challenge is to pick a sequence of such swaps to minimize the total number of operations (swaps + remaining deletions). A simple greedy left-to-right pass that applies the first available swap is not always optimal (there are cases where the order of performing swaps matters to achieve the true minimum).

- A robust approach is to treat the problem at the level of runs and pick the swap that yields the largest immediate reduction in the number of runs (i.e., the largest delta in the number of runs) at each step. After performing a swap, we update the run-length encoding locally and recompute potential future swaps near the changed region. We repeat until no AB A-with-B-1 pattern remains. The final answer is:
  - number_of_swaps_performed + final_number_of_runs (since each remaining run must be deleted in one operation).

- To implement efficiently:
  - Maintain the current run-length encoding as two lists: colors[] and lengths[].
  - Provide a function to try a swap at a given run index i (0-based) if the pattern holds, returning the new run encoding after performing the swap (with proper local collapsing/merging).
  - Use a priority queue (max-heap) to store candidate swaps with their immediate delta (reduction in the number of runs). Each candidate stores its i-position and the version of the current encoding when it was computed.
  - After performing a swap, only nearby positions can be affected. We re-evaluate candidates in a small neighborhood around the performed swap and push fresh candidates into the heap. We discard outdated candidates by tracking a version counter that increments after each mutation.

- This approach is designed to be near-linear in practice (number of swaps is at most number_of_runs - 1, and each operation touches only a small neighborhood). It also addresses the pitfall of naive left-to-right greedy by choosing the best local move available at each step.

- Complexity considerations:
  - Each successful swap reduces the number of runs by at least 1.
  - The neighborhood updates keep the per-swap work bounded to a small constant factor.
  - Overall, the approach runs efficiently for the given constraints (sum of N across tests up to 2e5).

- Output format: For each test case, print the minimum number of operations as an integer on its own line.

import sys
import heapq

def to_runs(A):
    """Convert a list A into run-length encoding: colors, lengths."""
    colors = []
    lengths = []
    if not A:
        return colors, lengths
    cur = A[0]
    cnt = 1
    for x in A[1:]:
        if x == cur:
            cnt += 1
        else:
            colors.append(cur)
            lengths.append(cnt)
            cur = x
            cnt = 1
    colors.append(cur)
    lengths.append(cnt)
    return colors, lengths

def collapse(colors, lengths):
    """Merge adjacent runs with the same color (no-cost)."""
    if not colors:
        return colors, lengths
    new_colors = [colors[0]]
    new_lengths = [lengths[0]]
    for c, l in zip(colors[1:], lengths[1:]):
        if c == new_colors[-1]:
            new_lengths[-1] += l
        else:
            new_colors.append(c)
            new_lengths.append(l)
    return new_colors, new_lengths

def try_operation(colors, lengths, i):
    """
    Try performing the AB A swap operation at index i on the run-length encoded sequence.
    i is the index of the first A block in the pattern A B A.
    Returns (new_colors, new_lengths) if possible, otherwise None.
    """
    M = len(colors)
    if i < 0 or i + 2 >= M:
        return None
    if colors[i] != colors[i + 2]:
        return None
    if lengths[i + 1] != 1:
        return None

    La = lengths[i]
    Lb = lengths[i + 1]  # must be 1
    Lc = lengths[i + 2]
    c = colors[i]
    d = colors[i + 1]

    e_exists = (i + 3 < M)
    if e_exists:
        e = colors[i + 3]
        Ld = lengths[i + 3]
    else:
        e = None
        Ld = 0

    # Build the local new blocks after the swap as described
    new_blocks = []
    new_blocks.append((c, La + 1))      # left A grows by 1
    new_blocks.append((d, 1))           # the swapped element
    if Lc > 1:
        new_blocks.append((c, Lc - 1))   # remaining part of right A, if any
    if e_exists:
        new_blocks.append((e, Ld))       # followed by the next block if exists

    # Prefix (before i)
    pre_colors = colors[:i]
    pre_lengths = lengths[:i]

    # Merge new_blocks into the prefix, then append the tail (i+4 and beyond)
    merged_colors = pre_colors[:]
    merged_lengths = pre_lengths[:]
    for col, ln in new_blocks:
        if ln <= 0:
            continue
        if merged_colors and merged_colors[-1] == col:
            merged_lengths[-1] += ln
        else:
            merged_colors.append(col)
            merged_lengths.append(ln)

    tail_colors = colors[i+4:]
    tail_lengths = lengths[i+4:]
    for col, ln in zip(tail_colors, tail_lengths):
        if merged_colors and merged_colors[-1] == col:
            merged_lengths[-1] += ln
        else:
            merged_colors.append(col)
            merged_lengths.append(ln)

    # Collapse possible adjacent duplicates again (defensive)
    merged_colors, merged_lengths = collapse(merged_colors, merged_lengths)
    return merged_colors, merged_lengths

def min_operations_for_case(A):
    colors, lengths = to_runs(A)
    # If already empty or trivial
    if not colors:
        return 0
    ops_swaps = 0
    gen = 0  # version counter to invalidate stale heap entries

    # Build initial candidate set: indices i where A B A pattern holds
    def is_candidate(i, cols, lens):
        if i < 0 or i + 2 >= len(cols):
            return False
        return (cols[i] == cols[i + 2]) and (lens[i + 1] == 1)

    # Helper to try and get the operation result for a given i
    def compute_candidate(i, cols, lens):
        if not is_candidate(i, cols, lens):
            return None
        res = try_operation(cols, lens, i)
        if res is None:
            return None
        new_cols, new_lens = res
        delta = len(cols) - len(new_cols)
        return (new_cols, new_lens, delta)

    # Initialize a max-heap of (negative_delta, index, gen)
    heap = []
    M = len(colors)
    for i in range(0, M - 2):
        cand = compute_candidate(i, colors, lengths)
        if cand is not None:
            new_cols, new_lens, delta = cand
            heapq.heappush(heap, (-delta, i, gen))

    # Main loop: perform swaps with best delta until no more beneficial swaps exist
    while heap:
        neg_delta, i, hgen = heapq.heappop(heap)
        if hgen != gen:
            # Outdated entry
            continue
        # Re-check if still valid and delta unchanged
        cand = compute_candidate(i, colors, lengths)
        if cand is None:
            continue
        new_cols, new_lens, delta_now = cand
        delta_original = -neg_delta
        if delta_now != delta_original:
            # Delta changed; push updated delta
            heapq.heappush(heap, (-delta_now, i, gen))
            continue

        # Apply this operation
        colors = new_cols
        lengths = new_lens
        ops_swaps += 1
        gen += 1  # new state
        M = len(colors)
        # Recompute candidates around the changed region: indices in [i-2, i+3]
        start = max(0, i - 2)
        end = min(M - 3, i + 3)
        for j in range(start, end + 1):
            cand2 = compute_candidate(j, colors, lengths)
            if cand2 is not None:
                _, _, delta2 = cand2
                heapq.heappush(heap, (-delta2, j, gen))
        # Note: some candidates far away remain valid; they will be checked when popped

    # After no more swaps, remaining runs must be deleted
    final_runs = len(colors)
    return ops_swaps + final_runs


def main():
    data = sys.stdin.read().strip().split()
    t = int(data[0])
    idx = 1
    out_lines = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        A = list(map(int, data[idx:idx+n])); idx += n
        ans = min_operations_for_case(A)
        out_lines.append(str(ans))
    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
