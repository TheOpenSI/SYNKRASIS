### Step-by-step reasoning
- Problem understanding:
  - For every subarray nums[l..r], we may perform up to k increments on elements inside that subarray to make it non-decreasing.
  - The subarrays are independent. We only care if the minimal number of increments needed for a given subarray is <= k.
- Key observation:
  - For a fixed left index l, if we walk to the right (increase r), the minimal number of increments to make nums[l..r] non-decreasing can be computed greedily:
    - Let cur_max be the maximum value seen so far in nums[l..r-1].
    - When we look at element nums[r]:
      - If nums[r] < cur_max, we need to increase nums[r] up to cur_max, costing cur_max - nums[r].
      - If nums[r] >= cur_max, no increment is needed and we update cur_max = nums[r].
    - The total cost is the sum of all such required increments for indices > l.
  - This greedy scheme yields the minimal total increments for the subarray (since we only ever raise elements to the current maximum seen so far).
  - Therefore a subarray l..r is valid iff this running cost is <= k.
- Algorithm outline:
  - For each left index l from 0 to n-1:
    - Initialize cost = 0 and cur_max = nums[l].
    - Count the length-1 subarray [l] as valid (cost = 0 <= k).
    - Extend r from l+1 to n-1:
      - If nums[r] < cur_max, add cur_max - nums[r] to cost.
      - Else, set cur_max = nums[r].
      - If cost <= k, count this subarray.
      - If cost > k, break out of the inner loop for this l, since extending r can only increase (or keep) cost.
- Correctness and complexity notes:
  - Correctness: The procedure computes the minimal increments required for each subarray based on the running maximum, which is optimal for making the subarray non-decreasing with only increments.
  - Complexity: In the worst case, this is O(n^2). While not subquadratic, this approach is straightforward, correct, and robust. If needed, a subquadratic solution would require a more sophisticated data-structure approach that is not straightforward given the per-subarray dependency on left bound l.

from typing import List

class Solution:
    def countNonDecreasingSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        if n == 0:
            return 0

        ans = 0
        a = nums  # local alias for speed

        for l in range(n):
            cost = 0
            cur_max = a[l]
            # subarray of length 1: always valid
            ans += 1

            # extend to the right
            for r in range(l + 1, n):
                v = a[r]
                if v < cur_max:
                    cost += cur_max - v
                else:
                    cur_max = v

                if cost <= k:
                    ans += 1
                else:
                    break

        return ans
