### Step-by-step reasoning
- Problem recap:
  - For every subarray nums[l..r], we may perform up to k increments on elements inside that subarray (independently for each subarray).
  - We want to count how many subarrays can be made non-decreasing with at most k increments.

- Understanding cost for a fixed subarray:
  - To make a subarray non-decreasing with only increments, the i-th element (relative to the subarray) must be at least the maximum of all previous elements in that subarray.
  - If we walk from left to right inside nums[l..r]:
    - Let cur_max be the maximum seen so far in the subarray (initialized to nums[l]).
    - For each next element a = nums[i]:
      - If a < cur_max, we must increment it to cur_max, costing (cur_max - a).
      - If a >= cur_max, no increment is needed for this element, and cur_max becomes a.
  - The total cost for subarray l..r is the sum of all required increments computed this way.
  - This greedy approach yields the minimal total increments for the subarray, since raising a value above the current running maximum only makes future costs larger.

- Consequence for counting:
  - For a fixed left index l, as we extend r to the right, the cost is non-decreasing (it never decreases with more elements on the right).
  - Therefore, for a fixed l, there is a (possibly empty) prefix of r values such that f(l, r) <= k. Once f(l, r) > k, extending r further can only increase cost, so we can stop for that l.
  - A straightforward implementation is to iterate l from 0..n-1 and, for each l, extend r from l to n-1 while accumulating cost and breaking when cost > k.

- Why this might fail on big inputs:
  - The straightforward approach is O(n^2) in the worst case.
  - With n up to 1e5, this is not feasible in Python for worst-case inputs. The logic itself is correct, but performance is the limiting factor for large inputs.

- Output format: Return an integer count of subarrays that can be made non-decreasing with at most k increments.

from typing import List

class Solution:
    def countNonDecreasingSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        if n == 0:
            return 0

        ans = 0
        a = nums  # local alias for speed

        # For each left boundary l, extend to the right and accumulate required cost
        for l in range(n):
            cost = 0
            cur_max = a[l]
            # Subarray of length 1 is always valid
            ans += 1

            # Extend to the right
            for r in range(l + 1, n):
                v = a[r]
                if v < cur_max:
                    cost += cur_max - v
                else:
                    cur_max = v

                if cost <= k:
                    ans += 1
                else:
                    break

        return ans
