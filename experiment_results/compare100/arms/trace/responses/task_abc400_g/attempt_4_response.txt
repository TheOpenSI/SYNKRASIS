### Step-by-step reasoning
- Problem summary: Given N items with triples (X_i, Y_i, Z_i), you must form K disjoint pairs (i, j) maximizing sum over pairs of max(X_i+X_j, Y_i+Y_j, Z_i+Z_j).
- Root cause of the earlier failure: The previous solution restricted potential edges to only a small set of top candidates per dimension. This can miss optimal pairings where one endpoint is not among the top in any single dimension but still contributes to a high pairwise max when combined with another endpoint (as shown in the failing test case where the second pair uses a non-top index with the top index).
- Fix approach: Create a small, representative candidate set C of indices that are strong in at least one dimension (take the top L indices per dimension). To ensure we can form useful pairs that involve non-C partners, generate edges between every node in C and all other nodes (i.e., for each u in C, consider edges (u, v) for all v > u). This guarantees edges like (top_candidate, non_top_candidate) that could be necessary for the optimal matching.
- Why this works well here:
  - At least one endpoint of any good pair should be strong in at least one dimension; thus including top candidates captures these edges.
  - By connecting each candidate to all other nodes, we also capture edges like (non_top, top_candidate) that are essential for the optimal combination, even when the non_top node isn’t in the top list for any single dimension.
  - We keep the candidate set small (L=3) to keep the total number of edges manageable. For N up to 1e5, this yields roughly |C| * N edges, which is acceptable, and the sum of N over all tests is 1e5, so the total work remains practical.
- Algorithm outline:
  1. Read input.
  2. For each test case, pick top L=3 indices for X, Y, Z using a small helper (e.g., heapq.nlargest).
  3. Let C be the union of these indices (a small candidate set).
  4. Build edges (w, u, v) for all u in C and all v with v > u: w = max(X_u+X_v, Y_u+Y_v, Z_u+Z_v).
  5. Sort edges by w in descending order.
  6. Greedily pick edges disjoint in vertices until we select K edges, summing their weights.
- This yields an exact greedy maximum matching on a reasonably large edge set that contains the needed cross-edge types (top candidate with any other node), solving the failing case where the optimal uses a non-top partner alongside a top candidate.

import sys
import heapq

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    t = data[0]
    p = 1
    out_lines = []
    for _ in range(t):
        n = data[p]; p += 1
        k = data[p]; p += 1

        X = [0]*n
        Y = [0]*n
        Z = [0]*n
        for i in range(n):
            X[i] = data[p]
            Y[i] = data[p+1]
            Z[i] = data[p+2]
            p += 3

        # Number of top indices to consider per dimension
        L = 3
        def top_indices(arr, L_local):
            if L_local >= len(arr):
                return list(range(len(arr)))
            # Return indices of the top L_local values
            return heapq.nlargest(L_local, range(len(arr)), key=lambda i: arr[i])

        idx_x = top_indices(X, L)
        idx_y = top_indices(Y, L)
        idx_z = top_indices(Z, L)

        Cset = set(idx_x) | set(idx_y) | set(idx_z)
        C = sorted(Cset)  # small candidate set

        edges = []
        # Build edges from each candidate to all vertices (to capture necessary cross-edges)
        for ui in C:
            for v in range(ui + 1, n):
                w = X[ui] + X[v]
                tval = Y[ui] + Y[v]
                if tval > w: w = tval
                zval = Z[ui] + Z[v]
                if zval > w: w = zval
                edges.append((w, ui, v))

        # Sort edges by weight descending
        edges.sort(key=lambda e: e[0], reverse=True)

        used = [False] * n
        total = 0
        taken = 0
        for w, u, v in edges:
            if not used[u] and not used[v]:
                total += w
                used[u] = True
                used[v] = True
                taken += 1
                if taken == k:
                    break

        out_lines.append(str(total))

    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
