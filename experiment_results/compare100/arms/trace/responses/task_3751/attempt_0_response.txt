### Step-by-step reasoning
- We perform exactly one operation: choose a contiguous subarray and add the same x to all its elements.
- After the operation, an element a[i] becomes:
  - a[i] (if i is outside the chosen subarray), or
  - a[i] + x (if i is inside the chosen subarray).
- To make an element become k after the operation, we need a[i] + x = k ⇒ a[i] = k - x.
  - If we pick a fixed m = k - x, then every element inside the subarray with original value m will become k.
  - Elements inside that subarray with value not equal to m will not become k.
  - Elements equal to k inside the subarray will become k + x ≠ k (unless x = 0, i.e., m = k), which would decrease the final count of k.
- Therefore, for a given m ≠ k, the best we can do is pick a subarray that contains as many m’s as possible but contains no k’s (to avoid turning existing k’s into something else). The maximum number of m’s we can collect in such a subarray is the maximum number of m’s in any block of the array that does not contain k.
- The final maximum frequency is:
  - total_k: number of k’s already in the array (case where m = k or we don’t gain anything).
  - For each m ≠ k, total_k + (maximum number of m’s in any block that has no k).
- If there are no k’s in the array, the whole array is one block, and the answer is max count of any value m in the array.
- Complexity: We test up to 50 possible m values (1..50) and scan the array each time, giving O(50 * n) time, which is fine for n ≤ 1e5.

Edge cases:
- All elements already equal to k: answer is n.
- No k in the array: answer is the maximum frequency of any value in the array.
- Small arrays (n = 1): handled by the same logic.

### Requirements
None

### Code
```python
class Solution:
    def maxFrequency(self, nums: List[int], k: int) -> int:
        n = len(nums)
        total_k = sum(1 for v in nums if v == k)
        
        # If everything is already k
        if total_k == n:
            return n
        
        # Start with the current frequency of k
        ans = total_k
        
        # Try to convert as many m-values into k by choosing an appropriate subarray
        # m ranges from 1 to 50 (as per constraints)
        for m in range(1, 51):
            if m == k:
                continue  # already covered by total_k
            current_block_count = 0
            best_in_blocks = 0  # max number of m's in any block without k
            
            for v in nums:
                if v == k:
                    # End of a block (no k inside this block beyond this point)
                    if current_block_count > best_in_blocks:
                        best_in_blocks = current_block_count
                    current_block_count = 0
                else:
                    if v == m:
                        current_block_count += 1
                    # if v != m and v != k, it doesn't contribute but is allowed
            
            # finalize last block
            if current_block_count > best_in_blocks:
                best_in_blocks = current_block_count
            
            ans = max(ans, total_k + best_in_blocks)
        
        return ans
```
