### Step-by-step reasoning
- For two dice i and j, let counts_i[v] be how many times value v appears on die i, and Ki be the number of faces on die i. Similarly counts_j[v] and Kj for die j.
- When rolling these two dice, the probability that both show the same value v is (counts_i[v]/Ki) * (counts_j[v]/Kj). Summing over all possible values v gives the probability for the pair:
  P(i, j) = sum_v (counts_i[v]/Ki) * (counts_j[v]/Kj) = dot(counts_i, counts_j) / (Ki * Kj),
  where dot is the sum over common values of counts_i[v] * counts_j[v].
- To maximize the probability, we simply compute P(i, j) for every unordered pair (i, j) with i < j and take the maximum.
- Efficiency: store each die as a dictionary mapping value -> its count on that die. For each pair, compute the dot product efficiently by iterating over the smaller of the two dictionaries and looking up the corresponding counts in the other dictionary. This yields a time complexity roughly O(sum over pairs of min(Di, Dj)), where Di is the number of distinct values on die i. With total faces across all dice ≤ 1e5 and N ≤ 100, this is easily fast enough.
- Numerical considerations: use Python float for the final probability. Print with enough precision (e.g., 15 decimal digits) to satisfy the required 1e-8 tolerance.
- Edge cases: if two dice share no common value, the probability is 0. If there are duplicates on a die, they are automatically handled via counts.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        print("0.0")
        return

    it = iter(data)
    N = int(next(it))

    # For each die: dict[value] = count, and Ki = number of faces
    dicts = []
    Ks = []

    for _ in range(N):
        Ki = int(next(it))
        Ks.append(Ki)
        counts = {}
        for _ in range(Ki):
            v = int(next(it))
            counts[v] = counts.get(v, 0) + 1
        dicts.append(counts)

    max_prob = 0.0

    for i in range(N):
        di = dicts[i]
        Ki = Ks[i]
        di_items = list(di.items())  # (value, count) pairs for faster iteration

        for j in range(i + 1, N):
            dj = dicts[j]
            Kj = Ks[j]

            # Compute dot product efficiently by iterating over the smaller dictionary
            if len(di) <= len(dj):
                dot = 0
                dj_get = dj.get
                for v, ci in di_items:
                    dot += ci * dj_get(v, 0)
            else:
                dot = 0
                di_get = di.get
                for v, cj in dj.items():
                    dot += cj * di_get(v, 0)

            prob = dot / (Ki * Kj)
            if prob > max_prob:
                max_prob = prob

    print("{:.15f}".format(max_prob))

if __name__ == "__main__":
    main()
