### Step-by-step reasoning
- The probability that two specific dice i and j show the same number is the sum over all possible values v of the probability that die i shows v and die j shows v.
- If die i has count_i(v) faces labeled v and total faces K_i, then P(i shows v) = count_i(v) / K_i. Similarly for die j.
- Therefore the pair probability is P(i, j) = sum_v (count_i(v) / K_i) * (count_j(v) / K_j) = dot(counts_i, counts_j) / (K_i * K_j), where dot is sum over all values v of count_i(v) * count_j(v).
- A straightforward approach computes the dot product for every pair (i, j). However, we can do this more efficiently by aggregating contributions per value:
  - Build a mapping value v -> list of (die_index, count_on_that_die) for all dice that contain v.
  - For each value v, for every pair of dice (i, j) in its list, add count_i(v) * count_j(v) to dot[i][j].
- After processing all values, for every pair (i, j) compute dot[i][j] / (K_i * K_j) and take the maximum.
- This approach is efficient since the total number of (die, value) entries is bounded by the total number of faces across all dice (sum K_i ≤ 1e5), and the inner pairwise accumulation per value is limited by the number of dice that share that value.
- Output uses 15 decimal places to satisfy the required precision.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        print("0.0")
        return

    it = iter(data)
    N = int(next(it))

    Ks = []
    counts = []
    value_map = {}  # value -> list of (die_index, count)

    for i in range(N):
        Ki = int(next(it))
        Ks.append(Ki)
        cnt = {}
        for _ in range(Ki):
            v = int(next(it))
            cnt[v] = cnt.get(v, 0) + 1
        counts.append(cnt)
        for v, c in cnt.items():
            value_map.setdefault(v, []).append((i, c))

    # Dot products: dot[i][j] = sum_v count_i(v) * count_j(v)
    dot = [[0]*N for _ in range(N)]

    for v, lst in value_map.items():
        m = len(lst)
        if m < 2:
            continue
        for a in range(m - 1):
            i, ci = lst[a]
            for b in range(a + 1, m):
                j, cj = lst[b]
                dot[i][j] += ci * cj

    max_prob = 0.0
    for i in range(N):
        Ki = Ks[i]
        for j in range(i + 1, N):
            Kj = Ks[j]
            val = dot[i][j] / (Ki * Kj)
            if val > max_prob:
                max_prob = val

    print("{:.15f}".format(max_prob))

if __name__ == "__main__":
    main()
