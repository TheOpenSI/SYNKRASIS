### Step-by-step reasoning
- For two chosen dice i and j, let freq_i[v] be how many times value v appears on die i, and Ki be the number of faces on die i. Similarly for die j with Kj.
- The probability that when rolling these two dice the outcomes match on value v is (freq_i[v] / Ki) * (freq_j[v] / Kj). Summing over all possible values v gives the total probability that both show the same number:
  P(i, j) = sum_v (freq_i[v] / Ki) * (freq_j[v] / Kj) = dot(freq_i, freq_j) / (Ki * Kj),
  where dot(freq_i, freq_j) = sum_v freq_i[v] * freq_j[v] is the dot product of the frequency vectors.
- To maximize the probability, compute P(i, j) for all pairs (i < j) and take the maximum.
- Efficient computation: store for each die a frequency dictionary freq_i mapping value -> count. For each pair (i, j), compute the dot product by iterating over the smaller of freq_i and freq_j to minimize lookups:
  dot = sum over v in smaller_dict of (count_in_smaller * count_in_other_if_present).
- This approach avoids constructing a global value-to-dice map and is efficient within the given constraints:
  - Total faces sum Ki ≤ 1e5.
  - N ≤ 100, so pairwise checks are at most ~4950.
- Precision: use Python floats (double precision). The final answer is printed with high precision (e.g., 15 decimal places) to satisfy the required error tolerance.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        print("0.0")
        return

    it = iter(data)
    N = int(next(it))

    Ks = [0] * N
    freqs = [None] * N  # list of dicts: value -> count

    for i in range(N):
        Ki = int(next(it))
        Ks[i] = Ki
        freq = {}
        for _ in range(Ki):
            v = int(next(it))
            freq[v] = freq.get(v, 0) + 1
        freqs[i] = freq

    max_prob = 0.0

    for i in range(N):
        freq_i = freqs[i]
        Ki = Ks[i]
        for j in range(i + 1, N):
            freq_j = freqs[j]
            Kj = Ks[j]

            # Compute dot product efficiently by iterating over the smaller dict
            if len(freq_i) <= len(freq_j):
                dot = 0
                for v, ci in freq_i.items():
                    cj = freq_j.get(v)
                    if cj is not None:
                        dot += ci * cj
            else:
                dot = 0
                for v, cj in freq_j.items():
                    ci = freq_i.get(v)
                    if ci is not None:
                        dot += ci * cj

            prob = dot / (Ki * Kj)
            if prob > max_prob:
                max_prob = prob

    print("{:.15f}".format(max_prob))

if __name__ == "__main__":
    main()
