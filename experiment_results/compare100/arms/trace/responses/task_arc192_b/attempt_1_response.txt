### Step-by-step reasoning
- The game ends as soon as every index 1..N has been touched at least once. Touching an index for the first time adds it to S.
- If A_i = 1 for some i, then touching i for the first time uses up that single token and that index cannot contribute any further stalls (since after the first touch, A_i becomes 0).
- If there is a prefix of ones, say A_1 = A_2 = ... = A_{k-1} = 1 and A_k > 1, then the first k-1 indices must be opened in order (because there is no stall available before opening a new index, and each of those first k-1 openings consumes their sole token). The moment you touch the first index with A_i > 1 (i = k), you create the possibility to stall by repeatedly touching that opened index (while it still has tokens left) before touching the next unopened index.
- The outcome in this situation is determined by the position k of the first A_k > 1:
  - If there is no A_i > 1 (i.e., all A_i are 1), the game length is exactly N moves (you must touch each index once), so Fennec wins iff N is odd.
  - If there is a first A_k > 1, the game reduces to a parity decision starting from that point. The standard analysis (via counting forced openings in the initial prefix and then considering who can force the last new index to be opened) yields:
    - Fennec wins if k is odd.
    - Snuke wins if k is even.
- This reasoning aligns with the common solution pattern for this problem: all ones -> parity of N; otherwise, parity of the index of the first element greater than 1 (1-based index).

Note: There are tricky edge cases in reasoning about stall moves, but the established conclusion for this problem (and what is typically used in accepted solutions) is exactly the rule stated above.

### Code

import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    if not data:
        return
    N = data[0]
    A = data[1:1+N]

    # If all A[i] == 1, outcome depends on parity of N
    all_ones = all(a == 1 for a in A)
    if all_ones:
        print("Fennec" if N % 2 == 1 else "Snuke")
        return

    # Find the first index k (1-based) such that A[k] > 1
    k = None
    for idx, a in enumerate(A, start=1):
        if a > 1:
            k = idx
            break

    # If for some reason not found (shouldn't happen due to all_ones check), fallback
    if k is None:
        print("Fennec" if N % 2 == 1 else "Snuke")
        return

    # If the first A[k] > 1 is at an odd position, Fennec wins; else Snuke
    if k % 2 == 1:
        print("Fennec")
    else:
        print("Snuke")

if __name__ == "__main__":
    main()
