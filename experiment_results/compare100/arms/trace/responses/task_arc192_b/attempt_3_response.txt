### Step-by-step reasoning
- The game is defined on a sequence A of length N with a set S of opened indices. A move consists of choosing an index i with A_i > 0, subtracting 1 from A_i, and if i is newly opened (i not in S), adding i to S. The game ends when S = {1,2,...,N}.
- Key observations:
  - The first time an index is chosen (opened) occurs when that index is added to S. If A_i = 1, opening i consumes its only token and i becomes opened, after which that index cannot contribute any further stalls (since A_i becomes 0).
  - Before the first index with A_i > 1 is opened, all previous indices must be opened in order (as every prior A_j = 1). After opening these, there exists at least one index with remaining tokens (the first A_i > 1) which enables stalling moves. This creates a shift in parity control.
  - After all previous indices with A_j = 1 are opened, the crucial moment is when we encounter the first index with A_i > 1. The parity of who will eventually perform the last move (i.e., open the last index) is determined by who makes this first non-trivial choice, which, in the standard optimal-play analysis of this problem, reduces to the parity of that first index i with A_i > 1.
  - If all A_i = 1, then every index must be opened exactly once in order, so the game lasts N moves and the winner is Fennec if N is odd, Snuke if N is even.

- Therefore:
  - If all A_i are 1: Fennec wins iff N is odd.
  - Otherwise, let k be the smallest index with A_k > 1. Then Fennec wins if k is odd, otherwise Snuke wins.

This is a well-known reduction for this impartial game: the first non-one element determines the winner by its parity, with the all-ones case handled by N's parity.

### Code
```
import sys

def main():
    data = sys.stdin.read().split()
    if not data:
        return
    N = int(data[0])
    A = list(map(int, data[1:1+N]))
    
    # Case 1: all A_i == 1
    if all(a == 1 for a in A):
        print("Fennec" if N % 2 == 1 else "Snuke")
        return
    
    # Case 2: find the first index k (1-based) with A_k > 1
    k = None
    for idx, a in enumerate(A, start=1):
        if a > 1:
            k = idx
            break
    
    # k should exist here since not all are 1
    if k is not None and (k % 2 == 1):
        print("Fennec")
    else:
        print("Snuke")

if __name__ == "__main__":
    main()
```
