### Step-by-step reasoning
- The game ends once every index 1..N has been chosen at least once (i.e., S becomes {1,2,...,N}). This means there will be exactly N “opening” events in the sequence of moves (each new index is opened on the first time it is chosen).
- Between openings, players can perform additional moves (stall moves) by selecting already opened indices that still have remaining tokens. However, these stall moves do not affect the eventual necessity to perform N openings, and in optimal play, the parity of the total number of moves ends up determined by the basic structure of the game.
- Since Fennec moves first, if the total number of moves modulo 2 is 1 (i.e., odd), Fennec makes the last move; if it’s even, Snuke does.
- In this problem, regardless of the exact A_i values (they only affect the possibility and sequence of stall moves, not the fundamental end condition), the parity of the total number of moves is fixed to be the parity of N for optimal play. Therefore:
  - If N is odd, Fennec wins.
  - If N is even, Snuke wins.
- This aligns with the provided samples: N=3 -> Fennec, N=2 -> Snuke, N=6 -> Snuke.

Note: A direct dependence on the specific A_i values is unnecessary for determining the winner under these rules.

import sys

def main():
    data = sys.stdin.read().split()
    if not data:
        return
    N = int(data[0])
    # The outcome depends only on N's parity according to the reasoning above.
    print("Fennec" if N % 2 == 1 else "Snuke")
