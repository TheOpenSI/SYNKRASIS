### Step-by-step reasoning
- The game ends as soon as every position i has been chosen at least once (i.e., added to S). Before a position is opened (added to S) you can choose other positions freely; after a position is opened you can still decrease its A_i by choosing it again (stall moves) as long as A_i > 0.
- If all A_i are 1, every position must be opened exactly once, so the game lasts N moves. Since Fennec starts, Fennec wins if N is odd, Snuke if N is even.
- If there exists some A_i > 1, the leftmost such index (the smallest i with A_i > 1) determines the outcome under optimal play: the first player (Fennec) can always force a win if that index is odd, otherwise the second player (Snuke) wins.
- Therefore the standard solution is:
  - If all A_i == 1: Fennec wins iff N is odd.
  - Otherwise, let k be the smallest index with A_k > 1. Fennec wins if k is odd, else Snuke.

This approach matches the intended optimal play strategy for this impartial combinatorial game and is the canonical solution for this problem type.

### Requirements
None

### Code
```
import sys

def main():
    data = sys.stdin.read().split()
    if not data:
        return
    N = int(data[0])
    A = list(map(int, data[1:1+N]))
    
    # Case 1: all A_i == 1
    if all(a == 1 for a in A):
        print("Fennec" if N % 2 == 1 else "Snuke")
        return
    
    # Case 2: find the first index k (1-based) with A_k > 1
    k = None
    for idx, a in enumerate(A, start=1):
        if a > 1:
            k = idx
            break
    
    # k exists since not all are 1
    if k is not None and (k % 2 == 1):
        print("Fennec")
    else:
        print("Snuke")

if __name__ == "__main__":
    main()
```
