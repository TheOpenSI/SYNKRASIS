### Step-by-step reasoning
- Problem understanding: We start with an empty array A. For i from 1 to N, insert i so that it becomes the Pi-th element from the start of the current A. This is equivalent to inserting i at position Pi (1-based) in the evolving array.
- Standard reverse construction: Instead of simulating insertions forward (which would be O(N^2)), build the final array from N down to 1. When placing i, exactly i positions are currently “empty” (the numbers i+1..N have already been placed). The Pi-th element from the left among the empty slots is where i must go in the final array.
- Data structure: Use a Fenwick Tree (Binary Indexed Tree) to keep track of empty slots. We initialize all N positions as empty (value 1). For each i from N down to 1:
  - Find the k-th empty slot from the left, where k = Pi.
  - Place i at that index in the final array.
  - Mark that slot as filled by updating the Fenwick Tree with -1 at that index.
- Correctness notes:
  - Uses 1-based indexing for both the Fenwick Tree and the final array to align with standard Fenwick implementations.
  - Pi is 1-based as per problem statement, so we query the Pi-th empty slot directly.
- Complexity: Each iteration performs O(log N) Fenwick operations, leading to O(N log N) time and O(N) space, which fits N up to 5e5.
- Performance considerations: For large N, avoid heavy Python overhead by inlining Fenwick operations and using fast I/O. This reduces risk of TLE on hidden tests.

import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    N = data[0]
    P = data[1:1 + N]

    # Fenwick Tree (1-based indexing)
    fw = [0] * (N + 1)

    def add(i, delta):
        while i <= N:
            fw[i] += delta
            i += i & -i

    def kth(k):
        # Find the smallest index pos such that prefix_sum(pos) >= k
        idx = 0
        bit = 1 << (N.bit_length() - 1)  # highest power of two <= N
        while bit:
            t = idx + bit
            if t <= N and fw[t] < k:
                idx = t
                k -= fw[t]
            bit >>= 1
        return idx + 1

    # Initially, all positions are empty => set value 1 at all indices
    for i in range(1, N + 1):
        fw[i] += 0  # no-op to keep structure explicit
        add(i, 1)

    A = [0] * (N + 1)  # 1-based final array

    for i in range(N, 0, -1):
        k = P[i - 1]  # Pi-th empty slot
        pos = kth(k)
        A[pos] = i
        add(pos, -1)  # mark this slot as filled

    sys.stdout.write(' '.join(str(A[i]) for i in range(1, N + 1)) + '\n')

if __name__ == "__main__":
    main()
