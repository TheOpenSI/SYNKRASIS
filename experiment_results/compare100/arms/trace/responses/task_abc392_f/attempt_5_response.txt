### Step-by-step reasoning
- Re-derive the process: The operation inserts i so that it becomes the Pi-th element from the start of the current array A (which contains 1..i-1). Simulating forward would be O(N^2). A common and efficient approach is to build the final array by processing i from N down to 1.
- Intuition for reverse construction: When placing i in the final array, among the N total positions, exactly i positions will remain empty (since we’ve already placed N, N-1, ..., i+1). The Pi-th empty slot from the left is the position where i must go so that, if we had inserted earlier elements forward, i would end up at position Pi at its step.
- Data structure choice: Use a Fenwick Tree (Binary Indexed Tree) to manage the empty slots. We maintain an array of 1s at all positions indicating “empty”. When we place a number, we set that position to 0 (update with -1). We need to query the k-th empty slot from the left, which is a classic Fenwick operation (order statistics on the prefix sums).
- Initialization optimization: Instead of performing N add operations to initialize the Fenwick tree with 1s, we can initialize the internal Fenwick array in O(N) with fw[i] = i & -i, which corresponds to an all-ones base array.
- Complexity: Each placement uses a constant number of Fenwick operations, each O(log N). Overall O(N log N) time and O(N) space, suitable for N up to 5e5.

None

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    N = data[0]
    P = data[1:1 + N]

    # Fenwick Tree (1-based indexing)
    fw = [0] * (N + 1)

    # Initialize Fenwick for an array where all a[i] = 1 (i.e., all slots empty)
    # For such a tree, the internal representation fw[i] = i & -i
    for i in range(1, N + 1):
        fw[i] = i & -i

    def add(i, delta):
        while i <= N:
            fw[i] += delta
            i += i & -i

    def kth(k):
        # Return the index of the k-th 1 in the current Fenwick (k-th empty slot)
        idx = 0
        bit = 1 << (N.bit_length() - 1)  # highest power of two <= N
        while bit:
            t = idx + bit
            if t <= N and fw[t] < k:
                idx = t
                k -= fw[t]
            bit >>= 1
        return idx + 1

    A = [0] * (N + 1)  # 1-based final array

    for i in range(N, 0, -1):
        k = P[i - 1]  # i-th step uses P_i; in reverse, use P[i-1]
        pos = kth(k)
        A[pos] = i
        add(pos, -1)  # mark slot as filled

    sys.stdout.write(' '.join(str(A[i]) for i in range(1, N + 1)) + '\n')

if __name__ == "__main__":
    main()
```
