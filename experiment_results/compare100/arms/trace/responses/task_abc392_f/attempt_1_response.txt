### Step-by-step reasoning
- Problem interpretation: For each i from 1 to N, insert the number i into A so that it becomes the P_i-th element from the beginning. This is equivalent to performing insertion at position P_i in the current array, which shifts elements to the right.
- Efficient approach: Instead of simulating insertions forward (which would be O(N^2)), process i from N down to 1 and fill a pre-allocated final array A of size N. If we imagine all positions initially empty, the i-th number should occupy the P_i-th empty slot from the left in the final array. This works because as we place larger numbers first, the relative order of smaller numbers does not affect already fixed positions.
- Data structure: Use a Fenwick Tree (Binary Indexed Tree) to maintain which positions are still empty. Start with all positions marked empty (value 1). For each i from N down to 1:
  - Find pos = the P_i-th empty slot from the left (kth one in the Fenwick Tree).
  - Set A[pos] = i.
  - Mark pos as filled by updating the Fenwick Tree at pos with -1.
- Correctness: This exactly simulates placing i at the P_i-th position in the current A, but in reverse by selecting the correct empty slot in the final array. The operation count is O(N log N) due to kth queries and updates.
- Complexity:
  - Time: O(N log N)
  - Space: O(N)
- Output format: Print A_1, A_2, ..., A_N separated by spaces, with a trailing newline.

None

import sys

class Fenwick:
    def __init__(self, n: int):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, idx: int, delta: int):
        i = idx
        while i <= self.n:
            self.bit[i] += delta
            i += i & -i

    def sum(self, idx: int) -> int:
        res = 0
        i = idx
        while i > 0:
            res += self.bit[i]
            i -= i & -i
        return res

    def kth(self, k: int) -> int:
        # Find the smallest index such that the prefix sum >= k
        idx = 0
        bit_mask = 1 << (self.n.bit_length())  # power of two >= n
        while bit_mask:
            t = idx + bit_mask
            if t <= self.n and self.bit[t] < k:
                idx = t
                k -= self.bit[t]
            bit_mask >>= 1
        return idx + 1

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    N = data[0]
    P = data[1:1 + N]

    ft = Fenwick(N)
    for i in range(1, N + 1):
        ft.add(i, 1)  # all positions are initially empty

    A = [0] * (N + 1)  # 1-based index for final array

    for i in range(N, 0, -1):
        k = P[i - 1]
        pos = ft.kth(k)  # the k-th empty slot from the left
        A[pos] = i
        ft.add(pos, -1)  # mark slot as filled

    sys.stdout.write(' '.join(str(A[i]) for i in range(1, N + 1)) + '\n')

if __name__ == "__main__":
    main()
