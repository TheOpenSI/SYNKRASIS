### Step-by-step reasoning
- The graph G is always bipartite in the game (an edge is only allowed if it does not create an odd cycle). So every connected component has a 2-coloring, and edges exist only between the two color classes of a component.
- A move can be:
  - adding an edge between vertices from two different components (no cycle formed), or
  - adding an edge between two vertices inside the same component but from opposite color classes (this creates an even-length cycle, thus still bipartite).
- The game ends when the graph becomes a complete bipartite graph K_{A, N−A} for some partition of the entire vertex set into A and N−A, i.e., every cross-pair across the final partition is already connected.
- For each initial connected component i, let (a_i, b_i) be the sizes of its two color classes (a_i + b_i = size_i). In the final global bipartition, from component i you must pick exactly one of its two color classes to be in A. Thus the final size |A| is the sum of one choice from each component: |A| = sum_i s_i where s_i ∈ {a_i, b_i}.
  - If size_i is even, a_i and b_i have the same parity, so that component contributes a fixed parity to |A| regardless of the choice.
  - If size_i is odd, a_i and b_i have opposite parity, so by choosing the orientation of that component you can flip the parity contribution of that component to |A|.
- Therefore:
  - If N is odd: parity(|A|) doesn't matter for finalEdges parity, because |A|*(N−|A|) is always even (one factor is even). The total number of moves parity equals parity(M). So Aoki (first player) wins iff M is odd.
  - If N is even: parity(|A|*(N−|A|)) equals parity(|A|). If there exists any odd-sized component, we can realize both parities for |A| by orienting that component appropriately, so the first player can force an odd total number of moves, hence Aoki wins.
  - If all components are even-sized, |A| has a fixed parity equal to the XOR of the parities contributed by each component's chosen color class (which is fixed given a chosen orientation per component). Let S_fixed be that fixed parity. Then total moves parity equals S_fixed XOR parity(M). If it equals 1, Aoki wins; otherwise Takahashi wins.
- Algorithm:
  - For each connected component, compute its color class sizes (a_i, b_i) via BFS/DFS in bipartite coloring (start color as 0). Track:
    - size_i parity (odd or even),
    - the parity of a_i (i.e., a_i % 2).
  - Let t_odd be the number of odd-sized components.
  - Let S_fixed be the XOR (parity) of a_i % 2 over all even-sized components.
  - Apply the rules above to decide the winner in O(N + M) time.
- This approach handles large inputs (N, M up to 2e5) in linear time and uses only standard data structures.

### Requirements
None

### Code
```
import sys
from collections import deque

def main():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    N = int(next(it))
    M = int(next(it))

    adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (N + 1)
    t_odd = 0      # number of odd-sized components
    S_fixed = 0    # parity contribution from even-sized components (xor of a_i % 2)

    for start in range(1, N + 1):
        if color[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        color[start] = 0
        cnt0, cnt1 = 1, 0

        while q:
            u = q.popleft()
            cu = color[u]
            for w in adj[u]:
                if color[w] == -1:
                    color[w] = cu ^ 1
                    if color[w] == 0:
                        cnt0 += 1
                    else:
                        cnt1 += 1
                    q.append(w)
                # Graph is guaranteed bipartite (no odd cycle)

        size = cnt0 + cnt1
        if size % 2 == 1:
            t_odd += 1
        else:
            S_fixed ^= (cnt0 & 1)

    if N % 2 == 1:
        # N is odd: finalEdges parity is always even, so moves parity equals M parity
        print("Aoki" if (M & 1) == 1 else "Takahashi")
        return

    # N is even
    if t_odd > 0:
        # There exists an odd-sized component, we can realize both parities for |A|
        print("Aoki")
        return

    # All components are even-sized: A parity is fixed to S_fixed
    total_parity = S_fixed ^ (M & 1)
    print("Aoki" if total_parity == 1 else "Takahashi")

if __name__ == "__main__":
    main()
```
