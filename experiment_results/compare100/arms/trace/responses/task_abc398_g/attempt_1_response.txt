### Step-by-step reasoning
- The game ends when no more moves are possible. A move adds an edge (i, j) that does not create an odd cycle. This is equivalent to preserving bipartiteness of the graph.
- In the end, the graph must be a complete bipartite graph K_{A, N-A} for some A (the final two-color partition of the vertices). The number of moves made during the whole game then equals:
  total_moves = A * (N - A) - M
  because K_{A, N-A} has A*(N-A) cross-edges and M edges already exist.
- The initial graph G is bipartite and consists of connected components. Each component i has a pair of color-class sizes (a_i, b_i) with a_i + b_i = s_i (the component size).
- The final A is determined by choosing, for each component, which color class contributes to the global A-side. Thus A ∈ { sum_i c_i | c_i ∈ {a_i, b_i} }.
- Parity observations (which matter for the parity of total_moves):
  - If N is odd: A*(N-A) is always even for any A, so total_moves parity equals M parity. Therefore Aoki wins iff M is odd.
  - If N is even: parity of A*(N-A) equals A mod 2. Hence total_moves parity equals M parity XOR (A parity).
    - If there exists at least one odd-sized component (i.e., some s_i is odd), then its two color-class sizes have opposite parity, so you can toggle the parity of A by choosing that component’s orientation. This means both parities of A are achievable, which in practice gives Aoki a winning position when playing optimally.
    - If all components are even-sized, then for every component a_i and b_i have the same parity, so the parity of A is fixed to S_fixed = sum over components of (size of one color class) mod 2 (we can take, for example, cnt[0] % 2 from each component). Then final moves parity is S_fixed XOR (M mod 2). Aoki wins iff this parity is 1.

- Time complexity: O(N + M) to explore the graph and count color classes in each component.

- Output format: print Aoki if the first player wins, otherwise print Takahashi.

None

### Code
```
import sys
from collections import deque

def main():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    N = int(next(it))
    M = int(next(it))

    adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (N + 1)
    t_odd = 0      # number of components with odd size
    S_fixed = 0    # parity contribution from even-sized components

    for start in range(1, N + 1):
        if color[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        color[start] = 0
        cnt = [0, 0]
        cnt[0] += 1

        while q:
            u = q.popleft()
            cu = color[u]
            for w in adj[u]:
                if color[w] == -1:
                    color[w] = cu ^ 1
                    cnt[color[w]] += 1
                    q.append(w)
                # Problem guarantees bipartite, so no need to handle conflicts

        size = cnt[0] + cnt[1]
        if size % 2 == 1:
            t_odd += 1
        else:
            # For even-sized components, both color-class sizes have same parity,
            # so we can take cnt[0] (parity of one color class) as the contribution to A.
            S_fixed ^= (cnt[0] & 1)

    if N % 2 == 1:
        # N is odd: total moves parity == M parity, independent of A
        print("Aoki" if M % 2 == 1 else "Takahashi")
        return

    # N is even
    if t_odd > 0:
        # There exists an odd-sized component, parity of A can be toggled;
        # first player (Aoki) has a winning strategy.
        print("Aoki")
        return

    # All components are even-sized: A parity is fixed to S_fixed
    total_parity = S_fixed ^ (M & 1)
    print("Aoki" if total_parity == 1 else "Takahashi")

if __name__ == "__main__":
    main()
```
