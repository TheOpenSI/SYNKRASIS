### Step-by-step reasoning
- The operation adds an edge without creating an odd cycle. This preserves bipartiteness of the graph.
- If the final graph cannot have any more moves, it must be a complete bipartite graph K_{A, N-A} for some A (the final global bipartition sizes). All other non-edge pairs would either be within the same color class (forbidden) or connect different components (which would be allowed unless they violate the global bipartition, but the end state with no moves is exactly complete bipartite across the final partition).
- Each connected component i of the initial graph has a bipartition with sizes (a_i, b_i) where a_i + b_i is the size of that component. When you merge components by adding cross-component edges, you effectively pick for each component which color class will align with a fixed global side. Thus the final A is achievable as A = sum_i c_i where c_i ∈ {a_i, b_i}.
- Parity observations (which determine the winner in this impartial normal-play game):
  - If N is odd: A*(N-A) is always even for any A. Therefore the total number of moves (M_final - M_initial) has parity equal to M mod 2. So Aoki (first player) wins iff M is odd.
  - If N is even: parity of A*(N-A) equals A mod 2. Thus total moves parity equals M parity XOR A parity.
    - If there exists at least one odd-sized component, then its two color-class sizes have opposite parity, so by choosing that component’s orientation you can toggle the parity of A. Hence both parities of A are achievable, and the first player has a winning strategy.
    - If all components are even-sized, then a_i and b_i have the same parity for every component, so the parity of A is fixed to a global value S_fixed = sum_i (parity of one color class in component i) mod 2 (we can take parity of a_i for each component). Then total moves parity is S_fixed XOR (M mod 2). The winner is determined by this fixed parity.

- Algorithm outline:
  1. Build the graph, compute for every connected component its bipartition sizes (a_i, b_i) by BFS/DFS.
  2. Let t_odd be the number of components with odd size.
  3. If N is odd:
     - Aoki wins iff M is odd; otherwise Takahashi wins.
  4. If N is even:
     - If t_odd > 0, Aoki wins.
     - Otherwise (all components even), compute S_fixed as XOR of (a_i mod 2) over all components. The winner is Aoki iff (S_fixed XOR (M mod 2)) == 1, else Takahashi.

- Complexity: O(N + M) time, O(N + M) memory.

- Output: print Aoki if the first player wins, otherwise Takahashi.

- External libraries: None

### Code
```
import sys
from collections import deque

def main():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    N = int(next(it))
    M = int(next(it))

    adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (N + 1)
    t_odd = 0      # number of components with odd size
    S_fixed = 0    # parity contribution from even-sized components (xor of a_i % 2)

    for start in range(1, N + 1):
        if color[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        color[start] = 0
        cnt = [0, 0]
        cnt[0] += 1

        while q:
            u = q.popleft()
            cu = color[u]
            for w in adj[u]:
                if color[w] == -1:
                    color[w] = cu ^ 1
                    cnt[color[w]] += 1
                    q.append(w)
                # Graph is guaranteed bipartite by problem statement

        size = cnt[0] + cnt[1]
        if size % 2 == 1:
            t_odd += 1
        else:
            # For even-sized components, both color-class sizes have same parity.
            # We can take parity of cnt[0] as the contribution to A.
            S_fixed ^= (cnt[0] & 1)

    if N % 2 == 1:
        # N is odd: total moves parity equals M parity
        print("Aoki" if (M & 1) == 1 else "Takahashi")
        return

    # N is even
    if t_odd > 0:
        # Existence of an odd-sized component allows toggling A parity -> Aoki wins
        print("Aoki")
        return

    # All components are even-sized: A parity is fixed to S_fixed
    total_parity = S_fixed ^ (M & 1)
    print("Aoki" if total_parity == 1 else "Takahashi")

if __name__ == "__main__":
    main()
```
