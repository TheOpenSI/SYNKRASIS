### Step-by-step reasoning
- The game keeps the graph bipartite: any edge added between vertices of the same color within a connected component would create an odd cycle, which is forbidden. Edges between vertices from different components are always allowed (they do not create a cycle).
- In the end, when no move is possible, the graph must be a complete bipartite graph K_{A, N-A} for some A, where A is the size of one color class in the final global bipartition.
- The final A is not completely free to choose independently per initial connected component because as components are merged by added edges, their relative orientation becomes coupled by the existing edges. However, one can derive the winning condition using parity arguments:
  - If N is odd: the final number of edges in a complete bipartite graph K_{A, N-A} is A*(N-A), which is always even for N odd. Thus the parity of the total number of moves equals M (the initial number of edges) modulo 2. The first player (Aoki) wins iff M is odd.
  - If N is even: A*(N-A) has the same parity as A. The parity of the number of moves equals parity(A) XOR parity(M).
    - If there exists any connected component with odd size, its two color classes have opposite parity, which allows the final A to have either parity, so the first player can force a win.
    - If all components have even size, the parity of A is fixed (call it S). Then Aoki wins iff parity(M) XOR S is 1.
- This yields a simple O(N+M) algorithm:
  - Compute, for each connected component, its size and the parity of one color class in an arbitrary bipartition (via BFS/DFS). For even-sized components, accumulate the parity of the chosen color class; count how many components have odd size.
  - Apply the rules above to decide the winner.

- Time complexity: O(N + M) memory and time.
- Correctness hinges on the parity-based final-state analysis and the ability to realize necessary orientations, which is captured by the outlined cases.

import sys
from collections import deque

def main():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    N = int(next(it))
    M = int(next(it))

    adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (N + 1)
    t_odd = 0      # number of components with odd size
    S_fixed = 0    # parity contribution from even-sized components (xor of a_i % 2)

    for start in range(1, N + 1):
        if color[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        color[start] = 0
        cnt0, cnt1 = 1, 0

        while q:
            u = q.popleft()
            cu = color[u]
            for w in adj[u]:
                if color[w] == -1:
                    color[w] = cu ^ 1
                    if color[w] == 0:
                        cnt0 += 1
                    else:
                        cnt1 += 1
                    q.append(w)
                # Graph is guaranteed bipartite (no odd cycle)

        size = cnt0 + cnt1
        if size % 2 == 1:
            t_odd += 1
        else:
            S_fixed ^= (cnt0 & 1)

    if N % 2 == 1:
        # N is odd: total moves parity equals M parity
        print("Aoki" if (M & 1) == 1 else "Takahashi")
        return

    # N is even
    if t_odd > 0:
        # Existence of an odd-sized component allows toggling A parity -> Aoki wins
        print("Aoki")
        return

    # All components are even-sized: A parity is fixed to S_fixed
    total_parity = S_fixed ^ (M & 1)
    print("Aoki" if total_parity == 1 else "Takahashi")

if __name__ == "__main__":
    main()
