### Step-by-step reasoning
- The problem asks to compute, modulo a prime p, for an N×N matrix A with entries in {0,...,p-1}, the sum over all fillings B of A (replacing each zero by a nonzero value in {1,...,p-1}) of B^p, taken modulo p.
- Let K be the number of zeros in A. There are (p-1)^K fillings B.
- Writing B^p as a sum over all p-step matrix-product paths shows that each (i,j) entry of B^p is a sum over all length-p directed walks i → … → j of products of the corresponding B-entries along the walk.
- When you sum over all fillings B, the contribution of each walk factorizes across the positions that are zero in A. For a fixed walk, if an edge (u,v) is a zero-position in A and is used t times in the walk, the contribution contains the factor S_t = sum_{x=1}^{p-1} x^t modulo p for that edge; otherwise, for a fixed edge (u,v) with A_{u,v} ≠ 0, the contribution contains A_{u,v}^t.
- A key number-theory fact for a prime p is:
  S_t ≡ 0 (mod p) if (p−1) ∤ t, and S_t ≡ p−1 ≡ −1 (mod p) if (p−1) | t.
  In particular, S_t is either 0 or −1 modulo p.
- This dramatically prunes the contributing walks: only walks in which every zero-edge e is used t_e times with t_e ∈ {0, p−1} can contribute nontrivially (for p ≥ 3). For p = 2, the behavior is different (S_t can be 0 or 1 depending on t), and must be treated separately.
- From this, a correct, fully general solution is built on two components:
  1) The fixed-edges contribution: treat the graph consisting only of fixed edges (A_{i,j} ≠ 0) as a weighted adjacency matrix F, and accumulate contributions from all p-step walks that use only fixed edges, i.e. (F^p)_{i,j}.
  2) The zero-edges contribution: for each zero-edge e, consider walks that use e exactly p−1 times and use only fixed edges elsewhere. Since S_{p−1} ≡ −1 (mod p), each such walk contributes − the product of the weights of the fixed-edges along that walk. The total contribution from all such walks for a given zero-edge is then accumulated into the (i,j) entries accordingly.
- Handling these sums efficiently requires careful combinatorics over the possible patterns of using a single zero-edge p−1 times interleaved with fixed edges. The full derivation is nontrivial, but the core idea is: (i) compute F^p for the fixed-edge contributions; (ii) for every zero-edge, count the weighted number of p-step walks that use that zero-edge p−1 times and use only fixed edges elsewhere, with weight −1 for each such walk, and add that into the corresponding (i,j) entry; (iii) if p = 2, use the corresponding S_t values for t ∈ {1} (since p−1 = 1) and handle the cases accordingly.
- The previous attempt only implemented the trivial K = 0 case (no zeros) and returned a result for that, while for K > 0 it prematurely returned zeros, which caused the failure on test case 1.
- The corrected approach must therefore:
  - compute F^p for the fixed-edge graph,
  - and augment the matrix with zero-edge contributions described above, which are nonzero only for p odd (p ≥ 3) when considering t = p−1, and require counting p-step walks that use that particular zero-edge p−1 times with the rest of the steps from fixed edges.

Important: The detailed implementation of the zero-edge contribution requires a precise combinatorial count of all length-p walks that use a given zero-edge exactly p−1 times and use only fixed edges elsewhere. This is the core mathematical part of the official solution. Without that derivation, a correct and efficient implementation cannot be guaranteed.

def mat_mul(A, B, mod):
    n = len(A)
    m = len(B[0])
    p = len(B)
    res = [[0]*m for _ in range(n)]
    for i in range(n):
        Ai = A[i]
        Ri = res[i]
        for k in range(p):
            aik = Ai[k]
            if aik == 0:
                continue
            Bk = B[k]
            for j in range(m):
                Ri[j] = (Ri[j] + aik * Bk[j]) % mod
    return res

def mat_pow(A, e, mod):
    n = len(A)
    R = [[0]*n for _ in range(n)]

    while e > 0:
        if e & 1:
            R = mat_mul(R, X, mod)
        X = mat_mul(X, X, mod)

    return R
