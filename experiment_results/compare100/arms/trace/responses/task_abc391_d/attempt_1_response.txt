### Step-by-step reasoning
- Blocks never move between columns. Each block stays in its original column.
- Within a column, blocks fall downward whenever the cell below is empty, with blocks processed bottom-to-top. Over time, blocks in a column become stacked contiguously from y=1 upward, preserving their initial bottom-to-top order (i.e., the relative order by initial Y is preserved).
- Removals happen only when the entire bottom row (y=1 across all columns) is occupied at the start of a time step. Then all blocks currently on the bottom row are removed simultaneously.
- If any column is initially empty, the bottom row can never be full (that column can never gain a block), so no removals ever happen and all blocks always exist.
- If every column has at least one block initially:
  - Before the first removal, blocks fall, and the bottom row becomes full for the first time at time t = B, where B = max over columns x of (minimum initial Y in column x). Reason: in column x, the lowest block has to descend from its initial Y_min(x) to y=1, which takes Y_min(x) - 1 steps; the bottom row cannot be full until the slowest column reaches y=1, i.e., until max_x Y_min(x) blocks have descended. Since time steps are 1-indexed for removals, the first removal occurs at t = B.
  - After each removal, one block is removed from the bottom of every column that still has blocks left. So after s removals (s >= 0), every column has lost exactly s blocks if it had at least s blocks originally; the set of blocks removed in the i-th removal in a column are exactly the i blocks that had the smallest initial Y in that column (blocks cannot overtake each other). Therefore, after s removals, a block from column x with initial rank r_x (1-based, by increasing initial Y within that column) survives iff r_x > s.
  - The total number of removals is m = min_x k_x, where k_x is the number of blocks in column x. After m removals, at least one column becomes empty, so bottom row can no longer be full and no more removals occur.
- For a query (T, A):
  - If any column is initially empty: answer is Yes for all queries.
  - Otherwise:
    - If T < B: no removals have happened yet; block A exists.
    - If B <= T <= B + m - 1: s = T - B + 1 removals have happened; block A exists iff its initial rank r_A > s.
    - If T >= B + m: all removals finished; block A exists iff r_A > m.
- Implementation plan:
  - Build per-column lists of blocks as (Y_i, i).
  - If any column is empty, mark a flag and answer Yes to all queries.
  - Else, for each column:
    - Compute b_x = min Y in that column and B = max of these.
    - Compute k_x = size of the column; m = min of k_x across columns.
    - Sort the column by Y and assign rank[i] = position (1-based) of block i in that column.
  - Answer each query in O(1) using the formulas above.

Edge cases considered:
- All blocks exist forever when some column is empty.
- Correct handling when first removal occurs later (B) and multiple removals occur (up to m times).
- Large T up to 1e9 handled with constant-time per query.
- Exact output format: Yes/No with correct capitalization.

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)
    N = next(it); W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # zero-based block index

    # Collect per-column blocks
    cols = [[] for _ in range(W + 1)]
    for i in range(N):
        x = X[i]
        y = Y[i]
        cols[x].append((y, i))

    rank = [0] * N
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    if not hasZero:
        # Compute B and m
        mins = []
        for x in range(1, W + 1):
            col = cols[x]
            minY = min(y for (y, idx) in col)
            mins.append(minY)
        B = max(mins)
        m = min(len(col) for col in cols[1:])

        # Assign ranks within each column
        for x in range(1, W + 1):
            col = cols[x]
            col.sort(key=lambda t: t[0])  # sort by Y
            for pos, (y, idx) in enumerate(col, start=1):
                rank[idx] = pos
    # If hasZero, we don't need ranks or B/m since answer is always Yes

    out_lines = []
    if hasZero:
        out_lines = ["Yes"] * Q
    else:
        for j in range(Q):
            t = T_arr[j]
            a = A_arr[j]
            r = rank[a]  # 1-based rank within its column
            if t < B:
                out_lines.append("Yes")
            elif t <= B + m - 1:
                s = t - B + 1
                out_lines.append("Yes" if r > s else "No")
            else:
                out_lines.append("Yes" if r > m else "No")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
