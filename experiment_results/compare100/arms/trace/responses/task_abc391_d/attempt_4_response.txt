### Step-by-step reasoning
- The process runs in discrete steps t = 1, 2, 3, ...
- At the start of step t, if every column has a block at the bottom row (y = 1), all blocks on the bottom row are removed. Then, for all remaining blocks, processed from bottom to top, each block moves down by 1 if there is no block directly below it.
- Because blocks never move horizontally, each column evolves independently except for the global removal event when the bottom row becomes full across all columns.
- For a column x, let k_x be the number of blocks in that column, and let Y_min(x) be the smallest initial Y among blocks in that column. The bottom row can become full in this column for the first time after Y_min(x) − 1 downward moves of its bottommost block. Since blocks in different columns don’t affect each other’s ability to fill the bottom row, the bottom row becomes full across all columns at the earliest step t = B, where
  - B = max over all columns x of Y_min(x)
  - If any column has zero blocks initially, the bottom row can never be full, so no removals ever occur.
- If every column has at least one block, how many removals happen in total? After each removal, blocks above cascade down by 1 within that step, so the number of blocks in each column decreases by 1 (for those columns that still have blocks). The process can continue as long as every column still has at least 1 block. Therefore the total number of removals is
  - m = min_x k_x
  - After m removals, at least one column becomes empty, so the bottom row can no longer be full and no further removals occur.
- The blocks removed at removals occur in the order of their initial Y (within each column, blocks are removed from bottom to top). If a block has rank r within its column when blocks are sorted by increasing initial Y, it will be removed on one of the first m removals if r ≤ m.
- Consequently:
  - If any column is empty initially: no removals; a block A_i exists for all times.
  - Otherwise (no empty columns):
    - Let B = max_x Y_min(x) and m = min_x k_x.
    - For a query (T, A):
      - If T < B: no removals have happened yet; A exists.
      - If B ≤ T ≤ B + m − 1: s = T − B + 1 removals have happened; block A exists iff its rank r_A in its column satisfies r_A > s.
      - If T ≥ B + m: all removals have occurred; block A exists iff r_A > m.
- We can preprocess per-column data:
  - For every column x, collect blocks as (Y, index). If any column is empty, we can answer Yes for all queries.
  - Compute B as the maximum of the column-wise minimum Y.
  - Compute m as the minimum of the column heights k_x.
  - For each block, compute its rank within its column when blocks are sorted by Y (1-based).
- Then each query is O(1) to answer.

This approach runs in O(N log N) time for preprocessing (sorting blocks within each column) and O(Q) for answering queries, suitable for N, Q ≤ 2e5.

### Requirements
None

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    N = next(it)
    W = next(it)

    # For each block i, store its column X[i] and height Y[i]
    cols = [[] for _ in range(W + 1)]  # 1-based indexing for columns

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        x = next(it)
        y = next(it)
        X[i] = x
        Y[i] = y
        cols[x].append((y, i))  # (Y, block_index)

    Q = next(it)

    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # convert to 0-based index

    # Check if any column is empty
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    if hasZero:
        # No removals ever occur; every query is "Yes"
        print("\n".join(["Yes"] * Q))
        return

    # No empty columns: compute B and m
    B = 0
    for x in range(1, W + 1):
        col = cols[x]
        minY = min(y for (y, idx) in col)
        if minY > B:
            B = minY

    m = min(len(cols[x]) for x in range(1, W + 1))

    # Compute rank (1-based) of each block within its column
    rank = [0] * N
    for x in range(1, W + 1):
        col = cols[x]
        col.sort(key=lambda t: t[0])  # sort by Y
        for pos, (_, idx) in enumerate(col, start=1):
            rank[idx] = pos

    out_lines = []
    for j in range(Q):
        t = T_arr[j]
        a = A_arr[j]
        r = rank[a]  # 1-based rank within its column

        if t < B:
            out_lines.append("Yes")
        elif t <= B + m - 1:
            s = t - B + 1
            out_lines.append("Yes" if r > s else "No")
        else:
            out_lines.append("Yes" if r > m else "No")

    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
```
