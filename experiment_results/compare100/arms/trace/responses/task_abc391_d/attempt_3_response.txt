### Step-by-step reasoning
- Blocks only move downward and never horizontally; each column evolves independently except for the global removal event when the bottom row is fully occupied.
- A column x has some blocks initially. Let Y_min(x) be the smallest Y among blocks in that column, and k_x be the number of blocks in that column.
- The bottom row can become full only if every column has at least one block present in the bottom row at the start of some step. Since blocks only move downward, the block with the smallest initial Y in a column will reach y=1 after Y_min(x) − 1 downward moves, i.e., after Y_min(x) − 1 steps. Therefore the first time the bottom row can be full is when all columns have their bottommost block at y=1 simultaneously, which happens at time B = max_x Y_min(x).
- If any column is initially empty, the bottom row can never be full (you can’t fill a column without any blocks), so no removals ever happen.
- After the first removal starts at time B, blocks are removed from the bottom row across all columns (one layer). Immediately after that removal, blocks above in each column move down to fill bottom row within the same step, so in the next step the bottom row is full again, triggering another removal, and so on.
- The process continues for m removals, where m = min_x k_x (the smallest column height). After m removals, at least one column becomes empty, so the bottom row can no longer be full, and no further removals occur.
- Therefore, for a query (T, A):
  - If some column is empty initially, no removals ever occur; block A always exists.
  - Otherwise:
    - If T < B, no removals yet; block A exists.
    - If B ≤ T ≤ B + m − 1, s = T − B + 1 removals have happened; block A exists iff its initial rank r_A within its column satisfies r_A > s.
    - If T ≥ B + m, all removals have happened; block A exists iff r_A > m.
- We can compute:
  - B = max over columns of their minimum Y (Y_min(x)).
  - m = min over columns of their sizes (k_x).
  - For each block, its rank r_A within its column (1-based, by increasing initial Y in that column).
- This yields O(N log N) preprocessing (sorting blocks within each column) and O(1) per query.

Edge cases:
- If any column has no blocks, answer is always "Yes" for all queries.
- Y values within a column are distinct (no two blocks share the same (X, Y) cell).

None

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    N = next(it)
    W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)

    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # convert to 0-based index

    # Build per-column lists of (Y, block_index)
    cols = [[] for _ in range(W + 1)]
    for i in range(N):
        x = X[i]
        y = Y[i]
        cols[x].append((y, i))

    # Check if any column is empty
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    if hasZero:
        # No removals ever occur; every query answers Yes
        print("\n".join(["Yes"] * Q))
        return

    # No empty columns: compute B and m
    B = 0
    for x in range(1, W + 1):
        col = cols[x]
        minY = min(y for (y, idx) in col)
        if minY > B:
            B = minY

    m = min(len(cols[x]) for x in range(1, W + 1))

    # Compute rank (1-based) of each block within its column
    rank = [0] * N
    for x in range(1, W + 1):
        col = cols[x]
        col.sort(key=lambda t: t[0])  # sort by Y
        for pos, (_, idx) in enumerate(col, start=1):
            rank[idx] = pos

    out_lines = []
    for j in range(Q):
        t = T_arr[j]
        a = A_arr[j]
        r = rank[a]  # 1-based rank within its column

        if t < B:
            out_lines.append("Yes")
        elif t <= B + m - 1:
            s = t - B + 1
            out_lines.append("Yes" if r > s else "No")
        else:
            out_lines.append("Yes" if r > m else "No")

    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
```
