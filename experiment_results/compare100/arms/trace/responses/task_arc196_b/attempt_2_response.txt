### Step-by-step reasoning
- Understand the problem: We have an HxW torus grid with each cell containing either Type A (connects two adjacent edges) or Type B (connects two opposite edges). Each tile can be rotated, producing different local patterns. Among all 4^a · 2^b patterns (a=#A tiles, b=#B tiles), we must count those patterns that yield no dead ends when the grid is viewed on a torus. The no-dead-end condition translates into a global consistency constraint: the endpoints on shared edges between neighboring tiles must match (right edge of (i,j) matches left edge of (i, j+1), and bottom edge of (i,j) matches top edge of (i+1, j)).
- A crucial observation: regardless of the exact local rotations, every cell contributes exactly two edge endpoints. If you sum the edge-usage patterns around a row (or a column) and account for the torus wrap, you get parity constraints that depend only on how many A tiles are in each row and in each column.
- After carefully analyzing the parity constraints across the torus, the necessary and sufficient condition for there to be any valid global configuration is:
  - Every row must contain an even number of A tiles.
  - Every column must contain an even number of A tiles.
  If any row has an odd number of A’s, or any column has an odd number of A’s, then no global configuration satisfies the no-dead-end condition, so the answer is 0.
- When all rows and all columns have an even number of A tiles, there are exactly two global configurations that satisfy the condition (the degrees of freedom collapse to two global choices). Thus the number of valid placements is 2 (mod 998244353). The counts of A vs B tiles affect the total number of patterns, but given the parity constraints, exactly two global patterns satisfy the no-dead-end requirement.
- Therefore, the solution reduces to checking parity of A’s per row and per column and returning 0 or 2 accordingly. This matches all given samples and aligns with the required torus-consistency logic.

Time complexity: We scan each character once per test case, O(HW) per case, with total HW over all tests ≤ 10^6. Memory: O(W) for column parity.

Edge cases: Large T with many small cases, or a single large case; our linear scan and simple parity checks handle all sizes within the constraints.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    idx = 1
    MOD = 998244353  # not really needed since answer is 0 or 2, but kept for completeness
    out_lines = []
    for _ in range(t):
        H = int(data[idx]); W = int(data[idx+1]); idx += 2

        col_parity = [0] * W  # parity of number of A's in each column
        all_rows_even = True  # flag: all processed rows so far have even A's

        for i in range(H):
            s = data[idx].decode(); idx += 1
            row_par = 0
            # update row parity and column parities
            for j, ch in enumerate(s):
                if ch == 'A':
                    row_par ^= 1
                    col_parity[j] ^= 1
            if row_par == 1:
                all_rows_even = False

        if not all_rows_even:
            out_lines.append("0")
            continue
        if any(p != 0 for p in col_parity):
            out_lines.append("0")
            continue
        out_lines.append("2")

    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
