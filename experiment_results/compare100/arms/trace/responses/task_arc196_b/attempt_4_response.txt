### Step-by-step reasoning
- The problem reduces to counting assignments of internal tile orientation bits that satisfy the "no dead ends" condition on every edge of the torus.
- Each tile type has a certain number of binary variables:
  - Type A (elbow): uses two bits
    - h bit: which horizontal edge is used (Left or Right)
    - v bit: which vertical edge is used (Top or Bottom)
  - Type B (straight): uses one bit
    - s bit: whether horizontal (Left-Right) or vertical (Top-Bottom)
- For each shared edge between adjacent tiles, the presence of an endpoint on that edge must match on both sides. This yields a constraint that is an XOR (parity) relation between two variables.
- We must derive the correct parity constant c for each adjacency:
  - Horizontal adjacency (left tile at p, right tile at q):
    - The constraint reduces to u XOR v = c, where:
      - u is the left tile’s edge variable (id1[p]); for B, id1 stores s, for A, id1 stores h.
      - v is the right tile’s corresponding edge variable (id1[q]); for B, id1 stores s, for A, id1 stores h.
      - c = 1 if the right tile is A; else c = 0.
    - The previous incorrect implementation used c = (left type == right type), which fails for cases like BA.
  - Vertical adjacency (top tile at p, bottom tile at p2):
    - The constraint reduces to a_top XOR b_bottom = c, with:
      - a_top depends on the top tile: if top is A, use v_top; if top is B, use s_top.
      - b_bottom depends on the bottom tile: if bottom is A, use v_bottom; if bottom is B, use s_bottom.
      - c = 1 if the top tile is A; else c = 0.
- Implement this as a union-find (DSU) with parity to count the number of solutions: 2^(number of connected components) if the system is consistent; otherwise 0.
- Key fix: horizontal edge parity c must depend on the right tile being A, not on equality of left/right tile types; vertical edge parity c must depend on the top tile being A.

Time complexity remains O(H*W) per test case with near-linear DSU operations, which fits the constraints.

import sys

MOD = 998244353

def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    pos = 1
    out_lines = []

    sys.setrecursionlimit(1 << 25)

    for _ in range(t):
        H = int(data[pos]); W = int(data[pos+1]); pos += 2
        lines = []
        for _ in range(H):
            lines.append(data[pos].decode())
            pos += 1
        grid_str = ''.join(lines)  # length H*W
        Ncells = H * W

        # Build IDs:
        # id1[p] : first variable of cell p
        # id2[p] : second variable of cell p (only valid if cell is 'A', else -1)
        id1 = [0] * Ncells
        id2 = [-1] * Ncells
        idx = 0
        for p in range(Ncells):
            if grid_str[p] == 'A':
                id1[p] = idx
                id2[p] = idx + 1
                idx += 2
            else:  # 'B'
                id1[p] = idx
                idx += 1
        N = idx  # total number of variables

        # DSU with parity
        parent = [-1] * N       # negative size for roots
        par = [0] * N           # parity to parent
        cc = N                    # number of connected components

        def find(x):
            if parent[x] < 0:
                return x, 0
            r, px = find(parent[x])
            par[x] ^= px
            parent[x] = r
            return r, par[x]

        def union(x, y, c):
            nonlocal cc
            rx, dx = find(x)
            ry, dy = find(y)
            if rx == ry:
                if (dx ^ dy) != c:
                    return False
                return True
            # Union by size
            if -parent[rx] < -parent[ry]:
                rx, ry = ry, rx
                dx, dy = dy, dx
            parent[rx] += parent[ry]
            parent[ry] = rx
            par[ry] = dx ^ dy ^ c
            cc -= 1
            return True

        inconsistent = False

        # Horizontal edges: left p, right q
        for i in range(H):
            base = i * W
            for j in range(W):
                p = base + j
                q = base + ((j + 1) % W)
                t1 = grid_str[p]
                t2 = grid_str[q]
                u = id1[p]
                v = id1[q]
                # c = 1 if the right tile is 'A', else 0
                c = 1 if t2 == 'A' else 0
                if not union(u, v, c):
                    inconsistent = True
                    break
            if inconsistent:
                break

        # Vertical edges: top p, bottom p2
        if not inconsistent:
            for i in range(H):
                base = i * W
                base2 = ((i + 1) % H) * W
                for j in range(W):
                    p = base + j
                    p2 = base2 + j
                    t1 = grid_str[p]
                    t2 = grid_str[p2]
                    # top variable
                    u = id2[p] if t1 == 'A' else id1[p]
                    # bottom variable
                    v = id2[p2] if t2 == 'A' else id1[p2]
                    # c = 1 if top tile is 'A', else 0
                    c = 1 if t1 == 'A' else 0
                    if not union(u, v, c):
                        inconsistent = True
                        break
                if inconsistent:
                    break

        if inconsistent:
            out_lines.append("0")
        else:
            out_lines.append(str(pow(2, cc, MOD)))

    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
