### Step-by-step reasoning
- Model: Each constraint A_{X_i} XOR A_{Y_i} = Z_i defines an XOR relation between two nodes. This yields a graph with N nodes and M undirected edges labeled by Z_i.
- Structure of solutions: In a connected component, fix the value at a root node to be R. Then every other node v in the component has A_v = dist[v] XOR R, where dist[v] is the XOR-sum of edge labels along any path from the root to v. The dist values are determined by the constraint Z along edges.
- Consistency check: For every edge (u, v, z), it must hold that dist[u] XOR dist[v] = z. If this fails for any edge, no solution exists.
- Minimizing the total sum: The overall sum across the component is sum_v (dist[v] XOR R). For each bit k, let c_k be the number of vertices in the component with dist[v] having bit k equal to 1. If we set R's bit k to 0, the contribution of bit k to the total sum is c_k * 2^k; if we set R's bit k to 1, it becomes (comp_size - c_k) * 2^k. To minimize the total sum, choose R_k = 0 when c_k <= comp_size - c_k, otherwise R_k = 1. Bits are independent, so we determine R bit-by-bit.
- Do this independently per connected component. Isolated vertices (no edges) are their own components; the minimal choice is A_i = 0.
- Complexity: BFS/DFS over the graph is O(N + M). Bit counting per component costs O(B * comp_size) where B is at most 30 (since Z_i <= 1e9). This fits the constraints (N up to 2e5, M up to 1e5).
- Implementation notes: Use iterative DFS to avoid recursion limits. Check self-loops and parallel edges naturally via consistency checks. We only need to consider bits up to max bit of any Z_i; higher bits would contribute nothing to dist values and would only increase the sum if used.

import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        print(-1)
        return

    it = iter(data)
    try:
        N = next(it)
        M = next(it)
    except StopIteration:
        print(-1)
        return

    adj = [[] for _ in range(N)]
    maxZ = 0
    for _ in range(M):
        x = next(it) - 1
        y = next(it) - 1
        z = next(it)
        adj[x].append((y, z))
        adj[y].append((x, z))
        if z > maxZ:
            maxZ = z

    dist = [0] * N
    vis = [False] * N
    A = [0] * N

    maxbit = maxZ.bit_length()

    for i in range(N):
        if vis[i]:
            continue

        # Iterative DFS to collect a component and compute dist[]
        stack = [i]
        vis[i] = True
        dist[i] = 0
        comp_nodes = []
        while stack:
            u = stack.pop()
            comp_nodes.append(u)
            for v, z in adj[u]:
                if not vis[v]:
                    dist[v] = dist[u] ^ z
                    vis[v] = True
                    stack.append(v)
                else:
                    if (dist[u] ^ dist[v]) != z:
                        print(-1)
                        return

        comp_size = len(comp_nodes)
        root = 0

        # Determine per-bit root to minimize the sum for this component
        if maxbit > 0:
            counts = [0] * maxbit  # counts[k] = number of vertices with dist[v]_k = 1
            for v in comp_nodes:
                dv = dist[v]
                for k in range(maxbit):
                    counts[k] += (dv >> k) & 1
            for k in range(maxbit):
                if counts[k] > comp_size - counts[k]:
                    root |= (1 << k)

        # Assign final A for nodes in this component
        for v in comp_nodes:
            A[v] = dist[v] ^ root

    print(' '.join(map(str, A)))

if __name__ == "__main__":
    main()
