### Step-by-step reasoning
- Let A = (A1, A2, ..., AN) be the unknown non-negative integers. For each constraint (X_i, Y_i, Z_i) we require A_{X_i} xor A_{Y_i} = Z_i.
- A convenient view is to decompose the problem by connected components of the graph G with vertices 1..N and edges (X_i, Y_i) labeled by Z_i. If a vertex is isolated, there is no constraint on its value.
- For a fixed component, pick a root vertex r and write A_v = R xor dist[v], where dist[v] is the XOR of Z-values along any path from r to v, and R is the unknown value A_r. If the constraints are consistent, dist[v] is uniquely determined (independent of path) and dist[r] = 0.
- Consistency check: For every edge (u, v, z), we must have dist[u] xor dist[v] = z. If at some edge this fails, no good sequence exists.
- If a component is consistent, then A_v = R xor dist[v]. As R varies, the sum of A_v over the component changes. For each bit position k, the k-th bit of A_v equals (R_k xor dist[v]_k). To minimize the total number of 1s (and thus the sum) across the component, for each bit k we should choose R_k so that the number of vertices with a 1 in that bit is minimized:
  - Let count1 be the number of vertices in the component with dist[v] having bit k equal to 1.
  - If count1 <= (component_size - count1), set R_k = 0; otherwise set R_k = 1.
  - This minimizes the number of 1s in that bit across A_v in the component.
- After determining R for the component, set A_v = dist[v] xor R for all vertices in that component.
- Complexity: We perform a single BFS/DFS per component to compute dist and check consistency (O(N + M)). While exploring, we accumulate per-bit counts of dist[v] to decide R. Overall this is O((N + M) * maxbit), where maxbit <= 30 since Z_i <= 1e9. This is efficient for N up to 2e5 and M up to 1e5.
- Edge cases:
  - M = 0: maxbit = 0, all A_i = 0.
  - Self-loops (X_i = Y_i): require Z_i = 0, otherwise impossible.
  - If any component is inconsistent, output -1.

import sys
from collections import deque

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        print()
        return
    it = iter(data)
    N = next(it)
    M = next(it)

    # Build adjacency: for each edge (u,v,z), add (v,z) to adj[u] and (u,z) to adj[v]
    adj = [[] for _ in range(N)]
    maxZ = 0
    for _ in range(M):
        x = next(it) - 1
        y = next(it) - 1
        z = next(it)
        adj[x].append((y, z))
        adj[y].append((x, z))
        if z > maxZ:
            maxZ = z

    maxbit = maxZ.bit_length()  # number of bits to consider

    dist = [0] * N
    vis = [False] * N
    A = [0] * N  # final answer

    for i in range(N):
        if vis[i]:
            continue
        # BFS/DFS for this component
        comp_nodes = []
        q = deque([i])
        vis[i] = True
        dist[i] = 0

        # counts[k] will count how many nodes in this component have dist[node] with bit k = 1
        counts = [0] * maxbit

        while q:
            u = q.popleft()
            comp_nodes.append(u)

            # Update bit counts for dist[u]
            if maxbit:
                d = dist[u]
                for k in range(maxbit):
                    if (d >> k) & 1:
                        counts[k] += 1

            for v, z in adj[u]:
                if not vis[v]:
                    dist[v] = dist[u] ^ z
                    vis[v] = True
                    q.append(v)
                else:
                    if (dist[u] ^ dist[v]) != z:
                        print(-1)
                        return

        comp_size = len(comp_nodes)

        # Determine root value R to minimize sum in this component
        root = 0
        if maxbit:
            for k in range(maxbit):
                if counts[k] > comp_size - counts[k]:
                    root |= (1 << k)

        # Set A[node] = dist[node] xor root for all nodes in this component
        for u in comp_nodes:
            A[u] = dist[u] ^ root

    print(' '.join(map(str, A)))

if __name__ == "__main__":
    main()
