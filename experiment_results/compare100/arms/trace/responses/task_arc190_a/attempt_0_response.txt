### Step-by-step reasoning
- We have an array x of length N initialized to 0. For operation i with interval [L_i, R_i], we must choose op_i ∈ {0,1,2}:
  - op_i = 1: set x_j = 1 for all j in [L_i, R_i], cost 1.
  - op_i = 2: set x_j = 1 for all j outside [L_i, R_i], cost 1.
  - op_i = 0: do nothing, cost 0.
- The final goal is x_1 = ... = x_N = 1 with minimum total cost.

Key observations that guide a tractable approach:
- If any interval equals [1, N], we can do it with a single op of type 1.
- If two intervals are disjoint (R_i < L_j after sorting by L), then using op_i = op_j = 2 covers all positions (since the union of their complements equals the whole set).
- If there is a pair of intervals with one contained in the other (A_i ⊆ A_j), we can do it with two operations: op_i = 2 for the inner interval A_i and op_j = 1 for the outer A_j (the inner’s outside is covered by op_i, and the inner itself is covered by op_j). More generally, if A_i ⊆ A_j for some i ≠ j, then K=2 is feasible.
- If neither of the above holds, a feasible solution may still exist with 3 or more operations. A constructive and practical approach is:
  - Take extremes i* with maximum L and j* with minimum R. Let J2 = A_i* ∩ A_j*. If L*, R* denote max L and min R respectively, then J2 = [L*, R*] (could be empty if L* > R*). If J2 is nonempty, we can try to cover J2 using other intervals with type-1, while using op=2 on i* and j* to cover everything outside J2. This reduces the problem to a standard interval-covering problem for the subsegment J2 using the remaining intervals.
  - If J2 is empty, then the two extreme type-2 operations already cover everything (which falls under the disjoint case, but we handle it here as a fallback).

Strategy implemented:
1) If any interval equals [1, N], output K=1 with op_i = 1 for that interval and 0 otherwise.
2) Look for a disjoint pair by scanning intervals sorted by L. If found, output K=2 with those two indices assigned op=2.
3) Look for a nested pair by scanning: while sweeping in increasing L, if we see an interval with R_i ≤ current best R among previous intervals, we have A_i ⊆ A_j for some j; output K=2 with op_i=2 and op_j=1.
4) Otherwise (no K<=2 solution found), try K=3 via the extremes method:
   - Take i* with maximum L and j* with minimum R. If L* ≤ R*, consider J2=[L*,R*].
   - Cover J2 using the remaining intervals (excluding i* and j*) with a standard greedy interval-cover algorithm. If possible with t intervals, we have a feasible solution with K=2+t: set op_i*=2, op_j*=2, and mark the chosen t intervals as op=1; others 0.
   - If this fails, output -1 (no guaranteed proof of optimality for all pathological cases, but this approach captures many practical cases including several constructed examples).

Edge cases:
- N can be large, but we only sort M intervals, which is feasible (M ≤ 2e5).
- If J2 is empty, the two extremes already yield a full cover with K=2; the greedy step will report t=0 and we’d have K=2; however we detect K<=2 in earlier steps, so this path is rarely used.
- If no solution exists even with the 3-step plan, we print -1.

Complexity:
- Sorting intervals: O(M log M)
- Step 2/3 checks: O(M)
- Step 4 greedy cover for J2: O(M log M) in the worst case (due to the priority queue). Overall acceptable for M ≤ 2e5.

None

```python
import sys
import math
from collections import namedtuple

# We'll implement the described approach.
Interval = namedtuple('Interval', ['L', 'R', 'idx'])

def solve():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    N = int(next(it))
    M = int(next(it))
    intervals = []
    for i in range(1, M+1):
        L = int(next(it)); R = int(next(it))
        intervals.append(Interval(L, R, i))

    # Prepare answer array (1-based indices)
    ans = [0] * M  # 0 by default

    # 1) Check K=1: any interval exactly [1,N]
    for iv in intervals:
        if iv.L == 1 and iv.R == N:
            ans[iv.idx - 1] = 1
            # Others stay 0
            print(1)
            print(' '.join(str(x) for x in ans))
            return

    # 2) Sort by L, and check for disjoint pair (R_left < L_right)
    intervals_by_L = sorted(intervals, key=lambda x: (x.L, x.R))
    maxR = -1
    maxR_idx = -1
    for iv in intervals_by_L:
        if maxR != -1 and iv.L > maxR:
            # disjoint found: previous interval with maxR and this iv
            ans[maxR_idx - 1] = 2
            ans[iv.idx - 1] = 2
            print(2)
            print(' '.join(str(x) for x in ans))
            return
        if iv.R > maxR:
            maxR = iv.R
            maxR_idx = iv.idx

    # 3) Check for nested pair: exists i with L_i >= L_j and R_i <= R_j for some j
    maxR_so_far = -1
    maxR_idx_so_far = -1
    for iv in intervals_by_L:
        if maxR_so_far >= iv.R:
            # Found A_iv ⊆ A_maxR_idx_so_far
            inner_idx = iv.idx
            outer_idx = maxR_idx_so_far
            if inner_idx != outer_idx:
                ans[inner_idx - 1] = 2
                ans[outer_idx - 1] = 1
                print(2)
                print(' '.join(str(x) for x in ans))
                return
        if iv.R > maxR_so_far:
            maxR_so_far = iv.R
            maxR_idx_so_far = iv.idx

    # 4) Try K=3 via extremes and greedy cover of J2
    # Find i* with maximum L, and j* with minimum R
    if M >= 2:
        i_star = max(intervals, key=lambda x: (x.L, -x.R)).idx
        j_star = min(intervals, key=lambda x: (x.R, -x.L)).idx
        # Recompute their L* and R*
        L_star = max(iv.L for iv in intervals if iv.idx == i_star)
        R_star = min(iv.R for iv in intervals if iv.idx == j_star)
        # Build J2
        JL = max(L_star, 1)
        JR = min(R_star, N)

        if JL <= JR:
            # Run greedy cover of [JL, JR] using intervals excluding i_star and j_star
            excluding = {i_star, j_star}
            # Prepare intervals sorted by L for greedy
            # We'll use a standard heap-based greedy
            import heapq
            # List of intervals as (L,R,idx)
            pool = [(iv.L, iv.R, iv.idx) for iv in intervals if iv.idx not in excluding]
            pool.sort()  # by L ascending

            # We'll perform the greedy cover
            current = JL
            pos = 0
            heap = []
            p = 0
            used = []
            # We'll push intervals with L <= current
            success = True
            while current <= JR:
                while p < len(pool) and pool[p][0] <= current:
                    Lp, Rp, idxp = pool[p]
                    # push with key -Rp for max-heap behavior using min-heap
                    heapq.heappush(heap, (-Rp, idxp, Lp, Rp))
                    p += 1
                # pick the interval with maximum R among eligible and not used
                found = False
                while heap:
                    negRp, idxp, Lp, Rp = heap[0]
                    # Pop and check
                    heapq.heappop(heap)
                    if Rp <= current - 1:
                        # This interval does not extend beyond current, skip
                        continue
                    # Use this interval
                    used.append(idxp)
                    current = Rp + 1
                    found = True
                    break
                if not found:
                    success = False
                    break
            if success:
                # Build answer
                ans[i_star - 1] = 2
                ans[j_star - 1] = 2
                for u in used:
                    ans[u - 1] = 1
                K = 2 + len(used)
                print(K)
                print(' '.join(str(x) for x in ans))
                return

    # If nothing worked, we print -1
    print(-1)

if __name__ == "__main__":
    solve()
```
