### Step-by-step reasoning
- We need to pick for each operation i one of {0,1,2} to minimize total cost, while ensuring all positions 1..N become 1 by the end.
- Observations:
  - Operation 1 paints inside [L_i, R_i].
  - Operation 2 paints outside [L_i, R_i] (i.e., [1, L_i-1] ∪ [R_i+1, N]).
  - If there exists an interval [L_i, R_i] = [1, N], we can paint all positions with a single operation (cost 1).
- If K = 2 is possible, we can do it with two non-zero operations. Several patterns guarantee full coverage:
  - AB: One interval contains the other. If there exist i ≠ j with [L_j, R_j] ⊆ [L_i, R_i], then op_i = 1 (paint inside I) and op_j = 2 (paint outside J) cover the entire range.
  - AA: Two intervals whose union covers [1, N]. This happens if there is an interval starting at 1 (L = 1) and an interval ending at N (R = N) such that their union is continuous: L2 ≤ R1 + 1, i.e., they touch or overlap.
  - BB: Two intervals disjoint. If there exist i ≠ j with [L_i, R_i] ∩ [L_j, R_j] = ∅, then painting outside both intervals with op2 on both of them covers the entire range.
- If none of K = 1 or K = 2 patterns exist, it may still be possible with K = 3 using a B,B,A pattern:
  - If there exists an interval I = [L_I, R_I] that contains at least two other intervals J1, J2 (i.e., there exist J1, J2 with [L_J, R_J] ⊆ [L_I, R_I] and J1 ≠ J2), then:
    - Do op_I = 1 (paint inside I),
    - Do op_J1 = 2 and op_J2 = 2 (paint outside J1 and outside J2).
    - This covers all positions: inside I is painted by A, outside I is painted by at least one of the two B-operations (since J1, J2 are inside I, their outside sets cover everything outside I as well).
- If none of the above patterns exist, the problem is impossible (-1).
- Algorithm plan:
  1) Check K = 1: any interval exactly [1, N].
  2) Check K = 2 in this order:
     - AB: sort by (L, R) and scan keeping the maximum R seen so far; if a current interval has R ≤ maxR from a previous interval, AB exists.
     - AA: find an interval with L = 1 having maximum R (R1) and an interval with R = N having minimum L (L2); if both exist and L2 ≤ R1 + 1, AA exists.
     - BB: with intervals sorted by L, if we encounter a current L greater than the maximum R seen so far, then there exist two disjoint intervals.
  3) If none, check K = 3:
     - For each interval I, count how many intervals J satisfy L_J ≥ L_I and R_J ≤ R_I (including I itself). If there exists I with count ≥ 3 (i.e., at least two other intervals inside I), we can construct a solution with A on I and B on two inside intervals.
     - Efficient way: group by L, process L in descending order, use a Fenwick tree on compressed R to compute for each I the number of intervals with L ≥ L_I and R ≤ R_I; include within-group counts for equal L.
  4) If none of the above yield a solution, print -1.

- Time complexity: 
  - O(M log M) for K = 1, 2 checks.
  - O(M log M) for K = 3 check using a Fenwick tree with coordinate compression.
  - Memory: O(M).

- Output format:
  - If impossible, print -1.
  - Otherwise, print K on the first line, and on the next line a space-separated sequence of M integers (0,1,2) representing the operation type for each input interval.

import sys
from bisect import bisect_right
from collections import defaultdict

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    M = next(it)

    intervals = []
    for i in range(1, M + 1):
        L = next(it)
        R = next(it)
        intervals.append((L, R, i))  # (L, R, idx)

    def print_result(K, ops):
        print(K)
        print(' '.join(map(str, ops)))

    # 1) K = 1: any interval exactly [1, N]
    for L, R, idx in intervals:
        if L == 1 and R == N:
            ops = [0] * M
            ops[idx - 1] = 1
            print_result(1, ops)
            return

    # 2) K = 2: try AB, AA, then BB

    # 2a) AB: exists i (outer) and j (inner) with [L_j, R_j] ⊆ [L_i, R_i]
    intervals_by_LR = sorted(intervals, key=lambda x: (x[0], x[1]))
    maxR = -1
    maxR_idx = -1
    for L, R, idx in intervals_by_LR:
        if maxR >= R:
            ops = [0] * M
            ops[maxR_idx - 1] = 1
            ops[idx - 1] = 2
            print_result(2, ops)
            return
        if R > maxR:
            maxR = R
            maxR_idx = idx

    # 2b) AA: two intervals whose union covers [1, N]
    idx_A1 = -1  # interval with L=1 having max R
    best_R1 = -1
    for L, R, idx in intervals:
        if L == 1:
            if R > best_R1:
                best_R1 = R
                idx_A1 = idx
    idx_A2 = -1  # interval with R=N having min L
    min_LN = 10**9
    for L, R, idx in intervals:
        if R == N:
            if L < min_LN:
                min_LN = L
                idx_A2 = idx
    if idx_A1 != -1 and idx_A2 != -1:
        # Get actual R1 and L2
        R1 = None
        L2 = None
        for L, R, idx in intervals:
            if idx == idx_A1:
                R1 = R
                break
        for L, R, idx in intervals:
            if idx == idx_A2:
                L2 = L
                break
        if L2 is not None and R1 is not None and L2 <= R1 + 1:
            ops = [0] * M
            ops[idx_A1 - 1] = 1
            ops[idx_A2 - 1] = 1
            print_result(2, ops)
            return

    # 2c) BB: two B-intervals with non-overlapping inner intervals
    maxR = -1
    maxR_idx = -1
    for L, R, idx in intervals_by_LR:
        if maxR != -1 and L > maxR:
            ops = [0] * M
            ops[maxR_idx - 1] = 2
            ops[idx - 1] = 2
            print_result(2, ops)
            return
        if R > maxR:
            maxR = R
            maxR_idx = idx

    # 3) K = 3: B, B, A pattern
    # We need an interval I that contains at least two other intervals J1, J2.
    # Compute for each I how many intervals J satisfy L_J >= L_I and R_J <= R_I (including I).
    all_R = sorted({r for (_, r, _) in intervals})
    KR = len(all_R)
    r_to_pos = {v: i + 1 for i, v in enumerate(all_R)}  # 1-based

    class Fenwick:
        def __init__(self, n):
            self.n = n
            self.bit = [0] * (n + 1)

        def add(self, i, delta):
            while i <= self.n:
                self.bit[i] += delta
                i += i & -i

        def sum(self, i):
            s = 0
            while i > 0:
                s += self.bit[i]
                i -= i & -i
            return s

    # Group intervals by L
    groups = defaultdict(list)
    for L, R, idx in intervals:
        groups[L].append((R, idx))

    L_values_desc = sorted(groups.keys(), reverse=True)

    totals = [0] * (M + 1)  # 1-based by idx
    bit = Fenwick(KR)

    from bisect import bisect_right

    for L0 in L_values_desc:
        group = groups[L0]
        # counts from groups with L > L0
        before_counts = {}
        for R, idx in group:
            before_counts[idx] = bit.sum(r_to_pos[R])
        # counts within the same L (same L0)
        Rs_in_group = sorted([R for (R, _) in group])
        for R, idx in group:
            cnt_same = bisect_right(Rs_in_group, R)  # includes itself
            totals[idx] = before_counts[idx] + cnt_same
        # add current group to BIT
        for R, idx in group:
            bit.add(r_to_pos[R], 1)

    candidate = None
    for L, R, idx in intervals:
        if totals[idx] >= 3:
            candidate = (L, R, idx)
            break

    if candidate is not None:
        L_I, R_I, I = candidate
        Js = []
        for L, R, idx in intervals:
            if idx == I:
                continue
            if L >= L_I and R <= R_I:
                Js.append(idx)
                if len(Js) >= 2:
                    break
        if len(Js) >= 2:
            J1, J2 = Js[0], Js[1]
            ops = [0] * M
            ops[I - 1] = 1
            ops[J1 - 1] = 2
            ops[J2 - 1] = 2
            print_result(3, ops)
            return

    print(-1)

if __name__ == "__main__":
    solve()
