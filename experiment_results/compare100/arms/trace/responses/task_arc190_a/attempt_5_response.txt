### Step-by-step reasoning
- Model the problem as a set cover with M sets S_i, where:
  - If we choose operation 1 on interval i, S_i = [L_i, R_i].
  - If we choose operation 2 on interval i, S_i = [1, L_i-1] ∪ [R_i+1, N].
  - If we choose operation 0, S_i = ∅.
- We want the union of chosen S_i to be the entire [1, N], while minimizing the number of non-zero operations.

Key observations:
- If any interval already covers all positions, i.e., [L_i, R_i] = [1, N], we can finish with K = 1 by choosing op_i = 1.
- With two operations (K = 2) we can cover all if one of the following patterns exists:
  - AB: There exists i ≠ j with [L_j, R_j] ⊆ [L_i, R_i]. Then op_i = 1 and op_j = 2 covers everything.
  - AA: There exists an interval starting at 1 and an interval ending at N such that their inside intervals overlap/meet, i.e., L1 = 1, RN = N, and L2 ≤ R1 + 1. Then painting inside both of them covers all.
  - BB: There exist i ≠ j with [L_i, R_i] ∩ [L_j, R_j] = ∅ (disjoint). Then painting outside both intervals (op = 2) for both covers all.
- If none of the above patterns exist, the problem can still be solvable with K = 3 using a B-B-A pattern:
  - If there exists an interval I = [L_I, R_I] that contains at least two other intervals J1, J2 (i.e., [L_J, R_J] ⊆ [L_I, R_I] for two different J), then:
    - Do op_I = 1 (paint inside I),
    - Do op_J1 = 2 and op_J2 = 2 (paint outside J1 and J2).
  - Because J1, J2 lie inside I, painting outside J1 and outside J2 together covers all positions outside I, while inside I is already painted by op_I.
- The above guarantees that if a solution exists, it can be achieved with K ∈ {1,2,3}. If none of the patterns exist, we output -1.

Algorithm outline:
1) If any interval is [1, N], print K = 1 and that op.
2) Try K = 2 patterns in this order:
   - AB: sort by (L, R) and keep the maximum R of all previous intervals. If a current interval’s R ≤ maxR seen before, we found AB.
   - AA: find an interval with L = 1 that has the largest R1, and an interval with R = N that has the smallest L2. If L2 ≤ R1 + 1, we found AA.
   - BB: sort by L and scan; if the current L > maxR seen so far, we found a pair of disjoint intervals.
3) If none of the above, try K = 3:
   - For each interval I, count how many intervals J satisfy L_J ≥ L_I and R_J ≤ R_I (including I itself). If there exists I with at least 3 such intervals (i.e., itself plus at least two other inside), pick I and two inside intervals J1, J2 and output K = 3 with ops: I -> 1, J1 -> 2, J2 -> 2.
   - Efficiently count inside intervals using a Fenwick tree (BIT) with coordinate compression on R, processing groups by L in decreasing order.
4) If none of the patterns yields a solution, print -1.

Time complexity:
- Each of the checks runs in O(M log M) (sorting and Fenwick operations). Overall O(M log M), which is feasible for M up to 2e5. Memory is O(M).

Output format:
- If impossible, print -1.
- Otherwise, print K on the first line, and a line with M integers (0, 1, or 2) representing the operation chosen for each input interval in order.

import sys
from bisect import bisect_right
from collections import defaultdict

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    M = next(it)

    intervals = []
    for i in range(1, M + 1):
        L = next(it)
        R = next(it)
        intervals.append((L, R, i))  # (L, R, idx)

    def print_result(K, ops):
        print(K)
        print(' '.join(map(str, ops)))

    # 1) K = 1: any interval exactly [1, N]
    for L, R, idx in intervals:
        if L == 1 and R == N:
            ops = [0] * M
            ops[idx - 1] = 1
            print_result(1, ops)
            return

    # 2) K = 2: try AB, AA, then BB

    # 2a) AB: exists i (outer) and j (inner) with [L_j, R_j] ⊆ [L_i, R_i]
    intervals_by_LR = sorted(intervals, key=lambda x: (x[0], x[1]))
    maxR = -1
    maxR_idx = -1
    for L, R, idx in intervals_by_LR:
        if maxR >= R:
            # j is current (L,R,idx); i is maxR_idx with [L_i,R_i] ⊇ [L_j,R_j]
            ops = [0] * M
            ops[maxR_idx - 1] = 1
            ops[idx - 1] = 2
            print_result(2, ops)
            return
        if R > maxR:
            maxR = R
            maxR_idx = idx

    # 2b) AA: two intervals whose union covers [1, N]
    idx_A1 = -1  # interval with L=1 having max R
    best_R1 = -1
    for L, R, idx in intervals:
        if L == 1:
            if R > best_R1:
                best_R1 = R
                idx_A1 = idx
    idx_A2 = -1  # interval with R=N having min L
    min_LN = 10**9
    for L, R, idx in intervals:
        if R == N:
            if L < min_LN:
                min_LN = L
                idx_A2 = idx
    if idx_A1 != -1 and idx_A2 != -1:
        # Get actual R1 and L2
        R1 = None
        L2 = None
        for L, R, idx in intervals:
            if idx == idx_A1:
                R1 = R
                break
        for L, R, idx in intervals:
            if idx == idx_A2:
                L2 = L
                break
        if L2 is not None and R1 is not None and L2 <= R1 + 1:
            ops = [0] * M
            ops[idx_A1 - 1] = 1
            ops[idx_A2 - 1] = 1
            print_result(2, ops)
            return

    # 2c) BB: two B-intervals with non-overlapping inner intervals
    maxR = -1
    maxR_idx = -1
    for L, R, idx in intervals_by_LR:
        if maxR != -1 and L > maxR:
            ops = [0] * M
            ops[maxR_idx - 1] = 2
            ops[idx - 1] = 2
            print_result(2, ops)
            return
        if R > maxR:
            maxR = R
            maxR_idx = idx

    # 3) K = 3: B, B, A pattern
    # We need an interval I that contains at least two other intervals J1, J2.
    # Compute for each I how many intervals J satisfy L_J >= L_I and R_J <= R_I (including I).
    all_R = sorted({r for (_, r, _) in intervals})
    KR = len(all_R)
    r_to_pos = {v: i + 1 for i, v in enumerate(all_R)}  # 1-based

    class Fenwick:
        def __init__(self, n):
            self.n = n
            self.bit = [0] * (n + 1)

        def add(self, i, delta):
            while i <= self.n:
                self.bit[i] += delta
                i += i & -i

        def sum(self, i):
            s = 0
            while i > 0:
                s += self.bit[i]
                i -= i & -i
            return s

    # Group intervals by L
    groups = defaultdict(list)
    for L, R, idx in intervals:
        groups[L].append((R, idx))

    L_values_desc = sorted(groups.keys(), reverse=True)

    totals = [0] * (M + 1)  # 1-based by idx
    bit = Fenwick(KR)

    for L0 in L_values_desc:
        group = groups[L0]
        # counts from groups with L > L0
        before_counts = {}
        for R, idx in group:
            before_counts[idx] = bit.sum(r_to_pos[R])
        # counts within the same L (same L0)
        Rs_in_group = sorted([R for (R, _) in group])
        for R, idx in group:
            cnt_same = bisect_right(Rs_in_group, R)  # includes itself
            totals[idx] = before_counts[idx] + cnt_same
        # add current group to BIT
        for R, idx in group:
            bit.add(r_to_pos[R], 1)

    candidate = None
    for L, R, idx in intervals:
        if totals[idx] >= 3:
            candidate = (L, R, idx)
            break

    if candidate is not None:
        L_I, R_I, I = candidate
        Js = []
        for L, R, idx in intervals:
            if idx == I:
                continue
            if L >= L_I and R <= R_I:
                Js.append(idx)
                if len(Js) >= 2:
                    break
        if len(Js) >= 2:
            J1, J2 = Js[0], Js[1]
            ops = [0] * M
            ops[I - 1] = 1
            ops[J1 - 1] = 2
            ops[J2 - 1] = 2
            print_result(3, ops)
            return

    print(-1)

if __name__ == "__main__":
    solve()
