### Step-by-step reasoning
- We have n pizzas (n is a multiple of 4). Each day we pick 4 pizzas and the weight gained is:
  - On odd days (1,3,5,...): the maximum Z of the chosen group W <= X <= Y <= Z.
  - On even days (2,4,6,...): the second maximum Y of the chosen group.
- We need to partition the pizzas into D = n/4 groups and assign them to days in order to maximize the total weight gained.

Greedy derivation:
- Sort all pizzas in descending order. Process days in that order to greedily construct groups.
- Day 1 (odd): We want the group’s maximum to be as large as possible. Take the current largest value as the group max (add to answer). To avoid wasting big numbers on this day, fill the remaining three slots of this group with the smallest available pizzas (i.e., remove three from the end).
- Day 2 (even): The group’s max is not counted. To maximize the second maximum (the one we gain on this day), fill the group with the three largest remaining pizzas. The second maximum will then be the largest among these three fillers, i.e., the first of these three removed values. Add that value to the answer.
- Repeat for subsequent days: on odd days, add the largest available; on even days, add the largest among the three largest remaining (i.e., the first filler) after removing the max for that day.

Implementation details:
- Use a deque of pizzas sorted in descending order.
- For each day i from 0 to D-1:
  - Pop the largest remaining as max_val (dq.popleft()).
  - If i is even (odd day in 1-based indexing):
    - Add max_val to the answer.
    - Remove three smallest remaining from the right (dq.pop() three times).
  - If i is odd (even day in 1-based indexing):
    - Remove three largest remaining from the left as fillers:
      - first = dq.popleft(); add first to the answer (this is the largest of the three fillers)
      - then dq.popleft() twice to remove the other two fillers.
- This approach runs in O(n log n) due to sorting and uses O(n) extra space.

Edge cases:
- n = 4 works as a single day.
- All pizzas equal yields a straightforward result.
- Large n (up to 2e5) is fine with O(n log n) time.

### Requirements
None

### Code
```python
from typing import List
from collections import deque

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        D = n // 4

        # Sort in descending order and use a deque for efficient pops from both ends
        dq = deque(sorted(pizzas, reverse=True))

        ans = 0
        for i in range(D):
            # Take the largest remaining as the group's max
            max_val = dq.popleft()

            if i % 2 == 0:
                # Odd day (1st, 3rd, ...): gain the group max
                ans += max_val
                # Fill the group with the three smallest remaining
                dq.pop()
                dq.pop()
                dq.pop()
            else:
                # Even day: do not gain the group max
                # Fill the group with the three largest remaining
                first = dq.popleft()  # largest among the three fillers
                ans += first
                dq.popleft()
                dq.popleft()

        return ans
```
