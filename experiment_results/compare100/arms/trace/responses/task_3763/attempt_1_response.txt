### Step-by-step reasoning
- The problem requires finding a horizontal line y = t such that the total area of portions of all squares below the line equals half of the total area of all squares.
- The existing approach uses a binary search to locate t such that area_below(t) is closest to half of the total area.
- The logic for computing area_below(t) per square is correct: for a square with vertical span [y, y+l], the area below t is:
  - 0 if t <= y
  - (t - y) * l if y < t < y + l
  - l * l if t >= y + l
- The test failure arises from formatting/precision: the binary search yields 1.1666666666666665, but the test expects 1.16667 (5 decimals). Although the numeric value is within 1e-5 of the true answer, the test harness compares formatted output strings.
- Fix: return the result rounded to 5 decimal places to match the expected formatting, while keeping the internal binary search accuracy intact.

from typing import List

class Solution:
    def separateSquares(self, squares: List[List[int]]) -> float:
        n = len(squares)
        ys = [s[1] for s in squares]
        ls = [s[2] for s in squares]
        ends = [ys[i] + ls[i] for i in range(n)]
        
        min_y = min(ys)
        max_y_plus = max(ends)
        total_area = 0.0
        for l in ls:
            total_area += l * l
        half_area = total_area / 2.0

        lo, hi = min_y, max_y_plus
        # Perform binary search to find t such that area below(t) ≈ half_area
        for _ in range(60):
            mid = (lo + hi) / 2.0
            below = 0.0
            for i in range(n):
                yi = ys[i]
                li = ls[i]
                if mid <= yi:
                    continue
                end_i = ends[i]
                if mid >= end_i:
                    below += li * li
                else:
                    below += (mid - yi) * li
            if below < half_area:
                lo = mid
            else:
                hi = mid
        ans = (lo + hi) / 2.0
        # Format to 5 decimals to match expected output in tests
        return round(ans, 5)
