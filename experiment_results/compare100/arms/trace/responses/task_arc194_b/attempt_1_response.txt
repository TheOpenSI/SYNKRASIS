- Implementation plan:
  1. Read N and the permutation P.
  2. Build pos array such that pos[v] gives the 1-based index of value v in P.
  3. Compute ans as the sum over v from 1 to N of abs(pos[v] - v).
  4. Print ans.

- Complexity: O(N) time and O(N) memory, suitable for N up to 2e5.

### Code
```
import sys

def main():
    input = sys.stdin.readline
    N = int(input().strip())
    P = list(map(int, input().split()))
    
    # pos[v] will store 1-based position of value v in P
    pos = [0] * (N + 1)
    for idx, val in enumerate(P, start=1):
        pos[val] = idx

    ans = 0
    for v in range(1, N + 1):
        ans += abs(pos[v] - v)

    print(ans)

if __name__ == "__main__":
    main()
```
