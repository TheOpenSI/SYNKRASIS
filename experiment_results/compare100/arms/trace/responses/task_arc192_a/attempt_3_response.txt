### Step-by-step reasoning
- Problem understanding
  - We are given a cycle of N positions with A_i ∈ {0,1}.
  - We want to know if there exists a string S (length N, over uppercase letters) such that by performing some operations of two specific AR C / C R A patterns around edges, we can turn all A_i to 1.
  - An operation on edge i (between positions i and i+1, with wrap) is possible iff the triple around that edge is either (S_i, S_{i+1}, S_{i+2}) = (A, R, C) or (C, R, A). In both cases the middle S_{i+1} must be 'R', and the ends S_i and S_{i+2} must be 'A' and 'C' in some order.
  - Crucially, two activated edges cannot be adjacent: if edge i is activated, S_{i+1} = 'R'. For edge i+1 to be activated, its middle would be S_{i+2}, which would have to be 'R', conflicting with S_{i+2} being 'A' or 'C'. So activated edges form a matching on the N-cycle.

- Reduction to a combinatorial problem
  - If we pick a set of edges E' to activate, the only requirement on S is:
    - For every i ∈ E': S_i and S_{i+2} are in {A,C} and S_i ≠ S_{i+2} (they must be A and C in some order).
    - For all i not in E', there is no requirement on S from this problem (we only need to ensure there exists a sequence of operations; additional activations are fine, but not required).
  - The set E' must be a matching (no two chosen edges share a vertex). This is the only global restriction.
  - For a given E', can we always assign letters S to satisfy all constraints S_i ≠ S_{i+2} for all i ∈ E'? The constraints form a graph on involved S_j variables with edges (i, i+2) for i ∈ E'. Because E' is a matching, you cannot have two activated edges that cause a cycle in this constraint graph; the graph is a disjoint union of simple paths. A path is bipartite, so it can be colored with A/C to satisfy all S_i ≠ S_{i+2}. Therefore, for any matching E' the corresponding S assignment exists.
  - Thus the problem reduces to purely graph-theoretic/dynamic programming: Is there a matching on the N-cycle such that every index i with A_i = 0 is incident to at least one chosen edge (i-1 or i)?

- DP formulation
  - Let x_i ∈ {0,1} denote whether edge i (between i and i+1, 0-based) is chosen.
  - Constraints:
    - No two adjacent edges in the cycle: x_{i-1} + x_i ≤ 1 (indices modulo N).
    - Coverage: every i with A_i = 0 must be covered, i.e., x_{i-1} = 1 or x_i = 1 (with wrap-around for i = 0, i-1 means last edge).
  - This is a cycle DP. Break the cycle by fixing x_0 ∈ {0,1}, then process i = 1..N-1 linearly with memory of x_{i-1}.
  - Transitions for i from 1 to N-1:
    - If x_{i-1} = 0:
      - If A_i = 0, then we must set x_i = 1 to cover i.
      - If A_i = 1, then x_i can be 0 or 1.
    - If x_{i-1} = 1:
      - Then x_i must be 0 (no adjacent edges).
  - After processing up to i = N-1, we close the cycle by checking the wrap constraint for index 0:
    - If x_0 = 0, then vertex 0 must be covered by x_{N-1}, so require x_{N-1} = 1 if A_0 = 0.
    - If A_0 = 1, vertex 0 doesn’t need to be covered; any x_{N-1} is fine.
    - If x_0 = 1, then vertex 0 is already covered; wrap constraint requires x_{N-1} = 0.
  - Run the DP twice: once with x_0 = 0 and once with x_0 = 1. If either yields a valid configuration, answer Yes; otherwise No.

- Correctness notes
  - Activating edges forms a matching; the S-assignability argument shows no further global obstruction exists beyond the matching constraint.
  - The DP handles all corner cases:
    - All A_i are 1 -> Yes (empty matching suffices).
    - N small and zeros scattered -> DP checks feasibility of covering zeros with non-adjacent edges.
    - Large N up to 2e5 -> O(N) time, O(1) extra space.

- Complexity
  - Time: O(N)
  - Space: O(1) beyond input storage

- No external libraries required.

import sys

def can_make_all_ones(A):
    # A is a list of ints 0/1, length n
    n = len(A)
    must = [ (a == 0) for a in A ]
    must0 = must[0]

    def attempt(start):
        # start = x_0 (0 or 1)
        dp0 = (start == 0)  # x_{i-1} = 0 for current i
        dp1 = (start == 1)  # x_{i-1} = 1 for current i

        # process i = 1..n-1 (edge indices)
        for i in range(1, n):
            new0 = False
            new1 = False
            if dp0:
                # previous edge is 0
                if not must[i]:
                    new0 = True  # we may set x_i = 0
                new1 = True      # we may set x_i = 1
            if dp1:
                # previous edge is 1 -> current must be 0
                new0 = True
            dp0, dp1 = new0, new1

        # Wrap-around constraints with x_0 = start
        if start == 0:
            # Vertex 0 must be covered if A_0 == 0 -> require x_{n-1} = 1
            if must0:
                return dp1
            else:
                return dp0 or dp1
        else:
            # start == 1: adjacency implies x_{n-1} must be 0
            return dp0

    return attempt(0) or attempt(1)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n = int(data[0])
    A = list(map(int, data[1:1+n]))
    print("Yes" if can_make_all_ones(A) else "No")

if __name__ == "__main__":
    solve()
