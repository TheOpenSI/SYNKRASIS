### Step-by-step reasoning
- The previous solution assumed we only flip each index with A_i != B_i exactly once and never flip any other indices. That is not always optimal: flipping some indices that are already equal (D_i = 0) can temporarily reduce the current sum S by flipping a 1 to 0, enabling subsequent flips to cost less, and then flipping back later to restore the original value. This can reduce the total sum of S after each operation.
- To capture this, we model a sequence of flips where each index i is flipped t_i times, with t_i ≡ D_i (mod 2) to end up with B_i. The total number of flips is m = Σ t_i.
- Each flip on i changes the current weighted sum S = Σ A_k C_k by delta_i, where delta_i depends on A_i just before the flip:
  - If A_i before flip is 1, delta_i = -C_i.
  - If A_i before flip is 0, delta_i = +C_i.
  These deltas alternate for the same i as we flip it multiple times: the sequence for i is either -C_i, +C_i, -C_i, ... or +C_i, -C_i, +C_i, ..., depending on the initial A_i.
- The total cost T equals sum of S after each flip. For a fixed m and a chosen multiset of deltas, the minimal possible T is achieved by:
  - Performing all flips that produce negative deltas first, in decreasing magnitude (largest C_i first).
  - Then performing flips that produce positive deltas, in increasing magnitude (smallest C_i first).
- This leads to a structure where for each i, the number of negative deltas neg_i and positive deltas pos_i contributed by i depend on t_i, A_i, D_i (where D_i = A_i xor B_i). Specifically, with t_i = D_i + 2q_i (q_i ≥ 0), we have:
  - If A_i = 0: neg_i = q_i, pos_i = D_i + q_i
  - If A_i = 1: neg_i = q_i + D_i, pos_i = q_i
- The total cost T can be written in terms of m, K = total number of negative deltas (K = Σ neg_i), and the per-index neg_i and pos_i. We can start from the baseline where q_i = 0 for all i (i.e., flip exactly the D_i indices once) and then greedily add extra pairs of flips (i.e., increase q_i by 1 for any i, which adds two more flips and increases both neg_i and pos_i by 1) if doing so decreases the total cost.
- We implement a greedy, lazy-evaluation improvement:
  - Compute the baseline state: m0 = Σ D_i, K0, neg_i, pos_i, and the initial total cost T0.
  - Repeatedly consider adding one extra pair of flips to any index i (i.e., increase q_i by 1), which increases m by 2, K by 1, neg_i by 1, and pos_i by 1.
  - For each i, compute the marginal change ΔT_i in the total cost if we add this extra pair, given the current global sums. Use a lazy-pricing approach with a min-heap to always try the candidate with the most negative ΔT_i first.
  - If the best ΔT_i < 0, apply the change for that i, update m, K, neg_i, pos_i, and the global aggregates, then re-evaluate ΔT for that i and push it back into the heap. If no ΔT_i is negative, stop; the current T is optimal.

This approach allows the solution to capture beneficial extra flips on A_i = 1 with D_i = 0 (or other indices, as the marginal benefit can come from various configurations) and converges to the true minimum.

import sys
import heapq

def compute_T(m, S0, K, neg, pos, Cs, n):
    total_neg = 0
    total_pos = 0
    for i in range(n):
        ni = neg[i]
        pi = pos[i]
        ci = Cs[i]
        total_neg += ci * (ni * (m + 1) - ni * (ni + 1) // 2)
        total_pos += ci * (pi * (m - K + 1) - pi * (pi + 1) // 2)
    return m * S0 - total_neg + total_pos

def calc_delta(i, m, K, neg, pos, Cs, S0, sum2neg_all, sumpos_all, n):
    # Marginal cost change if we increase q_i by 1 (i.e., add one extra pair for index i)
    Ci = Cs[i]
    ni = neg[i]
    pi = pos[i]

    # Term_before and Term_after for A-part
    Term_before = ni * (m + 1) - ni * (ni + 1) // 2
    Term_after = (ni + 1) * (m + 3) - (ni + 1) * (ni + 2) // 2
    DeltaA_i = Ci * (Term_after - Term_before)

    # A_extra = sum_{j != i} 2*Cj*neg_j
    A_extra = sum2neg_all - 2 * Ci * ni

    # DeltaT contribution from A-part: - (A_extra + DeltaA_i)  (inside 2*S0 - ...)
    # Now B-part
    # DeltaB_i
    DeltaB_i = Ci * ( (pi + 1) * (m - K + 2) - (pi + 1) * (pi + 2) // 2
                     - (pi * (m - K + 1) - pi * (pi + 1) // 2) )

    # B_extra = sumpos_all - Ci * pi
    B_extra = sumpos_all - Ci * pi

    # Total delta
    DeltaT = 2 * S0 - A_extra - DeltaA_i + B_extra + DeltaB_i
    return DeltaT

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        print(0)
        return
    it = iter(data)
    N = int(next(it))

    A = [int(next(it)) for _ in range(N)]
    B = [int(next(it)) for _ in range(N)]
    C = [int(next(it)) for _ in range(N)]

    # Baseline quantities
    S0 = 0
    D = [0] * N
    D_count = 0
    for i in range(N):
        S0 += A[i] * C[i]
        D[i] = A[i] ^ B[i]
        if D[i]:
            D_count += 1

    if D_count == 0:
        print(0)
        return

    # Initialize per-index neg_i and pos_i for q_i = 0
    neg = [0] * N
    pos = [0] * N
    for i in range(N):
        if A[i] == 0:
            neg[i] = 0
            pos[i] = D[i]
        else:  # A[i] == 1
            neg[i] = D[i]
            pos[i] = 0

    m = D_count
    K = sum(neg)  # total negatives
    # Baseline total cost
    T = compute_T(m, S0, K, neg, pos, C, N)

    # Precompute aggregates for delta computations
    sum2neg_all = sum(2 * C[i] * neg[i] for i in range(N))
    sumpos_all = sum(C[i] * pos[i] for i in range(N))

    # Build a min-heap of (DeltaT, i) for all i as potential increments
    heap = []
    for i in range(N):
        delta = calc_delta(i, m, K, neg, pos, C, S0, sum2neg_all, sumpos_all, N)
        heapq.heappush(heap, (delta, i))

    # Greedily apply improvements while negative
    while heap:
        delta, i = heapq.heappop(heap)
        # If this candidate is no longer negative due to previous updates, skip
        current_delta = calc_delta(i, m, K, neg, pos, C, S0, sum2neg_all, sumpos_all, N)
        if delta != current_delta:
            heapq.heappush(heap, (current_delta, i))
            continue
        if delta >= 0:
            # No further improvements possible
            break
        # Apply improvement for index i: increase q_i by 1 -> m += 2, K += 1, neg[i]++, pos[i]++
        m += 2
        K += 1
        neg[i] += 1
        pos[i] += 1
        sum2neg_all += 2 * C[i]
        sumpos_all += C[i]

        # Update total cost
        T = compute_T(m, S0, K, neg, pos, C, N)

        # Push updated delta for this i
        new_delta = calc_delta(i, m, K, neg, pos, C, S0, sum2neg_all, sumpos_all, N)
        heapq.heappush(heap, (new_delta, i))

    print(T)

if __name__ == "__main__":
    main()
