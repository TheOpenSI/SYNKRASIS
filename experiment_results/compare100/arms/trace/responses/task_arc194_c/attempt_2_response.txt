### Step-by-step reasoning
- Problem insight: Each operation flips a single A_i and incurs a cost equal to the new total sum S = sum_k A_k * C_k after the flip. Flipping the same index multiple times is allowed, but since S is always nonnegative, any extra pair of flips on an index with parity constraint D_i = A_i xor B_i will add nonnegative total cost, so it cannot help minimize the total. Therefore, in an optimal strategy, we only flip indices i with D_i = 1 exactly once (to satisfy A_i -> B_i). Indices with D_i = 0 are never flipped in the optimal solution.
- For indices with D_i = 1, the first (and only) flip at i has delta equal to:
  - -C_i if A_i = 1 (since flipping 1 -> 0 reduces S by C_i),
  - +C_i if A_i = 0 (since flipping 0 -> 1 increases S by C_i).
  To minimize the total sum of S across all flips, we should:
  - perform all negative deltas first (i.e., all i with A_i = 1 and D_i = 1), in decreasing order of C_i (largest impact first),
  - then perform all positive deltas (i with A_i = 0 and D_i = 1) in increasing order of C_i (smaller increases earlier to keep S low for subsequent steps).
- Implementation plan:
  - Compute S0 = sum_i A_i * C_i.
  - Collect neg = [C_i] for indices where D_i = 1 and A_i = 1; sort descending.
  - Collect pos = [C_i] for indices where D_i = 1 and A_i = 0; sort ascending.
  - Start with S = S0 and total T = 0.
  - Apply all neg deltas: for each c in neg, S -= c; T += S.
  - Apply all pos deltas: for each c in pos, S += c; T += S.
  - The result is T. If there are no D_i = 1, answer is 0.
- Complexity: O(N log N) due to sorting, which fits N up to 2e5.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        print(0)
        return

    it = iter(data)
    N = int(next(it))

    A = [int(next(it)) for _ in range(N)]
    B = [int(next(it)) for _ in range(N)]
    C = [int(next(it)) for _ in range(N)]

    # Baseline sum when A is as given
    S0 = 0
    neg = []  # C_i where D_i = 1 and A_i = 1 (negative deltas)
    pos = []  # C_i where D_i = 1 and A_i = 0 (positive deltas)

    for i in range(N):
        S0 += A[i] * C[i]
        D = A[i] ^ B[i]
        if D:
            if A[i] == 1:
                neg.append(C[i])
            else:
                pos.append(C[i])

    if not neg and not pos:
        print(0)
        return

    neg.sort(reverse=True)  # largest negative deltas first
    pos.sort()              # smallest positive deltas first

    S = S0
    T = 0

    # Apply negative deltas first
    for c in neg:
        S -= c
        T += S

    # Then apply positive deltas
    for c in pos:
        S += c
        T += S

    print(T)

if __name__ == "__main__":
    main()
