### Step-by-step reasoning
- Problem recap: You start with binary A, want to reach B by flipping one bit at a time. After each flip, you pay a cost equal to the current weighted sum S = sum A_k * C_k. You may flip any index any number of times. If A_i != B_i, the total number of flips on i must be odd; if A_i == B_i, the total flips on i must be even (could be zero, or two, four, ...). The challenge is to minimize the total cost.

- What happened before: The previous solution only considered performing the mandatory flips (one flip for every i with A_i != B_i) and optionally inserted a single extra pair of flips on a “buffer” index (where A_i == B_i and A_i == 1). That approach is insufficient because the optimal solution may require flipping multiple buffers (A_i == B_i) to minimize the total cost. The test case showed that using multiple buffers yields a better result than any single-buffer insertion.

- Key observation: If we decide on a fixed set of buffers (indices with A_i == B_i), each buffer contributes a pair of flips: a negative delta (-C_i) if the first flip is 1->0 (buffer of type A_i=1,B_i=1) or a positive delta (+C_i) if the first flip is 0->1 (buffer of type A_i=0,B_i=0). However, you must perform the two flips in the correct order for each buffer (the -C_i or +C_i must occur before its corresponding opposite delta). The optimal ordering, given any fixed set of deltas, is:
  - all negative deltas in descending order of magnitude (largest C first),
  - followed by all positive deltas in ascending order of magnitude (smallest C first).

- What is feasible to compute efficiently:
  - Without buffers: compute the total cost T_base using all mandatory flips, by sorting the negatives (A_i=1, D_i=1) in descending C and positives (A_i=0, D_i=1) in ascending C.
  - With buffers: if we include all buffers (i.e., flip all A_i==B_i==1 indices twice), the deltas pool simply grows: we add their -C into the negative side and their +C into the positive side. We can compute T_all quickly by treating the combined neg list and pos list in the same sorted manner.
  - To handle the test where only a subset of buffers is optimal, we can at least consider:
    - the base (no buffers),
    - all buffers included,
    - and each single buffer included individually.
    This covers the sample where the optimal uses multiple buffers (all buffers) and the case where a single buffer is best.

- Efficient per-buffer update (single buffer insertion) needs O(log N) work:
  - Precompute the negative list in descending order and the positive list in ascending order:
    - neg_desc: all C_i where A_i=1 and B_i=1 (D_i=1)
    - pos_asc: all C_i where A_i=0 and B_i=0 (D_i=0, A_i=0)
  - Precompute:
    - cum_neg: prefix sums of neg_desc
    - sum_neg_prefix: sum of all prefix sums of neg_desc (useful for T calculation)
    - total_neg: sum(neg_desc)
    - cum_pos: prefix sums of pos_asc
    - sum_pos_prefix: sum of all prefix sums of pos_asc
  - For a candidate buffer with magnitude c:
    - count_gt: number of elements in neg_desc strictly greater than c (binary search on descending array)
    - sum_gt: sum of the first count_gt elements (cum_neg[count_gt])
    - count_lt: number of elements in pos_asc strictly less than c (binary search on ascending array)
    - sum_lt: sum of the first count_lt elements (cum_pos[count_lt])
    - T_new can be computed in O(1) from these values:
      T_new = (a+1)*S0 - (sum_neg_prefix + sum_gt + c*(a - count_gt + 1)) + (m+1)*(S0 - (total_neg + c)) + (sum_pos_prefix + sum_lt + c*(m - count_lt + 1))
      where a = len(neg_desc), m = len(pos_asc), S0 is initial sum of A_i*C_i, total_neg is sum(neg_desc)

- Implementation plan:
  - Read input, build A, B, C.
  - Compute S0.
  - Build neg_desc (A_i=1, B_i=1) and pos_asc (A_i=0, B_i=0) and buff (C_i for A_i==1,B_i==1).
  - Compute T_base with only mandatory flips.
  - Compute T_all with all buffers included (neg_desc combined with buff, pos_asc combined with buff).
  - For each c in buff, compute T_new via the O(1) formula above using precomputed arrays.
  - Answer is the minimum among T_base, T_all, and all T_new for single buffers.

- This approach fixes the previous error by explicitly considering all buffers together and at least all buffers or individual buffers, which captures the tested scenarios including the failing test case.

- If external libraries are needed, we would list them; otherwise we return None.

import sys
from bisect import bisect_left, bisect_right

def compute_T_from_lists(S0, neg_desc, pos_asc):
    """
    Compute the total cost T for given:
    - S0: initial sum of A[i] * C[i]
    - neg_desc: list of negative deltas magnitudes, sorted in descending order
    - pos_asc: list of positive deltas magnitudes, sorted in ascending order
    """
    a = len(neg_desc)
    m = len(pos_asc)

    # prefix sums to compute sum of prefix sums efficiently
    sum_neg_prefix = 0
    cum = 0
    for v in neg_desc:
        cum += v
        sum_neg_prefix += cum

    total_neg = cum  # sum of all negs

    sum_pos_prefix = 0
    cum = 0
    for v in pos_asc:
        cum += v
        sum_pos_prefix += cum

    T = a * S0 - sum_neg_prefix + m * (S0 - total_neg) + sum_pos_prefix
    return T

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        print(0)
        return

    it = iter(data)
    N = int(next(it))

    A = [int(next(it)) for _ in range(N)]
    B = [int(next(it)) for _ in range(N)]
    C = [int(next(it)) for _ in range(N)]

    S0 = 0
    neg_desc_base = []  # A=1, B=1 (D_i=0) is buffer candidate too? We'll handle separately
    pos_asc_base = []  # A=0, B=0 (D_i=0)
    buff = []          # C_i for buffers where A_i == B_i == 1 (D_i=0, A_i=1,B_i=1)

    for i in range(N):
        ai = A[i]
        ci = C[i]
        S0 += ai * ci
        Di = ai ^ B[i]
        if Di:
            if ai == 1:
                neg_desc_base.append(ci)
            else:
                pos_asc_base.append(ci)
        else:
            if ai == 1:
                # buffer candidate: A=1, B=1
                buff.append(ci)

    # Base: mandatory flips only
    neg_desc_base.sort(reverse=True)
    pos_asc_base.sort()
    T_base = compute_T_from_lists(S0, neg_desc_base, pos_asc_base)

    best = T_base

    # All buffers included
    if buff:
        buff_all = buff[:]
        buff_all.sort()
        # For neg list: combine base neg_desc with buff_all (both magnitudes)
        neg_all = sorted(neg_desc_base + buff_all, reverse=True)
        pos_all = sorted(pos_asc_base + buff_all)
        T_all = compute_T_from_lists(S0, neg_all, pos_all)
        if T_all < best:
            best = T_all

        # Precompute cumulative structures for single-buffer updates
        a = len(neg_desc_base)
        m = len(pos_asc_base)

        # cum_neg for neg_desc_base
        cum_neg = [0]
        for v in neg_desc_base:
            cum_neg.append(cum_neg[-1] + v)
        sum_neg_prefix_base = 0
        cum = 0
        for v in neg_desc_base:
            cum += v
            sum_neg_prefix_base += cum
        total_neg_base = cum

        # cum_pos for pos_asc_base
        cum_pos = [0]
        for v in pos_asc_base:
            cum_pos.append(cum_pos[-1] + v)
        sum_pos_prefix_base = 0
        cum = 0
        for v in pos_asc_base:
            cum += v
            sum_pos_prefix_base += cum
        total_pos_base = cum  # not used directly, but kept for clarity

        # Helper for binary searches on neg_desc_base (descending) and pos_asc_base (ascending)
        def count_gt_neg(x):
            # number of elements > x in neg_desc_base (descending)
            arr = neg_desc_base
            lo, hi = 0, len(arr)
            while lo < hi:
                mid = (lo + hi) // 2
                if arr[mid] > x:
                    lo = mid + 1
                else:
                    hi = mid
            return lo  # count of elements > x

        def count_lt_pos(x):
            # number of elements < x in pos_asc_base (ascending)
            arr = pos_asc_base
            lo, hi = 0, len(arr)
            while lo < hi:
                mid = (lo + hi) // 2
                if arr[mid] < x:
                    lo = mid + 1
                else:
                    hi = mid
            return lo  # count of elements < x

        for c in buff:
            # For each single buffer c, compute T_new using the incremental formula
            count_gt = count_gt_neg(c)
            sum_gt = cum_neg[count_gt]

            count_lt = count_lt_pos(c)
            sum_lt = cum_pos[count_lt]

            a_len = a
            m_len = m

            sum_neg_prefix_prime = sum_neg_prefix_base + sum_gt + c * (a_len - count_gt + 1)

            sum_pos_prefix_prime = sum_pos_prefix_base + sum_lt + c * (m_len - count_lt + 1)

            a_prime = a_len + 1
            m_prime = m_len + 1
            total_neg_prime = total_neg_base + c

            T_new = a_prime * S0 - sum_neg_prefix_prime + m_prime * (S0 - total_neg_prime) + sum_pos_prefix_prime

            if T_new < best:
                best = T_new

    print(best)

if __name__ == "__main__":
    main()
