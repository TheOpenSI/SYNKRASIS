### Step-by-step reasoning
- For any subarray [l..r], the minimal number of increments needed to make it non-decreasing equals the sum of deficits against the running prefix maximum as we scan from left to right:
  - Let M be the running maximum of a[l], a[l+1], ..., a[i-1].
  - If a[i] < M, we need to increment a[i] by M - a[i]; otherwise M becomes a[i].
  - The total cost for the subarray is the sum of these deficits over i in [l+1..r].
- This can be viewed as a sequence of blocks defined by the positions where a new maximum occurs (record highs). If i_j is a record high (a[i_j] is greater than all previous elements in the subarray) and i_{j+1} is the next record high, then the block j covers indices [i_j, i_{j+1}-1] with M_j = a[i_j]. The block’s deficit is:
  - C_j = M_j * (i_{j+1} - i_j) - sum(a[i_j .. i_{j+1}-1])
  - Note: The first element i_j contributes zero deficit since M_j = a[i_j].
- For a fixed left index l, the subarray [l..r] spends full blocks until some i_t, after which the right end could be inside the current block. The total cost up to completing t blocks is sum_{j=0..t-1} C_j.
- We can precompute and accelerate counting:
  - Build the next greater to the right (NGR) pointers: ngr[i] = smallest j > i with a[j] > a[i], or -1 if none.
  - Define block starts as i, and the next block start as nextStart[i] = (ngr[i] != -1 ? ngr[i] : n). The block i covers [i, nextStart[i]-1] with cost C[i] = a[i] * (nextStart[i]-i) - (pref[nextStart[i]] - pref[i]).
  - Add a sentinel index n to simplify handling the last block. For the sentinel, nextStart[n] = n and cost would be 0.
  - Build binary lifting tables over the block-start graph:
    - up[i][t] = the block-start after taking 2^t full blocks starting at i
    - cost[i][t] = total cost of those 2^t full blocks
    - Size of tables is (n+1) x LOG, where LOG = (n+1).bit_length()
- For each left index l:
  - Start at cur = l and rem = k.
  - Use binary lifting to take as many full blocks as possible within rem:
    - For t from LOG-1 down to 0: if rem >= cost[cur][t], then rem -= cost[cur][t], cur = up[cur][t].
  - If cur == n, all remaining blocks fit; maxR = n-1, contribute n - l subarrays.
  - Otherwise, we are at the start of the next block cur, which ends at endCur = nextStart[cur] - 1. The remaining budget rem can extend within this current block. Compute the maximum r in [cur, endCur] such that:
    - deficit(cur, r) = a[cur] * (r - cur + 1) - (pref[r+1] - pref[cur]) <= rem.
    - Use a binary search on r to find the largest valid r.
  - The number of valid subarrays starting at l is maxR - l + 1, where maxR is the r found (or n-1 if we consumed to the end).
- This approach runs in O(n log n) time overall (preprocessing + per-left processing) and handles large inputs efficiently.

from typing import List

class Solution:
    def countNonDecreasingSubarrays(self, nums: List[int], k: int) -> int:
        n = len(nums)
        a = nums

        # Prefix sums for quick range sums
        pref = [0] * (n + 1)
        for i in range(n):
            pref[i + 1] = pref[i] + a[i]

        # Next Greater to Right (strictly greater)
        ngr = [-1] * n
        stack = []
        for i in range(n - 1, -1, -1):
            while stack and a[stack[-1]] <= a[i]:
                stack.pop()
            if stack:
                ngr[i] = stack[-1]
            else:
                ngr[i] = -1
            stack.append(i)

        # nextStart[i] = start index of the next block after i
        # If no next greater, nextStart[i] = n (sentinel)
        nextStart = [0] * (n + 1)
        for i in range(n):
            nextStart[i] = ngr[i] if ngr[i] != -1 else n
        nextStart[n] = n  # sentinel

        # Cost of the block starting at i: C[i] = a[i] * (end - i) - sum(a[i..end-1])
        C = [0] * (n + 1)
        for i in range(n):
            end = nextStart[i]
            C[i] = a[i] * (end - i) - (pref[end] - pref[i])
        C[n] = 0

        # Binary lifting over blocks
        # We consider states i in [0..n], where i = n is the sentinel (no more blocks)
        LOG = (n + 1).bit_length()
        up = [[n] * LOG for _ in range(n + 1)]
        cost = [[0] * LOG for _ in range(n + 1)]

        for i in range(n + 1):
            if i < n:
                up[i][0] = nextStart[i]
                cost[i][0] = C[i]
            else:
                up[i][0] = n
                cost[i][0] = 0

        for j in range(1, LOG):
            for i in range(n + 1):
                mid = up[i][j - 1]
                if mid != n:
                    up[i][j] = up[mid][j - 1]
                    cost[i][j] = cost[i][j - 1] + cost[mid][j - 1]
                else:
                    up[i][j] = n
                    cost[i][j] = cost[i][j - 1]

        ans = 0

        for l in range(n):
            rem = k
            cur = l
            # take as many full blocks as possible
            for t in range(LOG - 1, -1, -1):
                nxt = up[cur][t]
                if rem >= cost[cur][t]:
                    rem -= cost[cur][t]
                    cur = nxt
            if cur == n:
                ans += n - l
                continue

            endCur = nextStart[cur]  # the end+1 position of current block
            # Binary search within current block [cur, endCur-1] for maximum r with deficit <= rem
            low = cur
            high = endCur - 1
            best = cur
            while low <= high:
                mid = (low + high) // 2
                deficit = a[cur] * (mid - cur + 1) - (pref[mid + 1] - pref[cur])
                if deficit <= rem:
                    best = mid
                    low = mid + 1
                else:
                    high = mid - 1

            maxR = best
            ans += maxR - l + 1

        return ans
