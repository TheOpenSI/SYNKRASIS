### Step-by-step reasoning
- Understand the operations:
  - Swap: you can swap any adjacent pair in the current sequence.
  - Delete prefix: if the first i elements are all equal, you may delete those i elements in one operation (i can range from 1 to the current length).
- Key observation: Deleting is always done on a prefix of identical values. It is optimal to delete the entire first run (the whole prefix of the current front value) in one operation rather than partial deletions, because partial deletions would require more operations later to remove the rest of that run.
- Represent the sequence as runs: A sequence A can be compressed into runs of the form (color, length). Let the number of runs be M.
- What effect can swaps have to reduce the total number of operations?
  - A swap can only affect boundaries between runs. The only beneficial swap pattern is when we have a sequence of three consecutive runs of the form A^x, B^y, A^z (i.e., colors A, B, A with the middle run having length y).
  - If the middle run length y equals 1, a single swap can “connect” the two A runs in a way that reduces the number of separate blocks in the sequence, enabling one fewer deletion later. Intuitively, after dealing with such a triple, we can delete one more block of A in a single deletion than we could without the swap.
  - When y > 1, a single swap does not yield the same beneficial effect, and doing swaps to merge the two A runs would require moving the middle B run across several elements, which is not advantageous given the deletion rule.
- Therefore, the only beneficial swap-merge opportunities come from triples of consecutive runs (A^x, B^y, A^z) with y = 1 and the outer colors equal (A == A).
- If we can select k such non-overlapping triples, each triple yields a benefit of reducing the total number of operations by 1 (compared to deleting runs individually). If the original number of runs is M, and we can take k non-overlapping beneficial triples, the minimal total number of operations becomes M - k.
- This reduces to a simple DP on the list of runs:
  - Let colors[i] be the color of the i-th run and lengths[i] be its length.
  - A “good” start index i is when:
    - i <= M - 3
    - colors[i] == colors[i+2]
    - lengths[i+1] == 1
  - DP recurrence (traversed from right to left):
    - dp[i] = dp[i+1] if the triple starting at i is not good
    - If the triple is good: dp[i] = max(dp[i+1], 1 + dp[i+3])
  - The answer for a test case is M - dp[0].
- Complexity:
  - Building runs is O(N).
  - DP on M runs is O(M) per test case.
  - Sum of N over all test cases is at most 2e5, so this runs efficiently.

This approach aligns with the provided sample cases and handles typical edge cases (no duplicates, all distinct, etc.).

import sys

def min_operations_for_case(N, A):
    # Build run-length encoding: colors and their run lengths
    colors = []
    lengths = []
    if N == 0:
        return 0
    cur = A[0]
    cnt = 1
    for x in A[1:]:
        if x == cur:
            cnt += 1
        else:
            colors.append(cur)
            lengths.append(cnt)
            cur = x
            cnt = 1
    colors.append(cur)
    lengths.append(cnt)

    M = len(colors)
    if M == 0:
        return 0

    # DP to maximize number of non-overlapping good triples
    # A good triple starts at i if:
    #   i <= M-3
    #   colors[i] == colors[i+2]
    #   lengths[i+1] == 1
    dp = [0] * (M + 4)  # extra space to avoid bounds
    for i in range(M - 1, -1, -1):
        best = dp[i + 1]  # skip starting at i
        if i <= M - 3 and colors[i] == colors[i + 2] and lengths[i + 1] == 1:
            val = 1 + dp[i + 3]
            if val > best:
                best = val
        dp[i] = best

    return M - dp[0]

def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    idx = 1
    out_lines = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        A = list(map(int, data[idx:idx+n])); idx += n
        out_lines.append(str(min_operations_for_case(n, A)))
    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
