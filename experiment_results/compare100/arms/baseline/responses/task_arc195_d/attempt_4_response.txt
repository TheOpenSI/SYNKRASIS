### Step-by-step reasoning
- We model the sequence A by runs: consecutive equal values as (color, length). Let the number of runs be M.
- The only way to reduce the number of runs efficiently is by making a swap that merges three consecutive runs of the form A^x, B^y, A^z where the middle run has length y = 1 and the outer colors are the same (color(A) == color(A)). After such a swap, those three runs become a single run A^{x+z}, so the total number of runs decreases by 2. This swap costs 1 operation.
- If we perform k such disjoint reductions, the number of runs reduces by 2k, and we spent k operations on swaps. The remaining runs count becomes M - 2k, which must be deleted one-by-one, costing (M - 2k) operations. Total operations = k + (M - 2k) = M - k.
- Therefore, the goal is to maximize the number k of disjoint (non-overlapping) triples (A^x, B^y, A^z) with:
  - color of 1st and 3rd runs equal,
  - middle run length y = 1.
- This is a classic DP-on-runs problem: scan the run list and pick non-overlapping triples to maximize their count.
  - good starting index i (0-based) if i <= M-3 and colors[i] == colors[i+2] and lengths[i+1] == 1.
  - DP recurrence: dp[i] = max(dp[i+1], 1 + dp[i+3]) if the triple starting at i is good; else dp[i] = dp[i+1].
  - Answer for a test case: M - dp[0].
- Complexity: Building the run-length encoding is O(N). The DP runs in O(M). Across all test cases, the sum of N is at most 2e5, so this is efficient.

This approach matches the provided samples (e.g., the third sample yields 3 reductions, so 11 runs - 3 reductions = 8 total operations).

import sys

def min_operations_for_case(N, A):
    # Build run-length encoding: colors and their run lengths
    colors = []
    lengths = []
    if N == 0:
        return 0
    cur = A[0]
    cnt = 1
    for x in A[1:]:
        if x == cur:
            cnt += 1
        else:
            colors.append(cur)
            lengths.append(cnt)
            cur = x
            cnt = 1
    colors.append(cur)
    lengths.append(cnt)

    M = len(colors)
    if M == 0:
        return 0

    # DP to maximize number of non-overlapping valid triples
    # A valid triple starts at i if:
    #   i <= M-3
    #   colors[i] == colors[i+2]
    #   lengths[i+1] == 1
    dp = [0] * (M + 4)  # extra space to avoid bounds
    for i in range(M - 1, -1, -1):
        best = dp[i + 1]  # skip starting at i
        if i <= M - 3 and colors[i] == colors[i + 2] and lengths[i + 1] == 1:
            val = 1 + dp[i + 3]
            if val > best:
                best = val
        dp[i] = best

    return M - dp[0]

def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    idx = 1
    out_lines = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        A = list(map(int, data[idx:idx+n])); idx += n
        out_lines.append(str(min_operations_for_case(n, A)))
    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
