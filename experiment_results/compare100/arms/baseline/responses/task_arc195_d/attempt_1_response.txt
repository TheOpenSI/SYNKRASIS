### Step-by-step reasoning
- Represent the sequence as runs: colors and their consecutive lengths. Let M be the number of runs.
- Operation 2 (deleting a prefix that is all equal) effectively deletes a whole run in one go. If we do no swaps, we need M deletions.
- A single swap can help reduce the number of runs by 2 exactly when we have a triple of consecutive runs of the form:
  - color[i] == color[i+2], and the middle run i+1 has length exactly 1.
  - In that case, one swap can merge the outer runs into one run and also merge the two adjacent runs of the middle color (as shown in examples).
- If the middle run has length > 1, merging the two outer runs with a single swap is not possible; such a merge would require multiple swaps and does not yield the immediate 2-run reduction per swap that we can count as one operation in the optimal strategy.
- Therefore, the only useful “swap” operations that give a clean 2-run reduction are those corresponding to valid triples with len[i+1] = 1 and colors[i] = colors[i+2].
- After performing k such disjoint swaps (each swap reduces M by 2), the remaining number of deletions is M - 2k. The total number of operations is:
  total_ops = k (swaps) + (M - 2k) = M - k.
- We want to maximize k, the number of non-overlapping valid triples we can apply in sequence. A dynamic programming approach over the run list can find the maximum number of non-overlapping valid triples.
- DP formulation:
  - Let good(i) be true if i <= M-3, colors[i] == colors[i+2], and lengths[i+1] == 1.
  - dp[i] = maximum number of swaps we can perform starting from run i to the end.
  - Transition:
    - skip i: dp[i] = dp[i+1]
    - take triple at i (if good(i)): 1 + dp[i+3]
  - dp[M] = dp[M+1] = dp[M+2] = 0 as base cases.
  - Answer for a test case: M - dp[0].
- Complexity: Building runs is O(N). DP over M runs is O(M). The sum of N over all tests is up to 2e5, so this is fast enough.

- Edge cases:
  - If M < 3, no triple exists; answer is M.
  - The DP handles all cases in linear time in the number of runs.

None

### Code

import sys

def min_operations_for_case(N, A):
    # Build run-length encoding: colors and their run lengths
    colors = []
    lengths = []
    if N == 0:
        return 0
    cur = A[0]
    cnt = 1
    for x in A[1:]:
        if x == cur:
            cnt += 1
        else:
            colors.append(cur)
            lengths.append(cnt)
            cur = x
            cnt = 1
    colors.append(cur)
    lengths.append(cnt)

    M = len(colors)
    if M == 0:
        return 0

    # DP to maximize number of non-overlapping valid triples
    dp = [0] * (M + 4)  # extra space to avoid bounds
    for i in range(M - 1, -1, -1):
        best = dp[i + 1]  # skip starting at i
        if i <= M - 3 and colors[i] == colors[i + 2] and lengths[i + 1] == 1:
            val = 1 + dp[i + 3]
            if val > best:
                best = val
        dp[i] = best

    return M - dp[0]

def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    idx = 1
    out_lines = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        A = list(map(int, data[idx:idx+n])); idx += n
        out_lines.append(str(min_operations_for_case(n, A)))
    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
