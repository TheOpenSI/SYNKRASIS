### Step-by-step reasoning
- Represent the sequence as runs of consecutive equal values: (color1, len1), (color2, len2), ..., (colorm, lenm). Let M be the number of runs.
- Deleting a prefix that is all equal can remove the entire first run in one operation, but deleting only part of the first run does not reduce the number of runs. So, the only operation that reduces the number of runs by more than 0 is a swap that merges runs.
- A single swap can collapse three consecutive runs (a^x, b^y, a^z) into one run of color a if the middle run has length y = 1 and the outer colors are the same (color(a) == color(a)). In that case, after the swap, the three runs become a single run, reducing the total run count by 2. This is the only beneficial swap pattern to reduce the number of runs efficiently.
- Therefore, the optimal strategy is:
  - Count how many disjoint triples of consecutive runs i, i+1, i+2 satisfy:
    - colors[i] == colors[i+2]
    - lengths[i+1] == 1
  - Each such non-overlapping triple can be executed as one swap, reducing M by 2.
  - After performing all such swaps, the remaining runs (M - 2k) can be deleted from the front one by one, costing one operation per run. Total operations = k swaps + (M - 2k) deletions = M - k.
- To maximize k (the number of disjoint beneficial triples), use dynamic programming along the run list:
  - good(i) is true if i <= M-3, colors[i] == colors[i+2], and lengths[i+1] == 1.
  - dp[i] = maximum number of swaps achievable starting from run i to the end.
  - Transitions:
    - Skip the triple starting at i: dp[i] = dp[i+1]
    - If good(i): dp[i] = max(dp[i], 1 + dp[i+3])
  - Base: dp[M] = dp[M+1] = dp[M+2] = 0
- Answer for a test case: M - dp[0].
- Complexity: Building runs is O(N). DP over M runs is O(M). The sum of N over all tests is at most 2e5, so this runs efficiently.

None

import sys

def min_operations_for_case(N, A):
    # Build run-length encoding: colors and their run lengths
    colors = []
    lengths = []
    if N == 0:
        return 0
    cur = A[0]
    cnt = 1
    for x in A[1:]:
        if x == cur:
            cnt += 1
        else:
            colors.append(cur)
            lengths.append(cnt)
            cur = x
            cnt = 1
    colors.append(cur)
    lengths.append(cnt)

    M = len(colors)
    if M == 0:
        return 0

    # DP to maximize number of non-overlapping valid triples
    dp = [0] * (M + 4)  # extra space to avoid bounds
    for i in range(M - 1, -1, -1):
        best = dp[i + 1]  # skip starting at i
        if i <= M - 3 and colors[i] == colors[i + 2] and lengths[i + 1] == 1:
            val = 1 + dp[i + 3]
            if val > best:
                best = val
        dp[i] = best

    return M - dp[0]

def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    idx = 1
    out_lines = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        A = list(map(int, data[idx:idx+n])); idx += n
        out_lines.append(str(min_operations_for_case(n, A)))
    print("\n".join(out_lines))

if __name__ == "__main__":
    main()
