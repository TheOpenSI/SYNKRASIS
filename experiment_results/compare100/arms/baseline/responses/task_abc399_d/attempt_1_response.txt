### Step-by-step reasoning
- Let A be a sequence of length 2N where each number 1..N appears exactly twice. For a pair (a, b) with a < b to be valid, we must be able to end up with the two a’s adjacent and the two b’s adjacent by swapping an a with a b (repeatedly), with the additional requirement that initially neither the a’s nor the b’s are adjacent.
- Key observation: The only way to place two a’s adjacent after swaps is to have the four positions that currently hold {a, b} form two disjoint adjacent pairs in the array, i.e., two blocks {i, i+1} and {j, j+1} with i+1 < j, and each block contains one a and one b (in some order). After a sequence of allowed swaps, we can move the a’s into one of these two blocks and the b’s into the other block.
- Therefore, the problem reduces to looking at all adjacent pairs in A that consist of {a, b} (unordered). Each such occurrence defines a position i where A[i], A[i+1] are {a, b}. For a fixed unordered pair {a, b}, collect all starting indices i of such adjacent AB pairs and their orientation.
  - Orientation o = 0 if A[i] = min(a,b) and A[i+1] = max(a,b); o = 1 if A[i] = max(a,b) and A[i+1] = min(a,b).
- If there exist two occurrences i < j of the same unordered pair {a, b} that are non-overlapping (i.e., j - i >= 3), then the two AB blocks are disjoint and not adjacent, and the pair is valid.
- If the two occurrences are exactly adjacent blocks (j = i + 2), then adjacency of a or b initially happens exactly when the orientations are opposite (one block is (a, b) and the next is (b, a)). The pair is valid iff the orientations are the same (both (a, b) or both (b, a)).
- If there are more than two AB occurrences, it suffices to check against the earliest occurrence i0 for that pair:
  - If there exists any later occurrence i with i - i0 >= 3, then valid.
  - Else if there exists i with i - i0 == 2 and orientation matches the earliest orientation, then valid.
  - Otherwise, not valid.
- We count each unordered pair {a, b} at most once.

This approach runs in O(2N) per test case (linear in the array length) and uses O(number of distinct AB pairs) extra memory. The sum of N across all tests is at most 2e5, so this is efficient.

### Code
```
import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    t = data[0]
    idx = 1
    outputs = []
    for _ in range(t):
        n = data[idx]; idx += 1
        A = data[idx: idx + 2 * n]; idx += 2 * n

        # For each unordered pair p = (a,b) with a < b, store:
        # - i0: index of the first occurrence of adjacent AB pair (i, i+1) with {A[i], A[i+1]} = {a,b}
        # - o0: orientation of the first occurrence (0 if A[i]=a,A[i+1]=b; 1 if A[i]=b,A[i+1]=a)
        # - valid: whether this pair is already determined valid
        first_i = {}   # key: (a,b) -> i0
        first_o = {}   # key: (a,b) -> o0
        is_valid = {}  # key: (a,b) -> bool

        m = 2 * n
        for i in range(m - 1):
            x = A[i]
            y = A[i + 1]
            if x == y:
                continue
            if x < y:
                p = (x, y)
                o = 0  # A[i] = p[0], A[i+1] = p[1]
            else:
                p = (y, x)
                o = 1  # A[i] = p[1], A[i+1] = p[0]

            if p not in first_i:
                first_i[p] = i
                first_o[p] = o
                is_valid[p] = False
            else:
                i0 = first_i[p]
                o0 = first_o[p]
                if not is_valid[p]:
                    diff = i - i0
                    if diff >= 3:
                        is_valid[p] = True
                    elif diff == 2 and o == o0:
                        is_valid[p] = True
                    # else remain not valid yet

        ans = sum(1 for v in is_valid.values() if v)
        outputs.append(str(ans))

    print("\n".join(outputs))

if __name__ == "__main__":
    solve()
```
