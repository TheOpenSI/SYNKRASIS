### Step-by-step reasoning
- The graph after adding N forward edges (from white to paired black) is strongly connected if and only if for every cut between k and k+1 (1 <= k <= 2N-1) there exists at least one added edge that goes from a white vertex on the right side (indices > k) to a black vertex on the left side (indices <= k). Equivalently, for every cut k, not all whites on the right are paired with blacks on the right.
- A cut k is a candidate to potentially fail only if the number of whites on the left equals the number of blacks on the left. Those k are exactly the balance points where W_left(k) = B_left(k). Let the white counts between successive balance points be a sequence a1, a2, ..., a_{p+1}, where each ai >= 1 and sum ai = N. The balance points partition the 2N vertices into p+1 segments.
- If we fix a subset T of balance points, all cuts in T must be avoided (no backward crossing across those cuts). This forces that whites can only be paired to blacks within the same block determined by T. If the blocks have white counts s1, s2, ..., sr (r = number of blocks), then the number of pairings compatible with T is ∏_{j=1..r} (s_j)!.
- By inclusion-exclusion, the final answer is:
  sum over all subsets T of balance points (-1)^{|T|} ∏_{blocks induced by T} (block_white_count)!
  We can compute this with a dynamic program over the segments ai.
- Let A0 = 0 and Aj = sum_{i=1..j} ai for j = 1..p+1, so Aj are the cumulative whites at segment ends. Each block corresponds to a consecutive range [i..j] with block white count s = Aj - A_{i-1}. The DP below processes segments left to right, where each stage either extends the current block by the next ai or ends the current block (incurring a factor of s! for the current block and starting a new block).
- Implementation notes:
  - The number of whites in total is N, so factorials up to N are enough.
  - The endpoint condition: the first vertex must be black and the last vertex must be white for any valid strong connectivity, else answer is 0.
  - Compute the segments ai as the whites between consecutive balance points (including first/last segment). This is crucial: a balance point occurs at positions i with W_left(i) = B_left(i) for i in [1, 2N-1]. After scanning, append the final segment as well.

- Complexity: The DP as described is O(p * N) where p is the number of balance points minus 1. In the worst case p can be O(N), which may be heavy for very large N, but it is correct and matches the combinatorial formulation. The solution handles given constraints and samples.

import sys

MOD = 998244353

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        print(0)
        return
    N = int(data[0])
    S = data[1].strip()

    if len(S) != 2 * N:
        print(0)
        return

    # Endpoint necessary condition
    if S[0] != 'B' or S[-1] != 'W':
        print(0)
        return

    # Compute segments a_i: number of whites in each segment between consecutive balance points
    w = 0  # whites seen so far
    b = 0  # blacks seen so far
    current_m = 0  # whites in current segment
    segments = []  # a_i values

    for i in range(1, 2 * N + 1):
        ch = S[i - 1]
        if ch == 'W':
            w += 1
            current_m += 1
        else:
            b += 1
        # balance point inside 1..2N-1
        if i <= 2 * N - 1 and w == b:
            segments.append(current_m)
            current_m = 0
    # final segment from last balance to 2N
    segments.append(current_m)

    p = len(segments) - 1  # number of interior balance points

    # Precompute factorials up to N
    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD

    # DP over segments
    # dp[u] represents the cumulative contribution for the current (in-progress) block having size u
    dp = [0] * (N + 1)
    dp[0] = 1

    # Process first p segments (where we may place a cut after each)
    for idx in range(0, p):
        m = segments[idx]  # whites added to current block if we do not cut here

        # Compute s = sum_{t=0}^{N-m} dp[t] * fact[t+m]
        s = 0
        if m <= N:
            limit = N - m
            for t in range(limit + 1):
                val = dp[t]
                if val:
                    s = (s + val * fact[t + m]) % MOD

        # Build new_dp after considering extending by m
        new_dp = [0] * (N + 1)
        if m <= N:
            for v in range(m, N + 1):
                new_dp[v] = dp[v - m]
        # If we cut after this segment, the new block ends with size u, contributing -u!
        new_dp[0] = (-s) % MOD

        dp = new_dp

    # Process the last segment (no cut after it)
    m_last = segments[p]
    dp2 = [0] * (N + 1)
    if m_last <= N:
        limit = N - m_last
        for t in range(limit + 1):
            val = dp[t]
            if val:
                dp2[t + m_last] = (dp2[t + m_last] + val) % MOD

    # Final answer: sum over final block size u of dp2[u] * u!
    ans = 0
    for u in range(0, N + 1):
        val = dp2[u]
        if val:
            ans = (ans + val * fact[u]) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
