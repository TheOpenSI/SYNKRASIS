### Step-by-step reasoning
- The problem reduces to counting perfect matchings between white and black vertices such that the added edges (white -> paired black) together with the fixed chain edges 1->2->...->2N make a strongly connected directed graph.
- A known approach uses inclusion-exclusion over the cuts defined by balance points. Let a_i be the number of white vertices in each elementary segment between consecutive balance points (including the initial segment from the start to the first balance point and the final segment after the last balance point). There are p balance points (interior), hence p+1 segments with a_i >= 1 and sum a_i = N.
- For a fixed subset of balance points T, the graph is strongly connected iff at every cut (balance point in T) there is at least one cross edge going from the right side to the left side. Equivalently, whites and blacks within each block (consecutive segments determined by T) must pair internally. The number of valid pairings for a given partition into blocks is the product over blocks of (block_white_count)!.
- Therefore, by inclusion-exclusion over the p balance points, the answer is:
  sum over all ways to partition the sequence of segments a_1, ..., a_{p+1} into consecutive blocks of sizes s_1, ..., s_r (where s_j = sum of a_i in block j) of (-1)^{r-1} * product_j (s_j)!
- This leads to a dynamic programming approach that processes the segments left-to-right, maintaining the current open block white count s. You either continue the current block by adding the next a_i, or you end the current block (which contributes -s! to account for the inclusion-exclusion sign) and start a new block with the next a_i.
- A practical implementation keeps track of the possible current block sums s (from the concatenation of consecutive a_i's) and uses a scalar G = sum_s dp[s] * s! to efficiently account for ending a block: ending adds -G and restarts the next block with the next a_i.
- Finally, after processing all segments, the last block must be closed, contributing its factorial s! to the total. The total sum modulo 998244353 is the answer.

Note: The endpoint condition (first vertex must be black, last white) is necessary for strong connectivity in this setup; if violated, the answer is 0.

```
import sys

MOD = 998244353

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        print(0)
        return
    N = int(data[0])
    S = data[1].strip()

    # Endpoint necessary condition
    if S[0] != 'B' or S[-1] != 'W':
        print(0)
        return

    # Compute segments a_i: number of whites in each segment between consecutive balance points
    w = 0  # whites seen so far
    b = 0  # blacks seen so far
    current_m = 0  # whites in current segment
    segments = []  # a_i values

    for i in range(1, 2 * N + 1):
        ch = S[i - 1]
        if ch == 'W':
            w += 1
            current_m += 1
        else:
            b += 1
        # balance point inside 1..2N-1
        if i <= 2 * N - 1 and w == b:
            segments.append(current_m)
            current_m = 0
    # final segment from last balance to 2N
    segments.append(current_m)

    p = len(segments) - 1  # number of interior balance points

    # Precompute factorials up to N
    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD

    # DP over segments with the "open block" idea
    # dp[s] = total contribution for current open block having sum s (mod MOD)

    dp = [0] * (N + 1)
    # initialize with the first segment being the first open block
    m1 = segments[0]
    if m1 <= N:
        dp[m1] = 1

    # process interior segments: for i = 1 .. p, incorporate a_{i+1}
    for idx in range(1, p + 1):
        a = segments[idx]

        # Compute G = sum_{s} dp[s] * fact[s]
        G = 0
        for s, val in enumerate(dp):
            if val:
                G = (G + val * fact[s]) % MOD

        # Build new_dp by shifting the current blocks by a (continue current block)
        new_dp = [0] * (N + 1)
        if a <= N:
            for s in range(N - a + 1):
                val = dp[s]
                if val:
                    new_dp[s + a] = (new_dp[s + a] + val) % MOD

        # Ending the current block before starting a new one with sum 0,
        # but since the next block will start with 'a' in the next step, we instead
        # account for ending the previous block by placing a contribution at sum=0
        # and letting the next iteration add 'a'. Here we implement the variant
        # where ending a block inserts -G into dp[0].
        new_dp[0] = (-G) % MOD

        dp = new_dp

    # After processing all segments, we must close the final open block
    # Final answer is sum_{s} dp[s] * s!
    ans = 0
    for s, val in enumerate(dp):
        if val:
            ans = (ans + val * fact[s]) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```
