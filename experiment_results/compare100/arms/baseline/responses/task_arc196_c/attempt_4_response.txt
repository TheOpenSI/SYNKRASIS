### Step-by-step reasoning
- The problem considers a fixed directed chain 1 -> 2 -> ... -> 2N and N extra edges from white vertices to black vertices, determined by a perfect matching between the N white vertices and the N black vertices.
- A necessary and sufficient condition for strong connectivity in such a graph is that for every cut between vertices k and k+1, there exists at least one edge from a white vertex on the right side to a black vertex on the left side. Using inclusion-exclusion over the cuts defined by balance points (prefixes where the number of whites equals the number of blacks) leads to counting partitions of the string into blocks.
- The white/black balance points partition the string into segments. Between two consecutive balance points there are as many whites as blacks, so each segment i contains a_i whites and a_i blacks.
- If we partition the sequence of segments into r consecutive blocks, the i-th block has total whites W_i = sum a_j over that block and total blacks B_i = sum a_j over that block, hence W_i = B_i = s_i where s_i is the sum of a_j in that block.
- For a fixed partition into blocks, the only feasible way to pair whites to blacks (without creating a cross-edge back across a block boundary) is to pair whites and blacks within the same block. Moreover, for block i there are s_i! ways to pair its whites to its blacks. Therefore, for a partition into blocks with block sums s_1, ..., s_r, the number of pairings is product_j s_j!.
- The answer is the inclusion-exclusion sum over all partitions of the segments into consecutive blocks:
  sum over partitions into r blocks of (-1)^(r-1) * product_j (s_j!).
- We can compute this efficiently with a dynamic programming approach that processes the segments left-to-right, maintaining the current open block total whiteness s. When we pass a segment boundary, we have two choices:
  - Extend the current block by adding the next segment (increase s by a_i).
  - Close the current block before this segment, which contributes a factor of - (sum over all current open-block contributions of s! ), then start a new block with the next segment (initial sum becomes a_i in the next step).
- A compact DP keeps dp[s] = total contribution for configurations where the currently open block has total whites s (mod MOD). We also precompute factorials fact[t] = t! for t = 0..N.
- Important implementation detail: define segments a_i as the number of whites in each segment between balance points. To avoid counting an artificial trailing zero-length segment (which could happen if the last balance point is exactly at the end), we compute a_i by scanning the string and recording a segment exactly when the running balance diff (W - B) returns to 0. This yields all a_i > 0 and avoids extra zero-length segments.
- Endpoint condition: strongest connectivity requires the first vertex to be black and the last vertex to be white. If not, the answer is 0.

import sys

MOD = 998244353

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        print(0)
        return
    N = int(data[0])
    S = data[1].strip()

    # Endpoint necessary condition
    if S[0] != 'B' or S[-1] != 'W':
        print(0)
        return

    # Build a_i: number of whites in each segment between consecutive balance points
    diff = 0
    white_in_segment = 0
    segments = []
    for ch in S:
        if ch == 'W':
            diff += 1
            white_in_segment += 1
        else:
            diff -= 1
        if diff == 0:
            segments.append(white_in_segment)
            white_in_segment = 0
    # Note: by construction, the balance ends at the end, and segments are all positive.

    # Number of interior balance points p = len(segments) - 1
    p = len(segments) - 1

    # Precompute factorials up to N
    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD

    # DP over segments with the "open block" idea
    dp = [0] * (N + 1)
    if segments:
        m1 = segments[0]
        if m1 <= N:
            dp[m1] = 1

    # process interior segments: for idx = 1 .. p
    for idx in range(1, p + 1):
        a = segments[idx]

        # G = sum_s dp[s] * s!
        G = 0
        for s, val in enumerate(dp):
            if val:
                G = (G + val * fact[s]) % MOD

        # Extend current block by a (if possible)
        new_dp = [0] * (N + 1)
        if a <= N:
            for s in range(N - a + 1):
                val = dp[s]
                if val:
                    new_dp[s + a] = (new_dp[s + a] + val) % MOD

        # End current block before starting a new one with sum 0, i.e., insert -G into dp[0]
        new_dp[0] = (-G) % MOD

        dp = new_dp

    # After processing all segments, close the final open block
    ans = 0
    for s, val in enumerate(dp):
        if val:
            ans = (ans + val * fact[s]) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
