### Step-by-step reasoning
- The problem models the graph as a fixed forward chain plus N extra edges from white vertices to black vertices, where the black-white pairs form a perfect matching.
- A necessary and sufficient condition for strong connectivity is that for every cut between k and k+1, there exists at least one extra edge crossing from a white on the right side to a black on the left side.
- A known approach reduces the problem by looking at segments between balance points (positions where the number of whites equals blacks up to that index). Let a_i be the number of whites in the i-th segment. The segments form a sequence of positive integers summing to N.
- Using inclusion-exclusion over block partitions of the segments, the number of valid pairings for a fixed partition into r blocks with block sums s_1, ..., s_r is prod_j (s_j!). The final answer is the alternating sum over all partitions: sum over partitions (-1)^(r-1) * prod_j (s_j!).
- This leads to a dynamic programming approach that processes segments left to right, maintaining the contribution of the currently open block (its sum s).
- A bug in the previous implementation was in the transition that starts a new block at the current segment. When closing the current block before the current segment and starting a new block with the current segment as its first piece, the new block’s sum should be a_i, not 0. The previous code incorrectly placed the contribution into dp[0], which caused wrong counts.
- The fix: in the DP transition for each interior segment with a = segments[idx], after computing G = sum_s dp[s] * fact[s], we should:
  - Extend the current open block by a: new_dp[s + a] += dp[s]
  - End the current block before this segment and start a new block whose first segment is this current one: new_dp[a] += -G
- After processing all segments, close the final open block by summing dp[s] * fact[s].
- Additional endpoint condition: the first vertex must be black and the last vertex must be white; otherwise, the answer is 0.

import sys

MOD = 998244353

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        print(0)
        return
    N = int(data[0])
    S = data[1].strip()

    # Endpoint necessary condition
    if not S or S[0] != 'B' or S[-1] != 'W':
        print(0)
        return

    # Build a_i: number of whites in each segment between consecutive balance points
    diff = 0
    white_in_segment = 0
    segments = []
    for ch in S:
        if ch == 'W':
            diff += 1
            white_in_segment += 1
        else:
            diff -= 1
        if diff == 0:
            segments.append(white_in_segment)
            white_in_segment = 0
    # segments should be >0 and sum to N
    if not segments:
        print(0)
        return

    # Number of interior balance points p = len(segments) - 1
    p = len(segments) - 1

    # Precompute factorials up to N
    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD

    # DP over segments with the "open block" idea
    dp = [0] * (N + 1)
    m1 = segments[0]
    if m1 <= N:
        dp[m1] = 1

    # process interior segments: for idx = 1 .. p
    for idx in range(1, p + 1):
        a = segments[idx]

        # G = sum_s dp[s] * s!
        G = 0
        for s, val in enumerate(dp):
            if val:
                G = (G + val * fact[s]) % MOD

        # Extend current block by a (if possible)
        new_dp = [0] * (N + 1)
        if a <= N:
            for s in range(N - a + 1):
                val = dp[s]
                if val:
                    new_dp[s + a] = (new_dp[s + a] + val) % MOD

        # End current block before starting a new one with sum a
        new_dp[a] = (new_dp[a] - G) % MOD

        dp = new_dp

    # After processing all segments, close the final open block
    ans = 0
    for s, val in enumerate(dp):
        if val:
            ans = (ans + val * fact[s]) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
