### Step-by-step reasoning
- Understand the dynamics per column: Blocks never move horizontally. Gravity moves blocks down if the cell below is empty, and removals happen only when the entire bottom row (y = 1) is full at the start of a time step.
- When does removals start? After enough gravity steps, the bottom-most block in each column reaches y = 1. For a column x with its lowest block initially at Y_min_x, this happens after Y_min_x - 1 gravity moves. Removals occur at the beginning of time steps t where the bottom row is full, which happens when all columns have their bottom-most block at y = 1. The earliest such time t is B = max_x Y_min_x. There will be m removal steps, where m = min_x k_x (k_x is the number of blocks in column x). After m removals, at least one column becomes empty, so no further removals occur.
- Let r_i be the initial rank of block i within its column when blocks in that column are sorted by increasing initial Y (1 for the bottom-most block in that column, up to k_x).
- Queries:
  - If some column is empty initially, no removals ever happen; every block exists for all times.
  - Otherwise, for a query (T, A):
    - If T < B: no removals yet; block A exists.
    - If B <= T <= B + m - 1: s = T - B + 1 removals have happened. Block A exists iff r_A > s.
    - If T >= B + m: all removals finished; block A exists iff r_A > m.
- Implementation plan:
  - Build per-column lists of (Y, block_index). If any column is empty, answer Yes for all queries.
  - Otherwise compute B = max(min_Y_per_column) and m = min(column_heights).
  - For each column, sort by Y and assign rank to each block (store in a rank array).
  - Answer each query in O(1) time using the precomputed B, m, and rank.

This approach matches the process described: removals remove the current bottom block in every non-empty column, one per time step, for as many rounds as allowed by the shortest column.

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    N = next(it)
    W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # 0-based block index

    # Build per-column blocks
    cols = [[] for _ in range(W + 1)]  # 1..W used
    for i in range(N):
        x = X[i]
        y = Y[i]
        cols[x].append((y, i))

    # Check if any column is empty initially
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    if hasZero:
        # No removals ever occur; all blocks exist for all times
        print("\n".join(["Yes"] * Q))
        return

    # Compute B = max(minY_x) and m = min(k_x)
    minYs = []
    m = None
    B = 0
    for x in range(1, W + 1):
        col = cols[x]
        minY = min(y for (y, idx) in col)
        minYs.append(minY)
    B = max(minYs)
    m = min(len(col) for col in cols[1:W+1])

    # Assign ranks within each column
    rank = [0] * N
    for x in range(1, W + 1):
        col = cols[x]
        col.sort(key=lambda t: t[0])  # sort by Y
        for pos, (y, idx) in enumerate(col, start=1):
            rank[idx] = pos

    out_lines = []
    for j in range(Q):
        t = T_arr[j]
        a = A_arr[j]
        r = rank[a]
        if t < B:
            out_lines.append("Yes")
        elif t <= B + m - 1:
            s = t - B + 1
            out_lines.append("Yes" if r > s else "No")
        else:
            out_lines.append("Yes" if r > m else "No")

    print("\n".join(out_lines))

if __name__ == "__main__":
    solve()
