### Step-by-step reasoning
- The grid has W columns and a very large number of rows. Each block stays in its column; there is no horizontal movement.
- The bottom row is y = 1. At the start of a time step, if every column has a block at y = 1, all those bottom-row blocks are removed. After removal, remaining blocks in each column do not move in that same step (as argued by processing order: bottom to top, after removing bottoms every remaining block has a block directly below it).
- If any column is empty at any time, the bottom row can never be full again, so no more removals will ever occur.
- If all columns are non-empty initially:
  - Let k_x be the number of blocks in column x.
  - Let b_x be the minimum initial Y in column x (the lowest block in that column).
  - The bottom row becomes potentially full for the first time at time B = max_x b_x. Intuition: the bottom-most block in each column can reach y=1 after b_x - 1 steps; only when the last such column reaches y=1 (i.e., after B - 1 steps) can a removal happen at the next step.
  - Removals can happen for at most m steps, where m = min_x k_x. After m removals (one per column per removal step), at least one column becomes empty and no further removals will ever happen.
  - In each column, the blocks removed after s removals are exactly the s blocks with the smallest initial Y in that column (the s “lowest” blocks by initial height), because removals always take the current bottom block and blocks never pass each other.
  - Let r_i be the rank of block i within its column when blocks in that column are sorted by increasing initial Y (1 = lowest in that column, up to k_x).
- For a query with time T:
  - If any column is empty initially, answer is always Yes (no removals ever happen).
  - Otherwise:
    - If T < B: no removals yet; block exists.
    - If B <= T <= B + m - 1: s = T - B + 1 removals have happened; block i exists iff r_i > s.
    - If T >= B + m: all removals finished; block i exists iff r_i > m.
- This leads to an O(N log N) preprocessing (per-column sorting to assign ranks) and O(1) per query.

Potential tricky points:
- Correctly determine B as max of the per-column minimum Y values.
- Correctly determine m as the minimum column height.
- Correctly map block indices to their per-column rank r_i.
- Carefully handle the case when any column is empty: answer all queries with Yes.

Time complexity:
- Preprocessing: O(N log N) due to sorting within each non-empty column (total across all columns sums to N).
- Each query: O(1).
- Memory: O(N).

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)
    N = next(it); W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # 0-based index for blocks

    # Collect per-column blocks
    cols = [[] for _ in range(W + 1)]
    for i in range(N):
        x = X[i]
        y = Y[i]
        cols[x].append((y, i))

    rank = [0] * N
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    if not hasZero:
        # Compute B and m
        mins = []
        m = None
        B = 0
        for x in range(1, W + 1):
            col = cols[x]
            minY = min(y for (y, idx) in col)
            mins.append(minY)
        B = max(mins)
        m = min(len(col) for col in cols[1:])

        # Assign ranks within each column
        for x in range(1, W + 1):
            col = cols[x]
            col.sort(key=lambda t: t[0])  # sort by Y
            for pos, (y, idx) in enumerate(col, start=1):
                rank[idx] = pos
    # If hasZero is True, we don't need ranks or B/m since answer is always Yes

    out_lines = []
    if hasZero:
        out_lines = ["Yes"] * Q
    else:
        for j in range(Q):
            t = T_arr[j]
            a = A_arr[j]
            r = rank[a]
            if t < B:
                out_lines.append("Yes")
            elif t <= B + m - 1:
                s = t - B + 1
                out_lines.append("Yes" if r > s else "No")
            else:
                out_lines.append("Yes" if r > m else "No")

    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
