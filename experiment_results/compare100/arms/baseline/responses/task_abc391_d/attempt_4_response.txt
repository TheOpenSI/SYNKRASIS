### Step-by-step reasoning
- Understand dynamics precisely:
  - Blocks never move horizontally.
  - Each time step t starts by checking if the entire bottom row (y = 1) is occupied in every column. If so, all blocks currently at y = 1 are removed.
  - Then, in that time step, blocks are processed from bottom to top. If a block is in the bottom row or there is a block directly below it, it stays; otherwise it moves down by one cell.
  - Because gravity is applied after the removal check within the same time step, if a column has blocks above the bottom row, those blocks can cascade downward in that same step when the bottom row is empty.

- Key observations:
  - If any column has no blocks initially, that column will always stay empty. Therefore the bottom row can never be full, so no removals ever occur. In this case, every block persists forever; answer “Yes” for all queries.
  - If every column has at least one initial block, then a removal happens at time t = B, where B = max over columns of the minimum initial Y in that column (the lowest block in that column). This is because to have bottom row full at the start of time step t, every column must have had its lowest block reach y = 1 by the end of step t-1. The time needed for a column to bring its lowest block to y = 1 is (minY_x - 1) gravity steps; the latest among columns determines the first time step when all columns have a block at y = 1 at the start of a step.
  - After each removal step, one block from bottom in every non-empty column is removed. Thus after s removals, each column x has height k_x - s (where k_x is the initial number of blocks in that column), as long as s ≤ k_x for that column. The process can continue only while every column remains non-empty, i.e., until s reaches min_x k_x, call this m.
  - Consequently:
    - If t < B: no removals have happened yet; every block exists.
    - If B ≤ t ≤ B + m - 1: exactly s = t - B + 1 removals have occurred. A block in column x with rank r (1 is the lowest in that column, increasing with height) exists iff r > s.
    - If t ≥ B + m: all possible removals have occurred; a block in column x exists iff r > m.

- Plan:
  1) Group blocks by their column X_i. If any column is empty, output Yes for all queries.
  2) Otherwise compute:
     - B = max over columns of the minimum Y in that column.
     - m = min over columns of the number of blocks in that column.
  3) For each column, sort its blocks by Y ascending and assign a rank r (1-based) to each block.
  4) For each query (T, A):
     - If T < B: Yes.
     - Else if T ≤ B + m - 1: compute s = T - B + 1; answer Yes if rank[A] > s, else No.
     - Else (T ≥ B + m): answer Yes if rank[A] > m, else No.

- Complexity:
  - Building per-column lists: O(N)
  - Sorting all columns: O(N log N) in total
  - Answering Q queries: O(Q)
  - Memory is O(N)

- Edge cases:
  - Some column empty: all “Yes”.
  - Large T values: arithmetic uses integers; Python handles big ints.

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    N = next(it)
    W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # convert to 0-based index

    # Build per-column blocks
    cols = [[] for _ in range(W + 1)]  # 1..W used

    for i in range(N):
        x = X[i]
        y = Y[i]
        cols[x].append((y, i))

    # Check if any column is empty initially
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    if hasZero:
        # No removals ever occur; all blocks exist for all times
        sys.stdout.write("\n".join(["Yes"] * Q) + "\n")
        return

    # Compute B = max(minY_x) and m = min(k_x)
    minYs = []
    for x in range(1, W + 1):
        col = cols[x]
        minY = min(y for (y, idx) in col)
        minYs.append(minY)
    B = max(minYs)

    m = min(len(col) for col in cols[1:W+1])

    # Assign ranks within each column
    rank = [0] * N
    for x in range(1, W + 1):
        col = cols[x]
        col.sort(key=lambda t: t[0])  # sort by Y ascending
        for pos, (y, idx) in enumerate(col, start=1):
            rank[idx] = pos

    out_lines = []
    for j in range(Q):
        t = T_arr[j]
        a = A_arr[j]
        r = rank[a]
        if t < B:
            out_lines.append("Yes")
        elif t <= B + m - 1:
            s = t - B + 1
            out_lines.append("Yes" if r > s else "No")
        else:
            out_lines.append("Yes" if r > m else "No")

    sys.stdout.write("\n".join(out_lines) + "\n")

if __name__ == "__main__":
    solve()
