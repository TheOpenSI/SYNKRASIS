### Step-by-step reasoning
- Key observation: Blocks never move horizontally; each block stays in its column (X_i fixed). The only vertical interactions happen through the bottom row removal rule, which occurs simultaneously across all columns.
- If any column is initially empty, that column can never gain a block, so the bottom row can never be fully filled. Therefore, no removals ever happen and every block persists forever. In this case, all queries answer Yes.
- If every column has at least one block initially, there will be a first time step t = B when the bottom row becomes full at the start of the step. For a column x, the lowest block initially in this column has Y_min(x). Without any removals, after t-1 steps of gravity, that block reaches y = max(1, Y_min(x) - (t-1)). The bottom row becomes full exactly when t-1 ≥ Y_min(x) - 1 for all columns, i.e., t ≥ max_x Y_min(x). Thus B = max over columns of the minimum Y in that column.
- After the first removal at t = B, a removal happens in every subsequent step as long as every column still has at least one block (i.e., while the columns have not become empty). Each removal deletes exactly one block from the bottom of each non-empty column, and all remaining blocks in that column descend by one cell within that same step. If s steps of removal have occurred (s ≥ 1), then in every column the number of remaining blocks is k_x - s, where k_x is the initial number of blocks in that column. The process can continue until s reaches m = min_x k_x (the smallest column height).
- Therefore, define:
  - B = max_x minY_x, where minY_x is the smallest initial Y in column x.
  - m = min_x k_x, where k_x is the number of blocks in column x.
  - Rank r_i of block i within its column: 1 for the lowest block in its column, 2 for the next, etc. This is determined by sorting blocks in each column by initial Y ascending.
- For a query (T, A):
  - If T < B: no removals have happened yet; block A exists: Yes.
  - If B ≤ T ≤ B + m - 1: exactly s = T - B + 1 removals have occurred. Block A with rank r_A exists iff r_A > s.
  - If T ≥ B + m: all possible removals have happened; block A exists iff r_A > m.
- This approach runs in O(N log N) to sort blocks within columns (total across all columns is O(N)) and O(Q) to answer queries, with linear preprocessing.

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    N = next(it)
    W = next(it)

    X = [0] * N
    Y = [0] * N
    for i in range(N):
        X[i] = next(it)
        Y[i] = next(it)

    Q = next(it)
    T_arr = [0] * Q
    A_arr = [0] * Q
    for j in range(Q):
        T_arr[j] = next(it)
        A_arr[j] = next(it) - 1  # convert to 0-based index

    # Build per-column blocks
    cols = [[] for _ in range(W + 1)]  # 1..W used

    for i in range(N):
        x = X[i]
        y = Y[i]
        cols[x].append((y, i))

    # Check if any column is empty initially
    hasZero = False
    for x in range(1, W + 1):
        if len(cols[x]) == 0:
            hasZero = True
            break

    if hasZero:
        # No removals ever occur; all blocks exist for all times
        sys.stdout.write("\n".join(["Yes"] * Q) + "\n")
        return

    # Compute B = max(minY_x) and m = min(k_x)
    minYs = []
    for x in range(1, W + 1):
        col = cols[x]
        minY = min(y for (y, idx) in col)
        minYs.append(minY)
    B = max(minYs)

    m = min(len(col) for col in cols[1:W+1])

    # Assign ranks within each column
    rank = [0] * N
    for x in range(1, W + 1):
        col = cols[x]
        col.sort(key=lambda t: t[0])  # sort by Y ascending
        for pos, (y, idx) in enumerate(col, start=1):
            rank[idx] = pos

    out_lines = []
    for j in range(Q):
        t = T_arr[j]
        a = A_arr[j]
        r = rank[a]
        if t < B:
            out_lines.append("Yes")
        elif t <= B + m - 1:
            s = t - B + 1
            out_lines.append("Yes" if r > s else "No")
        else:
            out_lines.append("Yes" if r > m else "No")

    sys.stdout.write("\n".join(out_lines) + "\n")

if __name__ == "__main__":
    solve()
