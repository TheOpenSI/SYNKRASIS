### Step-by-step reasoning
- The total cost is the sum of the costs paid after each flip, not just the sum of the S values before flips.
- If we perform a sequence of m flips, with deltas delta_j = (1 - 2*A_before_j) * C_i for the flipped index i, the total cost equals:
  Total = sum over j of (S_before_j + delta_j) = sum S_before_j + sum delta_j.
- Here S_before_j evolves as S_before_{j+1} = S_before_j + delta_j, with S_before_1 = S0 = sum A_i*C_i.
- The sum delta_j over all flips equals S_final - S0, where S_final = sum B_i*C_i (since final A equals B).
- Therefore, Total = sum S_before_j + (S_final - S0).
- For exactly the indices where A_i != B_i (let D_i = A_i XOR B_i = 1), flipping each exactly once is optimal (extra flips only add nonnegative costs when considering the total structure; see derivation under the step above).
- Among all sequences flipping exactly those d indices, the optimal order is:
  - Do all indices with A_i = 1 and D_i = 1 first (negative delta), in descending C_i order.
  - Then do indices with A_i = 0 and D_i = 1 (positive delta), in ascending C_i order.
- This yields:
  - S0 = sum A_i * C_i
  - S_final = sum B_i * C_i
  - Neg and Pos lists of C_i values as described
  - d = |Neg| + |Pos|
  - Total' = d * S0 + sum(delta_j * (d - j)) over the chosen order
  - Final answer = Total' + (S_final - S0)
- The previous solution missed adding (S_final - S0); this caused the discrepancy in test case 3.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    N = int(next(it))

    A = [int(next(it)) for _ in range(N)]
    B = [int(next(it)) for _ in range(N)]
    C = [int(next(it)) for _ in range(N)]

    S0 = 0
    Sfinal = 0
    neg = []  # A_i = 1, D_i = 1 -> delta = -C_i
    pos = []  # A_i = 0, D_i = 1 -> delta = +C_i
    d = 0

    for i in range(N):
        ai = A[i]
        bi = B[i]
        ci = C[i]
        S0 += ai * ci
        Sfinal += bi * ci

        if (ai ^ bi) == 1:
            d += 1
            if ai == 1:
                neg.append(ci)
            else:
                pos.append(ci)

    if d == 0:
        print(0)
        return

    neg.sort(reverse=True)  # decreasing Ci for negative deltas
    pos.sort()              # increasing Ci for positive deltas

    total = d * S0

    # Neg contributions
    for idx, ci in enumerate(neg, start=1):
        weight = d - idx + 1
        total += (-ci) * weight

    # Pos contributions
    base_weight = d - len(neg)
    for t, ci in enumerate(pos, start=1):
        weight = base_weight - t + 1
        total += ci * weight

    # Add the final minus initial S, as derived
    total += (Sfinal - S0)

    print(total)

if __name__ == "__main__":
    main()
