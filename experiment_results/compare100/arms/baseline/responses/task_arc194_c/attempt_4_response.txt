### Step-by-step reasoning
- The operation flips exactly one bit A_i and then you pay the current sum S = sum_k A_k * C_k after the flip.
- To reach B, for every index i where A_i != B_i, the total number of flips on i must be odd; for indices where A_i == B_i, flips must be even. Flipping any index more than necessary (i.e., performing extra pairs of flips on any index) only increases the total cost because:
  - A pair of flips on an index i starting from A_i will cause S to go up and then back down (or down and back up), but you pay the intermediate S values, which adds extra positive cost.
  - Therefore, the optimal strategy is to flip each mismatched index exactly once and do not flip matched indices at all.
- If we flip mismatched indices exactly once, each such flip i contributes a delta to S of:
  - +C_i if A_i was 0 and B_i is 1
  - -C_i if A_i was 1 and B_i is 0
- Let deltas be the multiset of these contributions. The total cost for a fixed order of applying these deltas is:
  - Start with S0 = sum_i A_i * C_i
  - For each delta d in the chosen order, S becomes S + d and you pay that new S.
  - The total cost equals sum of the successive S values after each flip.
- To minimize the sum of prefix sums, deltas must be applied in nondecreasing order (i.e., sort deltas ascending). This single ordering is optimal; considering both ascending and descending (or multiple orders) is unnecessary and can lead to suboptimal results in some cases.
- Therefore, the correct solution is:
  - Compute S0.
  - Build deltas for all i with A_i != B_i.
  - If there are no deltas, answer is 0.
  - Sort deltas ascending and accumulate the total cost by applying them in that order.

### Code

import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    N = next(it)
    A = [next(it) for _ in range(N)]
    B = [next(it) for _ in range(N)]
    C = [next(it) for _ in range(N)]

    # Initial sum S0 = sum A_i * C_i
    S0 = 0
    deltas = []  # deltas for indices where A_i != B_i
    for i in range(N):
        S0 += A[i] * C[i]
        if A[i] != B[i]:
            deltas.append(C[i] if A[i] == 0 else -C[i])

    if not deltas:
        print(0)
        return

    # Optimal order: ascending deltas
    deltas.sort()

    S = S0
    total = 0
    for d in deltas:
        S += d
        total += S

    print(total)

if __name__ == "__main__":
    main()
