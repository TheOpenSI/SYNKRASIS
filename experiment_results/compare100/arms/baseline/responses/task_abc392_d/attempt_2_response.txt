### Step-by-step reasoning
- For a single die i, let Ki be the number of faces and let count_i[v] be how many faces show value v. The probability to obtain value v when rolling die i is P_i(v) = count_i[v] / Ki.
- If we pick two dice i and j, the probability that both show the same number is:
  P(i, j) = sum over all v of P_i(v) * P_j(v)
         = sum_v (count_i[v] / Ki) * (count_j[v] / Kj)
         = (1 / (Ki * Kj)) * sum_v count_i[v] * count_j[v].
- Therefore, for every pair (i, j) we can compute the dot product dot(i, j) = sum_v count_i[v] * count_j[v], and the probability is dot(i, j) / (Ki * Kj).
- To keep the time reasonable, for each pair we can iterate over the smaller of the two value distributions (the one with fewer distinct values) and accumulate the product with the corresponding counts in the other die.
- We compute the maximum probability over all pairs (i < j).
- Edge cases: duplicates on a die are naturally handled by counting frequencies; if two dice share no common values, the probability is 0.
- Output with high precision to satisfy the error requirement.

None

### Code
```
import sys
from collections import Counter

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        print("0.0")
        return

    pos = 0
    N = data[pos]; pos += 1

    dice = []
    for _ in range(N):
        Ki = data[pos]; pos += 1
        faces = data[pos:pos+Ki]; pos += Ki
        counts = Counter(faces)
        dice.append((Ki, counts))

    max_prob = 0.0

    for i in range(N):
        Ki, di = dice[i]
        for j in range(i + 1, N):
            Kj, dj = dice[j]

            # Compute dot product efficiently by iterating over the smaller distribution
            if len(di) <= len(dj):
                dot = 0
                for v, c in di.items():
                    dot += c * dj.get(v, 0)
            else:
                dot = 0
                for v, c in dj.items():
                    dot += c * di.get(v, 0)

            prob = dot / (Ki * Kj)
            if prob > max_prob:
                max_prob = prob

    print("{:.15f}".format(max_prob))

if __name__ == "__main__":
    main()
```
