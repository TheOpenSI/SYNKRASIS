### Step-by-step reasoning
- For two dice i and j, let count_i(v) be how many faces of die i show value v, and Ki be the number of faces of die i. The probability that both dice show the same number is:
  P(i, j) = sum over all values v of (count_i(v)/Ki) * (count_j(v)/Kj)
         = (1 / (Ki * Kj)) * sum_v count_i(v) * count_j(v)
  The inner sum is the dot product of the two value-count distributions.
- To maximize the probability, compute P(i, j) for all pairs i < j and take the maximum.
- To compute the dot product efficiently, iterate over the smaller of the two distributions (fewer distinct values) and accumulate count_i(v) * count_j(v) (using 0 if the value is absent in the other die).
- Complexity: total faces sum Ki <= 1e5. For each pair we do work proportional to the number of distinct values in the smaller die. Overall this is acceptable for N <= 100.
- Edge cases: duplicates on a die are handled by counting frequencies; if two dice share no common values, the probability is 0. Print with high precision (15 decimal places) to ensure 1e-8 accuracy.

None

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        print("0.0")
        return

    it = iter(data)
    N = next(it)

    dice_counts = []
    Ks = []

    for _ in range(N):
        Ki = next(it)
        Ks.append(Ki)
        counts = {}
        for _ in range(Ki):
            v = next(it)
            counts[v] = counts.get(v, 0) + 1
        dice_counts.append(counts)

    max_prob = 0.0

    for i in range(N):
        di = dice_counts[i]
        Ki = Ks[i]
        for j in range(i + 1, N):
            dj = dice_counts[j]
            Kj = Ks[j]

            # Compute dot product efficiently by iterating over the smaller distribution
            if len(di) <= len(dj):
                dot = 0
                for v, c in di.items():
                    dot += c * dj.get(v, 0)
            else:
                dot = 0
                for v, c in dj.items():
                    dot += c * di.get(v, 0)

            prob = dot / (Ki * Kj)
            if prob > max_prob:
                max_prob = prob

    print("{:.15f}".format(max_prob))

if __name__ == "__main__":
    main()
```
