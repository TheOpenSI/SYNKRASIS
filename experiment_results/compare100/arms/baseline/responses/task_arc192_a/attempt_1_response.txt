### Step-by-step reasoning
- Model the problem as selecting a set of edges E on the N-cycle (edges are between i and i+1, with wrap-around). If edge i is chosen, A_i and A_{i+1} become 1 via an operation. An edge can be chosen only if the surrounding S-triple around that edge is ARC or CRA, which imposes that two adjacent edges cannot be chosen simultaneously (since edge i requires S_{i+1}='R' and S_i/S_{i+2} in {A,C}, while edge i+1 would require S_{i+2}='R', which cannot both hold with the same S entries). Therefore, E must be a matching on the cycle (no two adjacent edges).
- For every i with A_i = 0, we must have i covered by at least one chosen edge: either edge i-1 or edge i is selected. This is the core constraint.
- We reduce the problem to finding a binary sequence x_1..x_N for the edges, where x_i = 1 if edge i is chosen, 0 otherwise, with:
  - No two adjacent edges chosen: x_i + x_{i-1} ≤ 1 (indices modulo N).
  - For every i with A_i = 0, x_{i-1} = 1 or x_i = 1.
- This is a constraint satisfaction on a cycle. Solve by breaking the cycle into two linear cases: fix x_1 = 0 or x_1 = 1, then process edges 2..N with a small DP tracking whether the previous edge is 0 or 1, ensuring the current vertex i is covered if needed.
- After processing to edge N, ensure wrap-around constraint for vertex 1:
  - If x_1 = 0 and A_1 = 0, then x_N must be 1.
  - If x_1 = 1, then x_N must be 0 (due to the no-adjacent-edges constraint around the cycle).
- If either starting choice yields a valid end state, the answer is Yes; otherwise, No.

This approach runs in O(N) time and O(1) extra memory.

import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    N = int(next(it))
    A = [int(next(it)) for _ in range(N)]

    # must[i] is True iff A_i = 0 (i is a vertex that must be covered)
    must = [False] * (N + 1)  # 1-based indexing for convenience
    for i in range(1, N + 1):
        must[i] = (A[i - 1] == 0)

    def feasible_for_start(start):
        # start is x1 in {0, 1}
        # Keep track if x_{i-1} was 0 or 1 as we sweep i = 2..N
        prev_zero = (start == 0)
        prev_one = (start == 1)

        for i in range(2, N + 1):
            new_zero = False
            new_one = False

            if prev_zero:
                # If x_{i-1} = 0, we may set x_i = 1 (always allowed)
                new_one = True
                # We can set x_i = 0 only if vertex i does not require coverage
                if not must[i]:
                    new_zero = True

            if prev_one:
                # If x_{i-1} = 1, we must keep x_i = 0 (no adjacent ones)
                new_zero = True

            prev_zero, prev_one = new_zero, new_one

            if not (prev_zero or prev_one):
                # No valid state for this i
                return False

        # After processing N, we have possibilities for x_N:
        # prev_zero -> x_N = 0 is possible
        # prev_one  -> x_N = 1 is possible

        must1 = must[1]
        if start == 0:
            # Vertex 1 must be covered by either x_N or x_1 (x_1 = 0 here)
            if must1:
                # Need x_N = 1
                return prev_one
            else:
                # No requirement on x_N
                return prev_zero or prev_one
        else:
            # start == 1: x_1 = 1 covers vertex 1; wrap requires x_N = 0
            return prev_zero

    ans = feasible_for_start(0) or feasible_for_start(1)
    print("Yes" if ans else "No")


if __name__ == "__main__":
    solve()
