### Step-by-step reasoning
- Let edges be E_i = (i, i+1) for i = 1..N, with i+1 interpreted modulo N (so E_N = (N,1)).
- An operation is allowed at index i if the triple S_i, S_{i+1}, S_{i+2} is either A-R-C or C-R-A. This means S_{i+1} must be 'R' and {S_i, S_{i+2}} must be {'A','C'} in some order.
- If we perform an operation on i, we set A_i and A_{i+1} to 1. Therefore, the only indices that can ever be turned to 1 are those in pairs (i, i+1) for i in some set E of allowed indices.
- Crucially, if i and i+1 are both in E, then i+1 must have S_{i+2} in {A,C} and S_{i+1} = 'R' simultaneously, which would force S_{i+2} to be both A/C and R indirectly — this leads to a conflict. In fact, two adjacent i cannot both be chosen. Hence the set E of usable indices must be a matching on the N-cycle (no two consecutive i’s in E).
- Conversely, for any matching E on the cycle, we can construct a string S realizing exactly E: for each i in E, set S_{i+1} = 'R' and S_i, S_{i+2} to be 'A' and 'C' (in any order). The constraints for different i in E are compatible because E is a matching and therefore no position is forced to be both 'R' and {A/C}, and no two edges share endpoints.
- Therefore, there exists a good string iff there exists a matching E on the cycle such that every index i with A_i = 0 is incident to at least one edge in E (i.e., i ∈ {i, i+1} for some i ∈ E). In other words, we need a binary choice x_i ∈ {0,1} for each edge E_i, where x_i = 1 means edge i is chosen, subject to:
  - No two adjacent edges chosen: x_i + x_{i-1} ≤ 1 (indices modulo N).
  - For every i with A_i = 0 (must i), either x_{i-1} = 1 or x_i = 1 (i is incident to a chosen edge).

- This becomes a DP on a cycle over edges. Let x_i denote whether edge i is chosen (1) or not (0). We must satisfy:
  - For all i, x_i ∈ {0,1}, and x_i + x_{i-1} ≤ 1 (modulo N).
  - For all i with A_i = 0, x_{i-1} OR x_i must be 1.
  - Wrap-around: x_N and x_1 also must satisfy the non-adjacent constraint.

- We solve this cycle CSP by breaking the cycle into two linear cases, fixing x_1 to 0 or 1, and performing a DP along i = 2..N. At the end we enforce the wrap condition between x_N and x_1.

- DP details for a fixed start x_1 = s (s ∈ {0,1}):
  - dp0 = whether there exists a valid assignment up to i-1 where x_{i-1} = 0; dp1 = same for x_{i-1} = 1.
  - Initialize with x_1 = s: dp0 = (s == 0), dp1 = (s == 1).
  - For i from 2 to N:
    - If previous is 0 (dp0):
      - Set x_i = 0 only if must[i] is False (otherwise i would be unsatisfied).
      - Set x_i = 1 is always allowed (must[i] is satisfied by x_i = 1).
    - If previous is 1 (dp1):
      - x_i must be 0 (since 1 + x_i ≤ 1).
    - Update dp0, dp1 accordingly.
  - After processing i = N, apply wrap-around constraints:
    - If x_1 = 0, wrap allows x_N to be 0 or 1; but if A_1 = 0 (must1), then x_N must be 1.
    - If x_1 = 1, then x_N must be 0 (due to non-adjacent wrap), and if A_1 = 0, it's automatically satisfied because x_1 = 1 covers index 1.
  - If either start choice yields a feasible end state, answer is Yes.

- Edge cases:
  - If A is all ones, the answer is obviously Yes (no constraints).
  - The tricky known case is when N is odd and A is all zeros; in that case no perfect matching exists on the cycle, hence No.

- Complexity: O(N) time, O(1) extra memory.

import sys

def can_cover(must, N):
    must1 = must[1]

    def check(start):
        # start is x_1
        dp0 = (start == 0)
        dp1 = (start == 1)
        # iterate edges i = 2..N
        for i in range(2, N + 1):
            new0 = False
            new1 = False
            if dp0:
                # from x_{i-1} = 0
                # choose x_i = 0 only if vertex i is not required to be satisfied
                if not must[i]:
                    new0 = True
                # choose x_i = 1 is always allowed (vertex i becomes satisfied)
                new1 = True
            if dp1:
                # from x_{i-1} = 1 -> x_i must be 0 due to non-adjacency
                new0 = True
            dp0, dp1 = new0, new1

        # Wrap-around constraints with x_1 = start
        if start == 0:
            # If vertex 1 is must, x_N must be 1
            if must1:
                return dp1
            else:
                return dp0 or dp1
        else:
            # start == 1: wrap requires x_N = 0
            if must1:
                # vertex 1 is already satisfied by x1=1; wrap still requires x_N=0
                return dp0
            else:
                return dp0

    return check(0) or check(1)


def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    N = int(next(it))
    must = [False] * (N + 1)  # 1-based
    for i in range(1, N + 1):
        a = int(next(it))
        must[i] = (a == 0)

    if can_cover(must, N):
        print("Yes")
    else:
        print("No")


if __name__ == "__main__":
    solve()
