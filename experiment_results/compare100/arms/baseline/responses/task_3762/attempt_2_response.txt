### Step-by-step reasoning
- Understand the process: You start outside the array and make at most m moves. Each move lands you on an index i and increments gameScore[i] by points[i]. After the moves, each index i has been visited k_i times, contributing k_i * points[i] to its score. The objective is to maximize the minimum among all gameScore[i], i.e., maximize min_i (k_i * points[i]).
- Observing a target minimum S: To guarantee every index i has at least S, you must have k_i * points[i] >= S for every i, which implies k_i >= ceil(S / points[i]) for all i. Let t_i = ceil(S / points[i]).
- A necessary condition for achieving minimum S is that the total number of visits (sum of k_i) is at most m, i.e., sum_i t_i <= m.
- It’s a common feasibility approach to binary search on S:
  - If sum_i ceil(S / points[i]) <= m, then S is feasible (we believe we can realize counts k_i >= t_i within m moves).
  - Otherwise, S is not feasible.
- The search range for S is [0, max(points) * m] because the largest possible score on any single index is at most m moves times the maximum point value.
- Time complexity: Each feasibility check is O(n). Binary search over up to about log2(max(points) * m) iterations (roughly <= 50 for given constraints) yields O(n log(max(points) * m)).
- Edge cases:
  - If m < n, it’s impossible to visit all indices at least once, so the maximum minimum is 0. This is naturally handled by the feasibility check (sum_i ceil(S / points[i]) >= n > m for any S > 0).

Overall, the approach uses binary search on the target minimum and a feasibility check based on necessary (and, with the stated reasoning, sufficient) counts required per index.

### Code
```
from typing import List

class Solution:
    def maxScore(self, points: List[int], m: int) -> int:
        if not points:
            return 0

        lo, hi = 0, max(points) * m

        while lo < hi:
            mid = (lo + hi + 1) // 2  # candidate minimum S
            total = 0
            for p in points:
                # ceil(mid / p) = (mid + p - 1) // p
                total += (mid + p - 1) // p
                if total > m:
                    break  # early exit if already impossible

            if total <= m:
                lo = mid
            else:
                hi = mid - 1

        return lo
```
