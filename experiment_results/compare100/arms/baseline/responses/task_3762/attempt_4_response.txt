### Step-by-step reasoning
- Problem insights:
  - Each move lands you on some index i and adds points[i] to gameScore[i].
  - After at most m moves, the vector gameScore has entries gameScore[i] = visits[i] * points[i], where visits[i] is the number of times index i was landed on.
  - The goal is to maximize the minimum across all i of visits[i] * points[i].

- Key observation:
  - If we target a minimum value S for every index, then to have gameScore[i] >= S we must visit index i at least t[i] = ceil(S / points[i]) times.
  - Since every move lands on exactly one index, the sum of all visits across all indices must be exactly m (we perform at most m moves, so we can distribute visits up to m).
  - Therefore, a necessary condition for achieving min >= S is sum_i t[i] <= m.

- Sufficiency of the condition:
  - For any target S, after computing t[i] = ceil(S / points[i]), if sum t[i] <= m, we can realize a feasible plan by distributing the extra visits (m - sum t[i]) across indices arbitrarily. The path constraints on a 1D line do not prevent realizing any nonnegative extensions c[i] >= t[i] with sum c[i] = m: we can always pick counts c[i] >= t[i] summing to m and, due to the linear structure, there exists a walk that visits indices according to those counts. (Intuitively, choosing counts c[i] with sum m and c[i] >= t[i] allows constructing the required sequence of moves that ends somewhere within the array.)
  - Thus the condition sum_i ceil(S / points[i]) <= m is both necessary and sufficient for feasibility of achieving minimum at least S.

- Strategy:
  - Binary search the largest S such that sum_i ceil(S / points[i]) <= m.
  - The search range is [0, max(points) * m] since the maximum possible per-index value cannot exceed points[i] * visits[i] with visits[i] <= m.

- Complexity:
  - Each feasibility check runs in O(n).
  - Binary search over a range up to about 1e15 yields roughly 50 iterations, so overall O(n log(max_value * m)) which is acceptable for n up to 5e4.

None

### Code
```
from typing import List

class Solution:
    def maxScore(self, points: List[int], m: int) -> int:
        """
        Binary search the maximum S such that sum(ceil(S / points[i])) <= m.
        This condition is both necessary and sufficient for being able to achieve
        a minimum gameScore of at least S after at most m moves.
        """
        if not points or m <= 0:
            return 0

        n = len(points)

        lo, hi = 0, max(points) * m

        def feasible(S: int) -> bool:
            if S == 0:
                return True
            total = 0
            for p in points:
                # ceil division: (S + p - 1) // p
                total += (S + p - 1) // p
                if total > m:
                    return False
            return total <= m

        while lo < hi:
            mid = (lo + hi + 1) // 2
            if feasible(mid):
                lo = mid
            else:
                hi = mid - 1

        return lo
```
