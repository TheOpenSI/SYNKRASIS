### Step-by-step reasoning
- We have n pizzas (n is a multiple of 4). We partition them into D = n/4 groups of 4 pizzas each. For a group with four weights, after sorting W <= X <= Y <= Z, on odd days we gain Z and on even days we gain Y.
- Let O be the number of odd days: O = ceil(D/2). Let E be the number of even days: E = floor(D/2). We can assign groups to days: O groups on odd days (contributing their maximum Z) and E groups on even days (contributing their second largest Y).
- Observations:
  - It is always optimal to place the O largest pizzas as the maxima Z of the O groups that will be eaten on odd days. If any of these O largest numbers were used as a Y (second largest) in an even-day group, you could instead use it as Z on an odd day and gain at least as much, while not decreasing the possible contribution on the even-day groups in a way that could compensate. So the O largest numbers should be used as the Z values for odd-day groups.
  - For the odd-day groups, we should fill each group with three of the smallest remaining pizzas. This minimizes the impact on the other groups (especially the even-day groups) and ensures the odd-day contributions come from the largest numbers.
  - After fixing the O largest numbers as Zs and using the 3O smallest numbers as fillers for these O groups, the remaining numbers form exactly 4E pizzas. These will be allocated to the E even-day groups. To maximize the sum of the even-day contributions (each being the second largest in its group), we should pair the largest remaining numbers together within these groups. If we sort the remaining 4E numbers in descending order and pair them as (top, second), (third, fourth), ..., the second element of each pair is the contribution Y for that group. Summing these second elements yields the maximum possible sum for the even-day contributions given the remaining numbers.
- Implementation idea (efficient and O(n log n)):
  1. Sort the array in ascending order.
  2. Compute D = n/4, O = ceil(D/2) = (D + 1) // 2, E = D - O.
  3. SumA (sum of Zs for odd days) = sum of the O largest numbers (the last O elements in the sorted array).
  4. The remaining middle segment of numbers (after removing the O largest and the 3O smallest) has length 4E. Its elements in ascending order are contiguous in the sorted array.
  5. The even-day contributions sumB can be obtained by taking, from this middle segment, every second element starting from the second position within that segment when arranged in descending order. Translating to the original ascending array indices, the positions are:
     - Start at index L = 3*O (the first index of the middle segment in ascending order),
     - Take positions L + 2*E, L + 2*E + 2, ..., L + 4*E - 2.
  6. The answer is SumA + SumB.

- Correctness sketch:
  - All odd-day contributions come from Z values of O groups; choosing the O largest as Zs is optimal.
  - The 3O smallest numbers are best used as fillers in those O groups to minimize any impact on the even-day groups.
  - The remaining 4E numbers are best arranged to maximize the sum of the E second-largest values by pairing the largest remaining numbers together.
  - The described indices precisely capture the sum of those E second-largest values within the middle segment.

- Edge cases:
  - If D = 1 (n = 4), O = 1, E = 0: answer is just the maximum of the four numbers, which matches SumA and no SumB contribution.
  - D even or odd: the formula handles both via O = ceil(D/2) and E = floor(D/2).

### Requirements
None

### Code
```
from typing import List

class Solution:
    def maxWeight(self, pizzas: List[int]) -> int:
        n = len(pizzas)
        D = n // 4
        # Sort ascending
        pizzas.sort()
        # Number of odd-day groups and even-day groups
        O = (D + 1) // 2  # ceil(D/2)
        E = D - O         # floor(D/2)

        # Sum of Z values for odd days: the O largest numbers
        # (last O elements in the ascending-sorted array)
        sumA = sum(pizzas[-i-1] for i in range(O))

        # Sum of Y values for even days:
        # remaining middle segment has length 4E and starts at index L = 3*O
        SumB = 0
        if E > 0:
            L = 3 * O
            # Indices in the ascending middle segment that correspond to
            # the second element of each pair when the middle segment is
            # arranged in descending order: L + 2*E, L + 2*E + 2, ..., L + 4*E - 2
            for k in range(E):
                idx = L + 2 * E + 2 * k
                SumB += pizzas[idx]

        return sumA + SumB
```
