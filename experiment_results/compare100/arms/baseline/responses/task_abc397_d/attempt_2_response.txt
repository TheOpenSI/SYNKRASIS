### Step-by-step reasoning
- We seek positive integers x > y > 0 such that x^3 - y^3 = N.
- Factor: x^3 - y^3 = (x - y)(x^2 + xy + y^2) = N.
- Let a = x - y > 0 and b = x^2 + xy + y^2. Then N = a * b.
- For a fixed a dividing N, with x = y + a, we can express b in terms of y and a:
  b = (y + a)^2 + y(y + a) + y^2 = 3y^2 + 3ay + a^2.
- We get a quadratic in y:
  3y^2 + 3ay + (a^2 - b) = 0.
  Its discriminant is Δ = (3a)^2 - 4*3*(a^2 - b) = -3a^2 + 12b.
- If Δ < 0, no real solution. If Δ ≥ 0, Δ must be a perfect square: Δ = s^2.
- The roots are y = (-3a ± s) / 6. Since y > 0, we take y = (s - 3a) / 6, which must be a positive integer. Then x = y + a.
- Important observations:
  - a = x - y must divide N, so it suffices to check divisors a of N.
  - For y > 0, b = x^2 + xy + y^2 = 3y^2 + 3ay + a^2 > a^2, hence N = a*b > a^3. Therefore a^3 < N, so a < cbrt(N). Thus it is enough to loop a from 1 up to floor(cuberoot(N)).
- Algorithm:
  1) Compute max_a = floor(cuberoot(N)) robustly (integer binary search).
  2) For a in 1..max_a:
     - If N % a != 0, continue.
     - b = N / a.
     - Δ = -3*a*a + 12*b. If Δ < 0, continue.
     - Let s = isqrt(Δ). If s*s != Δ, continue.
     - If (s - 3*a) is not divisible by 6, continue.
     - y = (s - 3*a) // 6. If y <= 0, continue.
     - x = y + a. Output x and y.
  3) If no pair found, output -1.
- Time complexity: O(cuberoot(N)) iterations. For N up to 1e18, max_a ≤ 1e6, which is efficient in Python.

### Requirements
None

### Code
```
import sys
import math

def icbrt(n: int) -> int:
    # Robust integer cube root: largest integer a with a^3 <= n
    lo, hi = 0, 10**6 + 2  # since cbrt(1e18) = 1e6
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if mid * mid * mid <= n:
            lo = mid
        else:
            hi = mid - 1
    return lo

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    N = int(data[0])

    max_a = icbrt(N)
    for a in range(1, max_a + 1):
        if N % a != 0:
            continue
        b = N // a

        Δ = -3 * a * a + 12 * b
        if Δ < 0:
            continue

        s = math.isqrt(Δ)
        if s * s != Δ:
            continue

        if (s - 3 * a) % 6 != 0:
            continue

        y = (s - 3 * a) // 6
        if y <= 0:
            continue

        x = y + a
        print(x, y)
        return

    print(-1)

if __name__ == "__main__":
    main()
```
