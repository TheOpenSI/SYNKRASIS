### Step-by-step reasoning
- The constraints A[u] XOR A[v] = Z for each edge (u, v) imply that within any connected component, once you fix the value at one node, all other values in that component are determined up to a global XOR with a component value.
- If we pick a root in a component and define P[i] as the XOR of edge weights along any path from the root to i, then any valid assignment has the form A[i] = t_c XOR P[i], where t_c is a non-negative integer associated with the component c of i.
- For an edge (u, v) with weight Z, consistency requires P[u] XOR P[v] = Z. If we ever see an edge where this fails, there is no solution (-1).
- If the component is consistent, the whole problem decouples per component. For a fixed bit k, A[i] bit k equals P[i] bit k XOR t_c bit k. Let cnt1 be the number of vertices in the component whose P[i] has bit k = 1. If t_c bit k = 0, the number of 1s at bit k among A is cnt1; if t_c bit k = 1, it is size_of_component - cnt1. To minimize the total sum, for each bit k we should pick t_c bit k = 0 if cnt1 <= size - cnt1, otherwise t_c bit k = 1.
- Do this independently for all components and all bits. The resulting A[i] = P[i] XOR t_c is a valid solution with minimal sum.
- Complexity: Building P and checking consistency is O(N + M). The per-bit minimization costs O(B * N), where B is the number of relevant bits (at most 30 since Z_i <= 1e9). This is efficient for the given constraints. Edge cases:
  - Self-loops with Z != 0 yield -1.
  - M = 0 yields all A_i = 0 as the minimal solution.

import sys
from collections import deque

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    M = next(it)

    # Build graph: 0-indexed nodes, edges with weight Z
    adj = [[] for _ in range(N)]
    maxZ = 0
    for _ in range(M):
        x = next(it) - 1
        y = next(it) - 1
        z = next(it)
        adj[x].append((y, z))
        adj[y].append((x, z))
        if z > maxZ:
            maxZ = z

    # Compute P[i] = XOR from component root to i, and verify consistency
    comp_id = [-1] * N
    P = [0] * N
    comp_sizes = []
    C = 0  # number of components

    for i in range(N):
        if comp_id[i] != -1:
            continue
        dq = deque([i])
        comp_id[i] = C
        P[i] = 0
        size = 0
        while dq:
            u = dq.popleft()
            size += 1
            for v, w in adj[u]:
                if comp_id[v] == -1:
                    comp_id[v] = C
                    P[v] = P[u] ^ w
                    dq.append(v)
                else:
                    # Check consistency on already-visited edge
                    if (P[u] ^ P[v]) != w:
                        print(-1)
                        return
        comp_sizes.append(size)
        C += 1

    # Per-bit minimization: decide t_c (the component's XOR shift)
    B = maxZ.bit_length()  # number of relevant bits
    T = [0] * C  # t_c for each component

    if B > 0:
        for k in range(B):
            bitmask = 1 << k
            cnt1 = [0] * C  # number of vertices in component c with P[i] having bit k = 1
            for i in range(N):
                if (P[i] & bitmask) != 0:
                    cnt1[comp_id[i]] += 1
            for c in range(C):
                if cnt1[c] > comp_sizes[c] - cnt1[c]:
                    T[c] |= bitmask

    # Build final A[i] = P[i] XOR T[comp_of_i]
    A = [0] * N
    for i in range(N):
        A[i] = P[i] ^ T[comp_id[i]]

    print(' '.join(map(str, A)))

if __name__ == "__main__":
    solve()
