### Step-by-step reasoning
- The constraints A_u XOR A_v = Z on an edge (u, v) mean that within any connected component, all A_i are determined up to a global XOR with a value t for that component.
- Pick an arbitrary root in each component and define P[i] as the XOR of Z-values along any path from the root to i (with P[root] = 0). For any valid solution, A_i must satisfy A_i = P[i] XOR t for some t that depends only on the component of i.
- We must also check consistency: for every edge (u, v) with weight Z, P[u] XOR P[v] must equal Z. If any edge contradicts this, no solution exists.
- To minimize the total sum of A_i, handle components independently. For a fixed bit k, A_i's k-th bit is P[i]_k XOR t_k. If t_k = 0, the number of ones at bit k among the component is cnt1 (the count of P[i] with k-th bit 1). If t_k = 1, the number of ones becomes component_size - cnt1. To minimize the sum, choose t_k = 0 if cnt1 <= size - cnt1, otherwise t_k = 1.
- Do this per bit up to the highest bit present in any Z (since P is built from XORs of Z). Finally, A[i] = P[i] XOR T[comp(i)], where T[c] is the chosen XOR offset for component c.
- Complexity: Building P and checking consistency is O(N + M). The per-bit minimization is O(B * N), where B ≤ 30 for Z ≤ 10^9. This fits comfortably for N ≤ 2e5 and M ≤ 1e5.

Edge cases:
- Self-loops with nonzero Z yield no solution.
- If M = 0, all A_i can be 0 (minimum sum).
- If multiple components exist, each component is minimized independently.

import sys
from collections import deque

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    M = next(it)

    adj = [[] for _ in range(N)]
    maxZ = 0
    for _ in range(M):
        a = next(it) - 1
        b = next(it) - 1
        w = next(it)
        adj[a].append((b, w))
        adj[b].append((a, w))
        if w > maxZ:
            maxZ = w

    # Compute P[i] (XOR from component root to i) and component IDs, with consistency check
    comp_id = [-1] * N
    P = [0] * N
    comp_sizes = []
    C = 0
    for i in range(N):
        if comp_id[i] != -1:
            continue
        dq = deque([i])
        comp_id[i] = C
        P[i] = 0
        size = 0
        while dq:
            u = dq.popleft()
            size += 1
            for v, w in adj[u]:
                if comp_id[v] == -1:
                    comp_id[v] = C
                    P[v] = P[u] ^ w
                    dq.append(v)
                else:
                    # Check consistency on an already discovered edge
                    if (P[u] ^ P[v]) != w:
                        print(-1)
                        return
        comp_sizes.append(size)
        C += 1

    # Build per-bit offsets T[c] to minimize the sum
    B = maxZ.bit_length()  # number of bits to consider
    T = [0] * C
    for k in range(B):
        bitmask = 1 << k
        cnt1 = [0] * C  # number of vertices in component c with bit k = 1 in P
        for i in range(N):
            if (P[i] & bitmask) != 0:
                cnt1[comp_id[i]] += 1
        for c in range(C):
            if cnt1[c] > comp_sizes[c] - cnt1[c]:
                T[c] |= bitmask

    # Compute final A[i] = P[i] XOR T[comp_id[i]]
    A = [0] * N
    for i in range(N):
        A[i] = P[i] ^ T[comp_id[i]]

    print(' '.join(map(str, A)))

if __name__ == "__main__":
    solve()
