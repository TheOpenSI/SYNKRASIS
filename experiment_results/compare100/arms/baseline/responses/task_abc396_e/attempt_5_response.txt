### Step-by-step reasoning
- Model the constraints as a graph: each index i is a node (1..N). For every constraint A_{X_i} XOR A_{Y_i} = Z_i, add an undirected edge between X_i and Y_i with weight Z_i.
- In a connected component, once you fix the value of one node, all other nodes in the component are determined up to a global XOR with a component-specific value. More concretely, pick a root r in the component and define P[v] as the XOR sum of edge weights along any path from r to v. Then any valid assignment has the form A[v] = P[v] XOR t_c, where c is the component of v and t_c is a non-negative integer (the component’s offset).
- Consistency check: along any edge (u, v, Z), we must have P[u] XOR P[v] = Z. If we ever see a violation, there is no solution (-1).
- If the component is consistent, the whole problem decouples by component. For a fixed bit k (0-based), A[v] has bit k equal to (P[v] bit k) XOR (t_c bit k). Let cnt1[c] be the number of vertices in component c whose P[v] has bit k = 1. If t_c's bit k = 0, the number of 1s at bit k among A is cnt1[c]; if t_c's bit k = 1, it is size_c - cnt1[c]. To minimize the total sum, for each component and each bit independently, pick t_c bit k = 0 if cnt1[c] <= size_c - cnt1[c], otherwise 1.
- After determining all t_c, the minimal-sum good sequence is A[v] = P[v] XOR t_{comp(v)}.
- Complexity: Building P and checking consistency is O(N + M). The per-bit optimization is O(B * N), where B is at most 30 (since Z_i <= 1e9). This is efficient for the given limits. Handle edge cases like self-loops (must have Z = 0) naturally through the consistency check.

import sys
from collections import deque

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    M = next(it)

    # Build graph: 0-indexed nodes, edges with weight Z
    adj = [[] for _ in range(N)]
    maxZ = 0
    for _ in range(M):
        x = next(it) - 1
        y = next(it) - 1
        z = next(it)
        adj[x].append((y, z))
        adj[y].append((x, z))
        if z > maxZ:
            maxZ = z

    # Compute P[i] = XOR from component root to i, and verify consistency
    comp_id = [-1] * N
    P = [0] * N
    comp_sizes = []
    C = 0  # number of components

    for i in range(N):
        if comp_id[i] != -1:
            continue
        dq = deque([i])
        comp_id[i] = C
        P[i] = 0
        size = 0
        while dq:
            u = dq.popleft()
            size += 1
            for v, w in adj[u]:
                if comp_id[v] == -1:
                    comp_id[v] = C
                    P[v] = P[u] ^ w
                    dq.append(v)
                else:
                    # Check consistency on already-visited edge
                    if (P[u] ^ P[v]) != w:
                        print(-1)
                        return
        comp_sizes.append(size)
        C += 1

    # Per-bit minimization: decide t_c (the component's XOR shift)
    B = maxZ.bit_length()  # number of relevant bits
    T = [0] * C  # t_c for each component

    if B > 0:
        for k in range(B):
            bitmask = 1 << k
            cnt1 = [0] * C  # number of vertices in component c with P[i] bit k = 1
            for i in range(N):
                if (P[i] & bitmask) != 0:
                    cnt1[comp_id[i]] += 1
            for c in range(C):
                if cnt1[c] > comp_sizes[c] - cnt1[c]:
                    T[c] |= bitmask

    # Build final A[i] = P[i] XOR T[comp_of_i]
    A = [0] * N
    for i in range(N):
        A[i] = P[i] ^ T[comp_id[i]]

    print(' '.join(map(str, A)))

if __name__ == "__main__":
    solve()
