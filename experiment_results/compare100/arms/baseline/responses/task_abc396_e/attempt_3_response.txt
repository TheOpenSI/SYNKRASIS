### Step-by-step reasoning
- The constraints A_u XOR A_v = Z for each edge (u, v) imply that within any connected component, once you fix A at one node, all other values in that component are determined via XOR along paths. Therefore, in a connected component c, all A[i] must be of the form A[i] = P[i] XOR t_c, where P[i] is the XOR of Z-values along any path from a chosen root to i, and t_c is a value that depends only on the component.
- To ensure a valid solution exists, we must verify consistency: for every edge (u, v) with weight Z, P[u] XOR P[v] must equal Z. If any edge violates this, no solution exists.
- If valid, each component is independent. For a fixed bit k, the k-th bit of A[i] is (P[i] bit k) XOR (t_c bit k). Let cnt1 be how many vertices in the component have P[i] with bit k = 1; the number of 1s among A[i] at bit k becomes:
  - cnt1 if t_c bit k = 0
  - (size_of_component - cnt1) if t_c bit k = 1
  We want to minimize the sum of all A[i], which is the sum over bits of (number of 1s at bit k) * 2^k. Therefore, for each bit k we should set t_c bit k to 0 if cnt1 <= size - cnt1, otherwise set it to 1. This minimizes the component’s contribution per bit, and hence the total sum.
- This per-bit minimization can be done independently for each component. Finally, A[i] = P[i] XOR t_c for the component of i gives a globally minimal-sum solution.
- Complexity: Building P and checking consistency is O(N + M). The per-bit minimization is O(B * N), where B is at most 30 (since Z_i <= 1e9). This fits the constraints.

Potential corner cases:
- Self-loops with nonzero Z cause immediate impossibility (A_u XOR A_u = Z != 0).
- M = 0 yields all A_i = 0 as the minimal solution.
- Multiple components are handled independently.

import sys
from collections import deque

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    M = next(it)

    # Build adjacency list with edges (u, v, w)
    adj = [[] for _ in range(N)]
    maxZ = 0
    for _ in range(M):
        a = next(it) - 1
        b = next(it) - 1
        w = next(it)
        adj[a].append((b, w))
        adj[b].append((a, w))
        if w > maxZ:
            maxZ = w

    # Compute P[i] (XOR from component root to i) and component IDs, with consistency check
    comp_id = [-1] * N
    P = [0] * N
    comp_sizes = []
    C = 0
    for i in range(N):
        if comp_id[i] != -1:
            continue
        dq = deque([i])
        comp_id[i] = C
        P[i] = 0
        size = 0
        while dq:
            u = dq.popleft()
            size += 1
            for v, w in adj[u]:
                if comp_id[v] == -1:
                    comp_id[v] = C
                    P[v] = P[u] ^ w
                    dq.append(v)
                else:
                    # Check consistency on an edge (u, v)
                    if (P[u] ^ P[v]) != w:
                        print(-1)
                        return
        comp_sizes.append(size)
        C += 1

    # Build per-bit offsets T[c] to minimize the sum
    B = maxZ.bit_length()  # number of relevant bits
    T = [0] * C
    for k in range(B):
        bitmask = 1 << k
        cnt1 = [0] * C  # number of vertices in component c with bit k = 1 in P
        for i in range(N):
            if (P[i] & bitmask) != 0:
                cnt1[comp_id[i]] += 1
        for c in range(C):
            if cnt1[c] > comp_sizes[c] - cnt1[c]:
                T[c] |= bitmask

    # Compute final A[i] = P[i] XOR T[comp_id[i]]
    A = [0] * N
    for i in range(N):
        A[i] = P[i] ^ T[comp_id[i]]

    print(' '.join(map(str, A)))

if __name__ == "__main__":
    solve()
