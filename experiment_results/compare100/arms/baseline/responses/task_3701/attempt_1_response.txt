### Step-by-step reasoning
- We need to transform the given string into a "good caption" where every block of equal letters has length at least 3. Each operation changes a character by ±1 in the alphabet, so changing caption[i] to letter L costs abs(cap[i] - L).
- A robust approach uses dynamic programming with states representing the last processed position, the letter at that position, and the length of the current run (capped at 3: 1, 2, or 3 meaning at least 3).
- A forward DP would be O(n * 26 * 3) for transitions if done carefully, but we also need to reconstruct the lexicographically smallest resulting caption among all minimal-cost solutions.
- To reconstruct efficiently, we compute a suffix DP suff[i][L][r] representing the minimal cost to transform the suffix i..n-1 given that at position i we place letter L with a current run length r (r in {1,2,3}). Then we can greedily reconstruct the lexicographically smallest string by always choosing the smallest possible t[i] that can still achieve the global minimum.
- For efficiency and memory, we store suff as a flat array using Python's array module (32-bit ints). This keeps memory manageable for n up to 5e4: roughly n * 26 * 3 integers (~3.9 million integers) which is around 15 MB in 32-bit integers.
- We optimize computation by using a per-suffix best-two optimization for the switch operation: for each i, precompute the best and second-best values of suff[i+1][M][1] over M, so we can compute the min switch quickly for any L without iterating 26 letters every time.
- Reconstruction:
  - Find the smallest starting letter L such that suff[0][L][1] equals the overall minimum.
  - Then walk from i=0 to n-2, at each step choosing either:
    - extend with the same letter (t[i+1] = t[i]) or
    - switch to a different letter M (t[i+1] = M) with M != t[i] and run length reset to 1,
    ensuring the total cost matches the suffix DP and breaking ties by lexicographic order (prefer smaller next character when costs are equal).
- Edge case: if n < 3, it is impossible to have all blocks of length at least 3, so return "".

from array import array

class Solution:
    def minCostGoodCaption(self, caption: str) -> str:
        n = len(caption)
        if n < 3:
            return ""

        # Convert caption to 0..25 indices
        cap = [ord(ch) - ord('a') for ch in caption]

        INF = 10**9

        # suff has shape: n x 26 x 3 (for r=1,2,3)
        # We'll store in a flat array for memory efficiency.
        size = n * 26 * 3
        suff = array('i', [INF] * size)

        def sidx(i: int, L: int, r: int) -> int:
            # r in {1,2,3}
            return (i * 26 + L) * 3 + (r - 1)

        # Base case: i = n-1
        last = n - 1
        for L in range(26):
            suff[sidx(last, L, 3)] = abs(cap[last] - L)
            # suff[last][L][1] and suff[last][L][2] remain INF

        # Build suff for i = n-2 down to 0
        for i in range(n - 2, -1, -1):
            # Precompute best two of suff[i+1][M][1] over M
            best1_val, best1_L = INF, -1
            best2_val, best2_L = INF, -1
            for M in range(26):
                val = suff[sidx(i + 1, M, 1)]
                if val < best1_val:
                    best2_val, best2_L = best1_val, best1_L
                    best1_val, best1_L = val, M
                elif val < best2_val:
                    best2_val, best2_L = val, M

            for L in range(26):
                cost_here = abs(cap[i] - L)

                # r = 1
                v_next_r2 = suff[sidx(i + 1, L, 2)]
                suff[sidx(i, L, 1)] = cost_here + v_next_r2

                # r = 2
                v_next_r3 = suff[sidx(i + 1, L, 3)]
                suff[sidx(i, L, 2)] = cost_here + v_next_r3

                # r = 3
                # best switch letter (M != L)
                if best1_L != L:
                    min_switch = best1_val
                    min_M = best1_L
                else:
                    min_switch = best2_val
                    min_M = best2_L

                v_same3 = v_next_r3
                best_next = v_same3 if v_same3 < min_switch else min_switch
                suff[sidx(i, L, 3)] = cost_here + best_next

        # Retrieve global minimum
        min_total = INF
        start_L = -1
        for L in range(26):
            val = suff[sidx(0, L, 1)]
            if val < min_total:
                min_total = val
                start_L = L

        if min_total >= INF or start_L == -1:
            return ""

        # Reconstruct lexicographically smallest answer
        res = [''] * n
        res[0] = chr(start_L + ord('a'))
        cur_L = start_L
        cur_r = 1

        for i in range(n - 1):
            cost_here = abs(cap[i] - cur_L)
            next_same_r = cur_r + 1
            if next_same_r > 3:
                next_same_r = 3
            same_cost = cost_here + suff[sidx(i + 1, cur_L, next_same_r)]

            switch_cost = INF
            best_M = -1
            if cur_r >= 3:
                # Find best M != cur_L minimizing suff[i+1][M][1]
                min_val = INF
                min_M = -1
                for M in range(26):
                    if M == cur_L:
                        continue
                    val = suff[sidx(i + 1, M, 1)]
                    if val < min_val or (val == min_val and M < min_M):
                        min_val = val
                        min_M = M
                if min_M != -1:
                    switch_cost = cost_here + min_val
                    best_M = min_M

            if same_cost < switch_cost:
                next_L = cur_L
                next_r = next_same_r
            elif switch_cost < same_cost:
                next_L = best_M
                next_r = 1
            else:
                # Equal costs: choose the option yielding smaller next character
                if best_M == -1:
                    next_L = cur_L
                    next_r = next_same_r
                else:
                    if cur_L <= best_M:
                        next_L = cur_L
                        next_r = next_same_r
                    else:
                        next_L = best_M
                        next_r = 1

            res[i + 1] = chr(next_L + ord('a'))
            cur_L, cur_r = next_L, next_r

        return "".join(res)
