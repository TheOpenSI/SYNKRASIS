### Step-by-step reasoning
- Problem understanding: At step i (1 ≤ i ≤ N), we insert the number i into the current array so that it becomes the P_i-th element from the start. Here P_i is between 1 and i. After all insertions, we output the final array A of length N.
- Key observation: If we build the final array A from back to front (i = N down to 1), when placing i there are exactly i empty slots left in A. P_i tells us that i should occupy the P_i-th empty slot from the left in the final array.
- Data structure choice: To efficiently find and fill the k-th empty slot, use a Fenwick Tree (Binary Indexed Tree) over positions 1..N:
  - Initialize all positions as empty (value 1 at each index).
  - For i from N down to 1:
    - k = P_i
    - Find pos = the k-th empty slot from the left using Fenwick tree (prefix-sum / kth order statistics).
    - Set A[pos] = i and mark pos as filled (update Fenwick with -1 at pos).
- Correctness reasoning: This reverse placement mirrors the effect of inserting i into the P_i-th position in the current array at step i, applied for all i from N down to 1. The final arrangement is uniquely determined and can be recovered in O(N log N) time with a Fenwick tree.
- Complexity: O(N log N) time, O(N) space. Handles N up to 5e5 comfortably in Python with optimized I/O.

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    P = [next(it) for _ in range(N)]

    # Fenwick Tree (Binary Indexed Tree) for range [1..N]
    bit = [0] * (N + 1)

    def add(idx, delta):
        i = idx
        while i <= N:
            bit[i] += delta
            i += i & -i

    def kth(k):
        # Find the smallest index pos such that the prefix sum >= k
        idx = 0
        bitMask = 1 << (N.bit_length())  # power of two >= N
        while bitMask:
            t = idx + bitMask
            if t <= N and bit[t] < k:
                idx = t
                k -= bit[t]
            bitMask >>= 1
        return idx + 1

    # Initialize: all positions are empty -> value 1 at each position
    for i in range(1, N + 1):
        add(i, 1)

    A = [0] * (N + 1)  # 1-based indexing for final output

    for i in range(N, 0, -1):
        k = P[i - 1]
        pos = kth(k)  # k-th empty slot from the left
        A[pos] = i
        add(pos, -1)  # mark this slot as filled

    # Output
    out = ' '.join(str(A[i]) for i in range(1, N + 1))
    sys.stdout.write(out)

if __name__ == "__main__":
    main()
```
