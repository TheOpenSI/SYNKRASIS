### Step-by-step reasoning
- Understanding the operation: At step i, we insert the number i into the current array so that it becomes the P_i-th element from the start. If the current length of A is i-1, P_i ranges from 1 to i. When P_i = i, i is appended at the end; when P_i = 1, i becomes the first element, and so on.
- Naive simulation would be O(N^2). We need an O(N log N) approach for N up to 5e5.
- Key idea: Reconstruct the final array A by processing i from N down to 1. At that moment, there are exactly i empty slots left in A. The value P_i tells us that i should occupy the P_i-th empty slot from the left in the final array.
- To efficiently find and mark the k-th empty slot, use a Binary Indexed Tree (Fenwick Tree):
  - Maintain an array of size N where bit[j] indicates whether position j is empty (1) or filled (0).
  - Initially, all positions are empty, so each position has value 1.
  - For i = N down to 1:
    - Let k = P_i (1-based).
    - Find pos = the k-th empty slot from the left using Fenwick tree (a standard kth-order statistic on a Fenwick tree).
    - Set A[pos] = i and mark that slot as filled in the Fenwick tree (add -1 at pos).
- Correctness: After placing i into the k-th empty slot, all later (larger) numbers have already been placed into some empty slots to the left or right, and the number of remaining empty slots equals i-1 for the next iteration. This mirrors the effect of inserting i into the P_i-th position in the current array at step i, ensuring the final arrangement matches all insertions.
- Edge cases and constraints:
  - N ≥ 1, 1 ≤ P_i ≤ i, so there is always a valid position.
  - Time complexity: O(N log N) due to N Fenwick operations, suitable for N up to 5e5.
  - Output format requires space-separated A_1 ... A_N in one line.
- With careful I/O and a robust kth function on the Fenwick tree, this approach should work on all valid inputs.

import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    P = [next(it) for _ in range(N)]

    # Fenwick Tree (Binary Indexed Tree) for range [1..N]
    bit = [0] * (N + 1)

    def add(idx, delta):
        i = idx
        while i <= N:
            bit[i] += delta
            i += i & -i

    def kth(k):
        # Find the smallest index pos such that the prefix sum >= k
        idx = 0
        bitMask = 1 << (N.bit_length())  # power of two >= N
        while bitMask:
            t = idx + bitMask
            if t <= N and bit[t] < k:
                idx = t
                k -= bit[t]
            bitMask >>= 1
        return idx + 1

    # Initialize: all positions are empty -> value 1 at each position
    for i in range(1, N + 1):
        add(i, 1)

    A = [0] * (N + 1)  # 1-based for final output

    for i in range(N, 0, -1):
        k = P[i - 1]
        pos = kth(k)  # k-th empty slot from the left
        A[pos] = i
        add(pos, -1)  # mark this slot as filled

    # Output
    out = ' '.join(str(A[i]) for i in range(1, N + 1))
    sys.stdout.write(out)

if __name__ == "__main__":
    main()
