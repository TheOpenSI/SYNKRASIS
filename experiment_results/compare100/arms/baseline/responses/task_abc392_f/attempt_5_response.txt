### Step-by-step reasoning
- Understanding the operation: At step i (1 ≤ i ≤ N), we insert the number i into A so that it becomes the Pi-th element from the beginning. After i insertions, A has length i, with i at position Pi.
- Observing the pattern: If we simulate from the end (i = N down to 1) and keep track of which positions in a final array of size N are still empty, placing i into the Pi-th empty slot from the left exactly mirrors the forward insertion process.
- Data structure choice: Use a Fenwick Tree (Binary Indexed Tree) to maintain counts of empty slots. Each position in 1..N starts as empty (count = 1). After placing a value into a slot, we mark that slot as filled by adding -1 at that index.
- Key operations:
  - kth(k): find the smallest index pos such that the prefix sum up to pos is at least k. This gives the k-th empty slot from the left.
  - update(pos, -1): mark a slot as filled.
- Algorithm:
  1. Read N and array P[1..N].
  2. Initialize a Fenwick Tree where bit[i] = i & -i, representing N empty slots.
  3. Create A[1..N].
  4. For i from N down to 1:
     - k = P[i]
     - pos = kth(k)
     - A[pos] = i
     - update(pos, -1)
  5. Output A[1], A[2], ..., A[N].
- Complexity: O(N log N) time and O(N) space, suitable for N up to 5e5.
- Edge cases: Works for the minimum input (N = 1) and all valid P_i in [1..i].

### Code

import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    P = [next(it) for _ in range(N)]

    # Fenwick Tree (Binary Indexed Tree) for 1..N
    bit = [0] * (N + 1)

    # Initialize: all positions are empty -> value 1 at each index
    for i in range(1, N + 1):
        bit[i] = i & -i  # lowbit(i)

    def add(idx, delta):
        while idx <= N:
            bit[idx] += delta
            idx += idx & -idx

    def kth(k):
        # Find the smallest index pos such that prefix_sum(pos) >= k
        idx = 0
        bit_mask = 1 << (N.bit_length() - 1)  # largest power of two <= N
        while bit_mask:
            t = idx + bit_mask
            if t <= N and bit[t] < k:
                k -= bit[t]
                idx = t
            bit_mask >>= 1
        return idx + 1

    A = [0] * (N + 1)  # 1-based

    for i in range(N, 0, -1):
        k = P[i - 1]
        pos = kth(k)
        A[pos] = i
        add(pos, -1)  # mark slot as filled

    out = ' '.join(str(A[i]) for i in range(1, N + 1))
    sys.stdout.write(out)
    sys.stdout.write('\n')

if __name__ == "__main__":
    main()
