### Step-by-step reasoning
- The previous solution treated vertical and horizontal edge choices independently and only enforced parity constraints per row/column. This misses the per-cell requirement for Type B tiles (p = 0) where exactly two endpoints must be present and they must be opposite edges, not a mix of vertical and horizontal endpoints. In particular, for cells with S[i][j] = 'B' (p = 0), the two edge-pairs (vertical U-D and horizontal L-R) must sum to exactly 2 endpoints in total, which imposes a cross-cell constraint between vertical and horizontal edge choices.
- A correct model is to treat the problem as a system of linear equations over GF(2) on variables representing the “reference” edge states for each column and each row:
  - Let D0_j be the reference down-edge state for column j (affects all Down edges in that column).
  - Let R0_i be the reference right-edge state for row i (affects all Right edges in that row).
  - For a cell (i, j) with A[i][j] = 1 (Type A): the vertical and horizontal edge states must flip between adjacent edges, giving equations:
    D_{i,j} XOR D_{i-1,j} = 1 and R_{i,j} XOR R_{i,j-1} = 1
  - For a cell (i, j) with A[i][j] = 0 (Type B): the vertical and horizontal edge states must be equal within their pair, but exactly one of the two pairs must be active. This yields a cross-cell constraint:
    D0_j XOR R0_i = B[i][j], where B[i][j] is computable from A by:
    Bcol(i-1) is XOR of A[t][j] for t from 1 to i-1 (with wrap), and Brow(i, j-1) is XOR of A[i][t] for t from 1 to j-1 (with wrap).
    Then B[i][j] = 1 XOR Bcol(i-1) XOR Brow(i, j-1).
- The equations for Type A cells decouple via a standard parity argument (the XOR sums along columns/rows must be 0 for a solution to exist). If any column has an odd number of A’s, or any row has an odd number of A’s, there is no valid placement.
- After ensuring the parity conditions, the remaining constraints reduce to a bipartite system:
  D0_j XOR R0_i = B[i][j] for all cells with A[i][j] = 0.
  This is a system of XOR-constraints that can be solved with a Disjoint Set Union (DSU) (Union-Find) structure that tracks parity between nodes.
- The DSU approach yields:
  - If a contradiction is found, the answer is 0.
  - Otherwise, each connected component of the bipartite graph contributes a factor of 2, so the answer is 2^(number_of_components) modulo 998244353.

Key implementation notes:
- We store the grid as a compact form: a list of bytearrays, one per row, with 1 for A and 0 for B.
- Parity checks are done in O(HW).
- We compute B[i][j] only for A[i][j] = 0 cells using an efficient per-column and per-row prefix approach with wrap handling:
  - For each column j, compute Bcol(i-1) for i = 0..H-1 as: Bcol(-1) = XOR_{t=1..H-1} A[t][j], and Bcol(i-1) = XOR_{t=1..i-1} A[t][j] for i > 0.
  - For row prefixes Brow(i, j-1), we maintain a running per-row prefix Brow_prev[i] that equals XOR_{t=1..j-1} A[i][t], and update Brow_prev[i] = Brow_prev[i] XOR A[i][j] after processing column j.
  - Then Bij = 1 XOR Bcol(i-1) XOR Brow_prev[i].
- We run DSU unions for each zero cell edge (column j node, row i node) with weight Bij.
- Finally, the number of components is found by counting distinct DSU roots, and the answer is 2^components mod 998244353.

import sys

MOD = 998244353

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.xor_to_parent = [0] * n  # parity from node to its parent

    def find(self, x):
        if self.parent[x] == x:
            return x, 0
        # Iterative path compression with parity tracking
        path = []
        cur = x
        while self.parent[cur] != cur:
            path.append(cur)
            cur = self.parent[cur]
        root = cur
        # Compute xor from each node on path to root
        xor_to_root = {}
        acc = 0
        for node in reversed(path):
            acc ^= self.xor_to_parent[node]
            xor_to_root[node] = acc
        # Path compression: set parent directly to root and update xor_to_parent
        for node in path:
            self.parent[node] = root
            self.xor_to_parent[node] = xor_to_root[node]
        # x's xor to root
        if x == root:
            return root, 0
        return root, self.xor_to_parent[x]

    def union(self, a, b, w):
        ra, xa = self.find(a)
        rb, xb = self.find(b)
        if ra == rb:
            # Check consistency: xa XOR xb must equal w
            return (xa ^ xb) == w
        # Union by rank
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
            xa, xb = xb, xa
        self.parent[rb] = ra
        # Set parity so that color[a] XOR color[b] == w
        # Let color[a] = color[ra] XOR xa, color[b] = color[rb] XOR xb
        # After linking rb under ra, color[rb] = color[ra] XOR t
        # Then (color[ra] XOR xa) XOR ((color[ra] XOR t) XOR xb) = w
        # => xa XOR t XOR xb = w  => t = xa ^ xb ^ w
        self.xor_to_parent[rb] = xa ^ xb ^ w
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1
        return True

def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    idx = 1
    out = []
    for _ in range(t):
        H = int(data[idx]); W = int(data[idx+1]); idx += 2

        # Read grid as compact A/B -> 1/0
        A = []
        row_parity = [0] * H
        col_parity = [0] * W
        ok_input = True
        for i in range(H):
            s = data[idx].decode(); idx += 1
            row = bytearray(W)
            rp = 0
            for j, ch in enumerate(s):
                if ch == 'A':
                    row[j] = 1
                    rp ^= 1
                    col_parity[j] ^= 1
            A.append(row)
            row_parity[i] = rp

        # Parity feasibility check: each row and column must have even number of A's
        if any(row_parity[i] for i in range(H)) or any(col_parity[j] for j in range(W)):
            out.append("0")
            continue

        # Build DSU over (W) column nodes + (H) row nodes
        n = W + H
        dsu = DSU(n)

        # Brow_prev[i] = XOR_{t=1..j-1} A[i][t], initially for j=0 we need Brow(i,-1)
        # Under row parity zero, Brow(i,-1) equals A[i][0]
        Brow_prev = [A[i][0] for i in range(H)]

        possible = True

        for j in range(W):
            # Build colA for this column
            colA = [A[i][j] for i in range(H)]
            # Build Bcol(i-1): prefix_col[k] = XOR_{t=1..k} A[t][j], with prefix_col[0] = 0
            prefix_col = [0] * H
            acc = 0
            for k in range(1, H):
                acc ^= colA[k]
                prefix_col[k] = acc

            # Process all i with A[i][j] == 0
            for i in range(H):
                if colA[i] == 0:
                    Bcol = prefix_col[i-1] if i > 0 else prefix_col[H-1]
                    Bij = 1 ^ Bcol ^ Brow_prev[i]
                    u = j          # column node
                    v = W + i      # row node
                    if not dsu.union(u, v, Bij):
                        possible = False
                        break
            if not possible:
                break

            # Update Brow_prev to Brow(i, j) for next column
            for i in range(H):
                Brow_prev[i] ^= colA[i]

        if not possible:
            out.append("0")
            continue

        # Count components: number of distinct DSU roots among all n nodes
        roots = set()
        for x in range(n):
            r, _ = dsu.find(x)
            roots.add(r)
        comps = len(roots)
        ans = pow(2, comps, MOD)
        out.append(str(ans))

    print("\n".join(out))

if __name__ == "__main__":
    main()
