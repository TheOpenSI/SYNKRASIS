### Step-by-step reasoning
- The game always keeps the graph bipartite, because an added edge is allowed only if it does not create an odd cycle.
- A move can be classified as:
  - Between two vertices in different connected components: this simply merges the components and never creates a cycle.
  - Between two vertices in the same component: this creates a cycle, and is allowed only if the distance between the two vertices in the current component is odd; equivalently, the two vertices must be in opposite bipartition colors of that component.

- In the end, there can be no further moves exactly when the graph becomes a complete bipartite graph with some global bipartition (A, B) of all N vertices: all missing edges are exactly the cross edges between A and B. The final number of edges is |A| * |B|, so the total number of moves performed equals
  moves = |A| * |B| - M.

- The main challenge is that the global partition (A, B) is not fixed at the start: each connected component has its own bipartition (a_i, b_i) with a_i + b_i = size of the component. When combining components, you effectively choose for each component which side maps to A. This gives flexibility in the final |A|, but parity constraints remain:
  - If N is odd: |A| and |B| have opposite parity, so |A| * |B| is always even. Thus moves parity equals M parity. Aoki wins iff M is odd; Takahashi otherwise.
  - If N is even: the parity of |A| * |B| equals the parity of |A| (since |B| has the same parity as |A|). Whether |A| can be chosen to be even or odd depends on whether there are odd-sized components:
    - If there exists any odd-sized component, you can flip orientations to realize both parities of |A|, but the game dynamics show that with at least one odd-sized component, Aoki has a winning strategy (the first player can force a win).
    - If all components have even size, the parity of |A| is fixed. Let S_fixed be the XOR of (size_of_color0_in_component mod 2) over all even-sized components (i.e., parity of the a_i for each component). Then the parity of moves is S_fixed XOR (M mod 2). Aoki wins iff this parity is 1.

- Algorithm:
  - Compute the bipartition of each connected component via BFS/DFS, obtaining counts (cnt0, cnt1) for each component.
  - For each component:
    - If its size is odd, increment t_odd (the number of odd-sized components).
    - If its size is even, accumulate S_fixed by XOR-ing (cnt0 mod 2).
  - Apply the decision rules above:
    - If N is odd: Aoki if M is odd, else Takahashi.
    - Else (N even):
      - If t_odd > 0: Aoki.
      - Otherwise: Aoki if (S_fixed XOR (M mod 2)) == 1, else Takahashi.

- Complexity: O(N + M) time and O(N + M) memory, suitable for N, M ≤ 2e5.

- No external libraries required.

None

### Code
```
import sys
from collections import deque

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    M = next(it)

    adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        u = next(it)
        v = next(it)
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (N + 1)
    t_odd = 0      # number of odd-sized components
    S_fixed = 0    # parity contribution from even-sized components

    for start in range(1, N + 1):
        if color[start] != -1:
            continue
        q = deque([start])
        color[start] = 0
        cnt0 = 1
        cnt1 = 0

        while q:
            u = q.popleft()
            cu = color[u]
            for w in adj[u]:
                if color[w] == -1:
                    color[w] = cu ^ 1
                    if color[w] == 0:
                        cnt0 += 1
                    else:
                        cnt1 += 1
                    q.append(w)
                # Given constraints, graph is bipartite, so no conflicts

        size = cnt0 + cnt1
        if size % 2 == 1:
            t_odd += 1
        else:
            S_fixed ^= (cnt0 & 1)

    if N % 2 == 1:
        print("Aoki" if (M & 1) else "Takahashi")
        return

    if t_odd > 0:
        print("Aoki")
        return

    total_parity = S_fixed ^ (M & 1)
    print("Aoki" if total_parity == 1 else "Takahashi")

if __name__ == "__main__":
    main()
```
