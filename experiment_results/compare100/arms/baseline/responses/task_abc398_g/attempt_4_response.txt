### Step-by-step reasoning
- The operation is allowed iff adding the edge does not create an odd cycle. In a bipartite graph, this means:
  - Connecting vertices in different connected components is always allowed (no cycle forms).
  - Connecting two vertices in the same connected component is allowed iff they have opposite colors in the current bipartition (connecting same color would create an odd cycle).

- Therefore, throughout the game the graph remains bipartite, and the final state (when no moves are possible) must be a complete bipartite graph K_{a,b} on all N vertices, i.e., every cross-edge across a partition (A, B) is present, and there are no edges inside A or inside B. The number of moves made in total is a*b − M.

- The partition (A,B) that the final complete bipartite graph uses must respect the bipartite components of the initial graph G:
  - Each connected component i has a bipartition of sizes (x_i, y_i) (x_i + y_i = size_i).
  - In the final K_{a,b}, for each component you either map its x_i side to A and y_i to B, or flip (map y_i to A and x_i to B). Thus a = sum over i of either x_i or y_i.

- Parity considerations:
  - If a component has odd size, then x_i and y_i have opposite parity, so this component allows flipping the parity contribution to a. If at least one component has odd size, you can realize both parities for a.
  - If all components have even size, then for every component x_i and y_i have the same parity, so the parity of a is fixed. Let S_fixed be the XOR (parity) of all x_i across even-sized components; this is the fixed parity of a when all components are even-sized.

- Let N be the total number of vertices. Then:
  - If N is odd, a and b have opposite parities, so a*b is always even. The parity of the total number of moves (a*b − M) is simply the parity of M (since even − M ≡ M mod 2). Therefore Aoki (first player) wins iff M is odd; Takahashi otherwise.
  - If N is even:
    - If there exists an odd-sized component, you can realize both parities of a, hence you can force a*b to be odd or even as needed. You can choose a*b parity to be opposite M parity, making the total number of moves odd. Thus Aoki wins.
    - If all components are even-sized, a*b parity is fixed to S_fixed. The total moves parity is a*b − M ≡ S_fixed − M (mod 2) which is S_fixed XOR (M mod 2). Aoki wins iff this value is 1.

- Algorithmically, compute for each connected component its bipartition sizes (x_i, y_i). Track:
  - has_odd: whether any component has odd size (x_i + y_i is odd).
  - S_fixed: XOR of x_i mod 2 over all even-sized components.
  - M and N come from input.

- Complexity: O(N + M) time, O(N + M) memory, suitable for N,M ≤ 2e5.

import sys
from collections import deque

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    M = next(it)

    adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        u = next(it)
        v = next(it)
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (N + 1)
    has_odd = False      # exists an odd-sized component
    S_fixed = 0          # parity contribution from even-sized components

    for start in range(1, N + 1):
        if color[start] != -1:
            continue
        q = deque([start])
        color[start] = 0
        cnt0 = 1
        cnt1 = 0

        while q:
            u = q.popleft()
            cu = color[u]
            for w in adj[u]:
                if color[w] == -1:
                    color[w] = cu ^ 1
                    if color[w] == 0:
                        cnt0 += 1
                    else:
                        cnt1 += 1
                    q.append(w)
                # The problem guarantees no odd cycle, so no color conflicts

        size = cnt0 + cnt1
        if size % 2 == 1:
            has_odd = True
        else:
            S_fixed ^= (cnt0 & 1)

    if N % 2 == 1:
        # a*b is always even; winner depends on M parity
        print("Aoki" if (M & 1) else "Takahashi")
        return

    if has_odd:
        # can realize both parities of a; first player can force win
        print("Aoki")
        return

    total_parity = S_fixed ^ (M & 1)
    print("Aoki" if total_parity == 1 else "Takahashi")

if __name__ == "__main__":
    main()
