### Step-by-step reasoning
- We model the problem as selecting up to two operations (cost 1 each) to turn all x_j to 1. If a single operation can cover everything, we output that.
- Observations:
  - A single operation can cover all only if there exists an interval [L_i, R_i] = [1, N] (op1). If so, K = 1 with that operation.
  - With two operations, there are a few viable patterns:
    1) Two op2 operations on two disjoint intervals. If two given intervals are disjoint, applying op2 on both will make every position fall outside at least one of the intervals, hence all ones.
    2) A containment pattern: if there exists A ⊆ B, then doing op2 on A and op1 on B makes all positions 1. This is because all positions outside A become 1 by op2, and all positions inside A (which are inside B) become 1 by op1.
    3) Two op1 operations whose union covers [1, N]. If there are two intervals whose union is the entire range, applying op1 on both covers all positions.
- Our approach:
  - Step 1: If any interval is exactly [1, N], print K = 1 with op_i = 1 for that interval.
  - Step 2: Detect two disjoint intervals (A, B). If found, print K = 2 with op_A = 2 and op_B = 2.
  - Step 3: Detect a containment pair A ⊆ B with a deterministically chosen B (outer) that minimizes R_B among all containers for A. Use a Fenwick tree (BIT) to efficiently find the minimal R_B ≥ R_A among previously seen intervals (sorted by L). This yields a canonical, stable pair (B, A) with B containing A. Print K = 2 with B as op1 and A as op2.
  - Step 4: If neither of the above works, check if two op1 operations can cover [1, N] by picking the interval with L ≤ 1 that extends farthest to the right (call it I1), then see if there exists another interval I2 with L ≤ R(I1) + 1 and R(I2) ≥ N. If so, print K = 2 with I1 and I2 as op1.
  - If none of the above succeed, print -1.

- The solution is designed to run in O(M log M) time (due to sorting and Fenwick operations) and O(M) memory, suitable for M up to 200k and N up to 1e6.

- The approach also selects a canonical containment pair (the outer interval with the smallest possible right endpoint that still contains the inner interval). This matches the expectation in samples and produces predictable outputs.

import sys
from collections import defaultdict

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    N = next(it)
    M = next(it)

    intervals = []
    for i in range(1, M + 1):
        L = next(it)
        R = next(it)
        intervals.append((L, R, i))

    # Step 1: single operation covering all
    for L, R, idx in intervals:
        if L == 1 and R == N:
            ans = [0] * M
            ans[idx - 1] = 1
            print(1)
            print(' '.join(map(str, ans)))
            return

    # Step 2: two disjoint intervals -> two op2
    intervals_by_L = sorted(intervals, key=lambda t: (t[0], t[1]))
    minR = 10**9
    minIdx = -1
    for L, R, idx in intervals_by_L:
        if minIdx != -1 and minR < L:
            ans = [0] * M
            ans[minIdx - 1] = 2
            ans[idx - 1] = 2
            print(2)
            print(' '.join(map(str, ans)))
            return
        if R < minR:
            minR = R
            minIdx = idx

    # Step 3: containment pair A ⊆ B with B chosen to minimize R_B (canonical)
    class Fenwick:
        def __init__(self, n):
            self.n = n
            self.bit = [0] * (n + 2)
        def add(self, i, delta):
            n = self.n
            while i <= n:
                self.bit[i] += delta
                i += i & -i
        def sum(self, i):
            s = 0
            while i > 0:
                s += self.bit[i]
                i -= i & -i
            return s
        def range_sum(self, l, r):
            if r < l:
                return 0
            return self.sum(r) - self.sum(l - 1)
        def find_by_prefix(self, target):
            idx = 0
            bitmask = 1
            while bitmask << 1 <= self.n:
                bitmask <<= 1
            while bitmask:
                t = idx + bitmask
                if t <= self.n and self.bit[t] < target:
                    idx = t
                    target -= self.bit[t]
                bitmask >>= 1
            return idx + 1

    intervals_by_L = sorted(intervals, key=lambda t: (t[0], t[1]))
    fen = Fenwick(N)
    buckets = defaultdict(list)
    for L, R, idx in intervals_by_L:
        # check if there exists a previous interval B with R_B >= R
        if fen.range_sum(R, N) > 0:
            # minimal R_B >= R
            base = fen.sum(R - 1)
            r_found = fen.find_by_prefix(base + 1)
            # get a B index with this R
            if buckets[r_found]:
                B_idx = buckets[r_found].pop()
                A_idx = idx
                ans = [0] * M
                ans[B_idx - 1] = 1
                ans[A_idx - 1] = 2
                print(2)
                print(' '.join(map(str, ans)))
                return
        # add current as potential B for future A
        buckets[R].append(idx)
        fen.add(R, 1)

    # Step 4: two op1's covering by union
    bestR = -1
    bestIdx = -1
    for L, R, idx in intervals:
        if L <= 1 and R > bestR:
            bestR = R
            bestIdx = idx
    if bestIdx != -1:
        for L, R, idx in intervals:
            if idx == bestIdx:
                continue
            if L <= bestR + 1 and R >= N:
                ans = [0] * M
                ans[bestIdx - 1] = 1
                ans[idx - 1] = 1
                print(2)
                print(' '.join(map(str, ans)))
                return

    print(-1)

if __name__ == "__main__":
    solve()
