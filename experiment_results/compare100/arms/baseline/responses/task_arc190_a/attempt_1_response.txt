### Step-by-step reasoning
- We need to pick for each operation i one of: do nothing (cost 0), set x in [L_i, R_i] to 1 (cost 1), or set x outside [L_i, R_i] to 1 (cost 1). The final array must be all ones.
- A simple successful solution can be found with certain patterns of operations:
  - If any interval is [1, N], we can finish with a single op1 (cost 1).
  - If there exist two disjoint intervals, using op2 on both intervals covers all positions (since their complements cover the entire range). This gives cost 2.
  - If there exists an interval starting at or before 1 and another ending at or after N, and their ranges overlap or touch (L2 ≤ R1+1), using op1 on both can cover [1, N] with cost 2.
  - If one interval is contained in another (A_i ⊆ A_j), we can use op2 on the inner interval and op1 on the outer one to cover everything with cost 2.
- We must be careful: a test case like [1,3] and [2,5] (test 3) requires two op1 operations even though no interval is [1,N] and the simple disjoint-two-op2 pattern doesn’t apply. So we additionally check for the two-op1 pattern.
- If no 2-operation solution exists, we attempt a 3-operation plan: use op2 on two “extreme” intervals to cover everything outside a middle segment J2, and try to cover J2 with a few op1 operations using a greedy interval cover on the remaining intervals. If possible, this yields a valid K=3 solution.
- If none of the above works, the answer is -1.

The fixed approach should cover all provided test cases, including tricky ones like test 3, where the minimal solution is two op1 operations.

import sys

def solve():
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    N = int(next(it))
    M = int(next(it))

    # Each interval is (L, R, idx) with idx 1-based
    intervals = []
    for i in range(1, M + 1):
        L = int(next(it)); R = int(next(it))
        intervals.append((L, R, i))

    ans = [0] * M  # 0 by default

    # 1) If any interval is exactly [1, N], finish with a single op1
    for L, R, idx in intervals:
        if L == 1 and R == N:
            ans[idx - 1] = 1
            print(1)
            print(' '.join(map(str, ans)))
            return

    # 2) Two op2 on two disjoint intervals -> covers all
    intervals_by_L = sorted(intervals, key=lambda t: (t[0], t[1]))
    bestR = -1
    bestIdx = -1
    for L, R, idx in intervals_by_L:
        if bestR != -1 and L > bestR:
            # Found a disjoint pair: bestIdx and idx
            ans[bestIdx - 1] = 2
            ans[idx - 1] = 2
            print(2)
            print(' '.join(map(str, ans)))
            return
        if R > bestR:
            bestR = R
            bestIdx = idx

    # 3) Two op1 pattern: one interval starting at/before 1, another ending at/after N
    i_best = -1
    R_best = -1
    for L, R, idx in intervals:
        if L <= 1 and R > R_best:
            R_best = R
            i_best = idx
    if i_best != -1:
        for L, R, idx in intervals:
            if idx == i_best:
                continue
            if R >= N and L <= R_best + 1:
                ans[i_best - 1] = 1
                ans[idx - 1] = 1
                print(2)
                print(' '.join(map(str, ans)))
                return

    # 4) Nested pair: inner interval contained in an outer interval -> outer as op1, inner as op2
    maxR_so_far = -1
    maxR_idx_so_far = -1
    for L, R, idx in intervals_by_L:
        if maxR_so_far != -1 and R <= maxR_so_far:
            inner = idx
            outer = maxR_idx_so_far
            if inner != outer:
                ans[inner - 1] = 2
                ans[outer - 1] = 1
                print(2)
                print(' '.join(map(str, ans)))
                return
        if R > maxR_so_far:
            maxR_so_far = R
            maxR_idx_so_far = idx

    # 5) Fallback: try a 3-operation solution via extremes and greedy cover of middle segment
    if M >= 2:
        # i_star: interval with maximum L (break ties by larger R)
        i_star_iv = max(intervals, key=lambda t: (t[0], -t[1]))
        i_star = i_star_iv[2]
        L_star = i_star_iv[0]
        R_i = i_star_iv[1]

        # j_star: interval with minimum R (break ties by smaller L)
        j_star_iv = min(intervals, key=lambda t: (t[1], t[0]))
        j_star = j_star_iv[2]

        L_j = j_star_iv[0]
        R_j = j_star_iv[1]

        A = max(L_star, 1)
        B = min(R_i, N)

        if A <= B:
            # Try to cover [A, B] with remaining intervals (excluding i_star and j_star) via greedy
            pool = []
            for L, R, idx in intervals:
                if idx == i_star or idx == j_star:
                    continue
                pool.append((L, R, idx))
            pool.sort(key=lambda t: t[0])

            current = A
            p = 0
            import heapq
            heap = []
            used = []
            possible = True

            while current <= B:
                while p < len(pool) and pool[p][0] <= current:
                    Lp, Rp, idxp = pool[p]
                    heapq.heappush(heap, (-Rp, idxp))
                    p += 1
                # Remove intervals that don't reach current
                while heap and -heap[0][0] < current:
                    heapq.heappop(heap)
                if not heap:
                    possible = False
                    break
                negRp, idxp = heapq.heappop(heap)
                Rp = -negRp
                used.append(idxp)
                current = Rp + 1

            if possible:
                ans[i_star - 1] = 2
                ans[j_star - 1] = 2
                for u in used:
                    ans[u - 1] = 1
                K = 2 + len(used)
                print(K)
                print(' '.join(map(str, ans)))
                return

    print(-1)

if __name__ == "__main__":
    solve()
