### Step-by-step reasoning
- The game ends as soon as every index 1..N has been used at least once (i.e., added to S). After that, no further moves occur, even if some A_i remain positive.
- If there is no index i with A_i = 1, then every opened index can still be drained at least once, making the parity of the total number of moves flexible. However, a key observation for optimal play is that the first player can force a win based on the position of the first 1 in the array.
- If there exists at least one A_i = 1, consider the leftmost such position first1 (1-based index). The game’s parity up to the moment the last index is opened is strongly influenced by how many positions remain to the right of first1.
  - If N - first1 is even, the first player can ensure the game ends on their move (Fennec wins).
  - If N - first1 is odd, the second player can force the ending move to be theirs (Snuke wins).
- If there is no 1 anywhere, the second player can force the game to end on their move (Snuke wins) for all N > 1.
- Special case: N = 1 always results in Fennec winning on the single available move.

Based on these observations, a compact rule emerges:
- If N == 1: Fennec
- Else if there exists an index i with A_i == 1:
  - Let first1 be the smallest index with A[first1] == 1
  - If (N - first1) is even, Fennec wins; else Snuke wins
- Else (no 1 in the array): Snuke wins

This rule matches the given samples:
- Sample 1: N=3, A=[1,9,2], first1=1, N-first1=2 even → Fennec
- Sample 2: N=2, A=[25,29], no 1 → Snuke

import sys

def main():
    data = list(map(int, sys.stdin.read().split()))
    if not data:
        return
    N = data[0]
    A = data[1:1+N]

    # Special case
    if N == 1:
        print("Fennec")
        return

    first1 = None
    for i, v in enumerate(A, start=1):
        if v == 1:
            first1 = i
            break

    if first1 is None:
        print("Snuke")
        return

    if (N - first1) % 2 == 0:
        print("Fennec")
    else:
        print("Snuke")

if __name__ == "__main__":
    main()
