### Step-by-step reasoning
- The game ends precisely when every index 1..N has been used at least once (i.e., added to S). Until that moment, players can choose to use an index that has already been used (stall moves) as long as its A_i remains positive.
- If there exists an i with A_i == 1, then that index can only be used once (its first use). After that, it cannot contribute to any stall moves. The strategic impact of such a 1 is that after the leftmost 1 appears, the remaining moves become constrained by the parity of how many positions remain to be included (and who makes the last first-use).
- If there is no A_i == 1 (i.e., all A_i >= 2), the players can still stall by repeatedly using some indices, but the overall parity outcome becomes governed by the parity of N itself. Intuitively, with all A_i >= 2, the last new index must be the N-th first-use, and the parity of N determines who makes that final, winning move.

From these insights, the winner can be determined with a simple rule:
- Find the leftmost index first1 with A[first1] == 1.
  - If such first1 exists, the winner is Fennec if (N - first1) is even, otherwise Snuke.
  - If there is no A_i == 1, the winner is Fennec if N is odd, otherwise Snuke.

This logic runs in O(N) time and uses O(1) extra memory beyond the input.

A previous attempt forgot the case "no 1 anywhere" where N is odd, which can change the winner to Fennec. The corrected approach handles that properly.

import sys

def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    N = int(next(it))
    A = [int(next(it)) for _ in range(N)]

    # Find the leftmost index with A[i] == 1 (1-based index)
    first1 = None
    for idx, val in enumerate(A, start=1):
        if val == 1:
            first1 = idx
            break

    if first1 is None:
        # No 1 exists in the array
        print("Fennec" if N % 2 == 1 else "Snuke")
        return

    # Leftmost 1 exists
    if (N - first1) % 2 == 0:
        print("Fennec")
    else:
        print("Snuke")

if __name__ == "__main__":
    solve()
