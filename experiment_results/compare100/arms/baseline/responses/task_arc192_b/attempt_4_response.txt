### Step-by-step reasoning
- We need to determine the winner of a two-player impartial game with the given rules.
- Key observation: The game ends once every index 1..N has been used at least once (i added to S). The total number of moves until termination depends on when the first 1 appears in the array.
- If there is no A_i equal to 1, the second player (Snuke) can always force the game to end on their move (except the trivial N=1 case handled separately).
- If there exists at least one A_i equal to 1, consider the leftmost position first1 where A[first1] == 1.
  - The parity of the remaining indices to the right, N - first1, determines who makes the final move.
  - If (N - first1) is even, Fennec wins; otherwise Snuke wins.
- Special case: N = 1 always results in Fennec winning on the single available move.
- Therefore the algorithm is:
  1) Read N and A.
  2) If N == 1, output Fennec.
  3) Find the smallest index first1 with A[first1] == 1. If none, output Snuke.
  4) If (N - first1) is even, output Fennec; else output Snuke.

### Code
```
import sys

def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    N = int(next(it))
    A = [int(next(it)) for _ in range(N)]

    # Special case
    if N == 1:
        print("Fennec")
        return

    # Find the first index with value 1 (1-based index)
    first1 = None
    for idx, val in enumerate(A, start=1):
        if val == 1:
            first1 = idx
            break

    if first1 is None:
        print("Snuke")
        return

    if (N - first1) % 2 == 0:
        print("Fennec")
    else:
        print("Snuke")

if __name__ == "__main__":
    solve()
```
