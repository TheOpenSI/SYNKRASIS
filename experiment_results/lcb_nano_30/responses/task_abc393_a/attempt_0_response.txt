### Step-by-step reasoning
- There are four oyster types: 1, 2, 3, 4. Exactly one of them causes sickness when eaten.
- Takahashi ate oysters {1, 2}; Aoki ate oysters {1, 3}.
- If the poisonous type is x, then Takahashi gets sick iff x is in {1, 2}, and Aoki gets sick iff x is in {1, 3}.
- Given S1 (Takahashi) and S2 (Aoki), determine x such that:
  - S1 == "sick" iff x in {1, 2}
  - S2 == "sick" iff x in {1, 3}
- A simple and robust approach: try x = 1..4 and pick the one that matches the given sick/fine statuses.
- Edge cases:
  - Input tokens may be separated by spaces or new lines; handle via splitting the input.
  - The problem guarantees exactly one valid x, so the loop should always find a solution.

### Requirements
None

### Code
```
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    S1, S2 = data[0], data[1]

    # Brute-force check for the poisonous oyster type
    for x in range(1, 5):  # types 1..4
        sick1 = x in (1, 2)  # Takahashi ate 1 and 2
        sick2 = x in (1, 3)  # Aoki ate 1 and 3
        if (S1 == "sick") == sick1 and (S2 == "sick") == sick2:
            print(x)
            return

if __name__ == "__main__":
    solve()
```
