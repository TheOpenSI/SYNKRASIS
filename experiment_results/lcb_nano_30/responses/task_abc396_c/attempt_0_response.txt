### Step-by-step reasoning
- We need to pick a subset of black balls and white balls such that the number of black balls is at least the number of white balls, maximizing the total value.
- If we decide to take exactly b blacks and w whites, the best choice is to take the top b black-valued balls (sorted in descending order) and the top w white-valued balls. So the maximum sum for given (b, w) is prefix_B[b] + prefix_W[w], where prefix_B and prefix_W are prefix sums of the sorted (desc) arrays.
- The constraint is b >= w. For each possible w (0..min(M, N)), we want the best possible b >= w. That is, max over b in [w..N] of prefix_B[b].
- Precompute best_from_w[w] = max_{b >= w} prefix_B[b]. Then the answer is max over w in [0..min(M, N)] of best_from_w[w] + prefix_W[w].
- This formulation also covers the option of choosing no balls: w=0, b=0 gives sum 0, and best_from_w[0] will be at least 0.
- Complexity: sorting dominates with O(N log N + M log M). Prefix and max scanning are O(N + M).

Edge cases:
- All values negative: best may be 0 by choosing no balls (achieved by w=0, b=0).
- M or N large; algorithm remains efficient with O(N log N + M log M).
- W’s positive values exceeding N: those configurations are not feasible due to b >= w; our bounds use w up to min(M, N).

None

### Code

import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        print(0)
        return
    it = iter(data)
    N = int(next(it))
    M = int(next(it))

    B = [int(next(it)) for _ in range(N)]
    W = [int(next(it)) for _ in range(M)]

    # Sort blacks and whites in descending order
    B.sort(reverse=True)
    W.sort(reverse=True)

    # Prefix sums
    prefix_B = [0] * (N + 1)
    for i in range(1, N + 1):
        prefix_B[i] = prefix_B[i - 1] + B[i - 1]

    prefix_W = [0] * (M + 1)
    for i in range(1, M + 1):
        prefix_W[i] = prefix_W[i - 1] + W[i - 1]

    # best_from[b_min] = max(prefix_B[b]) for all b >= b_min
    best_from = [0] * (N + 1)
    max_so_far = -10**30
    for b in range(N, -1, -1):
        if prefix_B[b] > max_so_far:
            max_so_far = prefix_B[b]
        best_from[b] = max_so_far

    # Evaluate answer for w in [0, min(M, N)]
    max_w = min(M, N)
    ans = 0  # choosing no balls is always an option

    for w in range(0, max_w + 1):
        val = best_from[w] + prefix_W[w]
        if val > ans:
            ans = val

    print(ans)

if __name__ == "__main__":
    main()
