### Step-by-step reasoning
- For two dice i and j, let counts_i[v] be how many faces of die i show value v, and Ki be the number of faces of die i. The probability that both dice show the same value v is (counts_i[v]/Ki) * (counts_j[v]/Kj). Summing over all possible values v gives the probability P(i, j) = sum_v counts_i[v] * counts_j[v] / (Ki * Kj).
- To maximize this probability, we need to evaluate P(i, j) for all pairs (i < j) and keep the maximum.
- A straightforward and efficient way is to compute the dot product dot(i, j) = sum_v counts_i[v] * counts_j[v], which is the numerator of P(i, j). Then P(i, j) = dot(i, j) / (Ki * Kj).
- To keep it efficient, for each pair we iterate over the smaller value-count map and look up counts in the other map, avoiding scanning all values of the larger die.
- Edge cases:
  - Duplicates on a die are handled by counting frequencies.
  - If two dice share no values, the dot product is 0, so the probability is 0.
  - Ki and Kj are at least 1, so Ki * Kj is never zero.
- Output is formatted with high precision to satisfy the error tolerance.

import sys

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        print("0.0")
        return

    it = iter(data)
    N = next(it)

    counts = []
    Ks = []

    for _ in range(N):
        Ki = next(it)
        Ks.append(Ki)
        d = {}
        for _ in range(Ki):
            v = next(it)
            d[v] = d.get(v, 0) + 1
        counts.append(d)

    max_prob = 0.0

    for i in range(N):
        di = counts[i]
        Ki = Ks[i]
        for j in range(i + 1, N):
            dj = counts[j]
            Kj = Ks[j]

            # Compute dot product efficiently by iterating over the smaller dict
            if len(di) < len(dj):
                dot = 0
                for v, c in di.items():
                    dot += c * dj.get(v, 0)
            else:
                dot = 0
                for v, c in dj.items():
                    dot += c * di.get(v, 0)

            prob = dot / (Ki * Kj)
            if prob > max_prob:
                max_prob = prob

    print("{:.15f}".format(max_prob))

if __name__ == "__main__":
    solve()
