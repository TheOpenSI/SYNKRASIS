### Step-by-step reasoning
- The problem guarantees there is exactly one N such that N! = X, with 2 ≤ X ≤ 3e18.
- Factorial grows quickly, and for X up to 3e18, N is at most 20 (since 20! ≈ 2.43e18 and 21! > 3e18).
- We can iteratively compute factorials starting from 1:
  - Initialize i = 1 and f = 1 (f will hold i!)
  - While f < X, increment i and multiply f by i
  - When the loop ends, f will be equal to X (as guaranteed). Output i.
- Edge cases: X = 2 yields N = 2; X = 6 yields N = 3, etc. The loop handles these naturally.

### Requirements
None

### Code
```
import sys

def main():
    data = sys.stdin.read().strip()
    if not data:
        return
    X = int(data)

    i = 1
    f = 1  # f = i!
    while f < X:
        i += 1
        f *= i
    # Given the problem guarantee, f should now be equal to X
    print(i)

if __name__ == "__main__":
    main()
```
