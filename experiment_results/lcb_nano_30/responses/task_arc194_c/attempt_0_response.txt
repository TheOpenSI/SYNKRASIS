### Step-by-step reasoning
- Let A be current bit vector and S = sum_k A_k * C_k. If we flip index i, A_i becomes 1 - A_i, and the new sum is S' = S + (1 - 2*A_i) * C_i. The operation costs S' (the sum after the flip).
  - If A_i = 0, flipping i increases S by C_i, so the cost is S + C_i.
  - If A_i = 1, flipping i decreases S by C_i, so the cost is S - C_i.
- Suppose we only flip indices where A_i != B_i exactly once (we must flip each differing bit an odd number of times, and flipping extra times generally adds nonnegative costs, so this single-flip plan is optimal).

Let D_i = A_i XOR B_i = 1 for indices we must flip, 0 otherwise. Let:
- Neg group: indices with A_i = 1 and D_i = 1 (flip from 1 to 0). For these, delta = -C_i.
- Pos group: indices with A_i = 0 and D_i = 1 (flip from 0 to 1). For these, delta = +C_i.
Initial sum S0 = sum_i A_i * C_i. Number of required flips d = |Neg| + |Pos|.

Total cost for an order of flips equals:
Total = d * S0 + sum over flips of delta_i * weight_i,
where weight_i is the number of remaining flips including this one, i.e., weight_i = d - (position in sequence) + 1.
To minimize that total, we should:
- Do all Neg flips before Pos flips (negative deltas should have larger weights).
- Within Neg, process by decreasing C_i (more negative delta first).
- Within Pos, process by increasing C_i (smaller positive delta first).

Algorithm:
1. Compute S0 and collect Neg_C = [C_i for i with A_i=1 and D_i=1], Pos_C = [C_i for i with A_i=0 and D_i=1].
2. Let d = len(Neg_C) + len(Pos_C). If d==0, answer is 0.
3. Sort Neg_C descending, Pos_C ascending.
4. Total = d * S0.
5. For j from 1 to len(Neg_C): Total += (-Neg_C[j-1]) * (d - j + 1).
6. Let base_weight = d - len(Neg_C). For t from 1 to len(Pos_C): Total += Pos_C[t-1] * (base_weight - t + 1).
7. Print Total.

Edge cases:
- If A already equals B, d = 0, answer is 0.
- Large N and C_i values handled by Python int (no overflow).

None

### Code
```
import sys

def main():
    data = sys.stdin.read().strip().split()
    it = iter(data)
    N = int(next(it))

    A = [int(next(it)) for _ in range(N)]
    B = [int(next(it)) for _ in range(N)]
    C = [int(next(it)) for _ in range(N)]

    S0 = 0
    neg = []
    pos = []
    d = 0

    for i in range(N):
        A_i = A[i]
        B_i = B[i]
        Ci = C[i]
        S0 += A_i * Ci
        Di = A_i ^ B_i
        if Di == 1:
            d += 1
            if A_i == 1:
                neg.append(Ci)  # delta = -Ci
            else:
                pos.append(Ci)  # delta = +Ci

    if d == 0:
        print(0)
        return

    neg.sort(reverse=True)  # decreasing Ci
    pos.sort()              # increasing Ci

    total = d * S0

    # Neg contributions
    for idx, ci in enumerate(neg, start=1):
        weight = d - idx + 1
        total += (-ci) * weight

    # Pos contributions
    base_weight = d - len(neg)
    for t, ci in enumerate(pos, start=1):
        weight = base_weight - t + 1
        total += ci * weight

    print(total)

if __name__ == "__main__":
    main()
```
