### Step-by-step reasoning
- Let B_i = (A_i + k) mod M for k = 0..M-1. We need the inversion count of B for each k.
- For k=0, compute inv0, the inversion count of A, using a Fenwick tree (BIT) over values 0..M-1.
- When we increase k by 1, the set W of indices i with B_i wrapping from M-1 to 0 consists exactly of indices with A_i = v, where v = M-1 - k (mod M).
- The change in inversion count from k to k+1 comes only from pairs (i<j) where exactly one of i or j is in W:
  - If i in W and j not in W, before the step B_i = M-1, B_j ≤ M-2, so there was an inversion; after wrap, B_i' = 0 ≤ B_j', so no inversion. These contribute -1 per such pair.
  - If i not in W and j in W, before step B_i ≤ M-2, B_j = M-1, so no inversion; after wrap, B_j' = 0 and B_i' ≥ 1, so inversion appears. These contribute +1 per such pair.
  - Pairs with both in W or both not in W do not change inversion status.
- Let W correspond to value v. For this v, define:
  - m = count of indices with A_i = v
  - sum_pos = sum of 1-based positions i where A_i = v
  - The two counts are:
    - C1(v) = number of pairs (i<j) with i∉W, j∈W
    - C2(v) = number of pairs (i<j) with i∈W, j∉W
  - One can derive:
    - C1(v) = sum_pos - m*(m+1)/2
    - C2(v) = m*N - sum_pos - m^2 + m*(m+1)/2
  - Therefore delta(v) = C1(v) - C2(v) = 2*sum_pos - m*N - m
- Then inv[k+1] = inv[k] + delta(v) with v = M-1 - k (for k = 0..M-2).
- We only need deltas for v = M-1, M-2, ..., 1; delta for v with m=0 is 0 anyway.
- Overall:
  - Compute inv0 via BIT on A.
  - Compute for each value v: m[v] and sum_pos[v].
  - Compute delta[v] = 2*sum_pos[v] - m[v]*N - m[v].
  - Build ans[0] = inv0; for k=0..M-2, ans[k+1] = ans[k] + delta[M-1 - k].
  - Print ans for k = 0..M-1.

Edge cases:
- Values not present in A yield delta[v] = 0.
- Large N, M up to 2e5; all arithmetic fits in Python int.
- A_i are guaranteed in [0, M-1].

### Requirements
None

### Code
```
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    N = data[0]
    M = data[1]
    A = data[2:2+N]

    # Fenwick Tree for initial inversion count (k = 0)
    size = M
    bit = [0] * (size + 1)

    def bit_add(idx, delta):
        i = idx + 1
        while i <= size:
            bit[i] += delta
            i += i & -i

    def bit_sum(idx):
        # sum of [0..idx]
        i = idx + 1
        s = 0
        while i > 0:
            s += bit[i]
            i -= i & -i
        return s

    inv0 = 0
    for i, val in enumerate(A):
        s = bit_sum(val)
        inv0 += i - s
        bit_add(val, 1)

    # Precompute m[v] and sum_pos[v]
    m = [0] * M
    sum_pos = [0] * M  # 1-based positions
    for idx, val in enumerate(A, start=1):
        m[val] += 1
        sum_pos[val] += idx

    # Compute delta[v] = 2*sum_pos[v] - m[v]*N - m[v]
    delta = [0] * M
    for v in range(M):
        if m[v] == 0:
            delta[v] = 0
        else:
            delta[v] = 2 * sum_pos[v] - m[v] * N - m[v]

    # Build answers for k = 0..M-1
    ans = [0] * M
    ans[0] = inv0
    for k in range(0, M - 1):
        v = M - 1 - k
        ans[k + 1] = ans[k] + delta[v]

    print("\n".join(map(str, ans)))

if __name__ == "__main__":
    main()
```
