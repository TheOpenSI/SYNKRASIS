Stage 2A - 10-Case Development Set
This pack contains the 10 Stage 1 calibration cases designated for initial Stage 2A development. For each Case ID, the optometry report is the source input and the corresponding OT reference document contains the final OT reference summary.
The optometry-report contents have not been edited during packaging; only the filenames have been standardised to the original Case IDs. The OT reference summaries have been reformatted as standalone Word documents for readability, without changing the summary wording.
The OT reference summaries are development references for comparison and refinement. They should not be concatenated with the optometry report when generating a model output.
